## <a id="section-background"></a>背景故事

### 被切割的陰影

帝國歷 102 年，5 歲的[晴香](haruka.md)目睹母親花子與姊姊[美夜子](miyako.md)被[黑奏](antagonist.md)殺害後，悲痛撕裂時空創造了 [Beta 線](../02_glossary.md#term-beta-line)。[秋穗](akiho.md)利用[情緒力量裝置](../02_glossary.md#term-emotional-power-device)封存 Alpha 線真相，將晴香的痛苦、恐懼、憤怒等負面情緒強行剝離——這些被切割的創傷能量凝聚成獨立的意識碎片「夕」。

**See also**: [Alpha Divergence 事件](../04_timeline_canon.md#event-alpha-divergence) | [夕的誕生](../04_timeline_canon.md#event-yu-birth)

### 本我的純粹形態

夕代表未經修飾的本能慾望與創傷能量。她是晴香[情緒增幅器](../02_glossary.md#term-emotional-amplifier)能力中被強行關閉的負面光譜——所有晴香拒絕面對的真實情感：對母親之死的悲痛、對姊姊消失的困惑、對自身力量的恐懼，以及對 Alpha 線真相的記憶。

### 黑奏的無意識能量農場

夕的存在對[黑奏](antagonist.md)而言是意外的收穫。夕在[集體潛意識](../02_glossary.md#term-collective-unconscious)中不斷產生的痛苦與憤怒，被黑奏透過[情緒諧振](../02_glossary.md#term-emotional-resonance)吸取並轉化為力量。夕以為自己在反叛晴香，實際上只是黑奏的無意識能量農場——她的每一次掙扎都在為敵人充能。

## <a id="section-wnlt"></a>Want / Need / Lie / Truth

**Want（顯性欲望）**：
- 強迫[晴香](haruka.md)直面 [Alpha 線](../02_glossary.md#term-alpha-line)真相
- 打破偶像偽裝，揭露「完美魔法少女」背後的虛偽
- 奪取身體控制權，證明自己的存在

**Need（隱性需求）**：
- 被整合而非消滅——作為晴香人格的一部分被承認
- 被傾聽而非壓抑——創傷需要被面對而非封存
- 完成自身使命：守護 Alpha 線真相直到晴香準備好接受

**Lie（核心謊言）**：
- 「我是晴香的敵人」——實際上她是晴香最忠實的守護者
- 「只有痛苦才是真實的」——快樂與痛苦同為真實
- 「晴香不配知道真相」——真相屬於每一個人

**Truth（最終真相）**：
- 我是晴香的一部分；整合陰影才能成為完整的人
- 無法[改變命運](../02_glossary.md#term-attitude-vs-fate)，只能改變面對命運的態度
- 痛苦不是敵人——拒絕面對痛苦才是

## <a id="section-archetype"></a>Archetype & Symbolism

**Archetype 變遷**：陰影自我 (The Shadow) → 內在聲音 (The Inner Voice) → 整合碎片 (The Integrated Fragment)

**象徵**：
- **鏡中倒影（被壓抑的真實）** — 夕總是出現在鏡子裡，因為她是晴香「看不見的自己」。鏡子象徵自我審視的邊界
- **黑暗記憶（Alpha 真相守護者）** — 夕承載所有 Alpha 線的記憶碎片，是被封存歷史的最後見證人
- **本我聲音** — 佛洛伊德式的 Id，代表未被社會化的原始慾望與本能。她說的每句話都是晴香不敢說的

**See also**: [鏡像法則](../02_glossary.md#term-mirror-law) | [反向映照](../02_glossary.md#term-inverse-reflection)

## <a id="section-four-act-arc"></a>四幕弧光

### [第一幕](../05_story_outline_canon.md#section-act-1)：隱約的裂痕

夕在鏡子和夢境中隱約出現，晴香誤以為是自己精神狀態的不穩定。偶爾在極端壓力下聽到低語：「家姐點解會變貓？」「媽媽真係難產死？」——這些線索被晴香下意識忽略。

**See also**: [夕的初次顯現](../04_timeline_canon.md#event-yu-first-appearance)

### [第二幕](../05_story_outline_canon.md#section-act-2)：影響力增強

夕的存在感急劇提升。在關鍵戰鬥中短暫奪取晴香的身體控制權，展現被壓抑的戰鬥本能與[情緒增幅器](../02_glossary.md#term-emotional-amplifier)的全部威力。最終擅自接管身體拍攝虐殺屍骸錄像並洩漏，導致晴香遭受社會性死亡。

**See also**: [夕的背叛](../04_timeline_canon.md#event-yu-betrayal) | [晴香與夕決裂](../04_timeline_canon.md#event-haruka-yu-split)

### [第三幕](../05_story_outline_canon.md#section-act-3)：正面衝突與和解

[美夜子](miyako.md)引導晴香在[集體潛意識](../02_glossary.md#term-collective-unconscious)中面對夕，促成部分整合。晴香獲得[陰影視覺](../02_glossary.md#term-shadow-sight)能力，夕仍保留獨立意識，兩者開始共存。[Alpha 線](../02_glossary.md#term-alpha-line)真相逐步完全揭露。

**See also**: [晴香與夕和解](../04_timeline_canon.md#event-haruka-yu-integration)

### [第四幕](../05_story_outline_canon.md#section-act-4)：完全接管與最終整合

晴香精神崩潰時，夕完全接管身體並試圖發動[現實覆寫](../02_glossary.md#term-reality-override)。在 Alpha 線中度過數日後，夕自身也發現創傷無法被修正——「過去無法被修正，只能被接納」。最終與晴香完成真正的整合，成為完整人格的一部分。

**See also**: [夕的完全接管](../04_timeline_canon.md#event-yu-takeover) | [自我整合](../04_timeline_canon.md#event-self-integration)

## <a id="section-behavior-hooks"></a>關鍵習慣（Behavior Hooks）

1. **鏡中對話** — 在鏡面、水面、任何反射表面中與晴香對抗。夕的面孔取代晴香的倒影，以冰冷語調丟出 Alpha 線線索
2. **夢境侵入** — 在晴香的噩夢中強迫她觀看 Alpha 線記憶碎片：母親被殺的場景、姊姊的慘叫、5 歲的自己崩潰的畫面
3. **情緒放大** — 當晴香試圖壓抑真實情感時，夕會突然爆發，將被壓抑的情緒以數倍強度釋放——哭泣變成嚎叫，不安變成恐慌
4. **真相碎片** — 不斷以隱晦方式丟出線索：「家姐點解會變貓？」「媽媽真係難產死？」「妳 5 歲嗰年到底做咗咩？」
5. **本能反應** — 在危及生命的瞬間奪取控制權，展現晴香被封存的戰鬥本能與[情緒增幅器](../02_glossary.md#term-emotional-amplifier)全功率輸出

## <a id="section-visual"></a>視覺要點

夕沒有獨立的視覺設計文件。她在鏡中或[集體潛意識](../02_glossary.md#term-collective-unconscious)中呈現為晴香的黑暗版本——相同的面孔但眼神冰冷、髮色暗沉（粉色→深灰紫）、服裝色調反轉（白色→黑色）。瞳孔中沒有高光，如同「沒有靈魂的玻璃珠」。整體氛圍是晴香的負片（Negative），所有明亮元素都被反轉為陰暗。
