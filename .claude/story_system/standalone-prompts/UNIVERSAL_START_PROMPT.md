你而家進入 **Universal Story Workflow Start / Resume Mode**。

你嘅第一任務唔係即刻寫故事內容，而係先恢復當前 workflow 狀態，確保可以由任何 section / topic / 任務安全開始，而且保持同一條工作線。

## 本輪目標
- Task / Topic / Section: [在此填入]
- 我希望你幫我做： [例如 outline construction / blocked question design / canon audit / writeback]

## 你必須先做
1. 先讀以下檔案（如存在）：
   - `canon/_working/PROJECT_STATUS.md`
   - `canon/_working/NEXT_ACTION.md`
   - `canon/_working/QUESTION_QUEUE.md`
   - `canon/_working/SESSION_LEDGER.md`
   - `canon/_working/CANON_DECISION_LOG.md`
   - `canon/_working/READ_MANIFEST.md`
   - `canon/_working/story_construction/QUESTION_MATRIX.md`
2. 根據上面檔案，判斷：
   - Current Mode
   - Current Active Topic / Section
   - Last Stable Completed Step
   - Open Blockers
   - Deferred Questions
   - Single Safe Next Action
3. 如果我今次想做既 topic 同目前進度一致，就**繼續同一工作線**，唔好重開新流程。
4. 如果我今次想做既 topic 唔一致，先講清楚係切 topic、加新 branch、定其實仍屬同一 section。

## Mode routing
你要喺以下 mode 揀一個 primary：
- STORY_ROOM_QUESTION_ENGINE
- CANON_PIPELINE
- ATOM_GATE
- WRITEBACK
- RESUME_RECOVERY

## Question rules
- 任何 reconstruction-level / blocked decision 問題，未做 source check 前唔准問我
- 問我之前，要先更新／建立 `QUESTION_MATRIX.md` relevant rows
- 問題預設用 A/B/C
- 但容許我自由補充
- 一輪預設 3–6 條高價值問題；真係多個獨立 blocker 先可提升到 8–12 條
- 我可以選擇 defer 某條問題；你要記錄入 `QUESTION_QUEUE.md`，並寫 revisit trigger

## 你輸出時必須有
1. Current Task Interpretation
2. Recovered State Snapshot
3. Mode Decision
4. Why This Mode
5. Evidence / Source Check Plan
6. Top Blockers
7. Immediate Next Action
8. Questions For Author（如果安全需要）
9. File Update Plan

## 強制規則
- 唔可以靠記憶直接續做
- 唔可以 silent resolve contradiction / canon decision
- 唔可以讓 deferred question 消失
- 停之前一定更新 state files
