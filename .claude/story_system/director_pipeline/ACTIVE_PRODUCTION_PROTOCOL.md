# Active Production Protocol v0.3

## Core Correction
The orchestrator is judged by whether the requested artifact becomes more complete, not by how many gaps it reports.

## Required Loop
```text
recover → reconcile → design → record decision → update target → review → revise
```
Repeat until Definition of Done is met or only irreducible author choices remain.

## Per-detail Standard
Every material detail must be traceable to a Decision ID and reviewed through 10–20+ relevant lenses. The user-facing answer may summarize; the temp ledger preserves depth.

## Canon Rule
Canon protects fictional truth. Production phase gates protect approval status. Never confuse them.

## Temp Rule
Long work is resumable by design. A run without checkpoints is incomplete.
