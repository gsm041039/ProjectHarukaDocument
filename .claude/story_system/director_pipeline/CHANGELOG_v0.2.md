# v0.2 — Adaptive Production Workflow

## Added
- Story work readiness and prerequisite diagnosis.
- Automatic upstream work discovery and downstream opportunity planning.
- 28-angle scalable production matrix.
- Dedicated character context, arc, psychology, knowledge, relationship, voice, scene objective and dialogue architecture skills.
- Dedicated gameplay dialogue integration and dialogue readiness gate.
- Completion-level labels from exploratory to implementation-ready.
- Artifact invalidation rule after upstream changes.
- Cantonese user guide and test prompts.

## Changed
- `/story-orchestrator` is now a production director, not only a router.
- Complete dialogue can no longer jump directly from scene summary to prose script.
- `story-dialogue-script` requires readiness verdict and upstream contracts.
- `story-dialogue-room` now supports a 24-angle post-draft review.

## Compatibility
Existing skills remain. Old direct skill invocation still works, but `/story-orchestrator` is the recommended entry point.
