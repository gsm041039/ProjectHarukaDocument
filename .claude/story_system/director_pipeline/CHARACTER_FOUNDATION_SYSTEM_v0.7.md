# Character Foundation System v0.7

## 核心原則
唔為每個角度複製一份互相重疊嘅 Bible。底層係一套共享角色核心資料；不同 skill 按用途建立人類易讀視圖。

## 三層資料
1. 角色全劇通用核心：說話、表演、決定、情緒、價值、注意力、危機、關係、知識、記憶。
2. 故事／遊戲動態狀態：目前知道、記得、信任、受傷、任務、玩家行為、對白播放狀態。
3. 場景用途視圖：今場說話、表演、資訊表達、runtime variants。

## 來源改動
所有通用文件記錄主要依據。來源變動時由 change impact manager 分析，foundation updater 更新，再由 downstream auditor 檢查舊內容。

## 升級規則
場景發現預設只係候選；跨場景重複、有 canon 支持並經作者確認後，先可升級成通用規則。
