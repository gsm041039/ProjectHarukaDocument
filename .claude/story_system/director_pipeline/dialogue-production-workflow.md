# Dialogue Production Workflow

## Scalable Workflow

### Stage 0 — Request and Readiness
- `story-work-readiness-diagnostician`
- source recovery
- scale classification: low / standard / major

### Stage 1 — Narrative and Character Recovery
- `story-character-context-recovery`
- `story-character-arc-positioner`
- `story-scene-objective-architect`
- `story-knowledge-state-mapper`

### Stage 2 — Psychology and Relationship
- `story-scene-psychology-mapper`
- `story-relationship-dynamics`

### Stage 3 — Voice and Architecture
- `story-character-voice-designer`
- `story-dialogue-architect`
- `story-performance-director`

### Stage 4 — Gameplay Delivery
- `story-gameplay-dialogue-integrator`
- other combat / cinematic specialists as needed

### Stage 5 — Gate and Draft
- `story-dialogue-readiness-gate`
- `story-dialogue-script`

### Stage 6 — Review and Testing
- `story-dialogue-room`
- `story-coverage-table-read`
- `story-directing-language-auditor`
- `story-grounding-auditor`

### Stage 7 — Implementation / Delivery
- `story-director-delivery-builder`
- Unity JSON projection only after stable IDs and implementation-ready verdict

### Stage 8 — Next Work
- `story-downstream-opportunity-planner`

## Adaptive Rule
Orchestrator may reuse approved artifacts and skip stages whose contracts already exist and remain valid. Any upstream change invalidating a contract must be declared before downstream reuse.
