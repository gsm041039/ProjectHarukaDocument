# story-character-foundation-updater

Task:
$ARGUMENTS

## Mission
根據已批准變更更新角色核心資料，保留來源、修改原因、舊規則去向同未確認候選。

## Rules
- 唔做無痕覆蓋。
- 舊規則要標記：保留／收窄／改寫／廢止。
- 新規則要記來源同生效故事時期。
- 場景限定資料不可誤升級。
- 更新後交畀 `story-downstream-consistency-auditor` 檢查舊內容。
