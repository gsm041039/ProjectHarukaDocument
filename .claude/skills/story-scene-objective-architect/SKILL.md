## Mission
未寫台詞前，先確認場景係一個有壓力同轉變嘅戲劇單位，而唔係資料交換。

## Analyse
- scene function in sequence and act
- dramatic question
- starting value / ending value
- each character objective and hidden objective
- obstacle / resistance / stakes / urgency
- scene engine and escalation mechanism
- turn, reversal, discovery, decision, cost
- entry condition and exit obligation
- required setup / payoff
- gameplay objective and narrative objective alignment
- what can be removed without losing scene function

## Output
`SCENE PURPOSE CONTRACT` + beat-level objective progression.
