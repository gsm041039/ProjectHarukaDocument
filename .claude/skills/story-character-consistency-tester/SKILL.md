# story-character-consistency-tester

Task:
$ARGUMENTS

## Mission
用不同情境測試角色仍然似唔似同一個人，而唔係只審當前劇本。

## Test Sets
- 道歉、求救、講大話、被揭穿、被羞辱、安慰、發怒
- 公開、私人、獨處、戰鬥、疲勞、受傷、崩潰
- 對最信任、最防備、權威、陌生人、敵人
- 角色知道／不知道／誤解資訊嘅版本
- 對白被中斷、重試、事件次序改變

找出：
- 所有人講法／動作太相似
- 後期成長提前
- 角色知道作者先知嘅事
- 招牌動作過度重複
- gameplay 資訊令角色變成 UI
