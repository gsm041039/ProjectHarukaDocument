# story-character-foundation-planner

Task:
$ARGUMENTS

## Mission
唔再等作者逐份文件提醒。收到場景／劇本目標後，主動判斷角色方面仲需要先知道啲咩，並只啟動真正會影響今次成果嘅工作。

## Foundation Areas
檢查：
1. 說話方式
2. 反應、動作與表演方式
3. 思考、決定與行動優先次序
4. 情緒形成、遮掩與恢復
5. 價值、底線與自我矛盾
6. 注意力與感知方式
7. 危機與戰鬥行為
8. 知道、相信、誤解與秘密
9. 記憶與重新理解
10. 關係、信任、依賴與權力
11. 玩家／任務造成嘅動態狀態
12. 角色可以自然承擔幾多 gameplay 資訊

## Status Classes
每一項標記為：
- 足夠，可直接用
- 已有但太窄，只屬某場戲
- 已有但可能過時
- 可由 canon 自動整理
- 需要提出候選同作者細執
- 今次唔需要

## Priority Rule
只推薦會實質改變今次交付嘅前置。
分成：
- 必須先做
- 建議先做
- 可以邊寫邊補
- 今次不做

## User-facing Output
正文用簡單廣東話講：
- 已經有咩
- 仲欠咩
- 點解會影響成品
- 建議先做邊幾項
- 問作者係咪開始自動做第一版再細執

Mini Log 必須顯示本 skill 同後續真正調用嘅 skills。
