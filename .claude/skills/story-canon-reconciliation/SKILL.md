# story-canon-reconciliation — Integrate Before Rejecting

Task:
$ARGUMENTS

## Classification
- `CANON_COMPATIBLE_ELABORATION`
- `CANON_REINTERPRETATION_CANDIDATE`
- `CANON_CHANGE_PROPOSAL`
- `HARD_CONTRADICTION`
- `INSUFFICIENT_EVIDENCE`

## Required Behaviour
1. Quote/summarize exact authoritative facts.
2. Separate fixed outcome from unspecified execution details.
3. Try compatibility construction first.
4. If conflict exists, build 2–3 reconciliation candidates with impact radius.
5. Recommend one provisional route and continue production.

Never use project sequencing rules as evidence that a scene idea is non-canon. Sequencing affects approval status, not fictional truth.
