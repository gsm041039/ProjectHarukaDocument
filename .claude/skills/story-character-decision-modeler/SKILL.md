# story-character-decision-modeler

Task:
$ARGUMENTS

## Mission
回答：角色點解會揀呢個行動，而唔係另一個？

## Required Output
使用：
`story_system/director_pipeline/templates/character_decision_priority_template.md`

包括：
- 第一時間會注意到咩、忽略咩
- 正常情況行動優先次序
- 危機／戰鬥行動優先次序
- 資訊不足時點估
- 幾時衝動、幾時保守
- 點樣將私人感情包裝成合理理由
- 點樣為錯誤決定辯護
- 邊條底線一觸碰就行動
- 幾時改變主意
- 故事不同時期排序點改變
- 對不同人物會唔會破例

每項要有 canon 證據、推導或候選標記。
