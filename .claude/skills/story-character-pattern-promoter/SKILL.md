# story-character-pattern-promoter

Task:
$ARGUMENTS

## Mission
將場景新發現保留為候選，跨場景重複後先提出升級建議。

## Promotion Gate
只有以下條件先可建議升級：
- 至少兩個獨立場景支持，或有正式人物設定直接支持
- 冇重大反例
- 清楚知道適用時期、關係與狀態
- 作者確認

輸出要講：
- 重複模式係咩
- 出現喺邊啲不同情境
- 應升級成全局、時期、關係定狀態規則
- 有咩風險
