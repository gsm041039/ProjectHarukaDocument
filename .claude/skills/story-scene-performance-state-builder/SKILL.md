# story-scene-performance-state-builder

Task:
$ARGUMENTS

## Mission
建立今場戲角色實際點演。只處理場景臨時狀態，唔改寫全劇通用 Performance Bible。

## Inputs
- 觀眾／玩家感受目標
- 角色通用 Performance Bible
- 角色當前記憶、關係、身體、情緒、危機狀態
- 場景範圍、場所、戰鬥與玩家控制

## Required Output
使用：
`story_system/director_pipeline/templates/scene_performance_state_template.md`

包括：
- 場頭身體基線
- 第一次刺激反應
- 壓力升級
- 轉折動作
- 場尾殘留
- 對場內每個人物嘅距離與接觸
- 邊啲台詞應由動作／沉默代替
- gameplay 中可見嘅短反應
- scripted 演出中可用嘅完整反應
- 今場禁止重複嘅招牌動作
- 新發現只標記為場景候選
