## Goal
- 恢復 last confirmed state

- 找出 blockers / deferred questions

- 幫換電腦／新 session 保持 continuity

## Required output
1. RECOVERED STATE
2. CONSISTENCY CHECK
3. ACTIVE TOPIC / SECTION
4. BLOCKING QUESTIONS REMAINING
5. DEFERRED QUESTIONS TO REVISIT
6. SAFE NEXT ACTION

8. LEDGER UPDATE SUMMARY（如 recovery 改變咗理解）
