1. 1. 被迫入局 :: 晴香只是普通學生，意外看見魔法少女戰鬥後，被美夜子交出變身裝置，正式被拖入不能回頭的世界。
2. 2. 四人組隊 :: 晴香、紫音、操、彩不是自然成為朋友，而是因屍骸危機與魔法少女制度，被迫組成互相依賴的小隊。
3. 3. 連結污染 :: 她們戰鬥時要共享情緒力量；代價是彼此會看見對方最深的創傷，靈魂邊界開始變得模糊。
4. 4. 日常裂開 :: 戰鬥後遺症開始入侵校園生活：手震、嘔吐、幻覺，令「平凡日常」慢慢變得不可信。
5. 4.5 家長日作戰 :: 朔洩密軍方高層會到小光讀嘅學校，隊伍策劃「家長日」潛入蒐集情報——紫音扮家姐、操扮媽媽，一整日難得嘅正常家庭幻象。晴香貪心想多留一陣而拖長行動，善意間接令紫音錯過補給時機。
6. 5. 紫音墮落 :: 拖長嘅家長日換嚟代價：紫音戒斷惡化下發現小光已死並變成屍骸，她無法再相信人類世界，轉而把屍骸當成需要保護的孩子。
7. 6. 秋穗暗線 :: 秋穗表面是可靠技術支援，暗中卻為救女兒愛莉，開始與刑思交易，埋下背叛伏線。
8. 7. 膠布哲學第一層 :: 晴香以全城最知名的偶像身份覆蓋情緒空洞——掌聲替代真實連結，舞台光芒填滿缺失的安全感。傷口不是不存在，只是貼了一塊叫「完美形象」的膠布。這是全四幕膠布哲學的第一層。
9. 8. 膠布哲學第二層 :: 紫音第一次正面撕開晴香的偶像形象——不是攻擊，而是拒絕讓她繼續用完美表演覆蓋傷口：「妳以為貼住張貼紙，個傷口就會好？」這是系統批判，也是第二層膠布：用他人的直接衝擊去揭露自己的迴避。
10. 9. 菲鏡中整合 :: 晴香首次在鏡中感知到菲的存在——同一具身體，兩種截然不同的自我。這是 Alpha 線與 Beta 線真相開始向內滲透的最早訊號，雖然晴香尚未明白其意義。
11. 1. 打怪無效 :: 隊伍雖然不斷消滅屍骸，但城市的痛苦沒有減少；每場勝利都只是把問題推遲到下一次爆發。
12. 2. 操調停失敗 :: 操獨自找到紫音棲身的廢棄糖果工廠，嘗試調停；紫音當機沒有回應，操受傷、被咬牙壓抑，將沉默扭曲解讀為「不當她是朋友」，觸發自己「不配被愛」的核心恐懼，這是她 Act II 第一個正式心理轉捩點。晴香隨後趕到，三種立場正面交鋒，最終親口將紫音放逐。
13. 2.2 夕鏡前攤牌 :: 放逐紫音當晚，夕喺鏡中現身，控訴晴香一直為彩補漏、為紫音送糖，卻從未真正接住自己——「跟住呢？」呼應Act I幕末晴香許下但一直冇兌現嘅承諾，「淨係一次得唔得？」講出咗積壓已久嘅落差。晴香轉身走開，唔係單純攰，而係承受唔到同一晚兩次結構相同嘅真相。呢場戲係E-09直播失控嘅心理引信，同飢渴嘅生理機制各自獨立。
14. 2.5 紫音稱王 :: 被放逐後，紫音正式以廢棄糖果工廠為根據地自稱女皇；她不是想毀滅世界，而是想保護被世界拋棄的怪物。
15. 2.7 幻象破滅 :: 廢棄糖果工廠冇人類獵物，飢餓嘅屍骸群無法再被供養，開始外流入城市。紫音沒有阻止，只是以扭曲母性嘅姿態跟住屍骸群一齊沖向城市——她自以為建立咗一個「冇傷害」嘅樂園，此刻幻滅。呢次外流事件成為帝國衛生行動嘅具體治安藉口。
16. 3. 菲直播失控 :: 在公開直播中，晴香體內的陰影人格菲完全接管身體，第一個動作是伸手觸碰美夜子臉上的血跡——壓抑十一年、想見「媽媽」同「以前會對住自己笑嘅家姐」嘅私心流露。菲清醒咁知道毀滅一樣係逃避，但仍然選擇為晴香揹起呢個罪名；吸走觀眾情緒後，全城第一次看見「天使」濾鏡下的恐怖真相。
17. 4. 天使變公敵 :: 直播片段無法刪除，晴香由被崇拜的國民天使，瞬間變成人人恐懼的情緒吸血鬼。
18. 5. 帝國清算 :: 帝國把失控影像當成證據，推動反魔法少女輿論，將晴香塑造成必須被清除的社會威脅。
19. 6. 形象商品化 :: 晴香的經理人沒有保護她，反而把她的怪物形象包裝成上癮商品，連她的崩潰都被拿去賺錢。
20. 7. 父親出賣・紗夜犧牲 :: 操的父親以「廢品可以重造」親手把她出賣給帝國；管理局同步武裝突襲大宅。管家紗夜擋槍犧牲，說了什麼——但創傷性耳鳴遮蔽了一切，操只看到口型，聽不到聲音。
21. 8. 秋穗毒品擴散 :: 秋穗為了換回女兒愛莉，繼續研究Emo-Visor；帝國利用這種毒品，把全城痛苦變成可管理的資源。
22. 9. 愛莉地底抵消 :: 愛莉雖然被困成石像，仍在精神世界中替母親收拾後果，像紙皮騎士一樣默默斬斷毒品侵蝕。
23. 10. 愛莉風暴爆發 :: 帝國衛生行動引發群體恐慌，成為壓垮愛莉的最後一根稻草；潛意識盾牌碎裂，主角團被迫進入超現實集體潛意識戰場。晴香第一次在黑暗深處看見那個只是想讓媽媽多看自己一眼的寂寞小女孩。
24. 1. 彩/刑思同體 :: 晴香以為身邊的葉語彩只是同班同學，真相卻是她與暴君刑思共用同一個身體，親近感變成威脅。
25. 2. 共痛計劃 :: 刑思提出把全人類神經連起來：任何人傷害別人，自己也會同樣痛，表面上是終結暴力。
26. 3. 自由被取消 :: 共痛計劃真正可怕之處，是它用「不再有人受傷」做理由，剝奪所有人的隱私、選擇與自我邊界。
27. 4. 秋穗交出弱點 :: 刑思要求秋穗交出晴香的能力資料與弱點；秋穗必須在保護晴香與拯救愛莉之間作選擇。
28. 5. 母親墜落 :: 秋穗最後選擇出賣晴香，因為她相信只要能救回愛莉，其他人的代價都可以被犧牲。
29. 1. 回到學校 :: 帝國策劃校園恐懼事件，強迫主角群在死亡威脅下繼續扮演普通同學，令安全的校園變成心理刑場。
30. 2. 恐怖扮家家 :: 長達兩週，越普通的場景越顯得不正常；魔法代價悄悄升級，隊員的身體開始計息，晨間意識斷層從兩秒拉長至半分鐘。
31. 3. 操人偶牆 :: 操被敵人的空間封鎖機制逼入死角，冷靜地用魔法絲線將自己縫入廢墟成為「人偶牆」——她揀嘅係企位守住通道，計算入面本身有生還機率，唔係求死。真正嘅死因係佢一貫嘅形式主義coping令佢對自己心之器剩餘量嘅估算系統性偏高，連自己都呃埋，性格本身就係死因。臨終前她說：「我選擇停留在我想停留的位置。」——這不是被迫，而是主動為自己的生命選擇了意義。
32. 4. 紫音自爆 :: 紫音在帝國廣場主動過載，以生命為代價為隊友擋住災難擴散。
33. 6. 廣場決戰 :: 決戰發生在全城都看得到的維多利亞廣場；晴香不只是跟刑思打，還要在所有市民面前接受審判。
34. 7. 刑思三重攻擊 :: 刑思如審判般由外向內逐層剝除晴香的自我防衛，一場攻擊、三個層次：①商品化——晴香的痛苦與崩潰早被消費，從未有人把她當人；②身份背叛——菲直播失控並非意外，是晴香親手創造的同伴用她的身體傷害了最想保護的人；③晨間斷層——每天早晨身邊所有人的大腦都短暫接觸 Alpha 線真實痛苦，她的「愛」才是最殘忍的酷刑。最後刑思拿出最深層的底牌——鐵絲網偶遇：帝歷102年五歲的晴香曾隔著鐵絲網目睹彩被守衛拖走，那刻許下的善意願望，正正是三年後創世能量精準賦予刑思力量的因果信標。
35. 8. 五歲創世 :: 五歲的晴香無法接受親人死亡，情緒失控時把現實重寫成 Beta 世界，令魔法、屍骸和帝國制度一併誕生。
36. 9. 英雄反轉 :: 晴香一直以為自己在拯救世界，但真相是：她想逃避的那一刻，正是這個地獄世界的起點。
37. 10. 緋潮重定義 :: 即將吞噬城市的紅色洪流，不只是天災，而是被晴香那次奇蹟抹走的人與痛苦，回來要求世界償還。
38. 0.5 凜介錯（Day 14 夜，早於下面嘅崩潰） :: 凜拒絕被治癒，選擇切除情感成為殺戮機器；美夜子親手為她執行介錯。呢場戲發生喺 Day 14 深夜、解放之戰同廣場決戰之前，同美夜子貓殼碎裂同一晚，先於下面「晴香崩潰」以後嘅事件。
39. 1. 晴香崩潰 :: 晴香得知自己是整場災難的起源後，精神徹底崩潰。
40. 2. 菲奪身重置 :: 菲強行奪取晴香身體，改寫現實進入一條新時間線（類 Alpha 線）。她在那裡發現即使死者復活，內心的空洞仍然存在；嘗試改回 Beta 線時，卻造出另一條全新時間線——被破壞的現實無法還原，留下永恆裂痕。
41. 3. 主觀二十年 :: 菲的改變現實失敗後，晴香意識被拉入集體潛意識最深處 L3 冥河，以加害者視角逐一親身經歷各個受害者最痛的時刻——已死隊友嘅死亡場景在扭曲時間中反覆重播，每次都給她一個「呢次可以救到」嘅假機會，一次又一次以全新方式失敗，直接攻擊她核心的拯救者情結；主觀上經歷漫長的二十年，菲以晴香的肉體維持身體機能，客觀上只過了數日。
42. 1. 二十年後醒來 :: 逐一經歷完各個受害者最痛的時刻後，晴香停止掙扎，主觀二十年終於過去，她清醒咁選擇醒來，同時取回這段時間發生過的殘酷記憶，不能再假裝不知道。
43. 2. 拒絕再修正 :: 她終於明白，靠力量修正世界只是在逃避痛苦；真正要做的是停止繼續製造代價。
44. 2.5 膠布哲學第四層 :: 晴香最終的承擔，不是「貼上最後一塊膠布」，而是承認這塊傷口根本不能靠膠布癒合——然後清醒地選擇用自己的存在去承接它。四幕膠布哲學的收束：不再遮蓋，不再逃避，而是直面代價本身。
45. 3. 愛莉現身 :: 晴香醒來後，愛莉以聖女騎士形態正式現身——她在晴香沉睡的二十年間一直守護著靈魂空間，如今走出來面對最後的戰局。
46. 4. 不同態度 :: 愛莉以自身為證：同樣的創傷，可以選擇不同的面對方式——這是點燃晴香最後希望的火種，也是愛莉走向對決的起點。
47. 5. 愛莉對彩 :: 愛莉與葉語彩正面交鋒——兩個同樣被創傷塑造的靈魂，用各自選擇的態度對撞。
48. 6. 彩填補裂縫 :: 刑思的保護者人格因自身意義耗盡而退場，原本被壓抑的彩重新浮現——她選擇主動承受螺旋痛苦，填補世界裂縫，讓晴香有機會走向最後的承擔。（刑思從未消滅彩，只是長期壓制她；彩一直都在。）
49. 7. 三位一體永恆守護者 :: 世界要求晴香償還奇蹟的代價，她主動選擇與集體潛意識源頭融合，意識清醒地成為永恆情緒濾網，溫柔守護仍然存在的魔法屍骸。
50. 8. 魔法系統終結 :: 晴香的承擔終止了魔法少女、屍骸與Emo-Visor的生產管線，剝削人的魔法系統停止運作。
51. 9. 普通地活下去 :: 倖存者失去魔法，回到沒有奇蹟的現實；他們只能靠彼此連繫與自己的態度，繼續普通地活下去。美夜子經歷一段記憶迷霧期、尋回自己之後回歸凡人，在有限的人生裡保持與晴香的連結，直至80歲自然終老。
52. 10. 美夜子笨拙演奏 :: 記憶迷霧期過去、尋回自己之後的某一天，美夜子以人類雙手重新撿起吉他——琴弦陌生，手指不再像記憶中那樣靈活。她演奏得一塌糊塗，但她沒有停止。這是全篇最後一個鏡頭：不是奇蹟，不是完美，而是一個普通人選擇繼續的姿態。
