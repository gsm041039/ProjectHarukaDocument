BATCH 5 — ULTRA-SHORT OPERATION PROMPTS

Purpose
- This batch provides compressed activation prompts for daily use.
- Use these when you do NOT want to upload the full prompt library every time.
- These short prompts assume the AI has already been given, or is currently following:
  - Operating Constitution
  - Ledger / checkpoint rules
  - Story Room / Canon pipeline rules
  - Author-first decision gate

Important
- These are NOT replacements for the full system files on first setup.
- Best use case:
  1) The project has already been initialized.
  2) Ledger / manifest / register files already exist.
  3) You want to quickly enter a working mode.

Contents
- SHORT_MODE_CHEATSHEET.txt
- SHORT_ACTIVATE_STORY_ROOM.txt
- SHORT_ACTIVATE_CANON_PIPELINE.txt
- SHORT_ACTIVATE_RESUME.txt
- SHORT_ACTIVATE_WRITEBACK.txt
- SHORT_ACTIVATE_ATOM_GATE.txt

Recommended usage
- New discussion / outline / scene development -> SHORT_ACTIVATE_STORY_ROOM
- Register docs / section docs / start canon intake -> SHORT_ACTIVATE_CANON_PIPELINE
- Resume after interruption / compression -> SHORT_ACTIVATE_RESUME
- Write approved decisions back into canon -> SHORT_ACTIVATE_WRITEBACK
- Force author-gated review for atom / conflict / duplicate -> SHORT_ACTIVATE_ATOM_GATE
