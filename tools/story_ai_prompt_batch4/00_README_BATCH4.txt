BATCH 4 — PRACTICAL ACTIVATION PHASE

Purpose:
This batch provides real-world activation prompts so the assistant can be started in the correct mode without you manually restating the workflow every time.

Use this batch AFTER Batch 1, Batch 2, and Batch 3 have already been uploaded/read by the target AI.

Files:
1) ACTIVATE_NEW_PROJECT.txt
   - Use when starting a fresh project / fresh story workspace.

2) ACTIVATE_STORY_ROOM_SESSION.txt
   - Use for day-to-day creative discussion, outline refinement, structure diagnosis, theme, pacing, atmosphere, character arc review.

3) ACTIVATE_CANON_PIPELINE_SESSION.txt
   - Use when you want the AI to process documents through intake/register/sectioning/candidate atoms/author gate.

4) ACTIVATE_RESUME_EXISTING_PROJECT.txt
   - Use when continuing an older project or when a long session got compressed/interrupted.

5) ACTIVATE_WRITEBACK_SESSION.txt
   - Use only after author decisions are already recorded and you want the AI to write back to canon and run QA.

Global reminder:
- The AI must still obey P1 Operating Constitution.
- If there is any contradiction, duplicate decision, canon upgrade, scope ambiguity, or ownership ambiguity, the AI must ask the author first.
- The AI must use ledger files and keep them updated.
