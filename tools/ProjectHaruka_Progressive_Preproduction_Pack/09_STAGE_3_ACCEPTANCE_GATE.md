- [ ] Character foundation responsibilities have explicit existing owners.
- [ ] Directing grammar owner is clear.
- [ ] Gameplay-story integration owner is clear.
- [ ] Codex can create/resume a temp run without relying on conversation memory.
- [ ] Codex can eventually hand off Beat/Sequence work into Scene work.
- [ ] Any newly added skill is a justified PORT of existing capability or has strong missing-owner proof.
- [ ] No duplicate Director Bible/Profile was created without need.
- [ ] No duplicate character truth system was created.
- [ ] Foundation readiness is "on demand"; Stage does not waste time fully writing every future scene asset.
