# v10.1｜Whole-Character First — 階段切換與出圖行為

## 最核心區分

- **逐部件掃描**係「分析嘅覆蓋範圍」：可以一次喺內部做完 9 類檢查，避免漏咗帽後髮帶、鞋襪等。
- **逐部件設計**係「候選已選定後嘅精修技術」：唔可以因為分析順序係頭→身→裙，就要求作者每個部件逐項揀，再開始全身方案。
- **全身探索**應先於細化。結構／配色／穿法之間互相定義優劣，例如帽型可能只有搭配另一件外套先成立。

## Phase 2 必須係真正完整設計方案

一個合格概念至少有：

`Character appeal + occasion → Whole-body visual thesis → Hair/head + upper + lower + footwear + accessories + palette + proportion relationship → expected appeal & price paid`

例如（完全虛構，不得當成某位已知角色的既定解法）：

- A/AMPLIFY：保留現有大衣與長下裝嘅放鬆感，重新安排上淺下深同外套長度，令角色嘅穩重更突出；改頭飾位置要係因為衣領輪廓已經變。
- B/REIMAGINE：以「想隱藏身份但自然有舞台氣質」為命題，嘗試另一種頭帽、外套穿法與短下裝互相搭配，主色塊從外面轉移到內層；分析由頭至腳嘅效果。

唔合格例子：A『袖子再大啲』、B『換漁夫帽』——呢兩個只係部件提案，除非佢哋被重新整合成全身主張。

## 生成探索圖前嘅精簡承諾

只需顯示：

1. 同一位角色、同一時期、同一服裝用途、同一目標魅力。
2. 候選 A / B 各自一句全身命題與 2–4 個互相支持嘅改動；包括頭、身、下裝、鞋同色塊。冇改嘅講明 KEEP。
3. 對原版可能損失乜、最易令角色變普通嘅風險。
4. 畫面要求同一基準站姿、相近鏡頭、相近完成度；不以 pose 或表情假裝設計提升。

**允許直接 image generation**；探索圖係用嚟判斷視覺解法，唔係已認可嘅正式 design proof。作者要求單張先測試都得，唔強制一次過多張。

## 全身候選比較

嚴禁將「畫得更漂亮」當成「角色設計更好」。每案最少自問：

- 係邊個可見關係（而非描述文字）提高角色專屬魅力？
- 同一比例、同一姿勢，第一眼焦點同色塊節奏有冇比原版改善？
- 是否真係符合人物行為、社會背景、服裝用途？
- 有冇抹走原版仍然有價值嘅獨特細節？
- 正側背可以做得到、角色動作動畫可以長期重複畫嗎？
- 仍不足但有潛力時：`DEVELOP`；唔可以強逼通過。

## v10.2 焦點先於配色

當全身候選已選定、而作者想加強配色或吸引力，先依 [`focal_hierarchy_v102.md`](focal_hierarchy_v102.md) 決定第一／第二視覺焦點與對比位置，**唔好先直接開幾個任意色彩比例方案**；研究局部高對比同無新增高彩度兩種機制，保護作者認可嘅服裝結構。

## 局部精修起點

必須先有選過嘅 **whole-character concept**，先針對該概念最弱部件試獨立變量。局部意見係 `PART_ONLY`，唔自動代表整套批准。全身遠讀仍應保持可比較；如果局部調整破壞整體概念就返回整體探索。

## 兩道不同門檻

- **探索圖門檻**：已知 Brief、已理解原版、已有完整角色視覺假設、生成用途標明 `EXPLORATORY`；唔需要前置 SVG 或正背三視圖，唔需要 production preflight json。
- **定稿門檻**：整體方案被選中 + 作者確認 + 正背做法可交代 + 說清楚原稿優點及代價 + Production precommit / 技術審查；先出正式 settei。

## 不能包裝成保證

程式可以阻止文件或流程跳關，**不能鑑定主角魅力、商業水準或角色識別**。真實品質由作者評價、同條件圖像比較及必要觀眾測試補足。
