# v10.0｜Creative Synthesis — AMPLIFY × REIMAGINE

**適用範圍**：任何角色、任何服裝；唔係固定要簡潔或華麗。決策喺正式出圖前執行，保留作者已同意嘅 Art Direction、身份限制及目標 Anime Production Detail。案例只支持方法有效性嘅候選假設，唔係審美定律。

## 第 1 步｜睇原稿究竟已經表達乜，而非硬搵錯

先寫一句原版角色 hook（例如「輕快自在」、「冷峻有主見」；必須來自可見設計與已知 brief，不可虛構故事），再點名 **兩個跨部件關係**，包括前背面、頭髮／頭飾、上裝與下裝量感、色塊、穿法、配件。分辨：
- `STRONG`：值得保留，仲有空間放大；
- `LIMITING`：真係壓制目標魅力嘅關係，並有畫面依據；
- `UNEXPLORED`：未必有錯，但另一個表現方式可能令角色更出色。

逐部件掃描係防止漏睇，唔係要求每件都改。詳見 `part_review_compact_v100.md`。

## 第 2 步｜同時建立兩條可畫嘅方案

| | AMPLIFY：放大原本魅力 | REIMAGINE：重構更強新主張 |
|---|---|---|
| 起點 | 原版最成功嘅觀感／關係 | 同身份、用途相容但不同嘅設計命題 |
| 核心問題 | 點用一個主要造型操作放大已有優勢？ | 係咪有另一套服裝語言更適合呢個人？ |
| 可用機制 | 重分配主次、放大某量感、移動視覺焦點、重排色片、令已存在母題參與結構 | 改衣服類型、穿法、主形體、輪廓節奏、整體上下身配色與比例連動 |
| 必須保留 | 已確認 identity／風格界線 | 已確認身份與人格事實；**現有服裝解法可以改** |
| 必須寫 | 已有 hook 如何更突出？邊種過度放大會破壞自然感？ | 新 visual thesis 點樣屬於呢個角色？同原版有咩必要而合理嘅差別？ |
| 假方案 | 只改一條線或隨意擴大細節 | 只換裝飾／換主色／跟時尚趨勢而冇完整新構思 |

兩條路線**唔強制同等幅度改動**，更唔係「A 一定贏 / B 一定贏」。要真正睇到視覺差異，而且觀感收益要同角色本人有關。原版亦係合法選項。

## 第 3 步｜整合，而唔係將局部修正堆滿全身

對每案寫 `THESIS → HERO SHAPE / COLOR MASS / WEARING → HEAD/BODY/BACK CONSEQUENCE → EXPECTED APPEAL → MAIN LOSS`。一個方案最好有一個清晰主張，唔等於永遠只可以改一件：相關連動可以同時改袖、腰、裙，但必須服務同一個觀感。唔係每個部位都要有母題；簡單大色塊可以係刻意設計。

`Anime Detail Level` 同審美**分開驗收**：紋理、縫線、固定小件、髮束複雜度係製作成本；具角色身份價值嘅細節可保留、簡化表示，而唔係一律刪除。唔以粗糙概念圖的品質評定方案美感；比較的是可見結構與預期表現。

## 第 4 步｜識得發展好點子

`KEEP ORIGINAL`、`DEVELOP IDEA`、`SELECT FOR TEST`、`REWORK IDEA` 四類用於創作迭代，其中 `DEVELOP IDEA` **唔係正式 render 授權**。當某方向有強嘅概念但現稿未成熟：
1. 保存最好嘅 **具體部件或色塊**；
2. 指出最大風險（例如失去親近感或上半身過重）；
3. 下一輪只試一個能真正驗證風險嘅變量；
4. 將兩條路線嘅成功部件混搭前，先審整體節奏，唔機械疊加。

**作者嘅局部 feedback 是選擇範圍，不是整套批准**：
- 「B 袖色好」⇒ `APPROVED_PART: 袖色`；`NOT_APPROVED: B 其他所有改動`；唔等於 B 完稿。
- 「A 太淺，但 D 最好」⇒ `PREFERENCE: D`、`REJECTED_REASON: A 整體失去主色`，下一輪可固定 D 形體單獨試色。
- 作者提出新配色 ⇒ 畫一版作者想法，可再提一版有明確原因嘅變體（有必要時），唔自行否決或者擅自覆蓋。

## 第 5 步｜一次一個可比較嘅變量，避免假進步

概念方向可大膽，但**比較時**要鎖住其他因素：要比袖色就鎖住袖形、人物／姿勢；要比袖形就鎖住顏色；如需連動變數，另外明列為「組合方案」，唔冒充單因子測試。正面認可唔代表背面或配件已一致：定稿之前逐件核對。

使用局部重色／遮罩局部造型修改，保持原稿其他像素及製作模型一致；生成嚴重走樣時改變編輯方法，唔連續生成整張資訊板。作者原稿永不覆蓋；候選同決策分開儲存。

## 判斷邊界

- 資料薄或無實圖嘅配色數字、母題出現次數、64 px 差異唔係「美感定律」。
- 可見改動幅度證明「有冇變」，唔證明「變好」；真人魅力判斷始終需用戶批准或實際受眾測試。
- 勿假裝一張候選設計證明其商業成功。可追溯流程係為咗**幫作品更好**，唔係生成大堆分數同報告。
