# Concept Selection Gate — v9.7（生成前必須做嘅淘汰）

## 點解要呢個 Gate

以前寫得出「為了讓配色更一致」就可以生成，但未驗證一致性是否真的提升角色魅力；又例如原版有靈魂的穿法被改成整齊，損失冇納入比較。**設計因果理由係進場資格，唔係過關證據。**

## 工作方法（小型設計評審，不是官僚打分）

**Stage A：為原版建立基準**

- 主印象／魅力，最有價值 2–3 個視覺關係，最有性格嘅穿法／配色／部件，合理嘅 Detail Level。
- 留一條 `KEEP ORIGINAL` 路線，問「有冇必需改嘅問題？或者純粹探索更好嘅可能性？」

**Stage B：至少兩個真正不同嘅設計想法**

- 寫可見改動，不寫空洞目標。例如「把腰部視覺重心由裙前中移到右後，令前面更乾淨，同時維持偏側綁結」。
- 一條路線必須能夠**冇新增表面裝飾**而成立（當 brief 容許時）；但華麗角色可以探索細節密度，只要講明其分佈與好處。
- 檢查方案係咪為特定角色服務；換畀任何角色都同樣成立嘅方案，通常唔夠有力。

**Stage C：反證／損失預測**

每案公開三句，字數少但內容唔可以空：
1. **可能提升**：因為 `可見 A` 改變咗 `A 與 B 的關係`，預期觀眾先睇到／感受到 `X`。
2. **可能損失**：原版 `Y` 係優勢，改後可能減弱 `Z`；後側／色彩／細節有連鎖影響。
3. **最強反方**：如果 `同尺寸原版與候選比較後` 出現 `K`，我會否決方案。

**Stage D：Veto（唔容許自說自話）**

逐項檢查並記 `CLEAR / RISK / BLOCKED / UNKNOWN`：

| 面向 | 必須答嘅問題 | BLOCKED 例子 |
|---|---|---|
| 人物魅力 | 係咪比原版更強化所需氣質？ | 只係「更高級／更潮」之類空話 |
| 跨部件節奏 | 頭髮、服裝、下裝、背面是否互相支持？ | 部分更靚，但全身更失衡 |
| 角色獨特性 | 是否保留重要身份並有更獨特人物選擇？ | 抹走招牌穿法、變普遍模板 |
| 配色關係 | 顏色相同／不同係咪真有視覺用途？ | 只因「統一」而換掉有性格的對比 |
| 簡繁與成本 | 在指定 detail 制度內是否可畫可動？ | 沒補救方案但加重線條追蹤成本 |
| 最低代價替代 | 有無更小風險方案達到同樣效果？ | 明知保留原版更強仍為求變化強改 |

**只要發現一項 `BLOCKED`，就不得 `SELECT FOR TEST` 作為合格設計升級。** `UNKNOWN` 重大時要補觀察／改用可測試假設，不得假裝已通過。Aesthetic appeal 係專業判斷並帶不確定性，不使用任意分數或假研究數據。

**Stage E：決定**

- `SELECT FOR TEST`：冇 blocker；勝過原版嘅假設具體，而且損失較可控。**只代表值得測試，唔代表客觀好過。**
- `REWORK IDEA`：有潛力但 blocker 或弱點未解；重新調整機制，再做 Gate。可以將一案「更好嘅部分」移植到另一個大形假設，唔直接套原圖。
- `KEEP ORIGINAL`：至少兩條方案都未形成值得冒風險嘅改善；原圖可繼續使用，另列未來研究方向。
- 若用戶想要純探索圖而未有強假設：可標 `EXPERIMENTAL—UNVERIFIED`，但不能說成設計過關；必須仍符合硬鎖與作者方向。

## 防止「出圖後先聰明」

保留 **Precommit** 同 **Post-render** 兩份分開資料：
- Precommit 包含 `選方案、反方理由、預期利弊、拒絕點、可見改動、KEEP/CHANGE/FORBID/OUTPUT`。
- Post-render 只能引用它；新增嘅洞察明標 `NEW INSIGHT`，唔得抹走原本風險。
- 出圖係用來測試假設，**唔係代替設計決策本身**。

## 三個通用反例

1. **顏色更統一但更無趣**：更一致不等於更有魅力；原有意外對比如果提供個性，必須保留或有同等替代。
2. **動漫細節減少但人物更普通**：Production Fit 可過，Design Gain 失敗，**不可標 upgrade**。
3. **輪廓改動很大但冇專屬理由**：大形差異唔代表成長；如果失去角色氣質，就應該 veto，即使畫得好。
