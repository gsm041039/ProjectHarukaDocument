# Wearing Identity Gate｜着法都可能係角色設計

## 目的
防止 AI 因為「整齊」、「標準」、「簡化」、「動畫易做」而機械地將原本有個性嘅服裝穿法磨平。**但唔預設不對稱一定好**，所有判斷服從作者所選 art direction 同用途。

## 1｜原稿盤點（只寫可見特徵）

針對影響造型嘅關鍵衣物，記錄：
- **選擇 / Choice**：正常着、披住、綁腰、搭肩、半穿、反穿、挽袖、敞開、扣一半、把外套改作攜帶等。
- **結構 / Construction**：腰間固定方式、袖／領開口、布料接合、重量、拉鏈與扣件位置、是否可自然穿脫。
- **形狀 / Silhouette**：左右厚薄、上下身視覺重量、外形凹凸、留白與負形、正側背邊界。
- **節奏 / Rhythm**：鬆緊、長短、整齊／鬆散、規則／破格、露出／遮蓋、硬／軟材質關係。
- **功能 / Use**：動作範圍、攜帶方便、季節、校規／制服規範（若作品提供）、動畫／3D 成本。

每個觀察先標 `[OBSERVED]`，唔由服裝判斷人格：例如「外套綁腰」係觀察；「叛逆」只有創作者有設定或其他作品證據先可以講成 canon。美術上可提出「觀感較隨性」但要標 `[DESIGN_JUDGMENT]`。

## 2｜辨認可能嘅『穿搭身份』

以下屬候選特徵，**唔係見到就一定要鎖**：
1. 人物特有嘅衣物使用方式（着法與別人不同）；
2. 形成有價值嘅不對稱、重心、視覺流向；
3. 與已知行動、習慣、世界觀或場景用途吻合；
4. 在正／側／背持續可辨，且可在必要動作中成立；
5. 移除後，角色會更接近泛用制服／泛用休閒穿搭。

有兩項或以上可作**進一步比較嘅理由**，**唔係量化合格線**。作者批准嘅硬鎖一律優先。

## 3｜三條候選路線（只按有需要挑選）

- `KEEP WEARING / REFINE`：保留原本嘅穿着方式，微調位置、垂墜、綁結、材料厚薄、衣物露出比例，減少瑕疵但保留人物差異。
- `ALTER WEARING / JUSTIFIED`：保留主要視覺關係，但有合理原因調整着法，例如改善動作衝突、故事換季、配合作者指定氣質。寫明失去與得到。
- `REPLACE WEARING / AUTHOR-LED`：大幅改變穿搭方向，只有作者批准或明確探索要求下進行；**新版本更整齊本身唔係充分理由**。

對每個新方案問：
- 原本嘅着法創造咗乜吸引力？而家係咪無端消失？
- 原版若已足夠好，是否應 `KEEP ORIGINAL`？
- 係咪將獨特設計變成標準制服？若係，係作者明確想要嘅新方向嗎？
- 有冇較小改動能解決問題，而唔抹走特有穿法？
- 新結構能否正側背交代清楚，而唔靠攝影角度／效果掩蓋？

## 4｜示意例子（通用情境，非任何個別角色設定）

原稿：角色把一件深色外套綁於腰間。其不對稱布料讓下身有層次，上身保持淺色留白。
- 候選甲：**保留綁腰**，調整結嘅位置和布料尾端長度，改善視覺節奏。
- 候選乙：**把外套穿上身**，可能更保暖、動作更實用，亦可能失去原版上下對比同隨性感。
- 如果 brief 係「更正式、更收斂」或環境寒冷，乙可能更好；如果 brief 要保留原版穿搭個性，甲可能更適合。

**唔會因為外套綁腰就推斷角色係叛逆、懶散或反傳統。** 亦唔因為乙更對稱就判定更專業。

## 5｜輸出與驗收

改圖前用一行寫：`Wearing identity: 原版着法 / 視覺功能 / 允許更改？ / 若更改會失去什麼 / 替代方案`。

改圖後用一行寫：`Wearing audit: PRESERVED / CHANGED_AS_APPROVED / UNAUTHORIZED_DRIFT / UNCLEAR`，附觀察和原版比較。未有同條件圖或觀眾證據時，保留主觀性及不確定性。
