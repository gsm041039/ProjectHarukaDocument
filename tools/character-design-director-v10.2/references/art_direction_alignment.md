# Art Direction Alignment — Universal Procedure

## 目的
先理解作者想要嘅角色體驗，再審查與創作。**唔預設簡約／華麗／潮流風；唔把某次測試嘅答案移植去其他角色。**

## 只追問真正欠缺嘅方向

- **Feeling & Character Fantasy**：觀眾第一眼應感受到乜？角色有咩獨特氣質？
- **Reference Boundary**：參考作品想借邊種特徵（形狀、色彩、材質、服裝語言）？唔想學邊種？
- **Complexity**：簡潔 / 中等 / 精緻 / 高裝飾 / 自定；細節應集中定平均？有冇動畫／建模成本限制？
- **Keep / Avoid**：身份必留點、反感效果、禁止元素。**限制僅屬當前角色及當前服裝形態。**
- **Scope**：只小修、可重設服裝、可改髮型、是否可以新增主題元素？

如用戶已提供，整理成 3–5 行 Brief，唔重複問；唔知道但對執行無影響，暫不問。只對**實際會改變決策**嘅歧義先詢問。

## 提案核對

1. 正面方向同禁區有冇衝突？
2. 係咪用『多咗 detail』代替設計論證？或者以『少 detail』當無條件正確？
3. 候選有冇優化原版具體問題，而唔係只係換裝風格？
4. 視覺重心、疏密、剪影與設計語言係咪吻合作者指定嘅風格？
5. 有冇真實執行風險（模糊剪裁、角色身份偏移、動作成本、不同角度失效）？

## 可複製 Brief（例子用抽象描述，非角色 canon）

```text
Design Intent: [第一眼觀感及角色用途]
Style References: [作者指定參考，或者 UNSPECIFIED]
Complexity Target: [作者描述；若未確認標 UNKNOWN]
Identity Locks: [已有設定必留]
Avoid: [明確唔要嘅效果 / 設計手法]
Change Scope: [本輪可改內容]
Validation: [用咩視角、距離、媒介同原稿比較]
Approval: PROVISIONAL / AUTHOR_APPROVED
```

如果未有明確作者意圖而任務係重大重設，建議先同作者確認 1–2 個最關鍵選擇；如明確要求即刻探索，可先做有標示的 provisional 候選，不作 canon。
