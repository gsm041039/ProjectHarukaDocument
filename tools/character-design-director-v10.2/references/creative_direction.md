# A｜Creative Direction：創作能力，唔止審稿

## 核心問題：「呢個人點解值得被望多眼？」

角色視覺吸引力唔係單一配色公式。用以下**設計操作語言**，將模糊評語轉成可畫嘅操作；只針對當前問題揀最有用兩三項。

| 評語或診斷 | 可以真正改嘅設計操作 | 注意代價 |
|---|---|---|
| 「靚但普通」 | 給焦點一個有邏輯嘅非常規比例／負形／穿法；令大型形體有一個意外但乾淨嘅節奏轉折 | 太多非常規點會雜；可能似別人 |
| 「主次唔清」 | 決定首讀、次讀、近讀；將重複高對比切口從非焦點移走，讓重要形體附近有視覺喘息位 | 減法可能犧牲世界信息 |
| 「太花」 | 保留內容但重排密度：整段安靜大面積＋集中一處高密度；合併同等重要嘅細節成一種有規律嘅視覺語法 | 作品本身可以需要高裝飾度 |
| 「角色感唔夠」 | 將個性落喺對衣物嘅**選擇與穿法**，如扣法、袖長、收納習慣、磨耗處；搭配站姿與面部方向 | 唔可由外表反推創傷或道德 |
| 「設計同主題離地」 | 揀角色獨有且**可見**嘅主張，轉成服裝結構、材質關係、可拆件或領口／袖／裙嘅收口 | 母題太直白會似 cosplay |
| 「二形態唔似同一人」 | 保留 1–2 個跨載體錨；調整位置、尺度或用途而非照抄全部 | 錨可能喺新底色失對比 |
| 「好似另一個角色」 | 拆分：頭髮量塊、臉部距離、衣物主構造、簽名色分布、母題位置；先改最接近既有作品嘅關係 | 原創性唔等於清關／無侵權 |
| 「有設計但唔順眼」 | 調整節奏（大/中/小）、上重/下重、直/曲/斜、硬/軟、暖/冷、規整/破格之間嘅**對比比例與過渡** | 無通用黃金比例或固定配方 |

## 分四層觀察

1. **遠讀（作品實際觀看距離）**：大形、視覺重心、首眼落點、同 cast 分隔。
2. **中讀（一般角色立繪）**：造型節奏、裙袖／頭髮分量、領口、上身／下身承接、色塊分配。
3. **近讀（美術細節）**：配件、縫線、紋樣、材質、設定式細節；佢哋可有價值，但唔代替遠讀。
4. **動態與多角度**：角色行走、攻擊、坐下、轉身、俯／仰視後主件會點變，唔可以靠靜圖判 PASS。

## 將人格轉成「可畫」外形，而非性格符號公式

從角色已知行為或情境出發，推導**角色本人會作出嘅選擇**，而唔係把悲傷畫黑色、善良畫圓形。例子：同一套制服，一人因做事方便而將外套穩固扣好；另一人經常將袖挽起。兩個都可以溫柔或冷淡；識別只係穿衣習慣差。

## 目標觀感（Aesthetic Target）

先界定觀感目標：例如「冷靜而神秘」、「熟悉之中帶微妙不協調」、「精緻但不繁複」、「美麗又帶威嚴」，然後寫視覺證據。`Elegant` 唔等於低飽和；`cute` 唔等於大眼；`premium` 唔等於金邊。要同作品已有角色／美術語法比，而唔係用隨機現成風格。

每個候選必需答：
- 第一眼希望望到邊個地方？
- 具體改咗一個乜嘢視覺**關係**（唔係只換顏色）？
- 呢個改法點解更屬於此角色，唔係任何角色都適用？
- 佢會犧牲乜？有冇另一方法成本更低？

## 三條探索路線例子（唔係固定 quota）

假設原稿有白色系戰鬥裙、藍色簽名色、頭部輪廓固定；身份鎖住。

- **Refine**：降低腰周裝飾密度，將注意力轉移到面部／肩線；保留原有色系同主要裝飾，調整裝飾節奏。
- **Restructure**：唔改身份同髮型，但重新安排上半身主件：例如將胸口一排細裝飾轉成單一衣領接合點，令肩→腰流向更清晰。
- **Reinterpret**：由「飾物貼喺衣服上」轉成「同一母題係布料分層與收口方法」；必要時出前後視圖證明真係穿到。

三個候選唔要求同一樣「更華麗」；設計師應保留反常但有力嘅版本，避免評分機器自動把所有作品磨成同一種整齊、低細節風格。

## 開放式參考研究（需要時）

跨作品、年代、媒介尋找「相似目標但採用不同解法」以及「似乎成功但條件唔同／失敗」案例。每次至少寫一個反例或競爭解釋。清楚分開官方一手發言、圖像觀察、AI 主張、觀眾證據，唔靠一張出名角色圖推導因果。

最好做**reference abstraction**：只借用結構策略（例如「高密度集中在領口」），唔照抄具體標誌、髮束、剪裁組合，避免無意中變成別人既有角色。

## v9.1 補充：有意義嘅減法 / 結構先於印花

「改善設計」先問 **改邊個形體關係**：例如短外套同褲腰如何分層、肩寬同下身點平衡、色塊如何令視線返回面部。唔係每個角色都應簡約；但如果原稿已經有角色專屬符號，喺所有物件重複印同一符號通常會稀釋主次。任何新增符號要有獨特功能，先考慮局部放大、搬位、刪除其他視覺噪聲。詳見 `change_rationale_gate.md`。


## v9.2.1 補充：依作者目標調節設計密度

一個角色「完成度更高」唔等於「細節更多」或「細節更少」。喺作者所選風格同製作需求之內，審查造型主次、形體節奏同整體一致性。

- **簡潔方向**：優先調整形狀、比例、剪裁、留白、配色，同少量精準重點；但唔可簡化到失去個性。
- **中等密度**：強調一個主要設計概念，加上少量支持佢嘅結構／配件，避免無目的散點。
- **高裝飾方向**：可容許複雜，但要設計出能夠被整體閱讀嘅層級、集中與呼應；唔等於每個部位都加 motif。
- **風格由用戶指定**：唔以現成潮流、工作室風格、某角色案例做全體默認；尤其唔將一次測試的拒絕理由硬套其他角色。
- **每一項新增與刪減都要講原因**：新增細節必須解釋價值同焦點；刪減亦要交代有冇削弱角色身份。


## v9.2.3｜Styling / Wearing Identity：着法係設計語言

「改得更標準」同「改得更吸引」係兩件事。當角色原版靠衣物嘅披法、綁法、鬆緊、不對稱、內外層可見比例建立個性，AI 應先分析呢個關係再創作；唔好一見到凌亂就自動整理。反過來，整齊亦可以係角色獨有嘅美術語言，唔可以機械加不對稱。

- **保留既有穿法 + 改善節奏** 同 **大幅重新穿着** 係兩種不同設計機制，必須交代各自代價。
- 觀察視覺特徵唔等於推導心理特質；「有距離感」係美術判斷，「有某種人格背景」要有設定證據。
- 有關穿着結構、物理路徑、反例與驗收，見 `wearing_identity.md`。
