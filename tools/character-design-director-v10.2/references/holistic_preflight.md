# Holistic Preflight：全身審視，先於局部設計

適用任何角色。目的唔係填滿大 checklist，而係防止只改最易改嘅部位；每項可用一兩行，但必須有 `OBSERVED / JUDGMENT / UNKNOWN` 嘅分別。**已看不到的背面/材質，標 UNKNOWN；絕不假設。**

## 六個系統，跨部位看關係

| System | 必須回答 | 可採取行動 |
|---|---|---|
| Appeal | 角色第一眼令人感到咩？係由邊啲大形、穿法、表情或視覺反差造成？邊啲只係觀察者猜想？ | 強化魅力而唔係強化裝飾 |
| Proportion | 頭／髮／肩袖／腰／裙褲／鞋嘅比例節奏，同側背輪廓互相點影響？ | 調節一個主槓桿，追蹤連鎖改動 |
| Color | 全身由大色面到帽後髮帶、鞋襪、鑲邊、小件：色相、明度、飽和與面積點呼應？刻意異色合理嗎？ | `KEEP / CHANGE / TEST`，逐個色彩決策附理由 |
| Wearing | 衣物點樣著？刻意不對稱、鬆垂、扭轉、綁法有冇身份意義？ | 唔擅自抹平非對稱 |
| Detail | 視覺焦點、留白、裝飾、紋理、縫線、髮束有冇合理主次？ | 只保留有識別/表意/功能價值嘅 detail |
| Production | 目標媒介與 normal-size 表現如何？正側背能否交代？需要追蹤幾多小物？ | 選 production LOD 而非一律刪細節 |

## Color Architecture：特別防漏查小配件

1. 列出三類：`major masses`（全身大色塊）、`support colors`（二級）、`micro accents`（小面積，例如帽帶、綁帶、鞋帶、耳飾）。
2. 每種重要微色塊需查：同身上邊個顏色相似或形成對比？如果有**兩條不同色嘅髮帶**，兩隻色分別傳達乜？有冇更合理替代？原版應唔應保留？
3. 區分 **有意識的色彩差異** 同 **冇驗證就沿用**；不把「更一致」當成絕對好。可以保留小面積意外色，但必須解釋主次同整體平衡。
4. 同時看前背視覺連續性；前面睇唔到嘅顏色可能係背面最大焦點。正常大小再測一次，而唔係只睇大圖色票。

## Design Opportunity 不是 Defect

- `OBSERVED`：原稿真正可見的分布、比例、穿法。
- `DESIGN_JUDGMENT`：設計師認為視覺順唔順、焦點清唔清；要有實際視覺理據。
- `EXPLORATION_HYPOTHESIS`：可能存在更好嘅解法，**唔代表原稿有錯**。
- `UNKNOWN`：缺原稿側背、故事或材質證據；先記錄，不硬編。

掃描後**揀最有潛力的 1–2 個整體關係**，而唔係機械地六項都要改。若大形本身好，下一輪也可能應優化色彩／穿搭／魅力表達；亦可以維持原版。
