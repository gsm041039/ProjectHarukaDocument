# 可複製交付範本（按任務刪減）

## 1｜單次設計提案（設計討論）

```md
# <角色> 設計方向｜Round <NN>
模式：CREATE / ENHANCE / AUDIT / ITERATE / PRODUCTION
Canon/鎖區：<資料／未知>
用途與觀看條件：<日常/戰鬥/立繪/頭像...>
想達到嘅第一眼感覺：<一句>

## 原版值得保留
- <具體可見部件及原因>

## 真正瓶頸
- <部位 + 影響>

## 候選 A — <設計主張>
- 具體改法：<位置 / 比例 / 材質 / 顏色 / 形狀 / 穿法>
- 點解專屬呢個角色：<已知設定／設計假設，二者分開>
- 預計改善：<第一眼 / 視覺節奏 / cast...>
- 代價：<身份 / 製作 / 場景...>
- 最可能推翻佢嘅比較：<同條件試驗>

## 候選 B — ...

## 對照結論
- 原版更強：<...>
- 候選較好：<...>
- 未驗：<...>
- 建議：KEEP_ORIGINAL / TEST_MORE / CHOOSE_A_FOR_EXPLORATION
- Canon 正式採用：PENDING_AUTHOR_APPROVAL
```

## 2｜研究來源紀錄

```md
- Claim: <此規則想解釋乜>
- Type: DESIGNER_QUOTE / OFFICIAL_IMAGE / EXTERNAL_REVIEW / AI_INFERENCE / HUMAN_TEST
- Reference: <URL / 本地相對路徑 / 可存取狀態>
- Supports: <具體支持乜>
- Does NOT support: <唔可以證明乜>
- Counterexample: <反例 or NOT_FOUND>
- Status: SUPPORTED_WITH_SCOPE / PROVISIONAL / UNVERIFIED
```

```md
# Suggestion <YYYYMMDD-NN>

```

## 4｜Production Handoff（只喺需要設定交付時）

```md
- Views: front / side / back（缺少要註明）
- Head identity: 頭身比例、五官固定點、髮束主分區、頭飾
- Outfit layers: 前後上下層、開合、扣件、支撐、可拆件
- Material: 硬挺 / 垂墜 / 彈性 / 不透明程度（視媒介）
- Colors: 主／輔／點綴色及所在部件；有數值就註明色彩空間
- Motion: 坐／跑／轉身／攻擊時會否穿插或遮面
- Simplification: 小尺寸／TV 動畫省略優先序
- Fixed vs flexible: 哪些必須一樣，哪些可依表演變動
- Not verified: <...>
```
