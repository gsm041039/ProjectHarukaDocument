# v10.0 → v10.1 — Whole Character First

## 修改動機

真實凜測試發現：AI 跟住 v10.0 Holistic Baseline 嘅部件檢查次序，竟然逐件要求作者決定帽、髮帶、Hoodie，甚至局部精修及生成；整體角色方向仍未建立。另一方面 v9.9 強制先 SVG 草圖又壓住咗用真正探索圖研究審美嘅工作。

## 修改

1. 首頁最高優先級：**分析可以逐件，設計要先全身**；固定角色 brief 唔重問。
2. 全流程重排：Brief → 全身 baseline → 完整人物 A/Amplify & B/Reimagine → 可直接生成同尺度**探索**圖 → 全身比較 shortlist → 才局部精修 → 才正式正側背 settei → 審核。
3. 兩道真正不同的關卡：探索圖不必先 SVG／正背 proof／production preflight；正式設定圖要經選案與製作驗證。
4. 禁止用 pose、笑容、飄髮、渲染品質偏差替代設計收益。
5. 作者「B 還可以但唔夠吸引」只意味 DEVELOP 候選，不迫局部定稿。
6. 加 `whole_character_first_v101.md`、可逐輪填嘅模板、階段程序測試，保留 v10.0 及 v8 原研究。

## 仍然不能保證

程式只驗證必要記錄，唔具美學判斷力。v10.1 是修正可執行流程，不是假裝已經通過實際新角色生成品質測試。
