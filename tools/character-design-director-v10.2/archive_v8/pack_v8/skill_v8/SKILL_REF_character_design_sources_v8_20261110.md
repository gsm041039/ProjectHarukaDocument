- **級別**（R3 #5 甲）：
  - **A**：設計者本人發言，刊於官方或有編輯責任嘅媒體；
  - **A\***：作者許諾嘅再構成；
  - **A-I**：機構；
  - **B**：記者轉述；
  - **T**：粉絲轉寫或英譯；
  - **I**：只見頁殼或者圖，正文未讀。
  - 方向之間評級唔一致嘅，兩個並列，唔代為升級。
  - **v5 細則（motif_world 提出，11-09 例子回合）**：同一篇訪談入面，**設計者本人直接引語＝A，記者地文／轉述＝B**；非設計者（製作人、聲優）講設計＝B；機構頁、官方圖＝A-I。只適用於 §7 EX 卡；v4 §1–§2 舊卡嘅並列級別冇改（重疊處喺 §7「對應」欄註明）。
- **證明程度**：PROC 有過程；END 只證成品；ANA 類比；CNT 反例。
- **語域標籤**：〔真人劇〕〔真人電影〕〔高訂〕〔舞台〕〔正裝〕〔競技遊戲〕〔主題樂園〕。帶標籤嘅例只證「手法存在」，唔可以決定日常服政策（R3 #18）。
- **核實狀態**：
  - **核**：協調者抽查開到。
  - **自報**：研究員自報開到，協調者冇重開。
  - **⚠未核**：有方向打唔開，或者各方報告矛盾。
  - **單源**：只有一個方向引用。
