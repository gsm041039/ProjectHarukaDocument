## 2. 規則

### G01｜先定用途同載體，再定輪廓大細（澄清）
- **規則**：先答「喺邊、俾邊個睇、做緊乜」。需要舞台／戰鬥級大輪廓就開另一個載體，唔好將日常服加大。日常要**可信、唔舞台化**（IDC）；「日常尺度」＝該場合現實可穿嘅尺度，禮裝場合本身闊唔算違規（CO：EX06 全身寬高比約 0.606）。特殊載體**唔一定**要加大（CO：EX09 リコリス；方向新量，未重產，只寫方向）。
- **用途閘門**：有日常＋特殊場合嘅角色。唔用：單一戰鬥載體角色（EX13，閘門變「幻想錨」）。
- **支持例**：EX01、EX04（寬高比 0.29 vs 0.85）、EX05、EX08、EX12、EX10、EX06。
- **圖像證據**：`research/commercial/img_examples_20261110/derived/01_side_by_side_standing_neutral.png`；`research/silhouette_cast/img_examples_20261110/aligned_headfeet_color.png`；`research/identity_canon/rules_r1_img/EX01_EX04_EX05_EX12_g01_carriers_h64.png`。
- **限制**：冇寫實日常便服主例；設計次序靠文本。載體差要喺中性或配對姿勢下成立（PM；見 G12(a)）。輪廓分寬度／面積／實心度各寫（SC：EX01 寬約 1.20、面積約 1.01）。
- **點驗通道**：全身 h64 彩色＋填實，正面；配對姿勢。
- **一手來源**：見 REF v7（CRYSTAR、クライマキナ、＝LOVE 等）。

### G02｜要更易認，就改主讀構造——唔好淨係放大徽章（澄清）
- **規則**：揀一件已有元素，改佢嘅結構、掛點、長度或尺度入遠讀大形。寫明**新根部 → 自由段 → 收尾**，喺改構存活嘅視角驗（FS）。母題入結構（層、紋、可轉件）；表面印紋係近讀層，唔負責遠讀（MW）。
- **用途閘門**：易混、需要遠讀。唔用：近讀層主張。
- **支持例**：EX13（尾尖約 0.68–0.69 H、膝環約 0.73–0.74 H；頭像 MAE 1.128）、EX07（三角面印 64 px 消失，ΔE00 約 0.74）、EX12（頭飾 1.76% → 8.87%）、EX01（結晶，目視）。
- **圖像證據**：`research/originality/img_examples_20261110/analysis_v2/board_main_asu_vs_old.png`；`lab/canon/_working/skill_distill/SKILL_EXAMPLES_IMG_20261110/I4_integration_check/EX13_frame0_asu_side_tip_vs_knee.png`；`research/motif_world/img_examples_20261110/outputs/02_thumbs_128_64_height_normalised.png`。
- **限制**：EX13 同時改比例／VFX；EX07 層同可拆只有文本。

### G03｜先寫規定欄，再揀一個主差欄（＋並行通道）【R2 投】
- **規則**：
  1. 先寫**規定欄**：邊件係組織／世界規定、**邊個揀**（組織、角色本人、設計者；IDC N1、PSY P01）。
  2. 保留共享文法，將個人差集中喺**一個主差欄**；需要時加**並行通道**。每欄寫明負責通道（CO）。
  3. **衣物剪影**同**頭髮剪影**分欄寫（HH）；宣傳立繪姿勢唔算一欄（PM）。
  4. 差欄係辨認線索，唔係性格診斷（PSY）。
- **用途閘門**：規定制服、團隊、同職角色。唔用：無規定嘅自由便服 cast（未有例）；戰鬥載體可改用輪廓分人（EX05 怪盗）。
- **支持例**：EX03（制服 ΔE00 約 0.1、髮約 37）、EX09（下衣物 IoU 約 0.74——站姿未配平，要連 v7 註「剔舉拳框後 0.80→0.84」引用；髮 IoU 0.246 含リボン；紅 vs 紺並行）、EX10（主差欄＝穿法，頭肩通道靠髮色／領口＝並行）、EX05（日常剪影 IoU 0.55，靠色＋着法）、EX11（髮／衣明暗）。
- **圖像證據**：`research/color_value/img_examples_20261110/out/01_side_by_side_h800.png`；`research/head_hair/img_examples_20261110/out_cafe_02_silhouettes_overlays.png`；`research/performance_motion/img_examples_20261110/analysis_v2/01b_sheet_pair_color.png`；`research/commercial/rules_r1_img/channel_sweep_sheet.png`（CO）。
- **限制**：EX09 唔可以全部歸頭部；EX05 日常 IoU 含姿勢（R4）。CO 通道 TVD 數〔方向新量，未重產〕唔引。「邊個揀」圖像見唔到，只靠文本（REF v7：副島、いみぎむる、neco）。
- **點驗通道**：最似隊友並排；全身 h64 正面＋頭肩方框各驗一次。
- **狀態**：CONFIRMED（5 例）。

### G04｜簽名色寫面積、位置、用途、通道（澄清）

### G05｜跨形態留錨，喺新底色仍要有對比【R2 投】

- **支持例**：EX01（白長髮兩形態主體積；但白髮 vs 白戰鬥服對比細——CV 指出要驗）、EX04（全身 IoU 約 0.13 vs 頭部裁切 0.56＝形錨）、EX12（頭區 IoU 約 0.43；錨係紫系色相家族）、EX14（橙髮＋白裙＋藍上身組合）、**EX02（明度錨：招牌髮型改咗，近黑主面積留；設計師一手「トレードマークの一つでもあったヘアスタイルをガラっと変えました」）**。

### G06｜換載體或轉媒介：四條路，寫明接手件同固定點【R2 投】

- **用途閘門**：細飾、點綴色、同色系隊友。唔用：有意融入嘅近讀層（EX07 ΔE00 約 0.74）。
