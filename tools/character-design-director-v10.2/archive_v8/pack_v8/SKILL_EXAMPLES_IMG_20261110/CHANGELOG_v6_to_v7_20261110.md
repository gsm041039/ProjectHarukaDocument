# 角色設計 skill：v6 → v7 改咗乜（2026-11-10 HKT）

一句講晒：**冇改任何設計方向，只係將 14 個參考例子講得更準，同埋加一條「講 64 px 之前要講清楚睇緊邊種縮圖」嘅規矩。**

## 新規矩：講 64 px 先講清楚睇緊乜
以前一句「64 px 睇得清」可以有好多意思。而家要寫明：
- 縮嘅係**成個人**，定係**頭肩一格**，定係**淨係塊臉**，定係官方自己出嘅縮圖；
- 係**彩色**定係**塗實嘅黑影**；
- 點裁、按乜嘢對齊高度、量咗乜、用邊種縮細方法。
同一個角色，全身縮圖同頭像縮圖第一眼睇到嘅嘢可以完全唔同（例如禮服大色塊喺全身好搶眼，喺貼臉頭像就幾乎睇唔到）。

## 改正咗嘅錯
- **李星（LoL）新版馬尾**：之前寫「垂到近小腿」，其實只係**約到膝頭**，仲略高過膝。
- **魔法少女兩姊妹**：之前寫「踢腳姿勢」，其實**兩個都冇踢腳**，只係一個伸手、各有一隻靴腳尖向外。
- **Persona 5 官方黑影圖**：官方黑影圖本身**冇字**；之前用嘅「剔走字」縮圖其實仲有字，已撤回。黑影圖嘅外框加粗咗，所以唔可以當身體面積。
- **Black Panther**：「2016 縮細到只剩一點」唔啱；按畫面高度縮，人仲有約 56–59 px，只係睇唔到三角紋。
- **NIGHT HEAD 兄弟**：有一組「頭髮 vs 衣服」光暗數，個「衣服」其實包埋褲，唔係外套，已唔再用嚟比較。
- **光之美少女小夾**：頭像縮圖只係**見到色點**，唔可以講「形狀認得出」。
- **Pecorine 王冠**：官方動畫角色一覽嘅細圖本身已經見到 3 個尖，唔使我哋自己縮圖去證。
- **Furyu 角色**：「闊咗幾多」要講明用邊種闊度（外框闊定最闊嗰行），兩種數唔同。
- **Climacina、Pecorine 戰鬥形態**：唔係「變暗咗」，量出嚟冇整體變暗。

## 補強咗嘅位
- 每個例子而家都分開寫「全身縮圖見到乜」同「頭像縮圖見到乜」。
- 每個例子後面加咗「圖證唔到乜」，免得睇圖講過頭。
- 參考檔加咗兩張清單：**可以引用嘅數字**（每個都有出處）同**唔准再用嘅數字**；草稿入面每個數已經自動核對過，全部喺可用清單、冇一個喺作廢清單。
- 淡色頭髮、姿勢唔同嗰啲量度，照舊要人手畫遮罩同講明係咩版本。
