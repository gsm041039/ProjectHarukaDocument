# FILE_READ_MANIFEST.md

## Scope
本輪以「Story Contradiction Auditor + Pre-Outline Question Architect」標準，先做 inventory，再讀取與故事 / canon / structure / outline / reveal / theme / ending 直接相關之文字文件。

## Read Coverage Summary

| File Group | Examples / Areas Covered | Read Status | Why Relevant | Notes |
|---|---|---:|---|---|
| Canon owner docs | series bible, world rules, glossary, character files, timeline canon, story / narrative / information design, decision log | Full / Core Full | 最高權重來源，決定當前 canon 狀態 | 作為主要判斷依據 |
| Working story construction docs | `canon/_working/story_construction/*`, question queue, evidence gaps, rough skeleton | Full / Core Full | 用於確認目前 blocked decisions、working state、outline 入口條件 | 發現多個 stale blocker 狀態 |
| Ledger / reports | session ledger, next action, pending questions, decisions, sync / contradiction / coverage reports | Full / Core Full | 用以確認作者已答問題、已解決決策與未同步位置 | 對識別 Sync Gap 很重要 |
| Backup screenwriter docs | 核心故事、角色、世界觀、Alpha/Beta、villain docs | Broad Relevant Read | 用來核對舊決策、舊 framing 是否仍有未同步的重要內容 | 不可忽略，避免只看 canon |
| Backup director docs | 四幕、information control、atmosphere、theme docs | Broad Relevant Read | 用於檢查 act function、theme framing、reveal ordering | 主要用於 Interpretation / Structural 檢查 |
| Draft / raw docs | `outline_raw.md`, `timeline_raw.md`, old notes | Relevant Read | 用於分辨舊說法、未同步內容、legacy idea 是否被誤當 canon | 低權重，不自動裁決 |
| Non-core utility / prompt / helper docs | tool prompts, helper workflow docs | Partial / Selective | 非故事本體，但可輔助確認流程與 status | 未作逐行深讀 |
| Binary / image / non-text files | images, non-text assets | Inventory Only | 依要求列入 inventory，但本輪閱讀重點仍為文字檔 | 非主證據來源 |

## Relevant Unread / Not Fully Deep-Read

- 與故事大綱 blocking 無直接關聯之非文字資產
