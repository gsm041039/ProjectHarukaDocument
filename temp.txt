創作討論：填滿這個空白的三條方向
方向一：「受傷仍救人」的主動危難 beat
她們在地下化期間，唔係無事可做——係做任何事都係在冒險。想像：

有人在夜區被屍骸攻擊，晴香團隊明知現場有帝國探子仍介入
救完之後被舉報：那個被救的人，因為害怕，打了匿名電話
情感核心：「我救了你，你出賣了我。」 → 這不是背景噪音，這是對「為什麼繼續做英雄」的最直接質問
這類 beat 可以輕量，一個「救援→被舉報→逃亡」的循環就夠，但它讓每個角色的選擇都有份量：

角色	在這個 beat 的選擇	功能
晴香	救還是唔救？救了會暴露	主題核心：仍然選擇救
美夜子	對被舉報的人有什麼反應？	冷酷 vs 理解的裂縫
操	救了之後說什麼？	傲慢被磨碎的過程
方向二：情緒設定世界的暗面——美食家線
「情緒美食家」係咩？

在帝國的情緒資本主義世界裡，有一種地下職業：把特殊情緒提煉、封裝、當「稀有食材」出售——比如「初吻的心跳」「第一次失戀的苦味」「母親離世那一刻的麻木感」。

這些「情緒食材」的買家，是帝國高層、富人階級——他們自身情緒已被制度磨平，需要「購買」真實情感體驗來感受活著的刺激。

對地下抵抗的影響：

這個地下市場和主角團有直接交叉——因為：

情緒食材的「原材料」來源之一，是被捕的魔法少女（她們情緒特別濃縮）
主角團在地下化期間可能需要借助這個地下網絡來獲取物資/情報
這個市場讓她們見識到：情緒設定的「黑暗版本」是什麼樣的社會
美食家線的可能 beat：

主角團接觸一個「情緒掮客」——一個既可作中間人也可出賣她們的角色
通過這個角色，建立「帝國管制下的情緒黑市」世界觀
也可以作為尋找朱音的情報線（朱音情緒成分特殊，黑市有她的蹤跡）
方向三：尋找朱音——主動搜尋線
朱音從 113年6月底被放逐後，消失於地下水道 11 個月，到 114年5月才回歸。

這不應該是「消失然後突然出現」——主角團應該有主動尋找的過程，而且每次失敗都有代價：

不同角色對「找不找朱音」有分歧：
晴香：必須找，我放棄了她
操：不找，找了也沒用
美夜子：冷靜分析：找朱音可能暴露位置
每次嘗試接近朱音的地點 → 都有帝國跡象 → 可能是朱音主動避開，或帝國也在監視
搜尋線的功能：

讓朱音的 114年5月回歸有觀眾期待積累
操的成長 beat（從「不找」到「去找」的轉變）
讓「放逐」不是道德決定的終點，而是需要主角面對的後果
問題整理：需要你決定的核心問題
Q-R1：地下救援 beat 的道德選擇

[NEW EVENT CANDIDATE — 12角度提案]

在追捕期間，主角團仍繼續救人，但被救者舉報了她們。
這類「救了→被出賣」的 beat，你想要幾個，以及情感基調是什麼？

A：一個 beat，觸目驚心型
→ 被出賣後，晴香幾乎放棄繼續救人。需要另一個事件/角色令她重建選擇的意義。
→ 份量最重，角色衝擊最大，適合放 Act III 中段。

B：兩個小 beat，積累型
→ 第一次被出賣：晴香沉默，隊伍氣氛崩壞。
→ 第二次仍然救：沉默地選擇，無台詞，只有行動。
→ 比 A 更細緻，適合搭配其他 beat 構成節奏。

C：不做成獨立 beat，而是作為其他 beat（如尋找朱音/美食家線）的背景質感
→ 每次行動都隱含這個風險，但不特別呈現「被舉報」事件本身。

Q-R2：「情緒美食家線」的入路方式

你有冇想像過「情緒黑市」這個世界觀面向？這條線可以有不同入路：

A：完全新角色——情緒掮客（地下市場中間人）
→ 主角團需要情報或物資，被介紹去找這個人
→ 他/她掌握城市黑市情報，也掌握朱音蹤跡線索
→ 危險在於：他/她同時可以把主角團賣給帝國

B：從已有角色延伸——秋穗揭露後的衍生
→ 秋穗的科學研究和帝國的情緒採集系統有關聯
→ 秋穗（已三層坦白）可以引導主角團理解這個系統的真正運作
→ 不需新角色，用現有資源建立世界觀

C：完全唔做這條線，情緒世界黑暗面留給 Act IV
→ Act III 聚焦在追捕、凜揭露、公開處刑——不分散節奏

D：作者自訂（情緒美食家係咩對你嚟係最 intuitive 的設計？）

Q-R3：搜尋朱音的主動線——做唔做？

現有設計：朱音 113年6月底被放逐，114年5月突然回歸（timeline_raw）。

A：做主動搜尋線（2-3個搜尋嘗試beat，失敗的）
→ 需要角色對「找不找朱音」有分歧的戲份
→ 操的成長 beat 可以設計在這裡（從「不找」到「我去找」）
→ 朱音的回歸有充分的期待積累

B：唔做搜尋，改為「朱音仍活著的訊號」零碎出現
→ 主角團沒有主動找，但偶爾見到朱音曾在某地的痕跡
→ 更詭異更痛苦，朱音的存在是「未解決的傷口」而非「可追蹤的線索」
→ 功能：讓晴香帶著罪疚感前行，無法解決，只能擱置

C：搜尋線和美食家線合併——通過情報網絡知道朱音「進入過」某些黑市場所
→ 更有世界感；兩條線互相支撐

② 美夜子記憶恢復——知道自己係晴香的親姐姐
③ 凜最終崩潰，自願去掉所有記憶變成 Unit 00-Null
這三件事你想在 Outline 層設計成：

A：三個獨立 beat（E-III-01, E-III-02, E-III-03）
→ 每件事有自己的情感呼吸空間
→ 美夜子弧線可以設計得最完整

B：兩個 beat（「揭露+記憶恢復」合並，「凜自願改造」獨立）
→ 節奏稍緊，但凜的結局 beat 份量獨立

C：一個大 beat（「凜弧線高潮」）
→ 最緊湊，但可能壓縮美夜子情感空間

Q-R5：公開處刑公告（114年5月）的具體設計方向

公開處刑公告是 Act III 的第一個「大錨點」——它的設計影響整幕的張力走向：

A：公告是對主角團所有人的集體死刑令
→ 最直接，壓迫感最強
→ 從這刻開始，每次行動都是「離死亡近一步」的計時炸彈

B：公告針對晴香一人，其他人的處置方式不同（重新改造/消除/流放）
→ 主角之間的張力：「因為我，你們都危險了」
→ 晴香的孤立感+罪疚感最高峰

C：公告是針對「魔法少女」這個身份的全面消滅令，非針對特定個人
→ 帝國視角最宏觀
→ 但個人化代價可能模糊
