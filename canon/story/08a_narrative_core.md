## <a id="section-three-layer"></a>三層符號分析框架（Three-Layer Symbolic Analysis）

每個場景、物件、事件必須同時在三個層次運作：

| 層次 | 名稱 | 功能 |
|-----|------|------|
| **L1** | **氣氛層 (Atmosphere)** | 觀眾/玩家的即時感官體驗與情緒基調 |
| **L2** | **角色關係層 (Character & Relationship)** | 推進人物心理狀態與人際關係的張力 |
| **L3** | **主題層 (Theme)** | 強化「態度 vs 命運」主旋律及其四大子主題 |

**設計鐵則**：任何設計只在單一層次運作 = 敘事資源浪費。優先投資能同時服務三層的元素。

## <a id="section-attitude-destiny"></a>態度 vs 命運（核心主旋律框架）

**主旨**：「面對無法控制的、殘酷的命運，唯有『態度』是個人最後且最珍貴的自由。」

**執行原則**：製造極度殘酷、無力感的「命運」環境，以凸顯角色選擇「態度」的難度與重量。

**四大子主題**（均為主旋律的分支表達）：

| 代號 | 子主題 | 核心命題 |
|-----|--------|---------|
| **主題A** | 力量的代價 | 任何超自然力量的獲取，都伴隨人性或完整性的侵蝕與犧牲 |
| **主題B** | 完美幻象的破滅 | 批判追求「無痛、無瑕」理想狀態的非人道本質 |
| **主題C** | 身份的本質（三元概念） | 「內在態度」遠比外在形態（人類/魔法少女/屍骸）更決定存在意義 |
| **主題D** | 連結的價值 | 共情、信任、互相扶持是對抗絕望的終極抵抗形式 |

**全劇主題走向（Alpha→Beta 弧光）**：「我唔想痛所以用魔法」→「我唔用魔法都要照顧自己」。故事不以消滅痛苦為終點，而以「即使無法消滅，仍選擇照顧自己」的態度作為最終的人物答案。

## <a id="section-dark-healing"></a>黑暗療癒系統（Dark Healing System）

**定義**：「療癒不是逃離痛苦。是在痛苦中找到自由——即使命運無法改變，態度仍屬於自己。」

**敘事弧光公式**：呈現苦痛 → 穿越苦痛 → 在苦痛中提取態度的自由

**絕對禁止清單（What NOT to write）**：

| 禁止 | 原因 |
|-----|------|
| 給予虛假希望（「努力必有回報」「好人終有好報」） | 否定命運的殘酷真實 |
| 否定痛苦（「讓過去過去」「時間治癒一切」） | 架空角色苦難的重量 |
| 強迫正能量（禁止讓角色「突然想通了」） | 允許角色選擇悲傷、憤怒、沉默——這也是態度自由 |
| 廉價救贖（轉變必須有真實代價） | 無成本的頓悟等同欺騙觀眾 |

**與黑暗系的區分**：
- **黑暗系**：呈現苦難，止步於苦難。
- **黑暗療癒系**：呈現苦難 → 穿越苦難 → 提取態度自由。

**基調**：溫柔的殘酷（Gentle Cruelty）——以悲憫呈現殘酷，不是折磨觀眾，而是讓他們在角色苦難中看見自己、在角色選擇中找到力量。

## <a id="section-cost-design"></a>代價設計原則（Cost Visibility Principles）

**普遍規則**：所有魔法少女系統利益皆有業力稅。代價不是抽象的——必須感官化、精確化、累積化。

**三種代價表現模型**：

| 模型 | 機制 | 例子 |
|-----|------|------|
| **感官喪失模型** | 過度使用特定情緒 → 喪失對應感知能力 | 過度使用希望 → 味覺消失；過度使用憤怒 → 無法感受平靜 |
| **靈魂延遲模型** | 戰鬥後意識暫時脫離肉身 → 短暫靈魂出竅的第三人稱視角 → 以物理/聲音衝擊暴力歸位 | 看著自己的手拿杯子卻感覺不到溫度；意識回歸時：刺耳耳鳴 + 針刺般肉體疼痛 |
| **共振失衡模型** | 每次變身製造魔法自我與人類自我的頻率失同步 → 逐漸加深的疏離感 | 角色在人群中感覺自己「不對頻」；鏡像映照失真 |

**累積規則**：代價不會重置或治癒——它們在整個 20 年系統運作期間不斷累積，直接餵入緋潮閾值突破。
