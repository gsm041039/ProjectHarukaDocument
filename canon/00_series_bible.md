## <a id="section-logline"></a>Logline & Premise

**核心 Logline**：
當歌手少女雨宮晴香發現自己在五歲時創造了整個「魔法世界」，她必須在 20 年的時間折返後，選擇繼續修正這個不完美的現實，還是接受自己是災難源頭並承擔代價。

**Premise**：
在一個情緒可以被量化、儲存、交易的[帝國](02_glossary.md#term-empire)中，魔法少女們以為自己是淨化負面情緒的英雄。但真相是：她們只是將痛苦從「可見」轉移到「不可見」的[集體潛意識](02_glossary.md#term-collective-unconscious)。當晴香發現自己在五歲時為了救回死去的摯友美夜子，無意中改變了整個世界線（[Alpha](02_glossary.md#term-alpha-line) → [Beta](02_glossary.md#term-beta-line)），創造了這個充滿魔法、情緒科技與屍骸的「高魔世界」——她必須面對：自己不是救世主，而是災難的創造者。

**核心矛盾**：
- **Alpha 線**：低魔世界，美夜子與母親花子死於黑奏攻擊
- **Beta 線**：晴香改變現實創造的世界，魔法系統、情緒科技、魔法屍骸皆源於此
- **20 年滯留**：晴香改變現實後因「因果債務」困在集體潛意識 20 年，暗面人格[「夕」](02_glossary.md#term-yu)用她身體守護世界

## <a id="section-ultimate-purpose"></a><a id="section-dark-healing"></a>終極目的：治癒（Dark Healing）

> 這是一個「[黑暗治癒系](02_glossary.md#term-dark-healing)」故事。所有的殘酷、痛苦與絕望，都服務於一個終極目標——**讓觀眾透過故事得到治癒**。

**治癒主張**：`Dark Healing` 的實作要點如下（完整術語口徑見 [Glossary](02_glossary.md#term-dark-healing)）。
- 治癒不是逃避痛苦，而是在痛苦中找到自由
- 唯有經歷真實的黑暗，光明才有重量
- 觀眾透過見證角色在絕望中選擇態度，獲得「我也可以這樣面對困境」的力量

**三個關鍵治癒時刻**：
1. **美夜子的大哭** — 情緒釋放的治癒，允許自己脆弱
2. **朱音、操的有尊嚴死亡** — 態度選擇的治癒，即使面對死亡仍選擇如何離開
3. **靈魂共鳴** — 連結延續的治癒，逝者的態度以精神形式傳承

## <a id="section-core-theme"></a>總主題：態度 vs. 命運

在不可控的、殘酷的命運面前，唯有「[態度](02_glossary.md#term-attitude-vs-fate)」是個體最後的、最珍貴的自由。

**四個核心子主題**：

| 子主題 | 內容 | 代表角色 |
|-------|------|---------|
| A: 力量的代價 | 任何超凡力量伴隨對人性的侵蝕與獻祭 | 所有魔法少女 |
| B: 完美的幻象 | 批判對「無痛苦、無瑕疵」追求的非人道本質 | 操、黑奏 |
| C: 身份的本質 | 內在「態度」比外在「形態」更能定義存在 | 朱音、美夜子 |
| D: 連結的價值 | 共情、信賴與守望是抵抗絕望的最終力量 | 晴香、朔 |

**核心敘事工具**：
- **[膠布哲學](02_glossary.md#term-band-aid-philosophy)**：Beta 線是貼在 Alpha 傷口上的巨大膠布，二十年後發炎為緋潮
- **[情緒守恆定律](01_world_rules_and_costs.md#rule-emotion-conservation)**：本檔只使用其命題效果（債務必回流），條文解釋留在 World Rules
- **[三位一體光譜](01_world_rules_and_costs.md#rule-trinity-spectrum)**：本檔只使用其敘事效果（身份邊界可滑移），分層條件留在 World Rules

## <a id="section-opposition-forces"></a>反對力量的六維分析

晴香的真正敵人不只是黑奏，而是**存在架構本身**：

| 維度 | 內容 | 具體呈現 |
|-----|------|---------|
| 1. 制度 | 帝國/消費主義 | 物化與消耗魔法少女 |
| 2. 規則 | 情緒守恆/三位一體光譜 | 絕對的物理法則 |
| 3. 命運 | Alpha 線修正意志 | 緋潮作為修正力量 |
| 4. 心理病灶 | 角色內心創傷/執念 | 自我毀滅傾向 |
| 5. 世界機制 | 維多利亞之淚/認知濾鏡 | 制度化的欺騙 |
| 6. 錯誤方法論 | 黑奏/夕用錯方法 | 修正派 vs 接納派 |

**核心洞察**：晴香幾乎舉世皆敵——要對抗社會、物理法則、命運、自己的隊友與自己的錯誤理念。

> **在無法戰勝的反對力量面前，晴香依然選擇了她的態度——這就是治癒的本質。**

### <a id="section-world-bug"></a>世界的 Bug（設計缺陷）

本作把「世界的錯誤」定義為一個結構性缺陷，而非單一惡人：  
人類可以在不感受他人痛苦的情況下做出傷害行為，令制度、技術與暴力容易結盟。黑奏把這個缺陷推到極端，提出[共振地獄](02_glossary.md#term-resonance-hell)作為修正方案；晴香則選擇另一條路——不以強制透明抹除自由，而是在不確定中承擔並連結。

此段只作系列命題入口；規則條文見 [World Rules](01_world_rules_and_costs.md)，角色方法論見 [黑奏](03_characters/antagonist.md) 與 [晴香](03_characters/haruka.md)。

## <a id="section-audience-experience"></a>受眾體驗設計

### 資訊控制：四幕資訊差

| 幕 | 觀眾狀態 | 設計目標 |
|---|---------|---------|
| 第一幕 | 與晴香一同相信「魔法少女=希望使者」 | 同步誤導——完全代入王道氛圍 |
| 第二幕 | 經歷凜的犧牲、系統真相揭露 | 認知崩壞——英雄敘事崩塌 |
| 第三幕 | 看似最終決戰以晴香失敗告終 | 偽高潮反轉——重思「勝負之外」 |
| 第四幕 | 晴香覺醒但失去記憶 | 永恆隔閡——觀眾懷著記憶看著遺忘一切的她 |

### 情感節奏

**起（虛假的希望）** → **承（代價的揭露）** → **轉（偽高潮/存在主義拷問）** → **合（態度的選擇/帶著傷痕的和解）**

## <a id="section-visual-philosophy"></a>視覺哲學

### 核心視覺矛盾：[溫柔的殘酷](02_glossary.md#term-gentle-cruelty)

使用最唯美、詩意、可愛的視覺語言，呈現最殘酷的命運與痛苦。讓「美麗」成為「痛苦」的放大器。

**範例**：少女崩潰不是猙獰哭號，而是在午後陽光中平靜微笑，眼中流下結晶化淚珠，墜地時發出心碎的碎裂聲。

### 核心美學：[破碎的美學](02_glossary.md#term-aesthetics-of-the-flawed)

不完整性、傷痕、裂痕本身蘊含淒涼美感。參照瓷器龜裂（哥窯開片）與日本金繼工藝——裂痕不是缺陷，是獨特的歷史勳章。

### 核心詰問：何為真實？

世界存在兩層：
- **表象現實**（社會規範、物理法則、清醒意志）
- **底層真實**（靈魂本質、內在創傷、集體潛意識）

### 五大視覺法則

| 法則 | 內容 |
|-----|------|
| [質化](02_glossary.md#term-law-of-substance) | 情緒擁有物理屬性（質量、溫度、質感） |
| [腐蝕](02_glossary.md#term-law-of-corruption) | 靈魂如瓷器般龜裂，碎片剝落結晶化 |
| 熵增 | 有序情緒趨向混沌態（虹彩色油污般黏稠） |
| [鏡像](02_glossary.md#term-mirror-law) | 鏡子映照靈魂真實狀態，魔法在鏡中無倒影 |
| 生理排斥 | 調用集體潛意識引發精神/感官/肉體排斥反應 |

## <a id="section-creative-execution"></a>創作執行原則

### 治癒敘事的禁忌

- **禁止虛假希望** — 不提供「努力就會成功」雞湯
- **禁止否定痛苦** — 不說「時間會治癒一切」
- **禁止強制正向** — 允許角色選擇悲傷/憤怒/沉默
- **禁止廉價救贖** — 轉變必須付出真實代價

### 導演核心原則（吸收自 CAN-08）

**象徵意義三層金字塔**：
1. **底層**：故事/角色層面的功能性作用
2. **中層**：主題/哲學層面的象徵意義
3. **頂層**：觀眾體驗層面的情感衝擊

**Alpha/Beta 演出原則**：
- Alpha 線殘影不要過早揭示全貌——讓觀眾和角色一起困惑
- 感官優先於視覺：優先聽覺、嗅覺、觸覺；保留視覺殘影給關鍵時刻
- 角色不會說「這是 Alpha 線記憶」，只會說「我係咪癲咗」

### <a id="section-narrative-promises"></a>敘事承諾（不可稀釋）

以下承諾是從母文檔收斂出的「硬約束」，重寫任何章節都不可破壞：

1. **不美化痛苦，但不迴避痛苦**：痛苦是存在的一部分，不是可一鍵刪除的雜訊。
2. **不把「修正世界」當答案**：故事的答案是「承擔 + 連結」，不是「重置 + 抹除」。
3. **不把角色工具化**：每個死亡或犧牲必須保留角色主體性與選擇性。
4. **不把制度邪惡扁平化**：帝國是結構性暴力，不是單一反派個人癲狂。
5. **不把結局寫成勝負論**：最終命題是「如何活」，不是「誰打贏」。

### <a id="section-tone-guardrails"></a>語氣與內容護欄

- 涉及創傷、解離與身體場景時，描寫重心必須放在**心理意義**與**敘事功能**，避免獵奇化。
- 涉及角色崩壞場景時，禁止用「爽感」語言包裝，必須維持悲劇倫理。
- 任何「看似奇蹟」的橋段，都要保留代價、後果與長尾影響。

### 暗主題：最終解答

所有角色用自己行動給出的答案——「應該做自己認為最值得做的事」：

- **晴香**：擁抱並承擔所有人的痛苦
- **美夜子**：珍惜眼前連結，以新身份活下去
- **朔**：解放被體制囚禁的靈魂
