## <a id="section-logline"></a>Logline & Premise

**核心 Logline**：
當歌手少女雨宮晴香發現自己在五歲時創造了整個「魔法世界」，她必須在 20 年的時間折返後，選擇繼續修正這個不完美的現實，還是接受自己是災難源頭並承擔代價。

**Premise**：
在一個情緒可以被量化、儲存、交易的[帝國](02_glossary.md#term-empire)中，魔法少女們以為自己是淨化負面情緒的英雄。但真相是：她們只是將痛苦從「可見」轉移到「不可見」的[集體潛意識](02_glossary.md#term-collective-unconscious)。當晴香發現自己在五歲時為了救回死去的摯友美夜子，無意中改變了整個世界線（[Alpha](02_glossary.md#term-alpha-line) → [Beta](02_glossary.md#term-beta-line)），創造了這個充滿魔法、情緒科技與屍骸的「高魔世界」——她必須面對：自己不是救世主，而是災難的創造者。

**核心矛盾**：
- **Alpha 線**：低魔世界，美夜子與母親花子死於黑奏攻擊
- **Beta 線**：晴香改變現實創造的世界，魔法系統、情緒科技、魔法屍骸皆源於此
- **20 年滯留**：晴香改變現實後因「因果債務」困在集體潛意識 20 年，暗面人格[「夕」](02_glossary.md#term-yu)用她身體守護世界

**世界本體論前提（Ontological Premise — CDL-248）**：本故事處於一個**「唯識宇宙（Consciousness-Centric Universe）」**——靈魂與意志是現實的唯一地基。物理世界並非客觀死物，而是由億萬靈魂的集體意志所撐起的**脆弱共識**。因此，所有的魔法、屍骸化與世界災難，本質上都是**靈魂爭奪「現實定義權」的物理顯化**。*See also: [World Rules: 第一公理](01_world_rules_and_costs.md#rule-consciousness-centric-universe)*

## <a id="section-ultimate-purpose"></a><a id="section-dark-healing"></a>終極目的：治癒（Dark Healing）

> 這是一個「[黑暗治癒系](02_glossary.md#term-dark-healing)」故事。所有的殘酷、痛苦與絕望，都服務於一個終極目標——**讓觀眾透過故事得到治癒**。

**治癒主張**：`Dark Healing` 的實作要點如下（完整術語口徑見 [Glossary](02_glossary.md#term-dark-healing)）。
- 治癒不是逃避痛苦，而是在痛苦中找到自由
- 唯有經歷真實的黑暗，光明才有重量
- 觀眾透過見證角色在絕望中選擇態度，獲得「我也可以這樣面對困境」的力量

**三個關鍵治癒時刻**：
1. **美夜子的大哭** — 情緒釋放的治癒，允許自己脆弱
2. **朱音、操的有尊嚴死亡** — 態度選擇的治癒，即使面對死亡仍選擇如何離開
3. **靈魂共鳴** — 連結延續的治癒，逝者的態度以精神形式傳承

### <a id="section-healing-clarification"></a>治癒的更精確定義

本作所說的「治癒」，不是問題被消除，也不是角色被修好。
真正的治癒，是角色在被看見、被承認之後，仍然願意靠自己踏出下一步。

這份力量不來自世界忽然變好，也不來自外界替角色解決一切。
它來自角色對痛苦的理解、對自身處境的接受，以及在絕望中仍保留態度選擇的能力。

因此，本作的治癒敘事必須同時成立兩件事：
- 人可以嘗試依賴別人、接受別人的火種與連結
- 但真正令人繼續前進的，始終是自己內心對痛苦的態度

## <a id="section-core-theme"></a>總主題：態度 vs. 命運

在不可控的、殘酷的命運面前，唯有「[態度](02_glossary.md#term-attitude-vs-fate)」是個體最後的、最珍貴的自由。

**四個核心子主題**：

| 子主題 | 內容 | 代表角色 |
|-------|------|---------|
| A: 力量的代價 | 任何超凡力量伴隨對人性的侵蝕與獻祭 | 所有魔法少女 |
| B: 完美的幻象 | 批判對「無痛苦、無瑕疵」追求的非人道本質 | 操、黑奏 |
| C: 身份的本質 | 內在「態度」比外在「形態」更能定義存在 | 朱音、美夜子 |
| D: 連結的價值 | 共情、信賴與守望是抵抗絕望的最終力量 | 晴香、朔 |

### <a id="section-story-direction"></a>故事真正方向

本作的故事方向，不是以「打敗敵人」作為終極目的。
戰鬥、敵對勢力、世界真相與災難升級，全部都服務於一個更核心的命題：

> 角色與觀眾要慢慢學識分辨——什麼是甜，什麼是真；
> 什麼是逃避，什麼是真正能支撐人活下去的力量。

因此，本作更接近一個「在甜美逃避世界中，重新學習如何活下去」的故事。
一群帶著各自痛苦的人，活在一個以甜美與魔法包裝痛苦的世界裡，慢慢學識唔再只靠假糖活，而係靠真實連結同自己內心繼續行。

**核心敘事工具**：
- **[膠布哲學](02_glossary.md#term-band-aid-philosophy)**：Beta 線是貼在 Alpha 傷口上的巨大膠布，二十年後發炎為緋潮
- **[情緒守恆定律](01_world_rules_and_costs.md#rule-emotion-conservation)**：本檔只使用其命題效果（債務必回流），條文解釋留在 World Rules
- **[三位一體光譜](01_world_rules_and_costs.md#rule-trinity-spectrum)**：本檔只使用其敘事效果（身份邊界可滑移），分層條件留在 World Rules

## <a id="section-opposition-forces"></a>反對力量的六維分析

晴香的真正敵人不只是黑奏，而是**存在架構本身**：

| 維度 | 內容 | 具體呈現 |
|-----|------|---------|
| 1. 制度 | 帝國/消費主義 | 物化與消耗魔法少女 |
| 2. 規則 | 情緒守恆/三位一體光譜 | 絕對的物理法則 |
| 3. 命運 | Alpha 線修正意志 | 緋潮作為修正力量 |
| 4. 心理病灶 | 角色內心創傷/執念 | 自我毀滅傾向 |
| 5. 世界機制 | 維多利亞之淚/認知濾鏡 | 制度化的欺騙 |
| 6. 錯誤方法論 | 黑奏/夕用錯方法 | 強行抹除式 vs 共情承擔式 |

**核心洞察**：晴香幾乎舉世皆敵——要對抗社會、物理法則、命運、自己的隊友與自己的錯誤理念。

> **在無法戰勝的反對力量面前，晴香依然選擇了她的態度——這就是治癒的本質。**

### <a id="section-world-bug"></a>世界的 Bug（設計缺陷）

本作把「世界的錯誤」定義為一個結構性缺陷，而非單一惡人：  
人類可以在不感受他人痛苦的情況下做出傷害行為，令制度、技術與暴力容易結盟。黑奏把這個缺陷推到極端，提出[共振地獄](02_glossary.md#term-resonance-hell)作為修正方案；晴香則選擇另一條路——不以強制透明抹除自由，而是在不確定中承擔並連結。

此段只作系列命題入口；規則條文見 [World Rules](01_world_rules_and_costs.md)，角色方法論見 [黑奏](03_characters/aya.md#section-kurokane) 與 [晴香](03_characters/haruka.md)。

## <a id="section-audience-experience"></a>受眾體驗設計

### 資訊控制：四幕資訊差

| 幕 | 觀眾狀態 | 設計目標 |
|---|---------|---------|
| 第一幕 | 與晴香一同相信「魔法少女=希望使者」 | 同步誤導——完全代入王道氛圍 |
| 第二幕 | 經歷凜的犧牲、系統真相揭露 | 認知崩壞——英雄敘事崩塌 |
| 第三幕 | 看似最終決戰以晴香失敗告終 | 偽高潮反轉——重思「勝負之外」 |
| 第四幕 | 晴香覺醒但失去記憶 | 永恆隔閡——觀眾懷著記憶看著遺忘一切的她 |

### 情感節奏

**起（虛假的希望）** → **承（代價的揭露）** → **轉（偽高潮/存在主義拷問）** → **合（態度的選擇/帶著傷痕的和解）**

**See also**: [Story Outline](05_story_outline_canon.md)

### <a id="section-emotional-curve"></a>核心情緒曲線

本作希望觀眾／玩家經歷的，不是單一情緒，而是一條逐步加深的情緒曲線：

1. **先被吸引**
   被 Beta 世界的甜美、繁華、魔法、偶像感與有趣變體吸引。

2. **再感到不安**
   開始察覺這個世界雖然美，但美得不自然；魔法本身也帶有不合理與異質的不安。

3. **甜下見黑**
   甜美時刻突然裂開，露出底下真正存在的黑暗、身體代價、情緒崩壞、羞恥與心理恐怖。

4. **再理解角色的痛苦**
   觀眾最終不只是理解設定，而是理解角色為何逃避、為何羞恥、為何需要糖衣。

5. **最後留下苦中有暖的力量感**
   本作不提供廉價的完美希望，但希望觀眾在離開故事時，帶著一種苦中有暖的力量感：
   即使不能被完全拯救，即使世界仍然殘酷，人仍然可以帶著傷、帶著被看見的記憶，繼續行下去。

## <a id="section-visual-philosophy"></a>視覺哲學

### <a id="section-world-texture"></a>世界質感：甜與不安共存的都市

Beta 世界不是單純「夠甜、夠靚、夠令人接受」所以危險。
更準確地說，它是一個**甜與不安共存，而且不安正慢慢長出形體的都市**。

這個世界有繁華、有娛樂、有便利、有偶像與魔法帶來的吸引力，也有令人想停留其中的日常慰藉。
但同時，它亦被不合理的魔法、情緒剝削、心理恐怖，以及正慢慢侵蝕日常的歌德式異質感所包圍。

此種世界質感在空間上呈現為：
- **日區**：光鮮、包裝完整、歌德元素被壓低或遮掩，代表體制與城市仍然成功維持表面秩序
- **夜區**：老香港質感逐漸被歌德元素侵蝕，代表 Beta 真相慢慢露出
- **魔法本身**：並不只是夢幻力量，而是一種本身就帶有不合理性與不安感的存在

歌德元素在本作中，不只是裝飾風格，而是像活體細胞一樣，慢慢入侵、覆蓋、改寫香港元素的異質存在。

### 核心視覺矛盾：[溫柔的殘酷](02_glossary.md#term-gentle-cruelty)

使用最唯美、詩意、可愛的視覺語言，呈現最殘酷的命運與痛苦。讓「美麗」成為「痛苦」的放大器。

**範例**：少女崩潰不是猙獰哭號，而是在午後陽光中平靜微笑，眼中流下結晶化淚珠，墜地時發出心碎的碎裂聲。

### 核心美學：[破碎的美學](02_glossary.md#term-aesthetics-of-the-flawed)

不完整性、傷痕、裂痕本身蘊含淒涼美感。參照瓷器龜裂（哥窯開片）與日本金繼工藝——裂痕不是缺陷，是獨特的歷史勳章。

### 核心詰問：何為真實？

世界存在兩層：
- **表象現實**（社會規範、物理法則、清醒意志）
- **底層真實**（靈魂本質、內在創傷、集體潛意識）

### 五大視覺法則

| 法則 | 內容 |
|-----|------|
| [情緒具象化](02_glossary.md#term-law-of-substance) | 極端情緒突破肉體極限，以物理形式顯現 |
| [靈魂碎裂](02_glossary.md#term-law-of-corruption) | 心之器如瓷器般龜裂，碎片剝落結晶化 |
| 意識解離 | 自我邊界消融，有序意識趨向混沌態（虹彩色油污般黏稠） |
| [鏡像](02_glossary.md#term-mirror-law) | 鏡子映照靈魂真實狀態，魔法在鏡中無倒影 |
| 生理排斥 | 調用集體潛意識引發精神/感官/肉體排斥反應 |

### <a id="section-psychology-embodiment"></a>心理學的具現化

本作其中一個核心創作方法，是把心理學概念、情緒機制、創傷反應、理想我與集體潛意識，具現化成魔法、都市現象與世界規則。

因此，本作不是單純用「隱喻」談心理學，也不是直接用理論解說角色。
而是讓觀眾先透過劇情、魔法、身體變化、都市異象與角色行為去感受，然後再逐步理解——原來這些超自然現象，本質上都對應著真實的人類心理結構。

這使本作既能維持奇幻與恐怖感，也能讓觀眾更直觀地理解創傷、逃避、羞恥、自我否定與連結的價值。

## <a id="section-creative-execution"></a>創作執行原則

### 治癒敘事的禁忌

- **禁止虛假希望** — 不提供「努力就會成功」雞湯
- **禁止否定痛苦** — 不說「時間會治癒一切」
- **禁止強制正向** — 允許角色選擇悲傷/憤怒/沉默
- **禁止廉價救贖** — 轉變必須付出真實代價

### 導演核心原則（吸收自 CAN-08）

**象徵意義三層金字塔**：
1. **底層**：故事/角色層面的功能性作用
2. **中層**：主題/哲學層面的象徵意義
3. **頂層**：觀眾體驗層面的情感衝擊

**Alpha/Beta 演出原則**：
- Alpha 線殘影不要過早揭示全貌——讓觀眾和角色一起困惑
- 感官優先於視覺：優先聽覺、嗅覺、觸覺；保留視覺殘影給關鍵時刻
- 角色不會說「這是 Alpha 線記憶」，只會說「我係咪癲咗」

### <a id="section-narrative-promises"></a>敘事承諾（不可稀釋）

以下承諾是從母文檔收斂出的「硬約束」，重寫任何章節都不可破壞：

1. **不美化痛苦，但不迴避痛苦**：痛苦是存在的一部分，不是可一鍵刪除的雜訊。
2. **不把「修正世界」當答案**：故事的答案是「承擔 + 連結」，不是「重置 + 抹除」。
3. **不把角色工具化**：每個死亡或犧牲必須保留角色主體性與選擇性。
4. **不把制度邪惡扁平化**：帝國是結構性暴力，不是單一反派個人癲狂。
5. **不把結局寫成勝負論**：最終命題是「如何活」，不是「誰打贏」。

### <a id="section-tone-guardrails"></a>語氣與內容護欄

- 涉及創傷、解離與身體場景時，描寫重心必須放在**心理意義**與**敘事功能**，避免獵奇化。
- 涉及角色崩壞場景時，禁止用「爽感」語言包裝，必須維持悲劇倫理。
- 任何「看似奇蹟」的橋段，都要保留代價、後果與長尾影響。

### 暗主題：最終解答

所有角色用自己行動給出的答案——「應該做自己認為最值得做的事」：

- **晴香**：擁抱並承擔所有人的痛苦
- **美夜子**：珍惜眼前連結，以新身份活下去
- **朔**：解放被體制囚禁的靈魂

## <a id="section-core-positioning"></a>作品核心定位（Core Positioning）

《魔法少女晴香物語》不是單純的黑暗魔法少女作品，也不是單純以殘酷衝擊觀眾的悲劇作品。
它的核心，是一個以「黑暗治癒（Dark Healing）」為目標的故事：透過甜美、夢幻、魔法與都市繁華包裝痛苦，讓角色與玩家逐步學會分辨什麼是逃避，什麼是真實，並最終理解——在面對痛苦與困難時，外界可以崩壞、世界可以扭曲，但一個人面對痛苦的態度，才是最終無法被奪走的力量。

本作的治癒，不是「問題被消除」，也不是「角色被修好」。
本作所說的治癒，是：角色在被看見、被承認之後，仍然願意靠自己踏出下一步；同時也明白，嘗試依賴別人、接受別人的火種，並不等於脆弱。

---

## <a id="section-world-nature"></a>世界本質（Nature of the World）

Beta 世界不是單純「夠甜、夠靚、夠令人接受」所以危險。
更準確地說，它是一個**甜與不安共存，而且不安正慢慢長出形體的都市**。

這個世界有繁華、有娛樂、有魔法、有商品、有吸引人的美感，也有令人想要停留其中的日常便利與情緒慰藉。
但同時，它亦被不合理的魔法、情緒剝削、心理恐怖、以及正在侵蝕日常的歌德式異質感所包圍。
它不是純粹的崩壞末日，而是一個仍在正常運作、卻正慢慢走向崩壞與侵蝕的病態都市。

Beta 世界最可怕的地方，不在於它完全虛假；而在於它確實承載了人內心真實的願望——想被愛、想逃離痛苦、想活下去、想被理解。
正因為它有一部分是真，所以它比單純的謊言更危險，也更令人難以離開。

---

## <a id="section-true-story-direction"></a>故事真正方向（True Story Direction）

本作的故事方向，不是以「打敗敵人」作為最終目標。
戰鬥、敵對勢力、世界真相與災難升級，都是敘事中的重要結構，但它們服務的核心，不是勝利，而是**辨認**。

角色與玩家真正要學會的，是：
- 分辨什麼是逃避性的甜，什麼是真實的暖；
- 分辨什麼是自我否定、羞恥與創傷驅動的選擇；
- 分辨在一個扭曲世界中，自己究竟是被推著活，還是仍然保有面對痛苦的主體性。

因此，本作更接近一個「在甜美逃避世界中，重新學習如何活下去」的故事。
一群帶著各自痛苦的人，活在一個以甜美與魔法包裝痛苦的世界裡，慢慢學識唔再只靠假糖活，而係靠真實連結同自己內心繼續行。

---

## <a id="section-thematic-core-extended"></a>主題核心（Thematic Core）

本作的主題，不是單純「世界很殘酷」。
本作真正的主題是：

> 外在會改變，世界會扭曲，甜可以成為陷阱；
> 但人在面對痛苦時的態度，才是最後唔可以被奪走的力量。

這裡的「態度」，不是空泛的正能量，而是一種心理學上的主體性：
即使人不能控制自己遭遇了什麼，也未必能立即改變世界，但仍然可以在理解自己痛苦的基礎上，選擇如何面對它、承受它、並繼續向前。

因此，本作的黑暗治癒，不是靠世界變好，而是靠角色在痛苦中重新獲得對自己的理解，並在被看見之後，願意重新行下去。

---

## <a id="section-true-warmth-vs-false-sweetness"></a>真暖 vs 假甜（True Warmth vs False Sweetness）

本作最核心的情感矛盾，是「真暖」與「假甜」的對立。

### 假甜

假甜不是單純虛假的東西。
它往往是好看、舒服、令人想依賴、甚至有一部份真實情感寄託的存在。
它可以是魔法少女的夢幻形象、情緒商品、變體科技、都市繁華、被美化的關係想像，也可以是一切令角色與玩家短暫忘記痛苦的糖衣。

假甜危險的地方，在於它會讓人活下去，但同時阻止人真正面對痛苦。
它是一種甜美的延緩，一種有代價的逃避。

### 真暖

真暖則永遠不是宏大、神聖、拯救式的。
真暖往往非常小、非常廉價、非常日常：一塊膠布、一粒糖、一次幫忙收拾崩潰後的爛攤子、一句真正承認對方痛苦的說話、一個可以暫時坐低呼吸的地方。

真暖不會立即改變世界，也不會消除痛苦。
但它會讓人明白：自己不是完全孤立的，自己仍然值得被看見，而這份被承認，足以成為重新前進的火種。

---

## <a id="section-player-experience-curve"></a>情緒體驗目標（Intended Player/Reader Experience）

本作希望帶給玩家／讀者的，不是單一情緒，而是一條完整的情緒曲線：

1. **先被吸引**
   Beta 世界應先呈現出它迷人、有趣、繁華、夢幻的一面，令玩家想探索、想停留、想再多看一眼。

2. **再感到不安**
   玩家會慢慢察覺：這個世界雖然美，但美得不自然；魔法雖然迷人，但本身就帶有不合理與異質的不安。

3. **再被黑暗刺穿**
   甜美時刻會突然裂開，露出底下真正存在的黑暗、羞恥、代價與心理恐怖。
   本作必須反覆使用「甜下見黑」的節奏語法，令玩家感受到：甜與黑不是分開存在，而是疊在一起。

4. **再理解角色的痛苦**
   玩家最終不只是理解設定，而是理解角色為何逃避、為何羞恥、為何需要糖衣、為何難以面對自己。

5. **最後留下苦中有暖的力量感**
   本作不提供廉價的完美希望，但希望讓玩家在離開作品時，帶著一種苦中有暖的力量感：
   即使不能被完全拯救，即使無法得到理想結局，人仍然可以帶著傷、帶著連結、帶著被看見的記憶，繼續行下去。

---

## <a id="section-beta-as-sin-civilization"></a>Beta 世界與晴香原罪（Beta as Civilization of Sin）

Beta 世界不只是設定上的平行現實，也不只是魔法存在的場域。
它本質上是由晴香創造的世界，是她原罪所長出的文明。

因此，Beta 世界中的痛苦、甜美、商品化、逃避、繁華與侵蝕，全部都與晴香的罪孽有根本性的關係。
這不代表 Beta 世界全然虛假，反而正正相反：它之所以如此有說服力、如此有魅力、如此真實，是因為它承載了真實願望——只是以一種扭曲、失衡、帶著代價的方式被實現。

晴香不是單純背住秘密的主角。
她是背住整個世界的人。
她的重量，既是世界級的陰影，也是關係級的刺穿。
平時，這份罪孽像重力一樣無處不在；真正令玩家扎心的，卻永遠是它如何在關係中被揭開、被承認、被直視。

---

## <a id="section-ending-temperature"></a>結局溫度（Ending Temperature）

本作的結局氣質，不應是勝利式的光明，也不應是純粹冷酷的絕望。
它應該是：

- **主：殘酷，但仍然相信有些東西值得守住**
- **副：哀傷，但溫柔**

整體而言，結局可以留下溫暖，但這份暖不一定完整落在某一個人身上。
對某些角色而言，可能仍然有歸屬、有延續、有被承接的可能；
但對晴香而言，她不可能擁有真正意義上的「好結局」。

晴香可以擁有的暖，不是被拯救，而是——即使在痛苦之中，她仍然在做正確的事。
那不是幸福，也不是釋放；而是一種悲傷、扎心、但有重量的贖罪。

---

## <a id="section-final-position"></a>作品總結（Final Position）

《魔法少女晴香物語》是一個關於逃避、羞恥、創傷、自我否定，以及如何在被看見之後重新前進的故事。
它以甜美、夢幻、魔法、都市繁華吸引玩家，再以不安、侵蝕、心理恐怖與情緒代價慢慢刺穿這層糖衣。

它最終想留下的，不是對世界的樂觀想像，而是一種更難、更苦、但更真實的希望：

> 世界可以絕望，但「被看見」之後仍能靠自己前進，而你可以嘗試唔再一個人。
