## <a id="section-reveal-timeline"></a>核心揭露時序與策略

### 三層揭露結構

| 揭露層 | 內容 | 時刻 | 觀眾狀態 |
|--------|------|------|---------|
| **L1：表層敘事** | 魔法少女打怪、少女日常、隊友友誼 | Act I ~ II 前期 | 以為故事是傳統王道 |
| **L2：系統真相** | 魔法的代價、屍骸化、情緒守恆 | Act II 中後期 | 開始懷疑世界規則 |
| **L3：存在真相** | Alpha 線、晴香創世、時間因果 | Act III 後期 ~ Act IV | 世界觀完全翻轉 |

### 「感激成毒藥」伏筆設計 — 五段式情緒守恆揭露結構

| 階段 | 機制 | 現象 | 作者意圖 |
|------|------|------|---------|
| **階段 1** | 隱形揭示 | 沒有明確說明，但透過細節累積（疲勞、低血糖、冷寂） | 觀眾感受「不對勁」但未能命名 |
| **階段 2** | 命名危機 | 第一次有角色明確說「代價」；晴香開始思考 | 從「不對勁」升級為「被欺騙」 |
| **階段 3** | 系統曝光 | 秋穗或黑奏直接解釋「魔法 = 情緒轉移」 | 規則層面的真相揭露 |
| **階段 4** | 代價視覺化 | [緋潮](02_glossary.md#term-scarlet-tide) 開始出現；倫理選擇變成不可避免 | 從「知識」變成「活生生的視覺」 |
| **階段 5** | 終極反轉 | Alpha 線真相 + 因果逆流；觀眾意識到「感激（晴香的願望）= 毒藥（系統崩壞）」 | 王道敘事完全顛覆 |

## <a id="section-key-scenes"></a>五個關鍵場景執行指引

### 場景 A：紫音「暴食斷頭台」

**時序**：114 年 5 月恐怖家家酒第 10 天

**功能**：紫音從「被黑奏誘惑的成癮者」轉變為「選擇給予而非掠奪」的分水嶺

**關鍵台詞與分鏡**：

```
粵語對白：
黑奏：「妳好鍾意食嘅野，我淨係得一啲。不過… 如果妳樂意，我可以同妳分享。」
      （伸出毒品盛宴）
紫音：「（抵抗）……無…… 無…… （突然轉向小光幻象） 不…… 唔可以……」
      （推開盛宴）
黑奏：「嗯？」
紫音：「（對著虛空的小光）對唔起… 收返埋啦。妳啲野食無味道……
      （轉向隊友） 妳哋知道，最好食嘅嘢，係邊個嗎？」
      （眼淚滑下，露出微笑）
      「……係同中意嘅人一齊食嘅時候。」
```

**色彩規格**：
- 前置：過飽和金色與橙色（代表毒品的誘人視覺）
- 誘惑峰值：顏色達到最飽和（RGB 255, 200, 0 左右）
- 轉折瞬間：冷藍火焰瞬間吞沒場景（對比極端）
- 結局：溫暖白光（清醒與原諒）

**時序設計**：
- 0:00 - 3:00：黑奏誘惑（懶散、緩慢）
- 3:00 - 3:30：紫音抵抗（節奏加快、心跳聲入場）
- 3:30 - 5:00：紫音的覺醒獨白（近乎靜止；只有微弱呼吸聲）
- 5:00 - 6:00：背景音樂迴歸；紫音擁抱隊友（光線柔和）

**導演要點**：
- 不是「紫音打敗黑奏」而是「紫音選擇了自己想要的活法」
- 黑奏此刻不應顯得邪惡，而是「真誠的誘惑」（更危險）
- 小光的幻象應該是紫音內心的投射，而非外部幽靈

### 場景 B：操「鋼鐵獨舞」

**時序**：114 年 5 月恐怖家家酒第 13 天

**功能**：操從「完美指揮官」的面具下解脫，第一次允許自己「失控」

**關鍵台詞與分鏡**：

```
粵語對白：
操：（被控制狀態下，聲音機械）「……絲線……掌控…… 我無得揀……」
    （突然爆發） 唔係！
黑奏：「妳……」
操：「（絲線開始自我切割） 我會揀！ 我會揀失控…… 我會揀倒下……
    （對彩喊，聲音最大的時刻） Aya！ 隨便跑！ 跌倒都唔緊要！
    （絲線徹底分裂） 因為…… 因為我會接住妳……」
```

**視覺規格**：
- 控制狀態：完全對稱的舞蹈，肢體精準但僵硬；絲線清晰可見（銀色）
- 覺醒瞬間：絲線開始不規則抖動；假髮逐片脫落（展現出被強制改造的痕跡）
- 衣物撕裂：進行式撕裂（不是瞬間完成），過程中露出身體上的傷疤或改造痕跡
- 最終姿勢：雙腿跪地，雙臂張開（與之前精確控制的姿態完全對比）

**慢動作特效**：
- 絲線被她自己的身體切斷的那一刻需要超慢動作（0.2 倍速）
- 假髮掉落的每一片都應該被獨立渲染
- 鮮血（如有）應該是最後才出現的視覺元素，強調代價

**聲音設計**：
- 控制時：背景是單調節拍 + 機械音（代表被操控）
- 覺醒時：節拍突然混亂、高頻尖嘯進入
- 最終：所有音效瞬間停止，只剩操的呼吸聲與彩的尖叫

**導演要點**：
- 這是整部作品中「自我解放」的高潮
- 不應該渲染為暴力或美化自傷；而是「我終於可以選擇自己」的視覺化
- 紗夜的手帕在此之後才會在「完美洋娃娃」場景中發揮作用

### 場景 B-2：操「完美洋娃娃」

**時序**：114 年 5 月恐怖家家酒第 13-14 天（緊接「鋼鐵獨舞」後）

**功能**：展示操進一步的自我改造——從「失去自由」到「自願進入新監獄」

**七階段視覺分鏡**：

1. **準備階段**：操以殘破的軀體進入繭狀結構；背景是她的幻想空間（茶室或教室）
2. **溶解階段**：身體逐漸透明化，邊界模糊；靈魂開始分離的視覺表現
3. **轉移階段**：靈魂如光線般注入傀儡體；傀儡開始成形
4. **套殼階段**：傀儡外層浮現華麗的洋娃娃服飾；動作開始同步
5. **人格冻結**：表情凝固成完美微笑；眼神變成玻璃質；最後一縷情感從眼中消失
6. **激活階段**：傀儡起身，姿態完美但詭異；走路動作如舞蹈般精確但不自然
7. **終焉標記**：特寫傀儡的眼睛——曾經充滿痛苦與掙扎的眼睛，現在完全空洞

**紗夜手帕的兩次使用對比**：
- **第一次**（鋼鐵獨舞後）：紗夜遞給操時，操無法感受到布料的觸感（「無觸感」）；淚水流下但操似乎感受不到
- **第二次**（完美洋娃娃完成後）：紗夜再次嘗試讓操感受手帕，但傀儡形態的操突然「感受」到了溫暖——最後一縷人性的閃現

**關鍵台詞**：
```
操：「呢個…… 係邊個…… ？」（指向鏡子中的傀儡形象）
夕（內心獨白）：「呢個唔係失敗…… 呢個係另一種完成。」
操最後的意識碎片：「這唔係我！ 這只係一個靚嘅監獄！！」
    （但聲音被傀儡的笑聲覆蓋）
```

**導演要點**：
- 不應該渲染為「恐怖」，而是「無奈的優雅」
- 傀儡形態應該視覺上比操本人更「完美」——這才是最殘酷之處
- 夕的旁白應該冷漠且哀傷

### 場景 C：美夜子「三段式覺醒」

**時序**：114 年 5 月嘆息之橋事件後 ~ 6 月初

**功能**：美夜子從「被保護的小動物」覺醒為「有主體性的人類」

**三個分段場景**：

#### **第一段：貓殼碎裂**
```
粵語對白：
美夜子：（在高壓連鎖事件後，貓形開始崩壞） 「唔…… 唔得…… 唔……
        （痛苦的嘶叫）」
晴香：「美夜子…… 返嚟！」
        （光環亮起，試圖強行維持貓形）
美夜子：「（貓形徹底碎裂） 受…… 受唔到…… （人類身體露出）
        係…… 邊個…… ？」
```

**視覺**：
- 貓形像陶瓷一樣龜裂（參考 [破碎美學](#section-aesthetics-of-flawed)）
- 裂紋中流出不是血而是光 — 象徵詛咒的逐漸消散

#### **第二段：月下窗台的存在確認測試**
```
粵語對白：
美夜子：（赤裸，站在月光窗台前） 「我……存在嗎…… ？」
        （開始用指甲狠狠畫過自己的手臂，留下紅痕）
        「會痛…… 所以…… 我係活著…… ？」
        （轉身面向晴香時，眼神充滿絕望）
        「但係…… 點解……我仲係…… 空嘅…… ？」
```

**色彩規格**：
- 月色：冷藍色（月白 #E6E6FA）
- 身體：高對比白（象徵失血或靈魂喪失）
- 血痕：最後才出現，且色彩極淡（象徵她已經習慣不被看見）

#### **第三段：晴香的擁抱與崩潰大哭**
```
粵語對白：
晴香：（不説話，直接走上前） 「（擁抱）…… 妳係我嘅…… 妳係…… 」
美夜子：「（身體突然放鬆） …… 我…… 我點樣…… 都唔緊要……
        只要…… （喉嚨哽咽） …… 妳…… 都係…… 」
        （開始無聲的、劇烈的哭泣——第一次真正的情感宣洩）
```

**視覺與聲音協調**：
- 擁抱時背景從冷色漸進為暖色（金色 #FDB462）
- 美夜子的哭泣最初無聲（代表她從未被允許哭出聲）
- 逐漸音量提高，最後是原始的、不加修飾的號啕大哭
- 晴香的擁抱力度應該是唯一的「有力」視覺元素——其他一切都在崩潰

**導演要點**：
- 第一段應該是「物理的痛苦」（詛咒破裂）
- 第二段應該是「哲學的痛苦」（存在危機）
- 第三段應該是「救贖的痛苦」（被允許失控）
- 此場景是整部作品中「被看見」的最純粹示範

### 場景 D：凜「遲來的終結」

**時序**：114 年 5 月嘆息之橋事件，紫音與操犧牲之後

**功能**：凜的完全脫線与美夜子最終的內心決裂

**視覺設計**：
- **完全靜默**：零人聲、零對白；凜與美夜子的所有溝通透過眼神與身體語言
- **背景音**：只有風聲、枝葉摩擦聲、以及越來越近的心跳聲
- **lighting**：月光 + 冷色調；凜在陰影中，美夜子在月光下

**美夜子事後的內心獨白**（唯一的人聲）：
```
粵語獨白：
「……殺…… 咗…… 」
「……冇奇蹟…… 壞咗既野…… 就係壞咗…… 」
「（聲音破裂） 佢連…… 最後…… 句…… 話…… 都…… 留…… 唔…… 到…… 」
（最終：只有抽噎聲）
```

**導演要點**：
- 不應該有戲劇化的對峙；凜只是靜靜地接受自己的宿命
- 美夜子此刻的行為不是「英雄」而是「赤裸的哀傷」——她知道自己殺死的是誰，也知道無法改變任何事
- 槍擊瞬間應該用慢動作，但聲音保持實時速度（聲與像不同步，強調時間錯亂）

## <a id="section-key-dialogue-canon"></a>關鍵場景粵語對白存檔（GAP-93/94/95 補加）

> 本節收錄 backup/draft/scenes/05_detailed_scenes.md 中可表演的場景文本原始台詞。canon/05 只有結構 beat；本節保存實際對白、情緒分鏡和粵語表演規格。

### <a id="scene-first-candy"></a>晴香對紫音——第一粒糖（膠布哲學開場詞）

```
晴香：（從口袋掏出一顆糖，遞給坐在地上的紫音）
      「……食粒糖先啦。」
```

**功能**：此台詞是整個膠布哲學的關鍵開場詞——「無言的善意比分析更早到達」。晴香沒有說「你還好嗎」，沒有問「發生什麼事」，只是給了一粒糖。這個細節規定了晴香的整個共感語言：不用言語分析，而是用具體而微小的行動表達「你在這裡」。

**表演規格**：糖必須是普通的，不花俏；紫音必須沉默接過，不立即回應；鏡頭在她拆糖紙時停留 3 秒，不移走。

### <a id="scene-akane-brother-monologue"></a>紫音關於弟弟的獨白（性格定義段落）

```
紫音：「我弟弟……（停頓）……嗰時我哋兩個都好餓。街市有人丟咗個橙喺地下。
      個橙係爛㗎，只係一半係好。
      我攞咗返嚟，剝咗個好嘅半個比佢食。
      佢食咗，笑咗，話：『姐，好甜。』
      （聲音裂開）
      我之後先知道…… 嗰半係苦㗎。
      佢係識㗎，係佢扮唔識。」
```

**功能**：這段獨白確立紫音的性格核心——她保護他人的本能不是抽象的，而是從具體的「吃苦」行為中建立起來的。她明白什麼是真正的犧牲（無聲地承擔），也明白弟弟對她的愛（假裝相信她的謊言）。

### <a id="scene-misao-last-words"></a>操的臨死宣言

```
操：（最後一刻，面對黑奏）
    「……妳以為我係妳棋子？
    呢個選擇……係我自己嘅。
    呢個……係我至後……自己揀嘅嘢。」
```

**功能**：這是操弧光的最終定義台詞——「主體性的最後確認」。她一生都在被人做決定，最後以自己的選擇結束，並且親口宣告這個事實。

---

### <a id="scene-akane-farewell"></a>紫音的告別詞

```
紫音：（看著晴香，微笑）
      「我唔想再一個人食飯。
      晴香……多謝妳嗰粒糖。」
```

**功能**：與「第一粒糖」場景對應的閉環台詞。紫音的整個弧光始於那粒糖，終於她最終承認「不再一個人」——即使此刻她正在失去一切，她選擇帶著「不再孤單」的記憶離開。

**設計原則**：禁止在這台詞後添加任何對白或解釋；台詞說完即切黑。

### <a id="scene-tea-house-dual-voice"></a>黑奏/彩茶館場景——雙重人格對白規格

```
（公開對話，「彩」的語氣）
彩：「……今日天氣唔錯。你呢？」

（私下的警告，聲音質地突然變化——同一個喉嚨，明顯更低、更平靜）
黑奏：（幾乎是氣聲，只有晴香聽到）「如果妳繼續咁落去…… 妳自己知點解嘅。」

（即時切換回「彩」）
彩：「啊，唔好意思，我剛才發夢。」
```

**關鍵技術規格**：「雙重人格對白」必須在同一場景中通過聲音質地差異表達——不是兩條字幕，而是同一個聲優的音色轉換。導演需要確保：①切換時有 0.3 秒的停頓；②晴香的臉部反應在聽到黑奏低語時有可見的微小驚愕；③彩切換回來後的「發夢」解釋必須以正常語速說出，不刻意強調。

## <a id="section-aya-foreshadow"></a>彩/黑奏雙重身份伏筆系統（Aya/Kurokanae Dual-Identity Foreshadow）

**設計原則（T15 定案）**：所有伏筆在初次接觸時必須能被合理解釋為巧合；只有在二周目（第二次觀看/閱讀）才能確認其真正含義。

| 類型 | 伏筆元素 | 初周目解讀 | 二周目確認 |
|------|---------|---------|---------|
| **視覺** | 瞳孔邊緣短暫的紫色閃光 | 疲勞或光線折射 | 黑奏人格浮現的早期徵兆 |
| **視覺** | 熊玩偶眼睛短暫發光 | 光線角度 | 黑奏以外部物件監視環境的訊號 |
| **行為** | 突然的頭痛或短暫發呆 | 壓力/魔法副作用 | 人格切換邊界的物理回響 |
| **行為** | 特定情境下右手下意識移向腰側（黑奏的武器位置）| 習慣動作 | 黑奏的肌肉記憶穿透彩的身體控制 |
| **對話** | 語氣突然從被動轉為命令語氣，隨後「發夢」解釋 | 情緒起伏 | 黑奏短暫奪取話語主導權 |
| **對話** | 對話中偶爾出現「我們」而非「我」，立刻自我修正 | 口誤 | 雙重主體的意識滲透 |
| **環境** | 鏡片/反光表面無故碎裂（彩路過時） | 物品老化/巧合 | 黑奏以情緒能量施壓周圍物件 |
| **環境** | 場景中總有一扇窗/門對齊彩的背後——但窗外景色異常陰暗 | 敘事構圖 | 黑奏的「後方視角」在環境中具現 |

**執行禁令**：禁止在同一場景集中呈現超過兩類伏筆——密度過高將破壞「巧合感」。

## <a id="section-reality-stitching-horror"></a>Reality Stitching 雙重恐懼設計（T17 定案）

**機制說明**：Light Veil（Reality Stitching 的表層稱呼）在初讀時呈現為晴香的保護性魔法——她讓隊友不記得某些危險記憶，以防止情緒崩潰。初讀觀眾理解為「晴香在保護大家」。

**雙重閱讀翻轉**：

| 觀看時機 | 同一機制的解讀 |
|---------|-------------|
| 初讀 | 晴香用 Reality Stitching 保護隊友，讓他們不必承受過重的記憶創傷 |
| 複讀（知道真相後）| 晴香系統性地抹除自己在他人記憶中的存在——每次隊友「忘記晴香做的某件事」，都是晴香在消除自己留下的痕跡 |

**恐懼類型**：不是突然嚇一跳，而是「我以為的溫柔，是孤獨的另一面」——晴香用保護性行為同時執行自我抹除，而她從未意識到兩者是同一件事。

**執行指引**：
- 第一次 Reality Stitching 場景**必須**讓觀眾感到溫暖——不能植入任何疑問信號
- 第二次出現時，植入一個「微小但可見的過度」——晴香抹除的稍微多了一點
- 第三次以後，觀眾應該開始不舒服——但無法命名不舒服的原因
- 複讀時：第一次使用已然恐怖

## <a id="section-three-reveal-chains"></a>三大揭示知識依賴鏈

> 本節記錄三個結構性揭示的前置知識序列設計。每個揭示的情感重量取決於觀眾在該時刻「已知」與「未知」的精確比例。前置知識缺失 → 揭示變成資訊堆填；前置知識過多 → 揭示失去衝擊。

---

### 一、晴香創世者揭示鏈

**揭示終點**：Act III 中 — 黑奏嘲諷式揭露「妳才是這個地獄的創造者」

| 階段 | 時序 | 觀眾已知 | 觀眾未知 | 策略 | 累積效應 |
|------|------|---------|---------|------|---------|
| **L0 前置** | Act I | 晴香有「改變現實」能力（傳說） | 她已使用過 | 都市傳說鋪墊 | 能力存在但無使用先例 |
| **L1 細節埋藏** | Act II 前期 | Alpha 線片段感覺「更安靜」；黑奏說「妳給了我這一切」；美夜子有既視感 | 為什麼 Beta 線充滿魔法而 Alpha 線沒有 | 細節埋藏，不主動解釋 | 觀眾感到「兩條線本質上不同」但無法命名原因 |
| **L2 角色知情** | Act II 末 | 夕已向晴香灌輸 Alpha 線記憶暗示 | 晴香有沒有真正承認 | 觀眾進入「知道晴香知道但她在逃避」的上帝視角 | **敘事張力**：觀眾與晴香之間的知識差 = 表演層的核心壓力來源 |
| **L3 確認揭露** | Act III 中 | 所有 L1/L2 積累 | 完整因果鏈 | 黑奏嘲諷式直接揭露 | 雙重衝擊 = 創世者確認 ＋「她一直知道但在逃避」的憤怒/心痛 |

**設計禁令**：
- L2 不得讓觀眾「完全確定」晴香已知——必須保留模糊性（晴香是在逃避還是在否認？）
- L3 揭露之前，觀眾不得看到任何「晴香主動承認」的場景；全部用行為迴避來提示

**See also**: [Story Outline Act III § 結構詭計](05_story_outline_canon.md#section-act-3) | [12 § 傲慢救世主模式](12_philosophy_and_systems.md#section-haruka-savior)

### 二、螢不可復活揭示鏈

**揭示終點**：Act IV 末 — 彩說「多謝你保護咗我咁耐」那一刻

**核心結構**：黑奏的一切罪行（情緒農場、永恆陷阱、對晴香的傷害）都指向同一個動機。揭示的衝擊不是「螢死了」，而是「這個動機從一開始就是不可能實現的」。

**前置知識建立順序（必須按序完成）**：

| 序號 | 前置知識 | 建立時機 | 方式 |
|------|---------|---------|------|
| P1 | 彩/黑奏是同一個人（DID） | Act III 前 | 行為累積，觀眾自行推斷。**最強積累節點：[E-16 EMB鐵桶包圍](04_timeline_canon.md#event-emb-siege)（CDL-246；原Act II-XX玻璃庭院茶會已WITHDRAWN併入，CDL-358）**——彩出現靈魂延遲/卡頓，黑奏聲線短暫穿透，彩事後毫不知情；觀眾感到「彩背後有什麼東西」，但謎底仍受保護 |
| P2 | 黑奏的根本動機是復活螢 | Act III 中（黑奏攤牌） | 直接陳述 |
| P3 | 螢是誰、彩與螢的關係（被保護了多久） | Act III 中-末 | 彩的記憶碎片 |
| P4 | 靈樹武器的本質：連靈魂一起消滅（集體潛意識中無任何碎片可回收） | Act III-IV | 世界規則確認（已在 [Decision Log CF-T06](99_decision_log.md) 及 [aya.md](03_characters/aya.md#section-kurokane) 定案） |

**揭示 moment 設計**：

彩說「多謝你保護咗我咁耐」（針對螢）→ 觀眾理解：彩接受了螢永遠不可能回來的事實。黑奏不接受。黑奏為了一個客觀上不可能的目標，親手造成了一切。

**情感設計要點**：
- 揭示不應是「告知」而是「確認」——觀眾在 P1–P4 完成後已隱約知道，彩的台詞只是將這個「已知」化成無可迴避的現實
- 黑奏不需要在場；彩的「多謝你」對著空氣說出，比直接衝突更殘酷

### 三、愛莉雙形態揭示鏈

**揭示結構**：兩個形態由不同原因觸發，觀眾需分別經歷才能理解愛莉的完整處境。

| 形態 | 觸發原因 | 觀眾揭示時機 | 衝擊設計 |
|------|---------|------------|---------|
| **石像/紙皮騎士形態** | 前史事故觸發 | Act I-II 日常線（石像身份逐漸清晰） | 「日常中有靜止的異常」→ 懸念積累 |
| **魔法少女形態** | 晴香（夕）第2次改變現實；愛莉當時內心渴望「有人拯救她/世界」 | Act III/IV 邊界（觸發瞬間） | 「同一個人，用完全不同的方式被捲入」→ 命運的荒誕感 |

**前置知識要求（魔法少女形態觀眾準備度）**：
- 觀眾需先理解：「改變現實」會回應願望（不是主動設計，而是情緒能量的共振）
- 觀眾需先知道：愛莉一直活在某種「等待被拯救」的狀態（石像形態已建立此認知）

**設計注意**：兩個形態的觸發原因相互獨立，但在主題上構成統一——愛莉一直是「世界改變的被動承受者」，第一次有了主動性是在成為魔法少女之後。

## <a id="section-closure"></a>敘述策略總結

所有五個場景的共同特點：
- **台詞不多**：關鍵場景應該讓視覺與音效說話
- **節奏反差**：快速的動作場景 vs. 慢速的情感場景
- **顏色心理**：每個場景都有明確的色溫轉變，代表心理狀態的改變
- **聲音層次**：至少三層（環境聲、角色聲、配樂），且應該在轉折時出現不同步（代表現實的破碎）
