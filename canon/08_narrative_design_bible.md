## <a id="section-three-layer"></a>三層符號分析框架（Three-Layer Symbolic Analysis）

每個場景、物件、事件必須同時在三個層次運作：

| 層次 | 名稱 | 功能 |
|-----|------|------|
| **L1** | **氣氛層 (Atmosphere)** | 觀眾/玩家的即時感官體驗與情緒基調 |
| **L2** | **角色關係層 (Character & Relationship)** | 推進人物心理狀態與人際關係的張力 |
| **L3** | **主題層 (Theme)** | 強化「態度 vs 命運」主旋律及其四大子主題 |

**設計鐵則**：任何設計只在單一層次運作 = 敘事資源浪費。優先投資能同時服務三層的元素。

## <a id="section-attitude-destiny"></a>態度 vs 命運（核心主旋律框架）

**主旨**：「面對無法控制的、殘酷的命運，唯有『態度』是個人最後且最珍貴的自由。」

**執行原則**：製造極度殘酷、無力感的「命運」環境，以凸顯角色選擇「態度」的難度與重量。

**四大子主題**（均為主旋律的分支表達）：

| 代號 | 子主題 | 核心命題 |
|-----|--------|---------|
| **主題A** | 力量的代價 | 任何超自然力量的獲取，都伴隨人性或完整性的侵蝕與犧牲 |
| **主題B** | 完美幻象的破滅 | 批判追求「無痛、無瑕」理想狀態的非人道本質 |
| **主題C** | 身份的本質（三元概念） | 「內在態度」遠比外在形態（人類/魔法少女/屍骸）更決定存在意義 |
| **主題D** | 連結的價值 | 共情、信任、互相扶持是對抗絕望的終極抵抗形式 |

**全劇主題走向（Alpha→Beta 弧光）**：「我唔想痛所以用魔法」→「我唔用魔法都要照顧自己」。故事不以消滅痛苦為終點，而以「即使無法消滅，仍選擇照顧自己」的態度作為最終的人物答案。

## <a id="section-dark-healing"></a>黑暗療癒系統（Dark Healing System）

**定義**：「療癒不是逃離痛苦。是在痛苦中找到自由——即使命運無法改變，態度仍屬於自己。」

**敘事弧光公式**：呈現苦痛 → 穿越苦痛 → 在苦痛中提取態度的自由

**絕對禁止清單（What NOT to write）**：

| 禁止 | 原因 |
|-----|------|
| 給予虛假希望（「努力必有回報」「好人終有好報」） | 否定命運的殘酷真實 |
| 否定痛苦（「讓過去過去」「時間治癒一切」） | 架空角色苦難的重量 |
| 強迫正能量（禁止讓角色「突然想通了」） | 允許角色選擇悲傷、憤怒、沉默——這也是態度自由 |
| 廉價救贖（轉變必須有真實代價） | 無成本的頓悟等同欺騙觀眾 |

**與黑暗系的區分**：
- **黑暗系**：呈現苦難，止步於苦難。
- **黑暗療癒系**：呈現苦難 → 穿越苦難 → 提取態度自由。

**基調**：溫柔的殘酷（Gentle Cruelty）——以悲憫呈現殘酷，不是折磨觀眾，而是讓他們在角色苦難中看見自己、在角色選擇中找到力量。

## <a id="section-four-act-atmosphere"></a>四幕結構氣氛設計

> 情節事件見 [Story Outline](05_story_outline_canon.md)；本節只定義每幕的導演氣氛目標。

**核心結構邏輯**：前兩幕（起承）必須成功騙到觀眾相信這是傳統英雄故事。第三幕（轉）的「偽高潮」以暴力手法打破這個期待，推故事進入第四幕（合）的存在主義哲學層。

### 第一幕（起）——心理驚悚

| 項目 | 規格 |
|-----|------|
| **主色調** | 焦慮、恐懼、疏離 |
| **結構目標** | 以晴香的個人危機為中心，將世界崩潰的種子埋在日光的裂縫下 |
| **感官規則** | 恐懼來自心理層（鏡中閃現的異常、令人不安的台詞細節、夕莫名的敵意），而非血腥或怪物 |
| **疏離技法** | 強調晴香因情緒損傷而產生的「世界外旁觀者」感——即使身處人群，她仍是局外人 |

### 第二幕（承）——希望被殘酷滲透

| 項目 | 規格 |
|-----|------|
| **主色調** | 表層希望，底層殘酷 |
| **結構目標** | 成功建立虛假英雄敘事，同時以細節不斷腐蝕它 |
| **欺騙功能** | 必須真誠地製造傳統史詩英雄幻覺，同時在每次勝利後配對殘酷代價 |
| **氣氛對比規則** | 希望火焰越高，現實的寒意越銳利。勝利 → 凜的犧牲、秋穗的墮落、晴香喪失味覺與創作能力 |
| **情緒積累目的** | 觀眾感到亢奮同時越來越不安——為第三幕的反轉積累最大位能 |

### 第三幕（轉）——崩潰點

| 項目 | 規格 |
|-----|------|
| **主色調** | 無力感、共情、荒謬 |
| **結構目標** | 在偽高潮暴力打破情緒期望，將故事從外部衝突拉回角色內心掙扎 |
| **氣氛破裂規則** | 在亢奮頂點：所有聲音/動作停止。死寂。世界崩潰。 |
| **荒謬感應用** | 在末日場景中嵌入正常人類細節（世界末日時收音機仍在播快樂廣告）加深悲劇衝擊 |
| **敘事翻轉** | 故事不是關於「如何獲勝」，而是「失敗後我們如何存在？」 |

### 第四幕（合）——殘酷深處的苦甜希望

| 項目 | 規格 |
|-----|------|
| **主色調** | 極度殘酷 → 感傷希望 + 懷舊 |
| **結構目標** | 回答第三幕的巨大問題——證明希望的真正價值在於選擇，而非獲勝 |
| **開場** | 以最大殘酷開場（晴香困於集體潛意識琥珀中）——「善意的囚籠比殘酷的毀滅更糟」 |
| **安慰層** | 使用香港特定感官細節（舊歌、食物香氣）觸發對「失去之美」的懷舊感——此溫柔成為最終選擇的情感基底 |

## <a id="section-cost-design"></a>代價設計原則（Cost Visibility Principles）

**普遍規則**：所有魔法少女系統利益皆有業力稅。代價不是抽象的——必須感官化、精確化、累積化。

**三種代價表現模型**：

| 模型 | 機制 | 例子 |
|-----|------|------|
| **感官喪失模型** | 過度使用特定情緒 → 喪失對應感知能力 | 過度使用希望 → 味覺消失；過度使用憤怒 → 無法感受平靜 |
| **靈魂延遲模型** | 戰鬥後意識暫時脫離肉身 → 短暫靈魂出竅的第三人稱視角 → 以物理/聲音衝擊暴力歸位 | 看著自己的手拿杯子卻感覺不到溫度；意識回歸時：刺耳耳鳴 + 針刺般肉體疼痛 |
| **共振失衡模型** | 每次變身製造魔法自我與人類自我的頻率失同步 → 逐漸加深的疏離感 | 角色在人群中感覺自己「不對頻」；鏡像映照失真 |

**累積規則**：代價不會重置或治癒——它們在整個 20 年系統運作期間不斷累積，直接餵入緋潮閾值突破。

## <a id="section-scene-execution"></a>場景執行規則（Scene Execution Grammar）

### 變身場景

**設計核心：變身 = 浮士德契約（T18 定案）**

每一次變身不是授權儀式，而是靈魂承諾書的又一次簽署。每次變身時角色明確知道——或者最終意識到——代價的計算在這一刻又推進了一格。視覺語法必須體現「交換」的雙重性：

- 變身光效不是純粹美麗的——光效中必須隱含代價視覺（閃現的裂紋、褪色的瞳孔、心之器微顫）
- 每次變身在聽覺層必須有細微的音調「沉降」——第一幕的變身音最純淨，此後每一幕的變身音略帶失真，但不刻意、不明顯
- 短暫的觀眾視覺失焦（1-2 幀黑場或失焦切換）
- 眾人記憶：「魔法少女一直都在這裡。」——不作解釋，讓觀眾從不完整的感官資料自行拼湊
- 避免用旁白或說明文字解釋現實修正

**情緒體驗設計意圖：身體被越界的恥辱（T-SHAME 原則）**

魔法使用的代價，在觀眾情緒層應產生「被強行越界」的羞辱感——而非英雄犧牲的悲壯感。這是刻意設計，不是副作用。

- **非自願快感在先**：變身啟動的[諧振的狂喜](../02_glossary.md#term-ecstasy-of-resonance)必須演出成身體違背意志的反應——角色感到快感，但同時知道這不是自己選擇的。演出語法：咬牙、迴避視線、快感中帶羞恥的眼神。
- **事後恥辱在後**：[生理排斥](../01_world_rules_and_costs.md#rule-physiological-rejection)的嘔吐、顫抖不是「代價」，是「身體知道自己被弄髒了」。演出語法：跪地、抱膝、強迫擦洗（呼應操的清洗儀式）、不願讓人靠近。
- **被觀看的悖論**：光幕濾鏡令她們正在承受的一切被過濾為「天使戰鬥」。觀眾（市民）越歡呼，她們的恥辱感越深——無法呼救、無法被真實看見。
- **禁止美化**：排斥期絕不允許悲壯化處理。正確基調：骯髒、失控、想躲起來，而非犧牲的崇高。

### 鏡像場景

- 固定鏡頭（避免快速橫搖——技法聰明感會打斷沉浸）
- 先呈現正常倒影，再緩慢引入「錯誤」細節（視線方向不對、身體位置偏差、倒影中有傷但本人沒有）
- 不要在效果上用力；讓「錯」的細節慢慢滲透觀眾的感知

### 屍骸化場景（CDL-271）

**設計核心：靈魂被困肉體，雙層交叉切割視覺**

屍骸化場景不是單一「怪物崩潰」，而是「靈魂逃脫失敗」的物理具現。必須同時呈現現實層與潛意識層的交叉，才能傳達「被困」的終極悲劇。

#### **現實層（Beta 線）：肉體異變**
- 心之器碎片破體而出，轉化為糖晶/齒輪/裝甲
- 情緒廢料倒灌導致生理異化：皮膚龜裂、身體扭曲、行為盲目
- 視覺規格：「概念層破壞」而非寫實腐敗（參見[破碎美學](#section-aesthetics-of-flawed)）
- 聲音：低沉的、痛苦的、非人類的咆哮，但並非純獸性——隱約有理智殘片在尖叫

#### **潛意識層：靈魂被困**
- 一條快要斷的光線（因果線），被一個閃亮的碎片卡住（執念錨點）
- 靈魂的身影在潛意識中絕望地拉扯，但無法掙脫
- 視覺隱喻：靈魂被鎖鏈/繩索/無形力量困住，眼睜睜看著自己的肉體失控
- 可視化選項A：靈魂呈現為「該角色年幼時的樣貌」（回到執念源頭的年紀），與長大的扭曲肉體形成對比
- 可視化選項B：靈魂周圍環繞著被保護的物體（執念的信物），物體發出微弱的光——唯一還活著的部分

#### **交叉切割的時機與節奏**

**Act I - II**：觀眾只看到現實層
- 屍骸 = 純粹的怪物，行為無可理喻

**Act III 前期**（紫音直覺階段）：潛意識層開始洩露
- 短暫的視覺異常：屍骸的眼神一瞬間有人性
- 屍骸的某個動作不是「攻擊」，而是「保護某樣東西」（無聲的執念表現）
- 觀眾開始疑惑：「她為什麼……還有意識？」

**Act III 中後期**（晴香陰影視覺展開）：雙層同時呈現
- 首次交叉切割：現實肉體正在殺戮 ↔ 潛意識靈魂正在尖叫「不要」
- 強烈視覺衝擊：怪物與被困者的絕望同時進行
- 聽覺設計：肉體的咆哮與靈魂的哭聲疊層（兩份音軌同時播放，造成極端不協和感）

**Act IV**：完整揭示
- 不再用交叉切割，而是「同時呈現」——觀眾習慣了雙視角
- 屍骸的每個動作都有雙層解讀：表面是怪物，裡面是被困靈魂的 1% 抵抗

#### **1% 控制力的具體呈現**

屍骸在 99% 盲目行為中，偶爾爆發的 1% 靈魂控制力：

| 表現 | 視覺語言 | 含義 |
|-----|--------|------|
| **死死抱住信物** | 怪物正在摧毀一切，但這雙手絕不鬆開某樣東西 | 執念仍活著 |
| **眼神一瞬清醒** | 怪物咆哮中，眼睛突然聚焦、有人的恐懼閃過 | 靈魂還在裡面 |
| **說出殘破遺言** | 獸性低吼中突然間歇，擠出一句不完整的人語 | 「對不起」、「我愛你」 |
| **停頓一秒** | 在瘋狂攻擊時突然靜止，然後繼續 | 被困靈魂搶到一秒控制權後又被壓制 |
| **保護姿態** | 怪物的攻擊模式突然轉為「檔住某人」而非「殺死」 | 愛的本能還在控制那 1% |

#### **禁止誤區**

❌ 將屍骸拍成「無意識的空殼」——這否定了 CDL-271 的整個前提  
❌ 將屍骸的執念動作浪漫化——應該呈現的是「絕望中的執著」，不是「優雅的犧牲」  
❌ 讓屍骸在戰鬥中忽然「恢復理智」——1% 控制力不夠讓她們停止，只夠做微小動作  
❌ 用交叉切割過度——應該逐漸調整觀眾視角，而非一直技法炫耀  

#### **敘事層的三次揭示**

1. **觀眾感受階段**：「咦，這隻屍骸為什麼……做了這個動作？」（不解釋）
2. **角色察覺階段**：紫音說「她們還活著」——觀眾開始相信
3. **真相完整階段**：晴香的陰影視覺開啟，雙層同時呈現

### 情緒崩潰場景

- **不要**扭曲畫面（不用視覺特效表現崩潰）
- **要**扭曲角色的感官報告：以肢體語言表現（過度換氣、噁心感、手抖、解離凝視）
- 觀眾透過演員的身體感知內在崩潰，而非透過特效

### Alpha 滲出場景（時間線滲透視聽語法）

**視覺語法**：

| 視覺元素 | Alpha 線 | Beta 線 | 滲出表現 |
|---------|---------|---------|---------|
| 色溫 | 暖色/日光 | 冷色/人造光 | 同一畫面冷暖並存，局部去飽和 |
| 焦距 | 柔和/朦朧 | 銳利/切削感 | 局部失焦，短暫漂移 |
| 構圖 | 穩定、對稱的日常感 | 壓迫、不對稱 | 瞬間出現「理想構圖」隨即破裂 |
| 質感 | 乾淨、溫暖 | 潮濕、粗糙 | 同一物件呈現雙重材質疊影 |

**音效語法**：
- **Alpha 線**：乾淨環境聲，層次薄，略帶空間殘響
- **Beta 線**：密集噪音，遠處警報，機械低頻嗡嗡
- **滲出瞬間**：聲場突然「空掉」（噪音層被抽走）→ 聲音斷半秒「訊號失落」→ 以另一時間線語境恢復

## <a id="section-four-walls"></a>四牆分類（Four Walls Classification）

每個核心角色的成長障礙可歸類為「四堵牆」。了解角色撞的是哪堵牆，是正確設計其弧光場景的前提。

| 牆 | 名稱 | 定義 | 代表角色 |
|----|------|------|---------|
| 牆一 | **身體牆** | 肉身傷痛、能力限制、生理代價阻礙 | 凜（光環處決、痛覺依存）、紫音（戰鬥成癮代謝） |
| 牆二 | **因果牆** | 過去的選擇製造了無法逃避的後果 | 秋穗（愛莉事故）、紫音（弟弟之死） |
| 牆三 | **關係牆** | 與他人之間的連結/裂痕/誤解阻礙成長 | 美夜子（凜之死 PTSD）、晴香（無法告訴任何人自己創世的事） |
| 牆四 | **身份牆** | 自我定義的危機——「我是誰」的問題無解 | 操（性別/身份枷鎖）、夕（陰影還是敵人？）、凜（重組後的記憶身份） |

**使用規則**：
- 每個場景最多主攻一堵牆；同時撞兩堵以上的場景是「過載場景」，應有明確的設計意圖。
- 角色弧光 = 學會以「態度」回應牆，而非打穿牆。

## <a id="section-four-beat-scene"></a>場景四拍模板（Four-Beat Scene Template）

每個敘事場景應具備以下四拍結構，確保場景同時推進情緒與世界觀：

| 拍 | 名稱 | 功能 | 常見失誤 |
|----|------|------|---------|
| 拍一 | **代價信號** | 在場景開頭置入「某件事已付出代價」的線索（畫面、台詞、行為） | 省略代價信號，讓場景缺乏情緒重量 |
| 拍二 | **本能反應** | 角色對代價信號的第一反應（往往是舊有模式的重演） | 讓角色直接做出成熟反應，跳過本能層 |
| 拍三 | **承接行動** | 角色在本能反應後做出的選擇（可能比本能更好或更差） | 承接行動與本能反應沒有因果關係 |
| 拍四 | **關係後果** | 這個選擇如何改變場景中角色之間的關係或認知 | 場景在「行動」後立即結束，沒有落地在關係層 |

**設計原則**：拍四必須落在「關係」而非「世界觀說明」。觀眾/玩家透過角色關係理解世界，而非透過世界說明理解關係。

## <a id="section-narrative-service-channels"></a>世界敘事四大角色服務管道

每個非主角角色在敘事結構中服務主線的方式，可歸類為以下四種管道：

### 管道一：誤會機（Misunderstanding Engine）

**功能**：製造關鍵的錯誤認知，讓主角在「錯誤的基礎上做出選擇」，為後段揭露製造能量。

**設計規則**：
- 誤會必須基於角色視角的合理性（讀者/玩家不能一眼看穿是誤會）
- 誤會必須在後段被揭露，且揭露時製造的震驚 ≥ 製造誤會時的期望

**代表使用**：凜的重組（美夜子以為凜是陌生人）、秋穗隱瞞愛莉意識存在（晴香不知道石像有知覺）

### 管道二：代價計時器（Cost Timer）

**功能**：以計時形式具現化「如果不採取行動，代價將繼續累積」的壓力。

**設計規則**：
- 計時器必須可視化（讀者/玩家能感知倒數）
- 計時器到期的後果必須比預期更嚴重（避免「狼來了」效應）

**代表使用**：愛莉的閘口負擔過載（每幕紙皮盔甲裂縫加深程度）、紫音弟弟的情緒結晶倒計時

### 管道三：鏡（Mirror）

**功能**：以對照角色或對照處境，讓主角（和讀者）看清自己的真實狀態。

**設計規則**：
- 鏡角色不是「更好的版本」，而是「不同選擇的結果」
- 鏡的有效性在於讀者/玩家能從對比中得出「哦，所以主角是在做這件事」

**代表使用**：
- 凜（放棄偶像夢）vs 晴香（活在偶像身份中）——鏡：晴香看見自己逃避了什麼
- 夕 vs 晴香本人——鏡：晴香看見自己壓抑了什麼

### 管道四：小確幸稀缺器（Small Joy Scarcity Engine）

**功能**：在高壓敘事中刻意置入「廉價的小確幸」，通過稀缺性讓讀者/玩家更珍視它，並在其消失時感受更深的失落。

**設計規則**：
- 小確幸必須「廉價」且「具體」（不是「友情」，而是「一起搶最後一個布丁」）
- 小確幸出現後，要讓讀者/玩家有時間在心理上依附它
- 小確幸的消失（或被打斷）是絕佳的情緒轉折點

**代表使用**：K 房場景（短暫的少女日常）→ 被突如其來的任務中斷；便利店布丁猜拳 → 手機被屍骸踩碎

## <a id="section-daily-interleave"></a>三層日常穿插法（Trauma-via-Behavior Protocol）

### 核心原則：創傷通過行為告知，不得使用直接閃回

**禁令**：不得以直接閃回（Direct Flashback）方式呈現角色的過去創傷事件——即：禁止在敘事當下切割時間線，插入還原性的過去場景鏡頭。

**理由**：直接閃回將觀眾/玩家從主線情感張力中切離，破壞當下時空的敘事連貫性；更重要的是，直接閃回把「應該被讀者自行建構的創傷」變成「被動接收的信息包」——這剝奪了創傷的情緒重量。創傷要透過行為讓人感受，不是透過說明讓人了解。

**替代方式**：三層日常穿插結構——

| 層次 | 功能 | 時間點 | 設計要求 |
|-----|------|-------|---------|
| **戰前行為告知** | 在戰鬥/衝突**前**，以日常行為暗示角色的創傷狀態 | Act II 起 | 行為必須足夠具體（特定動作、特定迴避），令觀眾不需解釋就能感知異常 |
| **戰後行為告知** | 在戰鬥/衝突**後**，以身體反應與習慣揭示創傷被觸動的程度 | Act II–III | 禁止讓角色直接說出「這件事讓我想起……」——只允許行為外化 |
| **幕間日常** | 在幕與幕之間的過渡場景中，以完全平凡的日常互動建立觀眾對角色的日常依附 | Act I–III 幕間 | 這些場景**必須** feel trivial——正是這種「無聊」才讓後來的失去有重量 |

**應用示例**：
- 操在據點洩露後，日常測量頻率從一天一次升至一天五次（行為外化，無需說明創傷內容）
- 美夜子在凜死亡後，開始把茶杯排成四個一組再放回（戰後行為告知）
- 晴香在進入「靜止搖籃」前一幕，依舊在後台認真整理道具——這個動作讓最後的失去更重（幕間日常的功能）

## <a id="section-horror-balance"></a>三層恐怖平衡製作規則（Three-Layer Horror Escalation Protocol）

**核心法則（T14 定案）**：恐怖場景必須嚴格遵循「日常 → 異常 → 恐怖」三層遞進。**禁止從日常直接跳入恐怖第三層。**

| 層次 | 名稱 | 功能 | 持續要求 |
|-----|------|------|---------|
| **第一層** | **日常（Ordinary）** | 建立觀眾對角色行為的正常基準線 | 必須足夠「無聊」——只有真正無聊的日常，才能讓異常顯得觸目驚心 |
| **第二層** | **異常（Anomaly）** | 在日常基準線上植入第一個「不對」的細節，讓觀眾開始懷疑 | 異常不得自我解釋——不允許角色或旁白點破異常；異常必須通過觀眾自行發現 |
| **第三層** | **恐怖（Horror）** | 異常累積至臨界點後的爆發或揭露 | 恐怖的衝擊力完全依賴於第一、二層的鋪墊——沒有日常和異常，恐怖就只是噪音 |

**違禁設計**：
- 直接從日常跳入第三層（感官爆炸、直接呈現屍骸或死亡）= 製造嚇一跳，但無法製造持續的不安
- 第二層異常用「角色指出異常」代替「觀眾自行察覺異常」= 把懸念破壞
- 第三層恐怖用「解釋原因」收尾 = 把未完結的恐懼感消解掉

**設計節奏範例**：
1. 第一層：美夜子在屋內整理槍械（正常日常行為）
2. 第二層：她把槍放下時，手在空中停了一秒——視角才發現她在聽某個聲音；但畫面裡沒有任何異常
3. 第三層：她緩緩轉向角落——角落什麼都沒有，但她說：「是妳回來了嗎。」

## <a id="section-symbol-objects"></a>五個核心符號物件四幕演化系統

每個核心符號物件在四幕中具有完整的意義演化——從日常道具到主題具現。

| 符號物件 | Act I（日常） | Act II（代價） | Act III（破碎） | Act IV（收束） |
|---------|------------|-------------|--------------|-------------|
| **可樂** | 晴香的日常快樂；與彩初見時分享 | 黑奏故意不喝（對「快樂」的拒絕） | 可樂罐被壓扁——晴香試圖維持的日常崩潰 | 空罐——有過快樂的證明，已無法重現 |
| **吉他** | 晴香音樂夢想的象徵；靜止搖籃前的最後演出 | 琴弦斷裂——力量與天真的代價 | 吉他被扔掉——「偶像晴香」的終結 | 美夜子保存斷吉他——晴香存在過的證物 |
| **速寫本** | 彩的速寫本——記錄「真實的彩」；黑奏不允許彩有這個 | 速寫本被奪走/毀損——彩自我主體性的侵蝕 | 碎頁——彩與黑奏的存在撕裂 | 彩在意識空間重新拿起速寫本——收復自我的宣示 |
| **吊墜** | 美夜子的吊墜——凜留下的遺物 | 吊墜裂縫加深——每次失去一個隊員 | 吊墜完全碎裂（嘆息之橋後） | 碎片仍被美夜子握著——「已失去但曾存在」 |
| **鏡** | 自然存在的鏡——日常使用 | 鏡面出現「錯誤」倒影（夕/黑奏的滲透） | 鏡全面碎裂——幻象/謊言無法維持 | 碎鏡片仍能映照——不完整的真相比謊言更真實 |

**執行原則**：每個物件的出現不得刻意，必須先以「日常用途」建立觀眾熟悉感，再讓意義自然累積。二周目觀眾應能回看 Act I 場景並感受「原來那時候已經開始了」。

## <a id="section-magical-girl-subversion"></a>五項魔法少女類型顛覆表

本作對魔法少女類型的五個核心顛覆：

| # | 類型期望（觀眾 / 類型慣例） | 本作設計 | 主題意義 |
|---|---------------------|---------|---------|
| **1** | 變身 = 力量授予（神聖儀式） | 變身 = 浮士德契約（靈魂協議的又一次簽署） | 力量的代價——沒有免費的強大 |
| **2** | 最近的人 = 最強的支持者 | 最近者 = 最深的敵人（黑奏/彩、夕/晴香、紫音/小光） | 愛本身不能免除傷害 |
| **3** | 最終戰鬥 = 英雄式勝利 | 最終戰鬥 = 必然失去某些東西（紫音/操的犧牲，晴香的靜止） | 態度的自由 ≠ 結局的完美 |
| **4** | 犧牲 = 有意義的轉折 | 犧牲不保證意義（意義由存活者如何記憶來定義） | 敘事不替角色的痛苦蓋章「有用」 |
| **5** | 愛 = 治癒/拯救的動力 | 愛導致瘋狂（紫音愛小光→屍骸首領；黑奏愛螢→共振地獄） | 未授權救贖——愛不賦予改變他人的權利 |
