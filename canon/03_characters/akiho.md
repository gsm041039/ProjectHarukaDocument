## <a id="section-background"></a>背景故事

### 被遺忘的第二名

秋穗與花子是雙胞胎姊妹。花子是天才中的天才——所有人的目光、讚美、期待都投向花子。秋穗永遠是「第二名」，永遠活在花子的陰影下。這份比較心態深入骨髓，成為她一切行為的原始驅動力：必須超越花子，必須證明自己不是附屬品。

### 愛莉的意外——第一個人造屍骸

愛莉事故構成秋穗角色弧的關鍵起點。此處只保留角色心理與責任意義；事故客觀鏈與機制口徑分別見 [Timeline：愛莉事故](../04_timeline_canon.md#event-aeri-accident) 與 [Glossary：魔法屍骸](../02_glossary.md#term-magical-corpse)。

**See also**: [愛莉事故](../04_timeline_canon.md#event-aeri-accident)

### 與魔鬼的契約

秋穗與黑奏的交易本質是「以母愛為名的自我綁架」：她明知代價殘酷，仍把希望押在黑奏手上。  
從這一刻起，秋穗每一次「為了救女兒」的決策，都同時在傷害另一批女兒。

### 罪孽的繼承者

為黑奏服務期間，秋穗犯下最不可饒恕的罪行——把美夜子推入 Unit 01 路線。此段聚焦罪責與心理後果；技術流程與事件順序見 [Timeline：美夜子復活](../04_timeline_canon.md#event-miyako-revival)。

**三層動機（設計者必讀）**：秋穗將美夜子推入 Unit 01 路線，底層是三重動機疊加：

1. **實驗預演**：美夜子是秋穗測試「集體潛意識技術能否重塑死者」的首個成功案例；真正目標是[愛莉](aeri.md)——美夜子的復活是能否復活愛莉的規模化預演。
2. **資源交換**：將「成功復活的活體兵器」交給[黑奏](aya.md#section-kurokane)和軍方，換取繼續研究復活愛莉的資源與特權。這是她與魔鬼契約的實質條款。
3. **潛意識僭越**：秋穗永遠活在花子陰影下。將花子最驕傲的大女改造成無自我的殺戮兵器，是秋穗對花子一種極度扭曲、夾雜內疚與報復的「超越」——這份動機是秋穗自己都不承認的底層暗流。

**移交時刻（Flashback 錨點）**：美夜子醒來的第一刻，秋穗以模仿花子的溫柔語調與動作接觸她，隨即向軍方人員冷酷下令移交。場景功能：「[持續表演規則](#habit-hanako-imitation)」在罪行頂點的極致撕裂——溫柔面具與殺戮執行在同一瞬間並存。具體對白／鏡頭留至 Scene 層確認。

**黑貓詛咒 Bug 的利用與棄守**：秋穗初期對軍方隱瞞了美夜子的「[避難所詛咒](../02_glossary.md#term-sanctuary-curse)」，以說辭掩護 Unit 01 的運作，換取所需研究特權。後期任務中詛咒意外觸發，軍方將 Unit 01 定性為有缺陷的半成品並降級。彼時秋穗已取得所需資源，未再出手干預——美夜子從此被邊緣化。這是秋穗罪孽鏈中最後、也最冷酷的一環：有用時保護，無用時放手。

**See also**: [美夜子復活機制](../04_timeline_canon.md#section-miyako-revival-mechanism) | [美夜子 Unit 01](miyako.md#section-background)

### 石像前的懺悔

每天，秋穗都會來到愛莉的石像前說話。她傾訴研究進展、說晴香今天的狀況、哭訴自己的罪孽。她不知道的是——愛莉在[集體潛意識](../02_glossary.md#term-collective-unconscious)的精神深處聽得到一切。每一句話，每一聲嗚咽，愛莉都記住了。

**See also**: [愛莉的濾心機制](../02_glossary.md#term-filter-mechanism)

### 深情——正面特質（CDL-337）

秋穗成日將「結果先係一切」掛喺口邊、可以為達目的不擇手段，但她會去愛莉個石像前面跪低，用溫度計問「愛莉，妳能聽到媽媽嗎？如果能，讓溫度上升 0.1 度」（[與結晶雕像的溫度問答](#habit-statue-dialogue)——呢個係 Behavior Hooks 第7項嘅私密儀式，同第1項「[石像前的懺悔](#section-behavior-hooks)」係兩個獨立習慣，唔可以混為一談）——一個以理性自豪嘅頂尖科學家，會日日夜夜對住一件（照佢自己科學標準嚟講）冇反應嘅石頭做呢種毫無理性可言嘅事，從未間斷。呢個先真係佢最真實嘅一面：她對愛莉嘅眷戀完全冇因為理性、冇因為冇回報而熄滅。呢個畫面本身唔使解釋任何背景，觀眾一睇就會感受到「呢個人失去咗好緊要嘅人，佢仲愛緊佢」，唔使等到揭露黑歷史先感受到動人。**擺位建議**：呢個habit如果喺Act I做成觀眾實際目擊嘅[NC]場景（唔止文字描述），可以做佢嘅表層討好特質，唔使靠USB暗中相助（CDL-323）呢類隱藏行動先建立好感。

**同美夜子「忠誠」嘅分別**：對象狀態唔同——美夜子嘅忠誠對象係仲喺度、仲有得保護嘅人；秋穗嘅深情對象係已經失去、冇得回應嘅人。方向唔同——美夜子向前守住未來；秋穗向後唔肯放手一段已完結嘅關係。道德糾纏程度唔同——美夜子嘅忠誠乾淨；秋穗嘅深情正正就係推佢做晒啲罪行（將美夜子推入Unit 01路線等）嘅同一股力量。

**違反套路預期——愛唔自動帶嚟道德救贖（CDL-341，方向確認，具體演出留Beat Sheet）**：建議喺第三幕「與黑奏持續合作」因果鏈中段（任一次失敗後）加一場戲：秋穗做完一次協助黑奏收割晴香情緒嘅骯髒任務後，深夜獨自去愛莉石像前做溫度問答儀式，呢次溫度真係升咗0.1度（或者佢自己以為升咗）。觀眾（套路化預期：「深情終於觸動咗佢，佢即將懸崖勒馬」）以為呢個係轉捩點。但翌日秋穗照樣返去同黑奏繼續下一輪合作，冇因此停手——深情畀咗佢一刻溫柔嘅錯覺，但完全冇轉化做行動上嘅煞停力。加害者深情套路通常係「愛係救贖嘅開關」，呢個提案反過來：深情真係發生、真係感動觀眾，但佢功能上同罪行係同一股燃料，唔係解藥，要嚟到第三幕結尾屢敗屢試全部落空先真正壓垮結果論。唔撞最終「放棄修正選擇承責」嘅結局，只係強化中段嘅漸進侵蝕過程。

### 瘋狂的結果論

「過程不重要，結果才是一切。」——這句話是秋穗的行事信條。為了救愛莉，她可以犧牲任何人；為了超越花子，她可以跨越任何道德底線。她開發[情緒毒品](../02_glossary.md#term-emo-visor)、協助建立[魔法少女](../02_glossary.md#term-magical-girl)系統、封存真相操控晴香——所有罪行都被「結果」合理化。

## <a id="section-wnlt"></a>Want / Need / Lie / Truth

**Want（顯性欲望）**：
- 復活[愛莉](aeri.md)——讓女兒從石像中甦醒
- 超越花子——證明自己是更優秀的科學家
- 保護 / 利用[晴香](haruka.md)——既是阿姨的守護，也是黑奏的棋子

**Need（隱性需求）**：
- 接受愛莉的現狀——石像中的愛莉仍然活著，只是以不同形式存在
- 原諒自己——停止以「救贖」之名累積更多罪孽
- 得到女兒的回應——但呢個需求本身注定得不到滿足；秋穗終其一生都唔會知道愛莉心裡到底想講咩（CDL-394）

**Lie（核心謊言）**：
- 「收集足夠能量就能救愛莉」——黑奏的承諾從未打算兌現
- 「結果才是一切」——過程中造成的傷害同樣真實且會留下長期後果
- 「我是為了愛莉才這麼做」——部分動機是為了超越花子和自我救贖

**Truth（最終真相）**：
- 真正的救贖不是修正過去，而是接納現在——但秋穗明白呢個真相，唔代表佢換得到平靜；佢做得到接納嘅動作（日日懺悔），換唔到接納本應帶嚟嘅安穩
- 愛莉需要的不是科學奇蹟，而是母親的一句「對不起」——呢句說話秋穗日日都講緊，但女兒嗰句「我原諒妳」嘅回音，永遠唔會傳返嚟俾佢聽見（CDL-394）
- [態度比命運更重要](../02_glossary.md#term-attitude-vs-fate)——「我做錯了，但我仍然每日選擇留低、選擇懺悔」呢個態度本身係真嘅，亦有其重量；但[情緒守恆定律](../01_world_rules_and_costs.md#rule-debt-dissolution)唔會因為態度真誠就豁免代價——呢個唔係故事話佢抵受懲罰，只係呢條法則本身從來冇度量「幾真誠」呢件事（CDL-394）

## <a id="section-archetype"></a>Archetype & Symbolism

**Archetype 變遷**：瘋狂科學家 (The Mad Scientist) → 悔恨的母親 (The Remorseful Mother) → 永劫懺悔者 (The Eternal Penitent)（CDL-394修訂終局定性）

**象徵**：
- **石像（罪孽鐵證）** — 愛莉的石像是秋穗一切罪孽的物質化見證。石像不會腐朽，罪孽也不會消散——它永遠立在那裡，逼迫秋穗面對自己
- **科學儀器（修正過去的徒勞）** — 秋穗的實驗室堆滿失敗的儀器，每一台都代表一次「修正過去」的失敗嘗試。科學是她的信仰，也是她的牢籠
- **無臉執行官（情緒守恆定律嘅懲罰，CDL-376修正；終局定性由CDL-394取代）** — 純白緊身衣、面部溶解為星光宇宙。呢個唔止係象徵——係情緒守恆定律對長期破壞情緒平衡嘅人嘅字面懲罰機制（見[自我消解](../01_world_rules_and_costs.md#rule-debt-dissolution)）：秋穗欠債累積到臨界值，靈魂裂縫俾帝國技術趁虛而入，將佢暫時編寫做呢個消解晒自我意識嘅兵器狀態。**主線入面，秋穗喺Act II曾經兩次以「悲鳴女妖」形態出現（E-04/E-07c）**——呢段時間佢係「無意識兵器」，連自己個女愛莉嘅存在都唔記得。呢兩次係暫時、可逆嘅（身份揭露後記憶恢復，繼續行落去第三/四幕）——但「暫時可逆」淨係指單次發作，唔係指佢最終嘅命運：Act II嘅兩次消解，其實只係一個更大、佢由頭到尾都未曾真正跳出過嘅循環（見[秋穗的循環](../04_timeline_canon.md#event-akiho-time-loop)）入面嘅短暫發作，佢自己完全唔知道呢個循環嘅存在，亦都唔知道自己終將永久困喺入面。**主線同冇晴香介入嘅失敗時間線，最終匯合去同一個終局（CDL-394）**——兩條時間線用嘅係同一條法則、同一個循環結構，分別只在於中途有冇一股外力（隊友介入、身份揭露）將佢暫時拉返；但呢股外力嘅作用範圍到第四幕為止，之後冇任何嘢再拉得住佢——兩條時間線殊途同歸，秋穗最終都係永久消解、困喺呢個循環入面，冇任何一條時間線俾佢真正走出嚟。呢個先係「結果論」走到極端嘅完整終點：為了結果連自我都消解咗，而且呢次消解——冇下一次拉返。

**點解係佢，唔係操／紫音／凜——罪責承受者 vs 傷害承受者嘅分野（CDL-394）**：情緒守恆定律機械式計數欠債，唔理會悔意幾真誠——呢個唔係故事判斷佢抵受懲罰（呢點同[見證守則](../08_narrative_design_bible.md#section-witness-principle)已確立嘅原則一致：痛苦同態度應該被見證，唔應該被評分定罪）。真正嘅分野在於欠債嘅**來源性質**：操／紫音／凜嘅欠債主要嚟自佢哋自己作為體制／系統壓力下嘅受害者所承受嘅傷害——佢哋欠嘅債，本質上係「被加諸喺身上嘅痛苦」被呢條法則誤算做代價。秋穗嘅欠債主要嚟自佢主動加害於人嘅行為本身（將外甥女美夜子推入Unit 01路線；成個災難源頭來自佢自己嘅科學野心）——呢筆帳唔係「佢承受咗幾多」，而係「佢造成咗幾多」。呢係一種**種類上（in kind）**、唔止程度上（in degree）嘅分別：受害者嘅債，法則有機會透過外力介入、清算或轉化；但主動加害者所造成嘅債，喺呢條機械冷漠嘅法則眼中係結構性冇得清——唔論佢事後幾真誠悔恨、幾努力懺悔，呢條數本身唔會因為態度而歸零。故事對佢嘅悔意依然係真嘅、值得被見證嘅（同[見證守則]一致——態度被見到，但唔被評分免除代價）；但「被見證」同「代價被豁免」係兩件事，秋穗最終得到嘅係前者，永遠唔係後者。

## <a id="section-four-act-arc"></a>四幕弧光

### [第一幕](../05_story_outline_canon.md#section-act-1)：茶餐廳老闆娘

秋穗以「茶餐廳老闆娘」身份守護[晴香](haruka.md)，隱藏科學家過去。表面是溫暖的阿姨，暗中培養晴香的[情緒增幅器](../02_glossary.md#term-emotional-amplifier)能力，監控其力量成長。每天仍到愛莉石像前懺悔。

### [第二幕](../05_story_outline_canon.md#section-act-2)：真相揭露

秋穗在第二幕失去「善意監護人」的道德位置。  
她從保護者翻轉為加害鏈節點，與晴香的關係由信任轉為審判。規則與機制內容統一回指 [守恆定律揭露](../04_timeline_canon.md#event-conservation-revealed)。

**USB 暗中完成入侵伏線（CDL-323）**：Phase D（身份揭露前），[桐生健](../03_character_index.md#char-kiryuken)因「中介組織跑腿」身份，經朔嘅黑市網絡輾轉攞到一支 USB，插入一個 Fallen Angel 零售終端試圖截糧/攞情報，表面失敗；實際上秋穗透過已確立嘅「暗中守護+監控」行為模式（CDL-110/114 CGM 後門邏輯一致）遠端暗中完成入侵，桐生健同團隊都唔知道成功背後嘅真正原因，只留低一個睇唔明嘅系統異常記錄（時間戳唔對板）做二周目伏線。此舉同秋穗一貫「有用時保護」嘅行事模式吻合——喺身份揭露前，佢仍然透過技術手段暗中扶助晴香團隊。

**See also**: [守恆定律揭露](../04_timeline_canon.md#event-conservation-revealed)

### [第三幕](../05_story_outline_canon.md#section-act-3)：最後抉擇

**內疚→與黑奏談判的因果鏈（設計者必讀）**：第二幕身份暴露後，秋穗的內疚不是被動情緒——它是推動她走向最極端行動的主動驅力。因果鏈如下：
1. 身份暴露 → 晴香的信任崩潰 → 秋穗無法再以「保護晴香」為行動正當性
2. 正當性喪失 + 愛莉無法復原 → 內疚與絕望疊加，形成「無論何種代價，我必須讓愛莉回來」的極端動機
3. 正規科學路線全部失敗 → 秋穗主動與黑奏談判，接受黑奏的「黑市條件」（以協助黑奏收割晴香情緒換取復原愛莉的承諾）
4. 談判後進行數次合作 → 秋穗發現黑奏的承諾本質上無法兌現（愛莉的死亡屬於世界規則不可逆項）
5. 徹底失敗的確認 → 第三幕的最後抉擇：放棄修正，選擇承責

**關鍵設計注意**：秋穗與黑奏的談判不是單一場景——它是橫跨整個第三幕早期至中期的持續合作關係，逐漸讓秋穗積累更多共謀代價。她的放棄不是突然轉變，而是每一次合作失敗後一點一點侵蝕掉結果論的防牆。

面對愛莉的石像做出最後抉擇——放棄修正過去。無數次的科學嘗試全部失敗，黑奏的承諾從未打算兌現。秋穗終於放下「結果論」，不再以救贖之名累積罪孽。

### [第四幕](../05_story_outline_canon.md#section-act-4)：終點就係冇終點（CDL-394，取代原「笨蛋老媽」終局）

秋穗嘅懺悔儀式行到最後一刻都冇停過——每日仍然嚟到愛莉石像前傾訴，一句都冇少、一日都冇斷（見[石像前的懺悔](#section-behavior-hooks)，習慣本身唔改變，永遠繼續）。但佢等緊嘅回應，由頭到尾都冇嚟過。

第四幕，帝國崩潰、隊友已經耗盡最後一次能夠將佢拉返嚟嘅外力，秋穗嘅靈魂裂縫終於冇任何嘢可以再修補——佢再一次、亦係最後一次消解做無臉執行官，呢次冇人可以（或者嚟得切）將佢拉返。故事冇畀佢任何一個乾淨嘅收尾畫面、冇最後一句對白、冇一個令觀眾覺得「佢終於解脫」嘅鏡頭——佢就咁樣，永遠留喺呢個循環入面：不斷嘗試救返個女、失控、變成無臉執行官、消解、重新有返一絲意識、再嘗試……無限重複，冇終點，亦都冇任何一次真正抵達終點。

> 「終點就係冇終點。」

呢句唔係比喻——係秋穗弧光實際嘅結構本身，唔係一句形容。佢冇得到「修復愛莉」，冇得到「被愛莉原諒」，甚至連「知道自己有冇被原諒」都冇得到——佢乜都唔知道，永遠唔知道，直到循環本身冇盡頭噉重複落去。

**觀眾知道，秋穗永遠唔知道——戲劇反諷（CDL-394）**：愛莉喺集體潛意識深處，其實日日都聽晒秋穗嘅懺悔，亦都早已原諒咗佢（見[aeri.md](aeri.md)）——但呢份原諒永遠困喺集體潛意識深處，永遠冇一日傳到秋穗度。觀眾／敘事本身係唯一見證到「呢份原諒確實存在過」嘅角色。秋穗自己，由始至終都唔知道女兒有冇原諒佢——佢帶住呢個永遠嘅唔知道，一直循環落去。呢個唔係悲劇性嘅懸念留白，係佢命運本身：連「唔知道」呢件事，佢都要重複體驗落去，因為循環每次重新開始，佢連自己曾經懺悔過幾多次都唔記得。

**機制連結**：呢個終局借用並擴展[秋穗的循環](../04_timeline_canon.md#event-akiho-time-loop)——原本淨係喺「冇晴香介入嘅失敗時間線」先會發生嘅終局狀態，CDL-394將呢個範圍限制拿走，令呢個循環同樣係主線秋穗最終、永久嘅命運（詳見[§Archetype & Symbolism](#section-archetype)無臉執行官段）。

## <a id="section-behavior-hooks"></a>關鍵習慣（Behavior Hooks）

1. **石像前的懺悔** — 每天固定時間來到愛莉石像前傾訴。有時是研究進展，有時是對晴香的擔憂，更多時候是無聲的哭泣。這個習慣從未中斷過
2. **科學儀器修復嘗試** — 實驗室裡堆滿失敗的原型機。每隔一段時間，秋穗就會徹夜不眠地嘗試新方案，然後在失敗後砸毀一切。隔天又重新開始
3. **過度保護晴香** — 以阿姨身份近乎窒息地保護晴香——不允許晴香冒險、不允許晴香接觸真相。保護的背後是利用：確保晴香的力量按計劃成長
4. **工作狂** — 投入研究試圖超越花子。即使花子已死，這份競爭心態仍驅動秋穗不眠不休。茶餐廳後面的密室就是她的秘密實驗室
5. **結果論執行** — 為達目的不擇手段。做決策時只問「結果是什麼」，從不問「過程中誰會受傷」。這個習慣在第三幕被打破
5a. <a id="habit-hanako-imitation"></a>**模仿花子語調（持續表演規則）** — 在[晴香](haruka.md)面前，秋穗有意識地模仿雙胞胎妹妹花子的說話語調和慣用舉止——更溫柔的收尾語氣、稍微側傾的頭部角度、特定的點頭節奏。這是所有她面對晴香出場場景的持續背景表演，不是單次事件。「茶餐廳老闆娘」的溫暖大半是花子形象的外借，而非秋穗本人的自然流露。偶爾「洩漏」冷效率（句子截斷、停頓時間過短）——是模仿裂縫，也是真實自我的短暫顯露。
6. <a id="habit-instrument-scan"></a>**儀器掃描愛莉遺物** — 深夜穿上實驗袍進入愛莉房間，用電磁場探測器、熱成像儀、微電流測量儀逐一掃描女兒生前物品（玩具熊、畫筆、洋娃娃），記錄數值、計算波形，喃喃：「靈魂必然會在物質上留下可測量的痕跡……」儀器只顯示正常物理數據，但她重調參數、換件物品、重新開始。科學 = 逃避情感的防衛機制；每次失敗強化絕望，卻無法停止——停止等於放棄，承認愛莉真的永遠消失
7. <a id="habit-statue-dialogue"></a>**與結晶雕像的溫度問答** — 掃描後在愛莉結晶雕像前跪下，用溫度計和振動頻率分析儀問：「愛莉，你能聽到媽媽嗎？如果能，讓溫度上升 0.1 度。」死死盯著屏幕期待回應，只有隨機波動。這是她唯一允許自己展現情感的時刻——但仍無法放下「我只是做實驗」的理性假象；雕像 = 被凍結的愛，儀器 = 將不可量化的愛工具化

8. <a id="habit-hand-tremor"></a>**手震——穩手嘅出賣**（CDL-347）— 秋穗嘅雙手係全故事最著名嘅穩：精密儀器操作、手術級精細動作，呢種穩定性本身就係佢科學家身份嘅專業自豪。但每次佢要講一句用「結果論」去合理化某個犧牲（例如將美夜子推入 Unit 01 路線嗰類決定），呢雙以穩定聞名嘅手會有半秒不受控嘅微震——佢通常即刻用另一隻手按住嗰隻手，或者刻意攞返件儀器嚟做啲精細動作壓返落嚟，掩人耳目。**自我欺騙延伸**：秋穗將呢個震動私下解讀做「我手唔夠穩，所以先做唔到花子嗰種級數嘅精度」——用一個純屬愧疚滲漏嘅生理反應，去說服自己「我技不如人」係一直追唔上花子嘅真正原因，藉此迴避承認真正令佢手震嘅係良心，唔係技術。呢個係佢「瘋狂的結果論」防牆入面最深嘅一層自我欺騙，連佢自己都冇拆穿過。

### 日常形態（港式茶記前台）

- **整體輪廓（第一眼：茶記老闆娘）**：深色短袖/薄長袖 T-shirt（黑、深藍、深灰，耐污不貼身）+ 短身薄外套（開胸，袖口微微捲起）+ 深色直筒工裝褲 + 黑色防滑便鞋；毛巾掛肩（灰/白，帶用舊感）；腰間一串鑰匙圈/開瓶器
- **髮型**：深紫色長髮鬆鬆紮起（帶幾條散髮），「忙到無時間打理」感；大鯊魚夾隨意夾住；眼鏡 + 細眼鏡鏈（偏實用，非華麗）
- **眼神**：半垂眼，上眼瞼壓住虹膜上半——疲倦但極度清醒；虹膜三層：外圈深葡萄紫瞳環、中層玫紫到粉紫漸層、內圈淡粉白；瞳孔偏細，高光克制；視線習慣落半格，只有講到愛莉或實驗結果時才直視人
- **隨身裝備（一定畫到）**：落單薄（細本，角位磨損有油墨污漬，橡筋圈住）+ 名貴筆（夾在耳朵靠髮際位置，筆身啞黑/深金屬，筆夾有精密切削刻度紋）
- **科學家暗號（第二眼先見）**：筆夾的極細刻度紋；落單薄夾著幾張帶編號/條碼感的細標籤貼（觀眾誤以為茶記單據，實為研究標記）；右手中指/食指輕微墨跡（長期記錄痕跡）；手腕一條黑繩/細金屬圈（工具圈，非珠寶）
- **行動語法**：站姿微微前傾、重心在前腳，隨時轉身應客；手上永遠有落單薄、筆或抹布其中一樣；平時冷冷地少笑，一笑即短暫收起；圍裙口袋裡仍藏著微型檢測儀器（監控晴香的情緒波動）

### 過去形態（帝國首席科學家）

- 白色實驗袍 + 商務套裝——冷酷、精確、不帶感情
- 頭髮束成嚴謹的髮髻，眼鏡反光遮住眼神——這是刻意的設計意圖：髮髻+眼鏡組合的「臉部遮蔽」預示「無臉執行官」形態的到來；觀眾在第一次見到科學家形態時會感覺「有點奇怪」，第三幕揭露後才明白那種感覺的來源
- 胸前別著帝國徽章——從未真心效忠，只是交易的憑證

### 未來形態（無臉執行官）

- 純白緊身衣 + 白色高跟鞋，面部溶解為星光宇宙
- 這是秋穗最終、永久的形態（CDL-394）——不再只屬於「失敗時間線」；主線與失敗時間線最終匯合到同一個永久消解終局，差別只在於中途有沒有外力短暫拉回過她（詳見 [§Archetype & Symbolism](#section-archetype) 無臉執行官段）
- 「結果論」走到極端的完整終點——為了結果連自我都消解，而且這一次消解，沒有下一次拉回
- 身體表面浮現科學公式與數據流——知識成為囚禁靈魂的牢籠
- **武器：手刃**——雙手可硬化或包裹能量形成手術刀刃，能切開空間本身；攻擊風格「優雅而致命的揮斬」，無多餘動作，每一下都是外科手術式的精確。比任何武器更令人不安的是：她使用的是自己的身體。
