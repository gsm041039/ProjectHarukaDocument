## <a id="section-background"></a>背景故事

### <a id="section-alpha-idol"></a>Alpha 線：溫柔偶像（木之本櫻味）

凜在 Alpha 線是一名新人偶像：記得粉絲名字、在演唱會後送手折星星、在日記本上寫每個人的生日。她的魔法在 Alpha 線本是暖色系——保護、包覆、不傷人。

**Alpha 原傷（粉絲自殺事件）**：一名精神崩潰的粉絲在演唱會後輕生。凜無法透過音樂拯救他，這件事令她精神崩潰，封閉全部情緒。「我的歌聲沒有辦法救任何人。」

### 魔法即病症——情緒凍結

從粉絲自殺事件開始，凜封閉所有情感，追求絕對理性——「情緒是敵人」。冰藍色的魔法風格正是她內心凍結的外在映射。精準、高效、零失誤——這是凜為自己打造的完美牢籠。

### 與美夜子的羈絆

[美夜子](miyako.md)是凜唯一信任的戰友。兩人在軍方兵器計劃中形成效率與存活的完美配合——凜負責精準打擊，美夜子負責掩護與收割。她們之間不需要語言，一個眼神就是一整套戰術。這是凜唯一允許自己擁有的「人類連結」。

### <a id="section-destiny-displacement"></a>命運置換——晴香願望含凜

晴香在 Alpha 線 5 歲崩潰時許下的大願，包含「讓凜成為守護者而非被折斷的人」的成分。晴香的願望字面意義上取代了凜命定的偶像位置——Beta 線裡，凜的魔法軌跡從保護型偶像轉向精準型軍方兵器（見 [Timeline — Alpha/Beta 分歧](../04_timeline_canon.md#event-alpha-divergence)）。

### <a id="section-pandora-protocol"></a>潘朵拉協議——工業必然的放養

軍方啟動潘朵拉協議，並非出於陰謀，而是對不可控魔法少女的被動管理流程——監測、引流、回收。凜的兵器化是帝國對魔法定時炸彈的無奈工業處理，而非針對性的主動設計。

### 犧牲——光環處決

為掩護[美夜子](miyako.md)撤退，凜主動引開 L3 [光環](../02_glossary.md#term-halo)。光環強行扭轉她的頭顱 180 度——「喀嚓」一聲，脊椎斷裂。這個聲音成為美夜子終身的 PTSD 觸發點。凜在死亡瞬間的眼神不是恐懼，而是「終於完成任務」的釋然。

**See also**: [Timeline — 凜的犧牲](../04_timeline_canon.md#event-rin-sacrifice)

### 被重組——縫回去的軀殼

[黑奏](antagonist.md)以殘存靈魂碎片加上情緒病毒技術，將凜具現化為情緒管理局公務員。記憶被刪除，但情感印痕殘留——她不記得美夜子的臉，卻在見到她的瞬間手指會無意識地收緊；她不記得犧牲，卻在看見冰藍色時心跳短暫停頓。所有記憶的語義消失了，但身體的反應尚在。唯一的物理證據是脖子上一圈淡淡紅線——頭顱被「縫回去」的痕跡（事件節點見 [Timeline](../04_timeline_canon.md#event-rin-reconstruction)）。

### <a id="section-core-wound"></a>核心創傷——感官剝奪

**（這是凜所有後期症狀的根因，不可與重組後症狀混淆。）**

犧牲後，靈魂碎片在情緒管理局的冰封裝置中存在了相當一段時間——凜保持意識清醒，但完全無法感知外界：沒有視覺、沒有聽覺、沒有觸覺、沒有任何移動能力，只有意識本身存在於完全的感官真空中。
這段「感官剝奪期」是凜後期症狀的直接根源：
- **紅線強迫症的根因**：重組後初次感受到痛覺時，那是她第一次在「存在」中接收到任何感官信號——痛覺因此成為「確認存在」的唯一可靠橋樑。沒有感官剝奪期，就無法理解她為何選擇痛覺而非其他感覺作為錨點。
- **痛覺依存的根因**：不是對痛的愛好，而是「任何感覺都比無感覺更接近活著」——痛覺是最難被情緒麻木過濾掉的感覺類型。
- **私密音樂連結的遺失感**：凜在感官剝奪期無法聽到任何聲音，包括音樂。重組後發現自己下意識哼出一段旋律，卻總是在某個特定音符上停下——那個音符之後，應該有另一個聲音接續；那個聲音永遠不再來了。

### 痛覺信徒覺醒

重組後的凜對正面情緒完全無反應——快樂、溫暖、希望，這些詞彙在她腦中只剩下語義，沒有感受。唯有痛覺是真實的。她開始用指甲挑頸上的紅色縫合線直到出血，在痛楚中確認自己的存在——「我痛故我在」。

### 拒絕治癒——自願兵器化

凜是全作最硬的反例：知道有機會回頭，仍然選擇唔回頭。  
呢個選擇唔係自毀浪漫，而係她最後一次對自己生命保留主導權。

## <a id="section-wnlt"></a>Want / Need / Lie / Truth

| 維度 | 內容 |
|------|------|
| **Want** | 透過痛覺證明存在；被[美夜子](miyako.md)記得 |
| **Need** | 接受自己已改變但依然是凜；承認渴望被愛 |
| **Lie** | 「只有痛覺能證明存在」「我是美夜子的污點」 |
| **Truth** | 選擇拒絕治癒也是[態度](../02_glossary.md#term-attitude-vs-fate)；美夜子愛的是真實的凜，不是完美的兵器 |

## <a id="section-archetype"></a>Archetype & Symbolism

**弧光**：溫柔偶像（木之本櫻味）→ 完美主義者 → 痛覺信徒 → 自願的兵器

| 符號 | 意義 |
|------|------|
| 紅線（脖子縫合線） | 死亡的證據 / 痛覺觸發點 / 被重組的烙印 |
| 冰藍光環 | 理性極致的象徵 / 處決她的凶器——加害者與受害者合一 |
| Unit 00 | 徹底切除情感的終極選擇——不是失敗，是態度 |
| 「喀嚓」聲 | 美夜子的 PTSD 觸發音 / 凜的犧牲永遠迴響 |

**主題關聯**：子主題 A「力量的代價」——理性凍結是凜對力量失控的極端回應。子主題 C「身份的本質」——即使被重組、記憶被改寫，凜的核心[態度](../02_glossary.md#term-attitude-vs-fate)（拒絕被定義）始終未變。

## <a id="section-four-act-arc"></a><a id="section-arc-acts"></a>四幕弧光

### [第一幕](../05_story_outline_canon.md#act-1)：公務員的日常

以重組後的公務員身份出現在情緒管理局。溫和微笑、精確動作、完美禮儀——但所有表情都是統一規格，像出廠設定的人偶。脖子上的紅線被高領襯衫遮蓋。她不記得自己是誰。

### [第二幕](../05_story_outline_canon.md#act-2)：紅線觸發

[美夜子](miyako.md)發現重組的凜。當美夜子看到那圈紅線時，「喀嚓」的記憶瞬間回潮——PTSD 全面爆發。凜對美夜子的激動反應沒有語義上的理解，但身體的情感印痕仍在——美夜子靠近時，凜的手指微微收緊；美夜子不小心觸碰到紅線時，凜短暫失神。她說不出原因，但那個瞬間身體比大腦更早「知道」某件事。

### [第三幕](../05_story_outline_canon.md#act-3)：拒絕治癒

記憶逐漸恢復。凜想起了美夜子、想起了犧牲、想起了自己曾經是兵器。她在可回頭的節點上仍選擇拒絕，並自願兵器化為 Unit 00。「我不需要被治癒。我選擇我自己的結局。」

### [第四幕](../05_story_outline_canon.md#act-4)：態度即自由

凜的最終選擇成為全作品[態度 vs. 命運](../02_glossary.md#term-attitude-vs-fate)主題的極端詮釋——拒絕治癒本身就是態度的自由。她不需要被拯救、不需要被修復。美夜子最終接受：愛凜，就要接受凜的選擇。

## <a id="section-behavior-hooks"></a>關鍵習慣（Behavior Hooks）

<a id="habit-red-line"></a>**紅線強迫症**：用指甲挑頸上紅色縫合線到出血——「痛……我係度……」每次挑開都是對存在的確認。根源見 [§感官剝奪核心創傷](#section-core-wound)：痛覺是感官剝奪期結束後，凜第一個能接收的感覺信號，因此成為不可替代的存在確認方式。

1. **情緒麻木**：對快樂、溫暖、希望完全無反應——面對善意時臉上浮現的「微笑」永遠是同一個角度、同一個弧度
2. **理性面具（早期）**：追求絕對理性，「情緒是敵人」——每個動作都經過精密計算，零冗餘
3. **痛覺依存（重組後）**：「我痛故我在」——在痛覺中尋找存在感，是唯一能讓瞳孔產生焦距變化的刺激
4. **替代品恐懼**：看到美夜子保護[晴香](haruka.md)時產生病態嫉妒——自己是否已經被取代？這是凜唯一無法用理性壓制的情緒

<a id="habit-half-melody"></a>**半首旋律停頓**：凜下意識哼出一段旋律，總是在同一個音符上停住——那個音符之後應該有另一個聲音接續，而那個聲音再也不會出現。感官剝奪期後，美夜子是唯一知道那段旋律如何接續的人；凜不再開口唱完它，這是她唯一允許自己以行為形式持有的悲悼。

<a id="habit-phantom-list"></a>**幻想未來清單**：凜維持著一份從未書寫的心理清單，記錄所有被死亡截斷的普通事物：「冬天限定的草莓牛奶」「美夜子說要帶我去的拉麵店」「下次演唱會的場次」。這些事項她清楚知道自己不會實現，清單存在的意義不是計劃，而是承認「這些事本來應該發生」。清單越長，意味著活著的時間越長。

## <a id="section-visual"></a>視覺要點

| 項目 | 描述 |
|------|------|
| 身高 | 165 cm |
| 體型 | 沙漏型，被訓練的優雅 |
| 核心關鍵詞 | 光輝、聖殿、黃金比例 |
| 主色 | 黃金色 + 香檳色 + 暖紅色 |

### 魔法形態（金色聖騎士）

白色胸甲 + 聖光披風 + 白金色長裙 + 聖光法杖（金色鳳凰造型）。整體風格是「教堂彩繪玻璃中走出來的聖女」——華麗、莊嚴、不可褻瀆。冰藍色戰鬥特效在金色基調中如霜花綻放。

### 常服

白色高領襯衫 + 金色外套 + 白色直筒裙 + 珍珠項鍊。高領襯衫的存在意義：遮蓋脖子上的紅色縫合線。

### 被重組後

外貌不變，但眼神空洞——所有微笑僵硬統一，像批量生產的表情貼紙。動作過度精確，連呼吸頻率都像被程式設定過。

### 關鍵視覺線索

脖子上一圈淡淡紅線——頭顱被縫回去的痕跡。平時被高領遮蓋，關鍵場景中暴露。紅線是全角色最重要的 Visual Clue，連接犧牲記憶與痛覺信仰。

### 視覺微細節

- **1/1000 度微笑弧光**：凜與美夜子相處的場景中，嘴角弧度在整個故事中以肉眼幾乎無法察覺的量微量上升。全作品最細膩的成長視覺——刻意設計為只有反覆觀看第一幕與第四幕才能確認的差值。
- **術前/術後微行為對比**：接受改造手術前，凜緊張時以右手指尖輕觸左腕脈搏點（確認心跳存在）。術後，同一個「確認」動作轉移目標——左手觸碰胸口裝置位置。動作模式相同，但確認的對象從「有機體心跳」轉為「機械設備」，在不解說的情況下揭示其內在參照物的改變。
