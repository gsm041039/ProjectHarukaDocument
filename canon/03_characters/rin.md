## <a id="section-background"></a>背景故事

### <a id="section-unloved-origin"></a>母親——被物化嘅童年起點（CDL-353）

凜嘅母親從來冇愛過佢。細個嗰陣，母親逼佢去做偶像歌手——唔係支持佢嘅夢想，係將佢當做賺錢工具。台上嘅掌聲係凜人生入面第一次感受到「原來我可以令人開心」；呢份因表演而來嘅溫暖，同母親冷漠嘅家形成強烈對比，令凜不知不覺將「對人溫柔、俾人開心」同「值得存在」劃埋等號——粉絲嘅愛，變咗做佢原生家庭冇畀過佢嘅嘢嘅代替品。帝國招募佢做魔法少女兵器嗰陣，畀咗一筆錢母親做「補償」——母親攞咗錢，從此頭也不回，冇再見過凜。**呢個係凜「溫柔冇得到合理回應」呢條線嘅真正起點，亦係佢自己都未必意識到嘅根**：佢對粉絲嘅溫柔，某程度上係對住一個從來冇愛過佢嘅母親、悄悄舉行嘅代替儀式。

### <a id="section-alpha-idol"></a>Alpha 線：溫柔偶像（木之本櫻味）

凜在 Alpha 線是一名新人偶像：記得粉絲名字、在演唱會後送手折星星、在日記本上寫每個人的生日。她的魔法在 Alpha 線本是暖色系——保護、包覆、不傷人。

**Alpha 原傷（粉絲自殺事件）**：一名精神崩潰的粉絲在演唱會後輕生。凜無法透過音樂拯救他，這件事令她精神崩潰，封閉全部情緒。「我的歌聲沒有辦法救任何人。」

### 魔法即病症——情緒凍結

從粉絲自殺事件開始，凜封閉所有情感，追求絕對理性——「情緒是敵人」。冰藍色的魔法風格正是她內心凍結的外在映射。精準、高效、零失誤——這是凜為自己打造的完美牢籠。

### 與美夜子的羈絆

[美夜子](miyako.md)是凜唯一信任的戰友。兩人在軍方兵器計劃中形成效率與存活的完美配合——凜負責精準打擊，美夜子負責掩護與收割。她們之間不需要語言，一個眼神就是一整套戰術。這是凜唯一允許自己擁有的「人類連結」。

### <a id="section-destiny-displacement"></a>命運置換——晴香願望含凜

晴香在 Alpha 線 5 歲崩潰時許下的大願，包含「讓凜成為守護者而非被折斷的人」的成分。晴香的願望字面意義上取代了凜命定的偶像位置——Beta 線裡，凜的魔法軌跡從保護型偶像轉向精準型軍方兵器（見 [Timeline — Alpha/Beta 分歧](../04_timeline_canon.md#event-alpha-divergence)）。

### <a id="section-pandora-protocol"></a>Stage 1——搜尋螢的靈魂容器（非潘朵拉協議）[CDL-307 修正]

凜嘅兵器化屬於魔法少女計劃 **Stage 1（徵召兵器，103-108年）**，並非後來嘅潘朵拉協議（109年才啟動，凜108年已犧牲，時序上不可能屬於此階段）。Stage 1 由黑奏親自主導，目標係搵到可承載螢靈魂碎片嘅肉身容器；凜是其中一名容器候選。軍事化強徵並非出於針對性陰謀，而是對「不可控魔法定時炸彈」的工業化管理，但凜因帶有[晴香五歲奇蹟願望的殘留印記](#section-destiny-displacement)（護甲效應）而保留完整人性，未如其他候選般變成「無意識魔法少女」——她的完整人性正是 Stage 1 最終被判定「人性不可控」而廢止的例證之一（見 [aya.md §Stage 1](aya.md#section-kurokane)）。

### 犧牲——光環處決

為掩護[美夜子](miyako.md)撤退，凜主動引開 L3 [光環](../02_glossary.md#term-halo)。光環強行扭轉她的頭顱 180 度——「喀嚓」一聲，脊椎斷裂。這個聲音成為美夜子終身的 PTSD 觸發點。凜在死亡瞬間的眼神不是恐懼，而是「終於完成任務」的釋然。

> 她本來想用聲音救人，最後卻連自己的聲音都留不住。

**See also**: [Timeline — 凜的犧牲](../04_timeline_canon.md#event-rin-sacrifice)

### 被重組——縫回去的軀殼

[黑奏](aya.md#section-kurokane)以殘存靈魂碎片，借[維多利亞之淚](../02_glossary.md#term-tears-of-victoria)集體潛意識深層讀寫功能，將凜重組為情緒管理局公務員。記憶被刪除，但情感印痕殘留——她不記得美夜子的臉，卻在見到她的瞬間手指會無意識地收緊；她不記得犧牲，卻在看見冰藍色時心跳短暫停頓。所有記憶的語義消失了，但身體的反應尚在。唯一的物理證據是脖子上一圈淡淡紅線——頭顱被「縫回去」的痕跡（事件節點見 [Timeline](../04_timeline_canon.md#event-rin-reconstruction)）。

**復原機制（CDL-331 修正）**：黑奏的重組並非自行發動現實覆寫，而係借[維多利亞之淚](../02_glossary.md#term-tears-of-victoria)——帝國監控集體潛意識嘅核心裝置，同時亦係軍方深層讀寫集體潛意識嘅唯一介面——操控晴香帝國歷102年創世時遺落、瀰漫成個 Beta 線嘅因果能量殘餘，完全還原凜的肉體至死前的物理狀態。此機制與美夜子復活（秋穗版）同屬借助維多利亞之淚嘅集體潛意識深層讀寫，差異在於施術者與靈魂保存方式：凜的靈魂碎片冰封於 EMB 裝置，而非在集體潛意識自然飄蕩。肉體物理上完整且活著，但靈魂攜帶「頸椎斷裂即死」的死亡印記，引發 [靈魂-肉體排斥反應](../01_world_rules_and_costs.md#rule-soul-body-rejection)——這是凜正面情緒語義化、一般觸覺弱化的底層機制。**注（CDL-333 修正）**：此為軍方/黑奏操控現存因果能量殘餘嘅局部技術層「奇蹟」（第四層現實覆寫）應用，屬細規模、操控殘餘型；並非「[巨大奇蹟](../02_glossary.md#term-reality-override)」（自行原生產生、世界級現實覆寫，全劇僅發生兩次：晴香5歲創世、菲/夕Phase J），唔計入「兩次巨大奇蹟」嘅事件計數，但仍受「奇蹟」三項硬限制約束。

### <a id="section-core-wound"></a>核心創傷——感官剝奪

**（這是凜所有後期症狀的根因，不可與重組後症狀混淆。）**

犧牲後，靈魂碎片在情緒管理局的冰封裝置中存在了相當一段時間——凜保持意識清醒，但完全無法感知外界：沒有視覺、沒有聽覺、沒有觸覺、沒有任何移動能力，只有意識本身存在於完全的感官真空中。

**死前嘅潛意識願望——想擺脫痛，攞到嘅係比痛更可怕嘅虛無（CDL-351）**：光環處決一刻嘅「釋然」（見[犧牲——光環處決](#section-background)）唔止係「終於完成任務」，底下仲藏住一個佢自己都未意識到嘅願望——如果冇咗記得住呢種痛（保護唔到粉絲、同美夜子之間永遠冇講出口嘅牽掛）嘅呢個自己，會唔會舒服啲？呢個潛意識願望，係佢冇去抵抗黑奏借維多利亞之淚抹走記憶嗰下嘅根本原因（對比其他Stage 1候選者因為晴香願望殘留印記而「人性不可控」，會抵抗抹走——凜嘅例外唔係佢特別強，而係佢特別冇爭取）。**但佢攞到嘅唔係解脫，係比痛楚可怕一萬倍嘅嘢**：完全嘅感官真空，連自己是否存在都確認唔到嘅虛無。呢個先精準解釋咗痛覺依存嘅轉變——唔係凜忽然變態鍾意痛，而係佢用最切身嘅方式學識咗：冇感覺唔係平靜，係比痛楚更深嘅深淵；痛至少證明緊「乜嘢都冇消失晒」。「我痛故我在」四個字，先有一個真正落過去嗰度、番過嚟嘅重量。

呢段「感官剝奪期」是凜後期症狀的直接根源：
- **紅線強迫症的根因**：重組後初次感受到痛覺時，那是她第一次在「存在」中接收到任何感官信號——痛覺因此成為「確認存在」的唯一可靠橋樑。沒有感官剝奪期，就無法理解她為何選擇痛覺而非其他感覺作為錨點。
- **痛覺依存的根因**：不是對痛的愛好，而是「任何感覺都比無感覺更接近活著」——痛覺是最難被情緒麻木過濾掉的感覺類型。
- **私密音樂連結的遺失感**：凜在感官剝奪期無法聽到任何聲音，包括音樂。重組後發現自己下意識哼出一段旋律，卻總是在某個特定音符上停下——那個音符之後，應該有另一個聲音接續；那個聲音永遠不再來了。

### 痛覺信徒覺醒

重組後的凜對正面情緒完全無反應——快樂、溫暖、希望，這些詞彙在她腦中只剩下語義，沒有感受。唯有痛覺是真實的。她開始用指甲挑頸上的紅色縫合線直到出血，在痛楚中確認自己的存在——「我痛故我在」。

### 黑奏——冇再回頭嘅救命恩人（CDL-353）

重組公務員身份嘅凜，某程度上將黑奏當做「救咗自己一命」嘅人——雖然佢對呢段記憶冇語義印象，但潛意識存在住一種近乎義務式嘅回報衝動，驅使佢做咗好多同自己溫柔本性有抵觸嘅事（例如執行情緒管理局某啲冷酷政策、監視/舉報平民）。**呢種順從最殘忍嘅位喺於：黑奏根本已經冇再留意佢**——108年凜犧牲、Stage 1正式終止之後，黑奏已經轉向耐心培養晴香（Stage 2潘朵拉協議，見[aya.md §Stage 1](aya.md#section-kurokane)），凜嘅存在對黑奏嚟講只係一個已經完成任務、冇再需要關注嘅舊項目。凜單方面盡力想符合一個已經move on嘅人嘅期望，換嚟嘅淨係沉默。

### 帝國走狗——被誤解嘅溫柔（CDL-353）

日常執勤入面，凜其實真心幫緊唔少市民——但制服本身就係一個標籤，市民見到情緒管理局徽章，本能戒備甚至講難聽說話（「帝國走狗」一類）。凜心裡明白，外表冷靜處理，唔會反駁或者解釋。呢個係佢溫柔被制度性誤解嘅日常背景質感，同下面粉絲之母/生母事件唔同層級——後兩者係尖銳嘅個人事件，呢個係長期、低強度、麻木咗嘅背景噪音，證明凜對「溫柔冇合理回應」呢件事，其實已經捱咗好耐。

### 兩次溫柔嘅崩塌——粉絲之母 vs 生母重逢（CDL-353，兩層遞進結構）

凜嘅溫柔唔係未經歷過痛苦嘅天真——佢細個已經捱過母親嘅冷漠、之後又捱住黑奏嘅冷待、日常仲要俾人當做走狗，佢一路都揀咗溫柔。真正令佢放棄嘅，唔可以係「又一次唔被珍惜」（呢個佢捱慣咗），必須係一擊攻擊緊「溫柔本身有冇意義」呢條信念根基嘅嘢——兩層遞進，同紫音「細佬vs小光死」（CDL-335）用嘅係同一種結構（第一次可以否認，第二次確認咗個恐懼）。

**第一層（種子，中段，可以捱得住）——粉絲之母**：凜以情緒管理局身份，喺一次任務／日常執勤中接觸到當年喺Alpha原傷入面輕生嗰個粉絲嘅母親——母親本身都瀕臨崩潰邊緣。凜出於真心幫咗佢（雙方都唔認得對方——凜個樣、聲音、身份全部changed）。但幫助之後，母親講出一句直接指控溫柔本身有害嘅說話——例如指控「你哋呢啲人成日笑住話會好轉，先害到我個女信咗、跟住發現冇好轉先自殺」，將凜嘅溫暖重新定性做「假希望嘅共犯」。凜要默默接住呢句原本針對自己、但對方唔知道係啱啱好講緊佢自己嘅指控，冇資格解釋、冇資格喊。呢一次，凜仲可以將呢個當做一個陌生人嘅片面指控，未完全確認個恐懼。

**第二層（確認，114年2月底-3月初，自願兵器化前夕）——生母重逢**：凜想知道自己死前嘅身世，主動問黑奏。黑奏（跟返已有嘅「數據養殖計劃」放養→絕望循環機制，見[aya.md](aya.md#section-kurokane)）刻意安排凜見返生母——呢個唔係單純殘忍，而係黑奏一路用緊嘅手法：畀希望，然後任由現實粉碎，收割崩潰產生嘅情緒能量，順道推凜向Unit00（更馴服、更斷絕情感）行多一步。凜帶住重新連結嘅開放心懷去見返生母（主動釋出溫柔，唔止係被動等待）——換嚟嘅係生母見到「死而復生」嘅女兒，直接、赤裸嘅噁心反應，冇解釋、冇擁抱、頭也不回噉走。呢次冇得辯解係陌生人唔理解——係佢一生最初、理應最應該接住佢溫柔嘅人，用最直接嘅生理反感確認咗「溫柔伸出去，換嚟嘅可能係嫌棄」。兩層夾埋，完成「我一直揀嘅嘢，可能一直都係錯嘅、冇意義嘅」呢個信念嘅崩塌。

### 拒絕治癒——自願兵器化

凜是全作最硬的反例：知道有機會回頭，仍然選擇唔回頭。
呢個選擇唔係自毀浪漫，而係她最後一次對自己生命保留主導權。

**三層命運被人決定嘅完整因果鏈（CDL-348）**：凜嘅心理唔止係「痛覺依存」，更深一層係——**佢一生入面「自己係邊個」呢件事，從來冇一次係佢自己揀嘅**。①**Alpha 原傷**：粉絲自殺事件令佢相信自己嘅溫暖/歌聲係靠唔住嘅承諾，退守做絕對理性。②**[命運置換](#section-destiny-displacement)**——呢層先係全部症狀嘅根，之前分析一直忽略咗：晴香五歲許嘅願望包含「想凜做守護者而唔係被折斷嘅人」呢個善意成分，**字面意義上取代咗凜命定嘅偶像位置**，Beta線嘅凜由保護型偶像變咗做精準型兵器——唔係佢自己揀，而係一個陌生人出於好意嘅願望，直接改寫咗佢應該係邊種人，而佢自己完全冇意識到呢件事發生過。③**替代品恐懼**（見 [habit-4](#section-behavior-hooks)）：見到美夜子全力保護晴香會產生病態忌妒——「自己係咪已經被取代咗？」——呢個唔係基於事實嘅指控（凜嘅犧牲本身正正係為咗掩護美夜子撤退，係愛嘅動作），而係佢潛意識已經帶住「我嘅位置隨時可以被一個更值得被救嘅人取代」呢個模版（第②層已經教識佢呢件事）在自動重演。三層焊埋一齊：凜由頭到尾，佢係邊個、佢死過又番生嗰個係咪佢，全部都係俾其他人（雖然出於愛）決定嘅，佢自己一次都冇揀過。

**呢個先令「自願」兩個字有真正重量**：之前每一次改變（偶像變兵器、死亡變重組公務員）都係其他人加喺佢身上；自願兵器化嗰刻，先係凜有記憶以嚟第一次由自己決定自己會變成咩——即使揀嘅係黑暗嘅嘢。

**點解係Unit00而唔係自殺——「有保證會有人搵到佢、放佢走」嘅深淵（CDL-351）**：Unit 00-Null 嘅終局狀態「活著但無感」「眼神空洞」，質感同[死前潛意識想擺脫痛而攞到嘅完全感官真空](#section-core-wound)非常接近——即係話凜最終選擇嘅，正正係一個好似返嗰個佢最驚嘅深淵嘅狀態。但呢次唔同嘅係：**佢揀嘅唔係「獨自返去嗰個深淵」，而係「保證會有人搵到佢、放佢走」嘅深淵**——佢揀美夜子做結束佢嘅人，因為美夜子有一個「[介錯人的覺悟](miyako.md#介錯人的覺悟)」嘅誓言，一定會嚟、一定會確保佢以人嘅身份死去，唔會撇低佢獨自留喺嗰度。自殺解決唔到呢個問題：自殺只會重演最恐怖嗰段（獨自面對虛無，冇人知、冇人陪、冇任何保證），仲要凜自己已經有一次死而復生嘅先例，冇證據話再死一次就一定唔會再俾人拉返嚟。凜嘅選擇本質係：情願行返入去嗰個佢最驚嘅深淵，但今次賭嘅係美夜子一定會嚟搵佢、一定會放佢走——呢個先真正回應咗佢對「被遺忘/被替代」（[替代品恐懼](#section-behavior-hooks)）嘅終極恐懼：即使去到冇感覺嘅深處，美夜子都會嚟。**呢個唔改變任何已有情節**（E-III-I5「凜的最終戰——遲來的介錯」保持不變），純粹補完點解一定要係Unit00、點解一定要係美夜子呢兩層心理原因。

**最後嘅溫柔——放棄自己，唔係放棄世界（CDL-353）**：凜最終嘅選擇係放棄自己，而唔係報復整個世界——呢一點係全條線最深嘅弔詭，必須突出。Unit 00-Null 擁有巨大破壞力，但即使喺意識接近清零嘅狀態下，凜（或者佢殘存嘅本能）都刻意避開多人聚集嘅地方；佢向美夜子提出嘅要求極度卑微——唔係求救、唔係求解釋，淨係求一個乾淨嘅結束就夠。**呢個先係凜由頭到尾都冇真正放棄過核心自我嘅鐵證**——佢已經唔再相信溫柔/保護有意義，但佢最後一個動作，依然係保護（唔傷及旁人），依然係溫柔（信任美夜子會乾淨咁完成，唔想俾任何人揹上額外痛苦）。凜自己可能已經冇意識去承認呢個係「佢自己」做緊嘅嘢，但觀眾睇得到：**凜從來冇放棄過做返凜，佢只係放棄咗「相信呢件事仲有意義」**。

**同美夜子「失去死亡權利」嘅主題配對（子主題C：身份的本質）**：美夜子嘅悲劇係「唔准佢停低」——佢死咗，但技術逼佢繼續活，冇資格擁有結束；凜嘅悲劇方向相反但同根——佢冇被剝奪「停低」呢個結果本身（佢真係死過、亦真係去到Unit00終點），佢被剝奪嘅係**點樣停低**——原本嗰次感官剝奪期，佢係獨自一個、冇人陪住、意外咁墮落去嗰個虛無。兩個都係「技術令自然嘅解脫過程被扭曲」嘅變奏，一個係「唔准停」，一個係「停嘅方式被剝奪咗尊嚴/陪伴」——凜最終嘅選擇，正正係佢自己攞返呢個「點樣停低」嘅主導權：呢次唔再獨自，唔再意外，係佢揀嘅人、揀嘅方式。

<a id="habit-final-severance"></a>**最後嘅斷絕（CDL-337）**：重組後嘅凜雖然記憶被刪，但[真實但唔自知嘅溫柔](#第一幕公務員的日常)一路殘存——放空時雙手仍會不受控咁摺出星星，摺完之後一如既往面無表情咁掃入垃圾桶（呢個「掃入垃圾桶」嘅處理方式本身由重組後開始就一直冇變，見[摺紙星星](#section-behavior-hooks)，唔係斷絕嘅訊號）。真正嘅斷絕發生喺自願兵器化嗰刻：連呢個不受控嘅摺紙衝動本身都被佢自己主動掐死——由「雙手不由自主咁摺出星星」變成「雙手唔再摺」。呢個先係真正嘅反差恐怖——唔係佢一開始已經冇晒溫柔，而係佢連自己都控制唔到嘅最後一絲身體記憶，都被自己揀擇連根拔起。

**違反套路預期——溫柔嘅濃淡同記憶恢復無關（CDL-341，方向確認，具體演出留Beat Sheet）**：建議喺Act III「記憶逐漸恢復」段加一場戲：美夜子見到凜又摺緊星星，呢次摺得比以前更專注、更似返記憶入面「通宵摺俾粉絲」嗰種認真，美夜子心裡浮現希望：「佢係咪快啲記番起、快啲好返？」（套路化解讀：溫柔回歸＝治癒進度條）。但呢個解讀一開始就係誤判——溫柔由重組復活嗰刻已經真實存在，同記憶恢復無關。真正嘅高潮反而係自願兵器化前一刻，凜清醒噉將呢粒完美嘅星星**主動捏碎**（唔再係一如既往面無表情噉掃入垃圾桶）——表面睇好似「佢連最後一絲溫柔都殺死自己」，但真正意義係凜第一次對呢份連自己都控制唔到嘅身體記憶行使完整主導權，係「態度即自由」主題嘅極端示範。呢個提案唔改「拒絕治癒係態度自由」呢個結局，只係用具體場景加強佢嘅說服力。

**嘆息之橋獨立場景（btd）**：凜在 [嘆息之橋](../04_timeline_canon.md#event-bridge-of-sighs) 有一個獨立的 beat（Phase G 或 H 某時），代表她弧光中的某個關鍵時刻。具體設計（事件內容、情感意義、與主角團的關係）待 Beat Sheet 層確認。

## <a id="section-wnlt"></a>Want / Need / Lie / Truth

| 維度 | 內容 |
|------|------|
| **Want** | 透過痛覺證明存在；被[美夜子](miyako.md)記得 |
| **Need** | 接受自己已改變但依然是凜；承認渴望被愛 |
| **Lie** | 「只有痛覺能證明存在」「我是美夜子的污點」「我的溫柔冇意義，甚至有害」（CDL-353） |
| **Truth** | 選擇拒絕治癒也是[態度](../02_glossary.md#term-attitude-vs-fate)；美夜子愛的是真實的凜，不是完美的兵器；她從未真正放棄過溫柔本身——只是放棄咗相信呢件事仲有意義（CDL-353，見[最後嘅溫柔](#拒絕治癒——自願兵器化)） |

## <a id="section-four-act-arc"></a><a id="section-arc-acts"></a>四幕弧光

### [第一幕](../05_story_outline_canon.md#act-1)：公務員的日常

以重組後的公務員身份出現在情緒管理局。溫和微笑、精確動作、完美禮儀。脖子上的紅線被高領襯衫遮蓋。她不記得自己是誰。

**真實但唔自知嘅溫柔——正面特質（CDL-337，修正原「統一規格出廠人偶」講法）**：記憶被刪除，但情感印痕殘留（見[被重組——縫回去的軀殼](#section-background)）唔止係生理反射咁簡單——凜對人真係會自然咁溫柔，禮貌、細心、留意人哋需要，呢份溫柔係**真實**嘅，唔係表演出嚟嘅制式笑容，只不過她自己完全解釋唔到呢份溫柔嚟自邊度、為咗邊個，好似肌肉記憶咁，唔使佢個「自我」有意識咁決定要溫柔。呢份溫柔由重組復活嗰一刻已經存在，唔係佢「慢慢變好」先浮現嘅嘢——一復活出嚟就已經係咁，唔使等成長先解鎖。觀眾喺Act I就可以直接感受到凜係一個溫暖、討人鍾意嘅角色，唔使靠事後解構先明白；核心悲劇喺於佢自己完全唔理解呢份溫柔嘅來源同意義，只係本能咁做緊。呢份溫柔喺重組後一直以呢種唔受控嘅身體記憶形式運作（貫穿[痛覺信徒覺醒](#section-background)之後都仲存在），直到[自願兵器化 Unit 00](#section-background)嗰刻，凜先主動掐熄呢個連自己都控制唔到嘅摺紙衝動本身——由「雙手不由自主咁摺出星星」變成「雙手完全唔會再咁做」。唔係「一開始已經全冷」，而係一路都仲有少少，直到佢揀擇斷絕呢個最後嘅殘留動作。

**殘忍只指向自己**：凜復活之後嘅黑暗面（紅線強迫症、痛覺依存、「我痛故我在」）全部係**自我傷害**，唔係對人殘忍——挑頸上縫合線出血、通宵冰水浸泡等自毀式行為，對象一律係自己。佢對其他人（美夜子、隊友、甚至陌生人）嘅態度由重組復活到自願兵器化之前，一直維持真實嘅溫柔（見上文），從未展現過對人嘅冷酷或惡意。即係話凜嘅殘忍同溫柔唔係同一個開關嘅兩面、亦唔係互相矛盾——佢係對己殘忍，對人溫柔，兩者同時成立、方向相反。

**E-02 信息種植（CDL-084）**：美夜子在 E-02 向晴香提出情緒連結時，以極簡一句提及凜，帶一瞬猶豫或沉默——「我以前…同一個人試過。應該有效。」晴香察覺美夜子的猶豫但沒追問。觀眾記住「美夜子有秘密/過去」，但不得任何具體信息。設計原則：極簡一句、不超出一句話，目的是種下印象而非揭露。

**E-04 前史呈現方式（CDL-068）**：短暫閃回片段（靜態圖像 + 美夜子旁白）；觀眾感受情緒衝擊但唔完全理解機制；刻意克制——不過早揭露美夜子弧光根源，保留晴香慢慢令她打開的感覺。E-02 的一瞬猶豫在此場景獲得回收，情感衝擊翻倍。

### [第二幕](../05_story_outline_canon.md#act-2)：紅線觸發

[美夜子](miyako.md)發現重組的凜。當美夜子看到那圈紅線時，「喀嚓」的記憶瞬間回潮——PTSD 全面爆發。凜對美夜子的激動反應沒有語義上的理解，但身體的情感印痕仍在——美夜子靠近時，凜的手指微微收緊；美夜子不小心觸碰到紅線時，凜短暫失神。她說不出原因，但那個瞬間身體比大腦更早「知道」某件事。

**中段踏腳石（2026-07-06 co-design）**：完整 PTSD 爆發之前，凜曾以管理局人員身份於愛莉潛意識風暴（Act II，見 ACT_II_OUTLINE.md E-11）近距離接觸美夜子——觸發一次無意識生理反應（手指收緊/見冰藍色心跳短暫停頓），冇對白冇自覺認知，純粹身體記憶碎片疊加。此為第二次近距離接觸（第一次為 Act I 普通交戰），強化後續正式揭露前嘅鋪墊密度。

### [第三幕](../05_story_outline_canon.md#act-3)：拒絕治癒

記憶逐漸恢復。凜想起了美夜子、想起了犧牲、想起了自己曾經是兵器。她在可回頭的節點上仍選擇拒絕，並自願兵器化為 Unit 00。「我不需要被治癒。我選擇我自己的結局。」

### [第四幕](../05_story_outline_canon.md#act-4)：態度即自由

凜的最終選擇成為全作品[態度 vs. 命運](../02_glossary.md#term-attitude-vs-fate)主題的極端詮釋——拒絕治癒本身就是態度的自由。她不需要被拯救、不需要被修復。美夜子最終接受：愛凜，就要接受凜的選擇。

## <a id="section-behavior-hooks"></a>關鍵習慣（Behavior Hooks）

<a id="habit-red-line"></a>**紅線強迫症→儀式化告別（習慣質感轉變，CDL-348）**：用指甲挑頸上紅色縫合線到出血——「痛……我係度……」每次挑開都是對存在的確認。根源見 [§感官剝奪核心創傷](#section-core-wound)：痛覺是感官剝奪期結束後，凜第一個能接收的感覺信號，因此成為不可替代的存在確認方式。平時呢個動作帶焦慮、強迫性質。**轉捩點**：自願兵器化前一刻（可回頭卻主動唔回頭嘅節點），凜挑紅線嘅動作首次變得平靜、唔急，甚至帶一絲溫柔——由「焦慮式強迫」轉做「平靜嘅、主動揀嘅告別儀式」，同[摺紙星星主動捏碎](#habit-final-severance)並行發生，一齊示範「呢次改變，終於係我自己揀嘅」。

**鏡中放大層（Shadow Passion；見 [Visual Bible — 內在陰影的超現實受難](../06_visual_bible.md#section-shadow-surreal-passion)）**：凜挑紅線分兩層呈現——**現實層**只剩極克制的微動作（指甲輕觸縫合線、手指無意識收緊）；**鏡中陰影層**則放大為超現實狂態：陰影瘋狂挑開頸上紅線至血流不止，並重複將冰冷金屬扣一格一格嵌入自身肉體。此狂態具現凜「沉溺苦難以拒絕成長 / 拒絕自救」的小我——痛楚成為她說服自己「我已咁慘、無能為力」的實體證據，陰影主動維持傷口以切斷被治癒的可能。呼應 [§ Want/Need/Lie/Truth](#section-wnlt) 的 Lie「只有痛覺能證明存在」。

1. **情緒麻木**：對快樂、溫暖、希望完全無反應——呢個麻木指嘅係佢**接收**善意時嘅內在感受（別人對佢好，佢冇任何主觀快樂/溫暖/希望嘅感覺，只剩語義）；呢個同[真實但唔自知嘅溫柔](#第一幕公務員的日常)——即佢**主動釋出**嘅溫柔——係兩件唔同嘅事：對外釋出的溫柔是真實的身體反射，但對內接收正面情緒的能力已經死咗
2. **理性面具（早期）→當面具做本我（心理防禦，CDL-349）**：追求絕對理性，「情緒是敵人」——每個動作都經過精密計算，零冗餘。**精確心理機制**：呢個面具唔止係做俾人睇嘅表演，凜自己都真心相信「呢個冷靜、受控嘅我」先係真正嘅自己——同[操嘅眼罩習慣](ayakomoji_misao.md#habit-eye-mask)（明知自己喺表演，摘低眼罩試圖搵返「真正嘅我」但永遠搵唔到）唔同，凜連「搵」呢個動作都冇咗，佢已經冇再問「面具下面係邊個」呢條問題——佢接受咗面具就係本我。根源係佢由頭到尾冇一次被容許自己揀（見[三層命運被人決定嘅完整因果鏈](#拒絕治癒——自願兵器化)）：連結／愛每次都以「被改寫」收場（晴香嘅願望、黑奏嘅重組），所以凜潛意識將呢個受控嘅面具當成**唯一冇被人拎走過嘅嘢**——佢唔信任任何人，甚至唔信任自己殘存嘅溫柔係屬於自己嘅（見下面[真實但唔自知嘅溫柔](#第一幕公務員的日常)——佢對自己嘅溫柔嘅解釋唔到，正正因為佢已經唔認呢份溫柔係「自己」嘅一部分）。
3. **痛覺依存（重組後）**：「我痛故我在」——在痛覺中尋找存在感，是唯一能讓瞳孔產生焦距變化的刺激
4. **替代品恐懼**：看到美夜子保護[晴香](haruka.md)時產生病態嫉妒——自己是否已經被取代？這是凜唯一無法用理性壓制的情緒
5. <a id="habit-passive-voice"></a>**被動語態自述→主動語態（語言習慣轉變，CDL-349）**：凜講起自己嘅遭遇，慣性用被動句式——「頭係俾人扭斷嘅」「記憶係俾人整走嘅」「呢個身體係俾人縫返嘅」，永遠以「俾人」做主導，唔用「我」做主詞。呢個同其他角色嘅自我敘事形成鮮明對比：彩／美夜子／操等人嘅核心 Lie 全部係主動式罪疚（「我做錯咗」「我唔配」），淨係凜一個係被動式受害（「啲嘢係人哋加喺我度」）——三層因果鏈全部係「被發生」而非「我做咗」。**轉捩點**：自願兵器化嗰刻，凜第一次用主動句式講自己（例如原本會講「呢個係人哋決定俾我嘅」，變成「呢個係我揀嘅」），同[紅線儀式嘅質感轉變](#habit-red-line)同一刻發生——語言同身體兩條線一齊完成「終於由自己嚟講自己嘅故事」呢個payoff。

<a id="habit-half-melody"></a>**半首旋律停頓**：凜下意識哼出一段旋律，總是在同一個音符上停住——那個音符之後應該有另一個聲音接續，而那個聲音再也不會出現。感官剝奪期後，美夜子是唯一知道那段旋律如何接續的人；凜不再開口唱完它，這是她唯一允許自己以行為形式持有的悲悼。

<a id="habit-phantom-list"></a>**幻想未來清單**：凜維持著一份從未書寫的心理清單，記錄所有被死亡截斷的普通事物：「冬天限定的草莓牛奶」「美夜子說要帶我去的拉麵店」「下次演唱會的場次」。這些事項她清楚知道自己不會實現，清單存在的意義不是計劃，而是承認「這些事本來應該發生」。清單越長，意味著活著的時間越長。

<a id="habit-paper-stars"></a>**摺紙星星（武器化的溫柔）**（CDL-154）— 凜在成為魔法少女/軍方武器之前，摺星星笨拙緩慢，但因為真心相信「小小的善意有用」，會通宵達旦一粒一粒慢慢摺（送給粉絲的心意，每粒都帶著純粹的祝福）。被軍方改造後，植入的頂級精細操作能力（Fine motor skills）讓她以殘影般的速度，單手摺出幾何比例完美的星星。被黑奏重組、記憶清空後，她不再知道這個習慣的來源——放空時雙手不受控地高速摺出一堆完美的星星，然後面無表情地全部掃入垃圾桶（「不具備戰術價值的無意義行為」）。**悲劇核心**：她失去了愛的能力，但身體還記住愛的形狀；她擁有了超凡的速度，卻永遠沒有辦法再將星星送給任何一個會為此微笑的人。**AKS 埋位**：Act I 旁觀者初見=「冷血特工在炫耀恐怖的手指靈活度」；Act II/III凜前史揭露後回溯=「原來她不受控的雙手，一直在追尋當年通宵摺星星的自己。」

| 體型 | 高中少女比例，偶像出身的輕盈感；兵器化後動作過度精準 |

| 主色 | 日常：黑 / 灰 + 隱藏黃色；MG1：孔雀綠 + 金 + 粉紅 + 白；MG2：黑 + 深綠 + 金屬 + 血紅痛覺點 |

### 常服（金絲雀隱身語法）

- **主題**：明星出街隱藏身份 + 金絲雀。凜喜歡唱歌，但被迫成為魔法少女與兵器，像會唱歌卻被困住的金絲雀。
-**外套與帽**：短身連帽外套（全黑/深灰）+ 鴨嘴帽；帽簷底側加一條極幼淡黃邊線（任何光線下都可讀到）；兜帽內襯灰粉/煙粉（低頭或風吹才露出的呼吸色）
- **裙**：深炭黑百摺裙，摺面加同色淡籠格壓紋（近看才見的籠格——被困歌鳥）；裙擺一兩條摺位內側有極淡黃羽片形 wedge（走路才閃一下）
- **整體語法**：外觀偏黑 / 灰 / 低調，壓低偶像辨識度；金絲雀語言只藏在帽飾、鈴鐺、耳環、內襯或走動時閃現的位置。
- **遮蓋功能（紅線）**：高領打底衫或兜帽領口遮蓋脖子紅色縫合線——功能同現有設定一致，以低調輪廓實現。
- **心理意義**：不是單純 casual，而是「會唱歌的人被迫噤聲」「明星被迫藏起自己」的日常版本。

### 魔法少女形態一（孔雀 / 飛行員）

- **主題**：孔雀 + 飛行員。此形態代表凜原本較明亮、自信、可愛的一面，是「飛行、展開、被看見」的版本。
- **主色與氣質**：孔雀綠為主色；金 + 粉紅 + 白負責拉回夢幻、可愛、木之本櫻味的少女感。
- **輪廓**：背上翼與飛行員外套改造而成的上衣共同形成 X shape；整體 character flow 向外展開，讀作開朗、自信、起飛。
- **飛行員語言**：外套與靴上白色毛毛用來拉回飛行員 / aviator 主題，避免設計只剩孔雀公主感。
- **孔雀語言**：孔雀不是純裝飾，而是「開屏」與「舞台上被看見」；此語言與凜 Alpha 線偶像身份互相呼應。

### 魔法少女形態二（痛苦化身 / 烏鴉）

- **主題**：痛苦的化身 + 烏鴉。此形態是凜以痛證明自己仍存在的極端結果。
- **C 型金屬扣**：金屬扣水平插入肉身，半圈埋入、半圈外露，並連接鐵鏈。這是此形態的核心視覺，不可簡化成普通飾扣。痛覺本身被服裝化、儀式化、華麗化。
- **服裝語氣**：長手套、露背、破絲襪與高跟鞋共同營造凜自認「世界最痛苦之人」的風塵女子感；不是性感服務，而是自我折磨、被觀看、被傷害的混合語言。
- **烏鴉語言**：肩上毛毛代表烏鴉羽毛；黑色 / 深綠 / 金屬扣與鐵鏈形成夜鴉般的沉重輪廓。
- **頸部遮掩**：頸部高領 / 飾帶刻意遮住由針線固定、快要掉下來的頭部。遮掩本身就是 visual clue：觀眾應感到「她不想讓人看見那裡」。
- **Character Shape**：整體倒 V，代表心理狀態差、收縮、自我保護、痛苦向內集中。與 MG1 的外開 X shape 形成明確反差。
- **髮型 / 色彩**：保持高中少女比例，不可成人化；痛苦版本可更尖、更垂、更沉，但仍需讀作同一個凜。

### 被重組後

外貌不變，眼神仍帶一絲空洞（意識同「自我」之間有解離感）；動作過度精確，連呼吸頻率都像被程式設定過。**（CDL-337 修正）**：微笑本身唔係「僵硬統一嘅表情貼紙」——溫柔嘅表情是真實嘅（見[真實但唔自知嘅溫柔](#第一幕公務員的日常)），只不過佢完全解釋唔到呢份溫柔嘅來源，所以個表情同佢空洞嘅眼神/過度精確嘅動作並存，形成一種「身體溫暖、意識抽離」嘅反差，而唔係純粹機械化嘅假笑。

### 關鍵視覺線索

脖子上一圈淡淡紅線——頭顱被縫回去的痕跡。平時被高領遮蓋，關鍵場景中暴露。紅線是全角色最重要的 Visual Clue，連接犧牲記憶與痛覺信仰。MG2 形態必須特別處理頸部遮掩，令「遮住」比「直接展示」更不安。

### 視覺微細節

- **1/1000 度微笑弧光**：凜與美夜子相處的場景中，嘴角弧度在整個故事中以肉眼幾乎無法察覺的量微量上升。全作品最細膩的成長視覺——刻意設計為只有反覆觀看第一幕與第四幕才能確認的差值。
- **術前/術後微行為對比**：接受改造手術前，凜緊張時以右手指尖輕觸左腕脈搏點（確認心跳存在）。術後，同一個「確認」動作轉移目標——左手觸碰胸口裝置位置。動作模式相同，但確認的對象從「有機體心跳」轉為「機械設備」，在不解說的情況下揭示其內在參照物的改變。
- **鏡像反映規格**：[靈魂-肉體排斥反應](../01_world_rules_and_costs.md#rule-soul-body-rejection)與[鏡像法則](../06_visual_bible.md#section-law-mirror-visual)的作用下，凜走過任何完整反光面，鏡中映照的是頸椎斷裂死亡瞬間的真實狀態：頸部以下蒼白瓷化裂痕向下蔓延，頭顱以異常角度微歪（斷頸陰影），表情空白如死前瞬間。現實中她外觀完整如常，鏡中卻是斷頸屍體。高領遮住紅線時，鏡像仍如實映照。
