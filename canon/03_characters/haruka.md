## <a id="section-background"></a>背景故事

### 誕生的悲劇與祝福

晴香的誕生源於深沉悲劇——[美夜子](miyako.md)「意外身亡」（被冰封）後，母親花子在失去大女兒的打擊下再度懷孕。晴香從一開始就承載雙重的祝福與詛咒：天生擁有特殊的「潛力之種」，可以變得很強大，也可能變得很危險。

### 創世者的身份（不自知的罪責）

晴香的核心罪責不是「做錯一件事」，而是她在極端創傷中改寫了現實，卻長期不知道自己是改寫者。  
她前半生以「普通魔法少女」身份行動，後半生才被迫承擔「創世者債務人」身份。這個身份反轉是她心理弧最硬的斷點。

**See also**: [Alpha Divergence 事件](../04_timeline_canon.md#event-alpha-divergence)

### 情緒增幅器的詛咒

5 歲時，她的力量被扭曲——變成情緒炸彈。她會把周圍人的感受放大到失控程度。這份[情緒增幅器](../02_glossary.md#term-emotional-amplifier)力量既是光源，也是隨時可能引爆的災難。

### 夕的誕生

為了自保，晴香的靈魂撕裂——所有無法面對的痛苦、恐懼、以及 Alpha 線的真實記憶，凝聚成潛意識人格[「夕」](../02_glossary.md#term-yu)。[秋穗](akiho.md)利用情緒力量裝置將真相封存，讓晴香只知道「媽媽生我時去世了」。

### 倖存者的缺失與孤獨

一出生就失去母親的缺失感，在她潛意識中植入「我無法保護我所愛的人」以及「我害怕再次失去」的劇毒信念。她將自己擺在「拯救者」位置上，發展出極端的討好型人格與拯救者情結。她對所有人都好，本質上是一種拒絕深層連結的防護罩——因為如果不深交，失去時就不會那麼痛。

### 形象被盜用——從「人」降格為「素材」

在[社會性死亡期](../04_timeline_canon.md#section-113-june-late)，晴香不只失去名聲，還被剝奪對自身公共形象的控制權。經理人把她的肖像權轉售成「晴香版情緒毒品」原料，使她從「希望象徵」被反轉成「可消費的幻覺商品」。  
這一擊直接打穿晴香的核心防線：她本來用「有用、可愛、可被需要」來維持存在感，結果連這套存在證明也被市場化吞噬。此後她與夕的衝突升級，不再只是「誰控制身體」，而是「我是否仍能定義我是誰」。

### 膠布哲學第三層揭露——原罪命名

在[真相揭露（膠布哲學第三層）](../04_timeline_canon.md#event-band-aid-third-reveal)中，晴香被迫聽見最殘酷的命名：Beta 線不是救贖完成，而是「在屍體上貼膠布」的延後崩解。  
這一步把晴香的罪責感由「我救唔到人」升級成「我可能就是災厄來源」。其心理功能是摧毀她最後的英雄敘事保護殼，逼她在第四幕改用「承擔」而非「修正」作為方法論。

## <a id="section-wnlt"></a>Want / Need / Lie / Truth

**Want（顯性欲望）**：
- 成為「給予他人希望」的完美偶像魔法少女
- 拯救所有人，不讓任何人受傷
- 獲得「被需要」與「被感激」的存在證明

**Need（隱性需求）**：
- 直面 [Alpha 線](../02_glossary.md#term-alpha-line)真相，接納自己作為「創世者」的責任
- 整合[夕](yu.md)，承認自己的陰影面
- 學會「我唔用魔法都要照顧自己」——不依賴拯救他人來證明存在價值

**Lie（核心謊言）**：
- 「我的真實情感是一把失控且致命的武器」
- 「我必須永遠快樂和有用，才能被愛和接納」
- 「如果我不再是『有用的英雄』，那個『作為人類的我』就會消失」

**Truth（最終真相）**：
- 無法改變事實（Alpha），只能[改變態度](../02_glossary.md#term-attitude-vs-fate)（Beta）
- 代價不會憑意志蒸發；她唯一能主導的是「如何承擔」與「為誰承擔」（規則口徑見 [情緒守恆](../02_glossary.md#term-emotion-conservation)）
- 愛自己不需要魔法——即使不完美，也值得被愛

## <a id="section-archetype"></a>Archetype & Symbolism

**Archetype 變遷**：拯救者 (The Savior) → 殉道者 (The Martyr) → 承擔者 (The Bearer)

**象徵**：
- **光與陰影的雙生子** — 晴香與[夕](yu.md)的共生關係，太陽必然伴隨影子
- **痛苦的容器（靜止搖籃）** — 最終形態：成為世界的情緒濾網，吸收並轉化[集體潛意識](../02_glossary.md#term-collective-unconscious)中的負面情緒
- **創世者與債務人** — [Beta 線](../02_glossary.md#term-beta-line)的創造者，同時也是因果債務的最大承擔者

## <a id="section-four-act-arc"></a>四幕弧光

### [第一幕](../05_story_outline_canon.md#act-1)：偶像魔法少女

王道氛圍。晴香相信自己是「希望使者」，以偶像身份散播光明。觀眾與她同步代入——魔法少女 = 正義。粉色長髮、飽和色彩、充滿活力的太陽形象。拯救者 Archetype 全開：對所有人笑、對所有人好、以為自己能拯救世界。

### [第二幕](../05_story_outline_canon.md#act-2)：認知崩壞

經歷[凜的犧牲](../04_timeline_canon.md#event-rin-sacrifice)、[三位一體光譜](../02_glossary.md#term-trinity-spectrum)真相揭露、系統本質暴露。英雄敘事崩塌。髮色暗淡，眼中高光消失，身上出現第一階段[情緒侵蝕](../02_glossary.md#term-emotional-erosion)紋章。棒球褸拉鍊拉高、戴上兜帽——從「太陽」退縮為「躲藏的人」。

### [第三幕](../05_story_outline_canon.md#act-3)：偽高潮

試圖用力量修正一切——以殉道者姿態獨自承擔所有人的痛苦。偽高潮以失敗告終。碎剪短髮 Wolf Cut，魔法服嚴重破損，身體局部出現結晶化，皮膚如瓷釉剝落。瞳孔深處出現「破碎星星」圖案——創世者的標記浮現。

### [第四幕](../05_story_outline_canon.md#act-4)：靜止搖籃

覺醒但失去記憶。成為「靜止搖籃」——世界的情緒濾網，吸收並轉化[集體潛意識](../02_glossary.md#term-collective-unconscious)的負面情緒。純白髮，近乎透明的灰白瞳孔。服裝融合了[夕](yu.md)的黑色元素。情感徹底耗損後的「空殼感」與神性的結合。觀眾懷著記憶，看著遺忘一切的她——這就是永恆隔閡的治癒。

## <a id="section-behavior-hooks"></a>關鍵習慣（Behavior Hooks）

1. **[膠布哲學](../02_glossary.md#term-band-aid-philosophy)** — 在手指或手臂貼彩色膠布，「痛是證據」。每次貼膠布都是儀式化的自我提醒
2. **鏡中對話** — 經常對著鏡子自言自語，試圖與[夕](yu.md)溝通（早期）或對抗（中期）
3. **絕對共感視界** — 能看見其他人看不到的「遊戲 UI」（血條、情緒圖標）——實際上是創世者特權，她誤以為是「同理心強」
4. **強制微笑** — 即使痛苦也會強制自己微笑，討好型人格的外在表現
5. **夜間獨白** — 深夜在無人處對著黑暗說話，釋放白天壓抑的情緒

## <a id="section-visual"></a>視覺要點

| 欄位 | 內容 |
|------|------|
| **身高 / 體型** | 154cm / 三角型 (Pear Shape)，蜜腿 (Honey Thighs) |
| **核心關鍵詞** | 太陽、光芒、女武神 |
| **主色** | 櫻花粉 (Sakura Pink) + 純白 (White) + 警示黑 (Warning Black) |
| **基礎幾何** | 圓形為主（頭部、眼睛、飾品），暗示親和力 |

### 平民形態（日區偶像私服）

- 內搭 V 領/圓領 T-shirt + Oversized 棒球褸（袖子偏長，焦慮時縮手萌袖）
- 熱褲 (Hot Pants)，露出蜜腿線條
- 關鍵單品：掛頸式大耳機、雙面盒墜項鍊（母親遺物）
- 行為 Tells：焦慮時縮手入袖口；說謊時過度燦爛笑容（面部肌肉僵硬）；疲憊時戴上耳機低頭切斷眼神接觸

### 魔法少女形態（公主女武神 x 戰甲禮服 Armored Gown）

- 「理想我」的具現化——不是社會要求的偶像，而是內心渴望成為的守護者
- 輕盈金色光紋胸甲 + 飄逸長紗裙擺（靜止時垂地如禮服，戰鬥時飄浮如翅膀）
- 盔甲元素：頸環、臂甲、腿甲——拘束感轉化為力量象徵
- 盔甲表面有微弱的金色光紋，隨戰鬥激烈程度變化明暗

### 武器：雙形態長矛 (Dual-Mode Spear)

- **模式 A — 近戰棍法**：矛桿延長，少林棍法動作，橫掃範圍攻擊。利用下盤（蜜腿）的穩定性作為軸心旋轉
- **模式 B — 投擲長矛**：矛頭發光，中距離投擲後召回（類似雷神之錘），精準打擊與位移
- **外觀**：華麗的金屬矛頭帶有「光芒/羽翼」紋路（女武神意象），矛桿可伸縮

### 視覺演變

| 幕 | 髮型/髮色 | 眼神/特徵 | 關鍵變化 |
|----|----------|----------|---------|
| 第一幕 | 粉色長髮，微捲，空氣感 | 動漫大眼，高光明顯 | 太陽形象，色彩飽和度 100% |
| 第二幕 | 髮色暗淡 | 高光偶爾消失，「玻璃珠」死魚眼 | 第一階段腐蝕紋章 |
| 第三幕 | 碎剪短髮 Wolf Cut，凌亂帶刺 | 瞳孔深處「破碎星星」圖案 | 魔法服破損，身體局部結晶化 |
| 第四幕 | 純白髮 | 極淡灰白瞳孔，近乎透明 | 融合夕的黑色元素，空殼感 + 神性 |
