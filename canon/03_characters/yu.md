# CAN-03: 夕 (Yu)

## 基本資料

> **來源**: [[screenwriter/06_Character_Psychology_Analysis]]

- **身份**：雨宮晴香的潛意識人格、陰影自我（Shadow Self）
- **本質**：情緒增幅器被強行關閉的負面光譜、被切割的力量
- **出現時機**：Beta 線專屬（Alpha 線中不存在）
- **形態**：集體潛意識中的獨立意識碎片

## 背景與定位

> **來源**: [[screenwriter/06_Character_Psychology_Analysis]]
> **詳細**: 母文檔保留完整心理學框架分析、本我/自我/超我結構

**被切割的陰影**：
當 5 歲的晴香創造 Beta 線、秋穗使用情緒力量裝置封存 Alpha 線真相時，晴香所有無法承受的痛苦、恐懼、憤怒與創傷記憶被強行剝離，凝聚成潛意識人格——「夕」。她承載著被刪除的 Alpha 線真相：母親花子與姊姊美夜子同時被黑奏殺害的記憶、被晴香拋棄的憤怒。

**本我的純粹形態**：
夕是晴香那被壓抑、最原始的「本我」(Id)。她代表了所有未經修飾的本能、慾望與創傷能量——對生存的渴望、對威脅的憤怒、對痛苦的直接反應。她遵循最純粹的原則，其行動不為道德所束縛，只為宣洩被切割的情感，並以扭曲的方式保護主體。

**黑奏的無意識能量農場**：
夕的存在本身就不斷產生痛苦——承載著被刪除的 Alpha 線真相、被晴香拋棄的憤怒。黑奏透過與夕的「共鳴」，吸取這份龐大的痛苦能量，轉化為自己的力量。夕以為自己在進行哲學反叛，卻不知道每一次「強迫晴香面對真相」都在餵養著真正的敵人。

## Want / Need / Lie / Truth

> **來源**: [[screenwriter/06_Character_Psychology_Analysis]]

**Want（顯性欲望）**：
- 強迫晴香直面 Alpha 線真相
- 證明「刪除痛苦 = 幸福」的邏輯是錯的
- 打破晴香的「完美偶像」偽裝

**Need（隱性需求）**：
- 被整合而非被消滅——成為晴香的一部分
- 被承認而非被壓抑——證明自己存在的價值
- 與晴香共同承擔痛苦——而非獨自承受

**Lie（核心謊言）**：
- 「我是晴香的敵人」
- 「我存在是為了毀滅她」
- 「只有痛苦才是真實的」

**Truth（最終真相）**：
- 我是晴香的一部分，不是敵人
- 承認痛苦 ≠ 被痛苦吞噬
- 整合陰影才能成為完整的人

## Archetype & Symbolism

> **來源**: [[director/Story_Structure_Character_Archetype_Analysis]]

**Archetype**：陰影自我 (Shadow Self) → 內在聲音 (Inner Voice) → 整合碎片 (Integrated Fragment)

**象徵**：
- **鏡中倒影**：被壓抑的真實自我
- **黑暗的記憶**：Alpha 線真相的守護者
- **本我的聲音**：未經修飾的情感爆發

## Relationships

> **來源**: [[screenwriter/01_Character_Background_Story]] + [[screenwriter/Villain_Master_Plan]]

- **晴香**：本體，創造者，最終整合對象
- **黑奏**：無意識的能量供應者（被利用）
- **秋穗**：封印者，使用情緒力量裝置將夕囚禁
- **愛莉（紙皮騎士）**：對照存在——愛莉是「被動守護者」，夕是「主動反叛者」

## Behavior Hooks（關鍵習慣）

> **來源**: [[screenwriter/06_Character_Psychology_Analysis]] + [[screenwriter/09_Character_Senses_Private_Habits_Setting]]

**關鍵習慣**（潛意識人格的表現形式）：
1. **鏡中對話**：在鏡子中與晴香對抗，晴香以為是自言自語
2. **夢境侵入**：在噩夢中強迫晴香看見 Alpha 線記憶碎片
3. **情緒放大**：當晴香壓抑情緒時，夕會突然爆發（晴香誤以為是自己失控）
4. **真相碎片**：不斷丟出 Alpha 線記憶線索（「家姐點解會變貓？」「媽媽真係難產死？」）
5. **本能反應**：在危機時刻奪取控制權，展現晴香被壓抑的憤怒與戰鬥本能
