## <a id="section-background"></a>背景故事

### 魔法即病症——藥物依賴與暴力代償

出身夜區毒品街區，父母是情緒膠囊的重度成癮者。朱音從小在飢餓與暴力中長大，14 歲為養家成為黑幫打手——戰鬥成為她的「精神毒品」，用腎上腺素壓制深入骨髓的罪惡感。18 歲時為獲取毒品再次淪為打手，暴力成為唯一能讓她忘記一切的代償方式。

### 甜蜜的屍體——創傷起源

14 歲的朱音在擔任黑幫打手期間私藏了高純度情緒結晶——外觀如糖果。弟弟在她外出買飯時誤食結晶，因能量過載七竅流血死亡。臉上掛著與父母吸毒後一模一樣的詭異笑容。「我帶回來的希望，親手殺死了我最愛的人。」

**See also**: [朱音的弟弟（次要角色）](../03_character_index.md#char-akane-brother)

### Alpha 原傷五步模板（CF-T20）

| 步驟 | 內容 |
|------|------|
| **Alpha 原傷** | 母親重度吸食情緒膠囊，朱音無力阻止——童年最深的無力感是：「我媽媽坐在那裡，但我救不了她。」 |
| **童願** | 「如果我夠強，她就不用食藥。」（5 歲的朱音在媽媽失去意識時許下的意念） |
| **Beta 修正** | 晴香的大願在 Beta 線讓朱音獲得魔法力量並成為戰鬥型少女——夠強、抗打、能保護人 |
| **守恆反噬** | 成為打手換取毒品，力量被工具化；弟弟誤食朱音私藏的高純度情緒結晶死亡——「我帶回來的希望，親手殺死了我最愛的人。」 |
| **態度缺口** | 「我終於有能力了，但我用能力做了最不應該做的事。」力量沒有解決根本問題，只是把傷害轉移到了弟弟身上。 |

### Alpha vs Beta 對照

朱音的雙線對照不是「哪條線較好」，而是「哪種痛更能把人扭曲」。
Alpha 線把她困在無力（無法救母親），Beta 線把她推向過度補償（有力量卻用錯）。她的悲劇核心是：終於有力量時，她已經不懂如何溫柔使用力量。

**Alpha 線命運（CF-008 事實）**：在 Alpha 線，朱音與弟弟最終因為夜區糧食斷絕而活活餓死——朱音先死，弟弟在幾天後隨之死去。這是所有 Beta 線飢餓補償行為的根因：病態囤積過期罐頭、「空米缸」象徵、以及用食物表達愛與保護的強迫傾向，都直接源自 Alpha 線的餓死記憶。朱音在 Beta 線不自知地過度補償，本質上是靈魂記憶在嘗試「這次我不要再餓死」。

### 小光——最後的溫暖錨點

小光是夜區小學生，唯一對朱音表現出善意的人。她填補了朱音失去弟弟後的空洞，成為朱音「給予」而非「索取」的第一個對象。小光讓朱音短暫相信：或許她也配擁有溫暖。

**See also**: [小光](ko_hikaru.md) | [小光之死](../04_timeline_canon.md#event-ko-hikaru-death)

### 悲劇的背叛與墮落

小光[屍骸化](../02_glossary.md#term-magical-corpse)後，被[黑奏](aya.md#section-kurokane)操控。朱音無法接受小光的「死亡」，選擇建立「屍骸樂園」——收容所有無主屍骸，成為屍骸首領。她將屍骸視為「飢餓的孩子」，試圖透過保護它們來彌補未能保護弟弟與小光的遺憾。

**See also**: [恐怖遊樂場事件](../04_timeline_canon.md#event-terror-playhouse)

### 調停失敗——被理解恐懼的反彈

在[操的調停嘗試](../04_timeline_canon.md#event-misao-mediation)中，朱音其實第一次被隊友正面承認痛苦，但她仍選擇拒絕。對朱音而言，若接受這份理解，就等於承認自己仍有「回到人群」的可能；而這會直接撞上她最深的罪惡感（弟弟與小光）。  
因此她採取更激烈的反彈：把「被看見」解讀為威脅，轉而加深屍骸首領身份。這是她在第三幕前仍持續下墜的心理關鍵。

### 燃燒的贖罪——嘆息之橋回歸

在嘆息之橋終局日，朱音穿著垃圾製成的鎧甲、手持生鏽電鋸回到隊伍。她以過載變身加上吞下過期糖果毒素觸發自爆——將自己燃燒成一座糖果山，保護隊友撤退。遺言：「我唔想再一個人食飯。」（事件定位見 [Timeline](../04_timeline_canon.md#event-bridge-of-sighs)）

**See also**: [嘆息之橋](../04_timeline_canon.md#event-bridge-of-sighs)

## <a id="section-wnlt"></a>Want / Need / Lie / Truth

**Want（顯性欲望）**：
- 戰鬥帶來的寧靜——用暴力壓制罪惡感
- 填補內心空虛——囤積物資、保護屍骸
- 保護小光——不讓弟弟的悲劇重演

**Need（隱性需求）**：
- 接受弟弟的死不是她的錯
- 學會給予比索取更能填補空虛
- 承認渴望連結——「我唔想再一個人食飯」

**Lie（核心謊言）**：
- 「只有戰鬥/毒品能讓我忘記」
- 「我是殺弟弟的兇手」
- 「我只配獨自承受」

**Truth（最終真相）**：
- 給予比索取更能填補空虛
- 出於愛的犧牲比義務更動人
- 治癒失敗不代表無法選擇如何燃燒（[態度 vs. 命運](../02_glossary.md#term-attitude-vs-fate)）

## <a id="section-archetype"></a>Archetype & Symbolism

**Archetype 變遷**：成癮者 (The Addict) → 墮落母親 (The Fallen Mother) → 燃燒的贖罪者 (The Burning Penitent)

**象徵**：
- **過期罐頭** — [Alpha 線](../02_glossary.md#term-alpha-line)空米缸的過度補償；在 Beta 線中病態囤積食物，用物質填補永遠填不滿的飢餓
- **波板糖** — 小光的遺物。甜蜜與死亡的雙重象徵——弟弟死於「糖果般的結晶」，小光用糖果表達善意
- **糖果山** — 最終形態。朱音燃燒自己化為巨大的糖果山護盾，將「毒品」轉化為「守護」——毒藥與解藥的終極統一

**主題關聯**：子主題 A「力量的代價」——戰鬥成癮作為力量代償。子主題 C「身份的本質」——「治癒失敗不代表無法選擇如何燃燒」。

## <a id="section-four-act-arc"></a>四幕弧光

### [第一幕](../05_story_outline_canon.md#act-1)：戰鬥成癮者

以戰鬥成癮者身份加入隊伍。囤積戰利品、過期罐頭、螺絲釘——[Alpha 線](../02_glossary.md#term-alpha-line)空米缸的過度補償。過度殘暴的戰鬥風格引起隊友不安，但她的戰鬥力不可否認。病態囤積與永恆警戒暗示深層創傷。

### [第二幕](../05_story_outline_canon.md#act-2)：小光與墮落

遇見[小光](ko_hikaru.md)——學會「給予」，短暫體驗溫暖。但小光[屍骸化](../02_glossary.md#term-magical-corpse)後，[黑奏](aya.md#section-kurokane)操控小光的屍骸。朱音精神崩潰，墮落為屍骸首領，建立「屍骸樂園」。

### [第三幕](../05_story_outline_canon.md#act-3)：屍骸首領

本幕的角色功能是把朱音推到「被愛也不敢回頭」的位置。  
她把屍骸當作可被餵養的孩子，實際上是在拒絕承認自己的喪失已無法回捲。這種拒認讓她與隊伍必然對立。

### [第四幕](../05_story_outline_canon.md#act-4)：燃燒的贖罪

[嘆息之橋](../04_timeline_canon.md#event-bridge-of-sighs)的回歸，標誌朱音由「索取型存活」轉成「給予型離場」。  
她最後承認的不是英勇，而是最基本的人類需求：想同人一齊食飯。這句遺言令她的贖罪回到關係，而不是回到神話。

## <a id="section-behavior-hooks"></a>關鍵習慣（Behavior Hooks）

1. **病態囤積** — 魔法空間塞滿過期罐頭、螺絲釘、碎布——任何「可能有用」的東西。Alpha 線飢餓記憶的過度補償
2. **戰鬥成癮** — 過度殘暴的戰鬥風格，只有在 High 狀態才能忘記弟弟死亡的畫面。戰後會出現明顯的戒斷反應（顫抖、盜汗）
3. <a id="habit-sleeping-in-boots"></a>**穿鞋守門** — 睡覺時永遠穿著軍靴，蜷縮在門口角落而非床上；門前堆疊空罐頭作簡易入侵警報。夜區生存本能的具象化：靴子 = 隨時可戰鬥/逃跑；床 = 自己不配擁有的「安全感」奢侈品。因姿勢不舒服而依賴毒品強制入睡，形成惡性循環
4. **餵養野狗** — 深夜暗巷餵癩皮狗。在飢餓者中看到自己，在被遺棄者中看到弟弟
5. **與屍骸的不倫連結** — 私下餵養無名[屍骸](../02_glossary.md#term-magical-corpse)，對它們說話、替它們取名——填補失去弟弟與小光的空洞
6. <a id="habit-dead-plants"></a>**養死植物的循環** — 強迫性買植物、種植、過度澆水、最終弄死，植物死後崩潰哭泣，過幾天又重新開始。這是對弟弟之死的強迫性重複：每次植物死亡都是弟弟之死的再現，每次買新植物都是「這次我一定能救活」的妄想
7. <a id="habit-feed-cat-miyako"></a>**餵貓形態美夜子** — 用母親的溫柔語氣照顧處於貓形態的美夜子：「乖貓貓，吃飯囉。」無法拯救弟弟，所以將母性投射到美夜子身上——照顧美夜子給她「至少有一次我養活了某個生命」的虛假安慰
8. <a id="habit-gum-chewing"></a>**長期咀嚼同一塊香口膠** — 咀嚼了好幾個月的香口膠，已褪色變形失去香氣，仍每天咀嚼。源自弟弟誤食結晶之死的創傷：象徵「咀嚼但吞不下去的痛苦」，好像只要還在咀嚼，就能證明「我沒有浪費，我沒有失敗」
9. <a id="habit-door-watching"></a>**望門習慣** — 在任何室內空間都會找一個角度讓自己能望見房門。不是出於防衛（那是睡覺時穿鞋守門的功能），而是等待：她的眼神每次有腳步聲靠近都會不自覺轉向門口，然後在不是弟弟的臉出現時迅速移開。她已屍骸化的小光也是從這個方向消失的。遇到帶孩子路過的陌生人，她會在門口多站一秒。

> 別人見到屍骸，朱音見到一個還沒聽完故事的小孩。

## <a id="section-visual"></a>視覺要點

| 欄位 | 內容 |
|------|------|
| **角色原型** | 狂戰士 / 暴走甜點師 |
| **代表色** | 糖霜白 + 幻覺彩虹 |
| **核心關鍵詞** | 成癮、暴食、糖果即毒品、鋸殺 |

### 平民形態（戒斷者）

- 枯草綠短髮，灰綠色 oversized 冷衫（萌袖掩飾顫抖的手）
- 寒背死魚眼，嘴裡永遠咬著東西（口香糖、筆蓋、吸管）
- 整體姿態：蜷縮、防禦、隨時準備逃跑或攻擊

### 魔法少女形態（Sugar Rush Patissier — 糖果暴走族）

- 白色蓬鬆蛋糕裙 + 圍裙，彩虹色雙馬尾
- 仿真糖果飾品（棒棒糖髮夾、軟糖手環、馬卡龍耳環）
- 滾軸溜冰鞋——高速移動 + 不穩定感的視覺化
- **武器**：粉紅笑臉電鋸——貼滿貼紙，啟動時發出扭曲的笑聲音效

### 特殊設計

- **牙齒**：平時虎牙 → 戰鬥進入狂暴階段時嘴角向耳延伸至 40 度角，露出異常整齊的鯊魚齒（[執念飽和](../02_glossary.md#term-saturation-of-obsession)的視覺化）
- **電鋸音效**：粉紅笑臉電鋸啟動時播放卡通笑聲與鋸齒聲的混音；音高隨攻擊力度線性上升——越用力，音調越詭異地高亢
- **調味粉罐道具**：朱音攻擊後在屍骸身上「調味」的儀式動作——從腰間取出貼有卡通標籤（含微笑圖標）的調味粉罐，撒在屍骸上「讓它更好吃」。這個動作是她心理中「食物=愛=殺戮」三者混同的外化儀式
- **鏡像本體（飢餓幽靈）**：戰鬥後，在有光反射的表面（鏡子、水面、玻璃）中出現朱音的 Alpha 線餓死版本——皮包骨、嘴巴被縫死、空洞眼眶。只有朱音能看見；對她而言不是幻覺，而是 Alpha 線靈魂記憶的殘留投影

### 屍骸女王完全形態

白色魔法少女服 + 黑色焦油蔓延 + 腐爛糖果飾品 + 糖晶硬殼。甜美與腐敗的混合體——「屍骸樂園」首領的視覺表現。
**完全形態補充**：光環退化化為白骨王冠，朱音以雙臂環抱[小光](ko_hikaru.md)的廢鐵屍骸，形成「以殘骸為寶座」的構圖——這是朱音「墮落母親」Archetype 的視覺頂點：王冠代表她對屍骸群的統治，懷抱姿勢代表她從未放棄的母性執念。

### 視覺演變

| 幕 | 外觀 | 關鍵變化 |
|----|------|---------|
| 第一幕 | 戒斷者——枯草綠短髮、oversized 冷衫 | 萌袖掩飾顫抖，病態囤積 |
| 第二幕 | Sugar Rush Patissier 覺醒 → 遇見小光 | 彩虹色元素增加，短暫明亮 |
| 第三幕 | 屍骸女王——黑色焦油蔓延，腐爛糖果 | 甜美與腐敗融合 |
| 第四幕 | 垃圾鎧甲 + 生鏽電鋸 → 糖果山 | 燃燒自爆，最終形態 |
