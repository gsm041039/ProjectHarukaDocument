## <a id="section-background"></a>背景故事

### 魔法即病症——藥物依賴與暴力代償

出身夜區毒品街區，父母是情緒膠囊的重度成癮者。紫音從小在飢餓與暴力中長大，14 歲為養家成為黑幫打手——戰鬥成為她的「精神毒品」，用腎上腺素壓制深入骨髓的罪惡感。18 歲時為獲取毒品再次淪為打手，暴力成為唯一能讓她忘記一切的代償方式。

### 甜蜜的屍體——創傷起源

14 歲的紫音在擔任黑幫打手期間私藏了高純度情緒結晶——外觀如糖果。弟弟在她外出買飯時誤食結晶，因能量過載七竅流血死亡。臉上掛著與父母吸毒後一模一樣的詭異笑容。「我帶回來的希望，親手殺死了我最愛的人。」

**See also**: [紫音的弟弟（次要角色）](../03_character_index.md#char-akane-brother)

### Alpha 原傷五步模板（CF-T20）

| 步驟 | 內容 |
|------|------|
| **Alpha 原傷** | 母親重度吸食情緒膠囊，紫音無力阻止——童年最深的無力感是：「我媽媽坐在那裡，但我救不了她。」 |
| **童願** | 「如果我夠強，她就不用食藥。」（5 歲的紫音在媽媽失去意識時許下的意念） |
| **Beta 修正** | 晴香的大願在 Beta 線讓紫音獲得魔法力量並成為戰鬥型少女——夠強、抗打、能保護人 |
| **守恆反噬** | 成為打手換取毒品，力量被工具化；弟弟誤食紫音私藏的高純度情緒結晶死亡——「我帶回來的希望，親手殺死了我最愛的人。」 |
| **態度缺口** | 「我終於有能力了，但我用能力做了最不應該做的事。」力量沒有解決根本問題，只是把傷害轉移到了弟弟身上。 |

### Alpha vs Beta 對照

紫音的雙線對照不是「哪條線較好」，而是「哪種痛更能把人扭曲」。
Alpha 線把她困在無力（無法救母親），Beta 線把她推向過度補償（有力量卻用錯）。她的悲劇核心是：終於有力量時，她已經不懂如何溫柔使用力量。

**Alpha 線命運（CF-008 事實）**：在 Alpha 線，紫音與弟弟最終因為夜區糧食斷絕而活活餓死——紫音先死，弟弟在幾天後隨之死去。這是所有 Beta 線飢餓補償行為的根因：病態囤積過期罐頭、「空米缸」象徵、以及用食物表達愛與保護的強迫傾向，都直接源自 Alpha 線的餓死記憶。紫音在 Beta 線不自知地過度補償，本質上是靈魂記憶在嘗試「這次我不要再餓死」。

### 小光——最後的溫暖錨點

小光是夜區小學生，唯一對紫音表現出善意的人。她填補了紫音失去弟弟後的空洞，成為紫音「給予」而非「索取」的第一個對象。小光讓紫音短暫相信：或許她也配擁有溫暖。

**黑社會報復——戒斷成因（CDL-343，取代CDL-319「困喺外面幾日」講法）**：呢段時期紫音開始唔想再做黑社會打手，想脫離。黑社會唔容許佢脫離，策劃報復——一次伏擊襲來，紫音獨自應戰擊退，但力竭陷入嚴重戒斷狀態。「家長日作戰」（見`ACT_II_OUTLINE.md` E-07c）照常進行，紫音扮「家姐」出席；晴香其實經朔嘅情報網絡聽到黑社會報復嘅風聲，但揀咗唔講——唔想搞亂小光僅有嘅一日快樂時光。紫音透過成癮崩潰雷達（[習慣#12](#section-behavior-hooks)）留意到晴香表情有異，但揀咗唔出聲追問——同操調停嗰場「有偵測到但刻意判斷唔出手」（CDL-341）係同一個特質嘅第二次出現，但呢次結果係悲劇：紫音自己完全冇辦法預先知道邊次先係啱。

**小光之死場景**：小光被攻擊的那一刻，紫音正處於嚴重的戰鬥戒斷狀態（伏擊後力竭嘅延續）——顫抖的手，眼神空洞，眼白外露，目光失焦。她並非麻木，而是戒斷令她在最關鍵的一刻失去反應能力，只能眼白白看著小光被擊倒。這成為她此後最深的罪惡感來源之一：「我有能力，但在最重要的那一秒，我的身體背叛了我。」

**See also**: [小光](ko_hikaru.md) | [小光之死](../04_timeline_canon.md#event-ko-hikaru-death)

### 獨自清洗堂口——崩潰的第一層（CDL-343，新增場景）

小光死後、黑奏耳語之前，紫音第一個崩潰反應係獨自一人殺晒成個黑社會堂口——同佢戰鬥成癮嘅coping pattern吻合，佢唔識用第二種方式處理呢種痛。呢個係佢崩潰嘅第一層（暴力復仇），黑奏其後乘虛而入，引導佢轉向第二層（母性佔有式屍骸樂園）——兩層都係唔肯接受失去嘅表現，只不過方向唔同。

### 悲劇的背叛與墮落

小光[屍骸化](../02_glossary.md#term-magical-corpse)後，被[黑奏](aya.md#section-kurokane)操控。紫音無法接受小光的「死亡」，選擇建立「屍骸樂園」——收容所有無主屍骸，成為屍骸首領。她將屍骸視為「飢餓的孩子」，試圖透過保護它們來彌補未能保護弟弟與小光的遺憾。

**See also**: [恐怖遊樂場事件](../04_timeline_canon.md#event-terror-playhouse)

### 調停失敗——被理解恐懼的反彈

在[操的調停嘗試](../04_timeline_canon.md#event-misao-mediation)中，紫音其實第一次被隊友正面承認痛苦，但她仍選擇拒絕。對紫音而言，若接受這份理解，就等於承認自己仍有「回到人群」的可能；而這會直接撞上她最深的罪惡感（弟弟與小光）。  
因此她採取更激烈的反彈：把「被看見」解讀為威脅，轉而加深屍骸首領身份。這是她在第三幕前仍持續下墜的心理關鍵。

### 燃燒的贖罪——帝國廣場回歸

在帝國廣場終局日，紫音穿著垃圾製成的鎧甲、手持生鏽電鋸回到隊伍。她以過載變身加上吞下過期糖果毒素觸發自爆——將自己燃燒成一座糖果山，保護隊友撤退。遺言：「我唔想再一個人食飯。」

**Change Trigger（CDL-318，地點 2026-07-07 修正 CDL-320）**：紫音早喺 Day13 之前已被晴香打敗、被黑奏人手截獲囚禁（CDL-304）。**喺囚禁／押解期間**，黑奏帶嚟操 Day13 鋼鐵獨舞犧牲嘅死訊——作為佢「情感辨識缺失」測試嘅延伸（想睇紫音會唔會流露真感情）。曾經放逐佢嘅隊伍，並冇因為佢離開而停手，仍然一個一個為保護世界戰死。這個衝擊令紫音長期未講出口嘅連結渴望——「望門習慣」（等一個唔會返嚟嘅人）與「留一份習慣」（每餐留多一份，從不解釋留俾邊個）——終於有咗答案：如果冇人會返嚟解釋，不如自己帶住呢份留低咗嘅嘢返去。**這不是「有人拯救佢」令佢軟化，而是「佢走咗，佢哋都仲係咁樣」嘅衝擊**，將她「索取型存活」推向「畀出型離場」嘅最後一步；帝國廣場自爆，是她第一次主動為人留低嘢，而非等人畀她。

## <a id="section-wnlt"></a>Want / Need / Lie / Truth

**Want（顯性欲望）**：
- 戰鬥帶來的寧靜——用暴力壓制罪惡感
- 填補內心空虛——囤積物資、保護屍骸
- 保護小光——不讓弟弟的悲劇重演

**Need（隱性需求）**：
- 接受弟弟的死不是她的錯
- 學會給予比索取更能填補空虛
- 承認渴望連結——「我唔想再一個人食飯」

**Lie（核心謊言）**：
- 「只有戰鬥/毒品能讓我忘記」
- 「我是殺弟弟的兇手」
- 「我只配獨自承受」

**Truth（最終真相）**：
- 給予比索取更能填補空虛
- 出於愛的犧牲比義務更動人
- 治癒失敗不代表無法選擇如何燃燒（[態度 vs. 命運](../02_glossary.md#term-attitude-vs-fate)）

## <a id="section-archetype"></a>Archetype & Symbolism

**Archetype 變遷**：成癮者 (The Addict) → 墮落母親 (The Fallen Mother) → 燃燒的贖罪者 (The Burning Penitent)

**象徵**：
- **過期罐頭** — [Alpha 線](../02_glossary.md#term-alpha-line)空米缸的過度補償；在 Beta 線中病態囤積食物，用物質填補永遠填不滿的飢餓
- **波板糖** — 小光的遺物。甜蜜與死亡的雙重象徵——弟弟死於「糖果般的結晶」，小光用糖果表達善意
- **糖果山** — 最終形態。紫音燃燒自己化為巨大的糖果山護盾，將「毒品」轉化為「守護」——毒藥與解藥的終極統一

**主題關聯**：子主題 A「力量的代價」——戰鬥成癮作為力量代償。子主題 C「身份的本質」——「治癒失敗不代表無法選擇如何燃燒」。

## <a id="section-four-act-arc"></a>四幕弧光

### [第一幕](../05_story_outline_canon.md#act-1)：戰鬥成癮者

以戰鬥成癮者身份加入隊伍。囤積戰利品、過期罐頭、螺絲釘——[Alpha 線](../02_glossary.md#term-alpha-line)空米缸的過度補償。過度殘暴的戰鬥風格引起隊友不安，但她的戰鬥力不可否認。病態囤積與永恆警戒暗示深層創傷。

**裝置獲得 + 魔法即精神毒品設計（CDL-051）**：紫音做黑幫打手謀生期間追捕走私客，對方逃跑時丟下裝有[情緒力量裝置](../02_glossary.md#term-emotional-power-device "絕大多數魔法少女依賴的外部裝置，用於連接集體潛意識。帝國內置監控與生物安全鎖(光環)。只有晴香、愛莉可直接使用魔法而無需依賴此裝置。")的盒子。裝置感應到紫音骨子裡強烈的「飢餓感」瞬間自動啟動。魔法效果 = 戰鬥中極致快感 → 成為麻醉「細佬死亡罪惡感」的精神毒品。這確立了紫音的「魔法＝精神毒品」設定：她追求戰鬥的根源，是借腎上腺素壓制永遠壓不下去的罪惡感。細佬死亡 = 紫音全部情感行為的底層驅動。

**珍寶珠入隊場景（CDL-052）**：入隊前，紫音以「搶怪黨」身份混跡夜區，專搶晴香等人打至殘血的屍骸，吸走情緒核心即走。某次戰鬥後紫音能量耗盡倒在路邊痛苦抽搐（戒斷症狀）。晴香找到她，剝開一粒珍寶珠（波板糖）塞入她口中說：「食粒糖先啦，雖然無魔法咁好味，但係會飽肚㗎。」久違的人的微小善意令紫音大腦當機——像被餵食的流浪狗，從此跟隨晴香。深層心理：紫音視貓型美夜子為「藥頭與保險栓」（搵屍骸的工具）；晴香天真善良令她想起死去的細佬，觸發痛苦的保護慾，是她一切給予行為的真實源頭。

### [第二幕](../05_story_outline_canon.md#act-2)：小光與墮落

遇見[小光](ko_hikaru.md)——學會「給予」，短暫體驗溫暖。

**小光之死 + 紫音Cascade（CDL-229；CDL-230）**：

- **E-07a（小光之死，CDL-229）**：高強度戰鬥中小光過載崩解，在紫音懷中消散。紫音的邏輯世界在此崩潰：「我一直保護你，結果還是……」。黑奏乘虛而入：「他沒有死，只是換了生存方式。」這句話成為紫音墮落的轉折點。
- **E-07b（廢棄糖果工廠，CDL-230）**：紫音帶著屍骸化的小光建立「屍骸樂園」（廢棄糖果工廠）。晴香等人找到紫音，嘗試用「三位一體辯論」（「死亡是什麼？」）打破紫音的執念。紫音反問令晴香邏輯崩潰；最終晴香以王道式強行「放逐」（「你這個怪物，走！」），短暫把紫音推開——但這個放逐行為埋下E-12三重癱瘓的歷史槓桿。廢棄糖果工廠視覺象徵：腐爛甜蜜/死去童年純真；紫音以懷抱小光廢鐵屍骸坐在糖果碎堆中形成「墮落母親王座」視覺頂點（CDL-236）。

**E-12三重癱瘓的紫音角色（CDL-239；CDL-242）**：晴香率隊主動討伐後，紫音在物理敗局中拋出道德炸彈：「邊個先係弱小？點解人類有生存權，我哋就要被消滅？」三位一體道德拷問令晴香王道正義完全無法反駁；紫音舉起的手臂露出E-04舊傷（P-A09 PAYOFF，CDL-240），晴香親眼確認眼前的「怪物」曾為保護她們流過血——晴香失語崩潰。

### [第三幕](../05_story_outline_canon.md#act-3)：屍骸首領

本幕的角色功能是把紫音推到「被愛也不敢回頭」的位置。  
她把屍骸當作可被餵養的孩子，實際上是在拒絕承認自己的喪失已無法回捲。這種拒認讓她與隊伍必然對立。

**屍骸首領身份（CDL-236）**：紫音=屍骸女王/屍骸首領100%專屬——不是帝國部署的角色，而是主動以「墮落母親」archetype建立的身份。糖果王座+懷抱小光廢鐵屍骸的視覺頂點：光環退化為白骨王冠，雙臂環抱形成「以殘骸為寶座」構圖。  
**與晴香的對立root（CDL-237~239）**：晴香主動出擊討伐觸發E-12，紫音以三位一體道德拷問令晴香失去出手能力；此刻紫音並非「帝國的棋子」，而是真實的「被晴香放逐的人以其自己的哲學反噬晴香」。

### [第四幕](../05_story_outline_canon.md#act-4)：燃燒的贖罪

帝國廣場的回歸，標誌紫音由「索取型存活」轉成「給予型離場」。  
她最後承認的不是英勇，而是最基本的人類需求：想同人一齊食飯。這句遺言令她的贖罪回到關係，而不是回到神話。

### 正面特質——兩層（CDL-337）

「心軟」呢個講法唔啱紫音——她對「被理解」嘅反應係反彈、拒絕、加深屍骸首領身份（見上文調停失敗一節），呢個係「唔心軟」嘅行為模式。正面特質分兩層：**表層＝成癮崩潰雷達**（[習慣#12](#section-behavior-hooks)，唔使魔法，單憑直覺睇穿他人精神崩潰前兆，沉默行動，觀眾第一眼已經可以感受到「呢個睇落好惡嘅人其實好細心」，唔使等背景解釋）；**底層＝畀出型忠誠**（囚禁期得知操死訊後，重新定義自己想點樣活/死，最終帝國廣場自爆掩護隊友撤退——一個直接改變戰局結果嘅選擇）。

**兩層嘅「未自覺」唔係同一種未自覺，要分清楚**：成癮崩潰雷達（習慣#12）紫音自己清楚知道自己識用、亦會主動採取行動（擋在前面、遞糖）——佢未自覺嘅唔係「識唔識用呢個能力」，而係「呢個能力代表咩」：佢從未將呢個能力理解為「我係一個細心/善良嘅人」，亦未追溯到自己嘅創傷根源（呢個追溯要留到 Act II/III 揭露先發生，見習慣#12 AKS埋位備註）。相反，餵狗、望門、留一份呢類習慣係連行為本身都未必意識到自己識做緊（望門習慣原文已寫明「不自覺轉向門口」）——呢種先係真正行為層面嘅未自覺。

**違反套路預期——沉默係判斷唔係麻木（CDL-341，已取代原「冇餘力接收」講法，正式落實入`ACT_II_OUTLINE.md` E-07a）**：操主動調停嗰場，紫音對操嘅剖白毫無回應，原本寫法係「佢當刻已經冇餘力接收」；作者裁決改做——紫音嘅成癮崩潰雷達其實有偵測到操「完美偽裝下嘅恐懼崩潰」，但佢刻意判斷唔出手：提早介入只會令操以為兩人仲有得救、加深操對佢嘅救世主情結，令操事後受更重嘅二次傷害；佢已經開始默默決定自己嘅結局，唔出手先係佢對操最後嘅溫柔。套路道德邏輯係「有能力偵測到危機就應該出手救」，觀眾（同操本人）會將紫音嘅沉默讀做「佢麻木/佢已經壞埋」；但呢個沉默其實一路都係經過判斷嘅犧牲式節制，唔係能力唔夠或者情感麻木——同美夜子/秋穗嘅案例同一種結構：特質一早已經係啱嘅，只係套路化觀眾讀錯做「無意義嘅冷漠」。

Act I 唔應該畀紫音一個自覺嘅正面特質標籤——即係唔可以令紫音自己講出/意識到「我原來係個善良嘅人」呢種自我理解。對表層（習慣#12）嚟講，呢個限制係指佢唔會將個能力包裝、命名成「善良」，但唔妨礙觀眾第一眼已經睇得出佢細心（呢個係觀眾層面嘅感受，唔等於紫音自己嘅自我認知）；對底層嘅餵狗、望門、留一份嚟講，呢個限制連行為本身都應該保留做**未自覺嘅行為線索**，直到操死訊嗰刻先令佢哋連埋一齊爆發，否則呢個轉折會變得多餘。

## <a id="section-behavior-hooks"></a>關鍵習慣（Behavior Hooks）

1. **病態囤積** — 魔法空間塞滿過期罐頭、螺絲釘、碎布——任何「可能有用」的東西。Alpha 線飢餓記憶的過度補償
2. **戰鬥成癮** — 過度殘暴的戰鬥風格，只有在 High 狀態才能忘記弟弟死亡的畫面。戰後會出現明顯的戒斷反應（顫抖、盜汗）
3. <a id="habit-sleeping-in-boots"></a>**穿鞋守門** — 睡覺時永遠穿著軍靴，蜷縮在門口角落而非床上；門前堆疊空罐頭作簡易入侵警報。夜區生存本能的具象化：靴子 = 隨時可戰鬥/逃跑；床 = 自己不配擁有的「安全感」奢侈品。因姿勢不舒服而依賴毒品強制入睡，形成惡性循環
4. **餵養野狗** — 深夜暗巷餵癩皮狗。在飢餓者中看到自己，在被遺棄者中看到弟弟
5. **與屍骸的不倫連結** — 私下餵養無名[屍骸](../02_glossary.md#term-magical-corpse)，對它們說話、替它們取名——填補失去弟弟與小光的空洞
6. <a id="habit-dead-plants"></a>**養死植物的循環** — 強迫性買植物、種植、過度澆水、最終弄死，植物死後崩潰哭泣，過幾天又重新開始。這是對弟弟之死的強迫性重複：每次植物死亡都是弟弟之死的再現，每次買新植物都是「這次我一定能救活」的妄想
7. <a id="habit-feed-cat-miyako"></a>**餵貓形態美夜子** — 用母親的溫柔語氣照顧處於貓形態的美夜子：「乖貓貓，吃飯囉。」無法拯救弟弟，所以將母性投射到美夜子身上——照顧美夜子給她「至少有一次我養活了某個生命」的虛假安慰
8. <a id="habit-gum-chewing"></a>**長期咀嚼同一塊香口膠** — 咀嚼了好幾個月的香口膠，已褪色變形失去香氣，仍每天咀嚼。源自弟弟誤食結晶之死的創傷：象徵「咀嚼但吞不下去的痛苦」，好像只要還在咀嚼，就能證明「我沒有浪費，我沒有失敗」
9. <a id="habit-door-watching"></a>**望門習慣** — 在任何室內空間都會找一個角度讓自己能望見房門。不是出於防衛（那是睡覺時穿鞋守門的功能），而是等待：她的眼神每次有腳步聲靠近都會不自覺轉向門口，然後在不是弟弟的臉出現時迅速移開。她已屍骸化的小光也是從這個方向消失的。遇到帶孩子路過的陌生人，她會在門口多站一秒。
10. <a id="habit-one-share"></a>**留一份習慣** — 每次進食都自動留出多一份：多夾一筷、多盛一碗、多拿一個麵包。這個動作在弟弟死後從未中斷，已成為肌肉記憶。她從不解釋那份留給誰，隊友也從不問。有時她會在那份食物涼透之後，把它一聲不響地收起來。

11. <a id="habit-taste-synesthesia"></a>**味覺通感（Taste Synesthesia）** — 紫音對親近接觸的人有被動味覺感知：能以味道「讀取」他人的情緒狀態。非主動施展，只在對方情緒強度超過閾值時無意識觸發。「晴香，妳今天的悲傷……食落去好似過期嘅士多啤梨牛奶。」她很少提及這項能力——「別人的味道好苦。」

13. <a id="habit-laugh-instead-of-cry"></a>**嗤笑彈開（笑代替喊，日常縮小版）**（CDL-347）— 紫音家族三代都用笑掩蓋唔可承受嘅嘢：父母嗑藥後嘅詭異笑容、細佬誤食結晶死時臉上一模一樣嘅笑容、小光斷氣嗰刻紫音自己「徒手打到骨折仍狂笑」（CDL-335）。呢個機制平時以縮小版本反覆出現：俾人講中痛處、或者見到令佢動容嘅溫柔（隊友一個冇預期嘅關心動作、小光講句真心話），紫音會第一時間「嗤」一聲短促冷笑彈開，跟住即刻轉移話題或者出拳/踢嘢遮蓋。呢個日常尺度嘅笑聲係CDL-335大崩壞嘅伏線——每一次細嗤笑都係同一種家族傳承嘅表情語言喺重複，直到小光死嗰場徹底失控爆發成真正嘅狂笑。

<!-- Sources: CDL-347 作者確認 2026-07-28（story-orchestrator co-design） -->

12. <a id="habit-collapse-radar"></a>**成癮崩潰雷達（AKS埋位）**（CDL-157）— 紫音不需要任何魔法，單憑肉眼和直覺就能看穿他人的精神崩潰、偽裝與解離狀態。她能在一個人正式發作前幾分鐘感知到「這個人快崩了」，能看穿美夜子的「解離性麻木」、操完美偽裝下的恐懼崩潰、晴香「強行正常」的情緒壓制。她幾乎從不解釋自己怎麼看出來的——只是突然移過去擋在前面，或者遞一塊糖。**心理根源**：在夜區毒窟浸泡太久，親眼看著父母吸毒成癮、弟弟過載暴斃、不計其數的人在她面前精神崩解；她太熟悉「靈魂壞掉的味道」。**與 habit #11（味覺通感）的分工**：味覺通感=被動接收情緒味道（能力層）；成癮崩潰雷達=主動觀察行為徵兆（經驗層），兩者並存不衝突。**AKS埋位**：Act I觀眾=「底層混混的街頭直覺」；Act II/III紫音歷史揭露後：「那不是直覺，是用無數次看著身邊人崩潰死去換來的血淚履歷。」

> 別人見到屍骸，紫音見到一個還沒聽完故事的小孩。

## <a id="section-visual"></a>視覺要點

| 欄位 | 內容 |
|------|------|
| **角色原型** | 黑社會打手 / 不良少女 / 暴走甜品師 |
| **代表色** | 日常：紫髮 + 紅挑染 + 黃布條；魔法：甜品色 + 青藍鬼火漸變 |
| **核心關鍵詞** | 小狗、危險偽裝、不良少女、甜品師、skull 小狗、鋸齒、zig-zag flow |

### 平民形態（不良少女 / 小狗偽裝）

- **核心 silhouette**：短身上衣 + 短褲 + 吊帶襪 + 厚靴。整體讀作不良少女、黑社會打手，但仍保留少女感。
- **髮色與危險感**：紫色髮配紅色挑染，增加危險與暴力預感；黃色布條用作辮子固定，形成高辨識度焦點。
- **髮型性格**：頭上髮髻插入剪刀，代表她作為黑社會打手隨時有武力可用。髮廊有大量突出尖位，鬢邊水平突出，讀作難相處、衝動、充滿尖銳感。
- **少女感遮掩危險性**：露肚、短褲、吊帶襪塑造不良少女形象；上衣印有可愛小狗圖案，加上長袖間條內衣，把危險感拉回少少少女可愛，令她不像單純暴力角色。
- **小狗主題**：靴上毛毛、褲上吊帶裝飾、上衣小狗圖案共同建立小狗 motif。日常的小狗語言是「可愛外皮」，用來遮掩危險性和降低他人戒心。
- **日常髮型限制**：日常不使用大雙辮。她作為打手需要靈活，不能留過長頭髮；這個限制會在魔法少女形態中被反轉。

### 魔法少女形態（甜品師 / skull 小狗）

- **主題**：甜品師；副主題為 skull 小狗。甜品不是純可愛，而是與毒糖、弟弟誤食、暴力加工連在一起。
- **日常小狗 → 變身 skull 小狗**：日常的小狗 motif 是可愛偽裝；變身後扭轉為 skull 小狗，將原本可愛符號異化成危險、暴力、死亡與糖果主題的混合物。
- **布料語言**：衣服刻意使用大量鋸齒狀布料；左右不平衡是核心，不可整理成對稱美少女服。
- **不平衡規則**：襪子左右不同、裙上蝴蝶結不在正中、裝飾節奏有偏移。整體 character flow 需要是 zig-zag，而不是穩定 A-line 或正中對稱。
- **髮型願望**：魔法少女形態使用大雙辮，代表她希望有長頭髮；現實中作為黑社會打手需要靈活而不能留長，變身後終於能把這個願望外化。
- **髮色鬼火感**：頭髮青藍色漸變配色用來營造鬼火感，配合 skull 主題；變身後色彩語言會明顯由日常的紫紅危險感轉向鬼火、幽靈、死亡糖果感。
- **武器**：大型糖果粉碎鎚。武器必須配合甜品師主題，同時加入鋸齒設計，像用來粉碎硬糖、骨頭與幻想的重型甜品工具。

### 特殊設計

- **牙齒**：平時虎牙 → 戰鬥進入狂暴階段時嘴角向耳延伸至 40 度角，露出異常整齊的鯊魚齒（[執念飽和](../02_glossary.md#term-saturation-of-obsession)的視覺化）。
- **糖果粉碎音效**：大型糖果粉碎鎚揮動時帶有硬糖碎裂、金屬撞擊與卡通甜品音效的混音；越憤怒，糖碎聲越像骨裂。
- **調味粉罐道具**：紫音攻擊後在屍骸身上「調味」的儀式動作——從腰間取出貼有卡通標籤（含微笑圖標）的調味粉罐，撒在屍骸上「讓它更好吃」。這個動作是她心理中「食物=愛=殺戮」三者混同的外化儀式。
- **鏡像本體（飢餓幽靈）**：戰鬥後，在有光反射的表面（鏡子、水面、玻璃）中出現紫音的 Alpha 線餓死版本——皮包骨、嘴巴被縫死、空洞眼眶。只有紫音能看見；對她而言不是幻覺，而是 Alpha 線靈魂記憶的殘留投影。

### 屍骸女王完全形態

白色魔法少女服 + 黑色焦油蔓延 + 腐爛糖果飾品 + 糖晶硬殼。甜美與腐敗的混合體——「屍骸樂園」首領的視覺表現。
**完全形態補充**：光環退化化為白骨王冠，紫音以雙臂環抱[小光](ko_hikaru.md)的廢鐵屍骸，形成「以殘骸為寶座」的構圖——這是紫音「墮落母親」Archetype 的視覺頂點：王冠代表她對屍骸群的統治，懷抱姿勢代表她從未放棄的母性執念。

## <a id="section-quotes"></a>核心台詞

> 「我帶回來的希望，親手殺死了我最愛的人。」

*最深恐懼的具現——紫音帶回的糖（希望）成為弟弟致死的毒。折射「傲慢救世主」主題：給予本身可以是傷害。*

> 「晴香，妳今天的悲傷……食落去好似過期嘅士多啤梨牛奶。」

*紫音的味覺通感能力——以食物味道感知他人情緒狀態，是她理解世界的獨特方式。*
