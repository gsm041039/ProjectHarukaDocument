## <a id="section-background"></a>背景故事

### 破碎的瓷娃娃——恐懼露出破綻的人

操不是完美主義者——她是「恐懼露出破綻的人」。24 小時不間斷地表演「完美女性」，每一個動作、每一句話都經過精密計算。這不是追求卓越，而是恐懼驅動的生存策略：一旦表演崩潰，她相信自己會被丟棄。

### 核心恐懼

「如果被發現我是假的就會被丟棄——像父親丟棄真正的我。」父親拒絕接納生理女性的操，強制以男性身份養育她作為家族繼承人。操學會了一套完美偽裝：用表演取代真實，用優雅掩蓋恐懼。

### 紗夜——唯一的無條件之愛

管家紗夜是操生命中唯一給予無條件愛的人。在父親拒絕接納的環境下，紗夜默默守護操的真實身份。臨終時揭露真相：「妳根本唔係少爺……妳係我最靚嘅女。」紗夜的死亡與父親的背叛共同觸發操的精神崩潰。

**See also**: [紗夜（次要角色）](../03_character_index.md#char-sayo) | [鏡像破碎之夜](../04_timeline_canon.md#event-mirror-shatter-night)

### 據點洩露事件——虛榮的代價

操因虛榮心洩露團隊據點位置，導致情緒管理局突襲。[美夜子](miyako.md)在掩護撤離時重傷。操坦白認錯——這是她第一次放下「完美」的面具，承認自己的失誤。隊伍選擇原諒她，成為操弧光中的第一個成長轉折：被接納的不是完美的表演，而是真實的缺陷。

### 調停失敗——完美理性的破產

在[朱音失控期](../04_timeline_canon.md#event-misao-mediation)，操第一次不用「戰術正確」說服隊友，而是直接暴露情感：「我知妳痛，我都痛；但我唔會放棄妳。」調停仍然失敗，並以她重傷收場。  
這次失敗是操心理弧的硬轉折：她確認「控制、秩序、優雅」並不能處理所有痛苦，之後才會在第四幕走到「鋼鐵獨舞」與「人偶牆」的非完美承擔。

### 無心完美人偶——形式極致的代價

紗夜死後，操製作了一具完美的女性人偶軀殼，將自己的意識注入其中。她終於擁有了「完美的身體」——卻無法感受冷暖、無法流淚、無法觸碰。「沒有痛覺的完美比地獄更可怕。」她親手打碎人偶，選擇回到殘缺但真實的身體。

### 鏡像破碎之夜

父親的背叛（將操交給帝國）與紗夜的犧牲（臨終揭露真相）在同一夜發生。雙重打擊將操推入半[屍骸化](../02_glossary.md#term-magical-corpse)狀態。在崩潰邊緣，操做出定義性的選擇——「停留」。

**See also**: [鏡像破碎之夜](../04_timeline_canon.md#event-mirror-shatter-night)

### 公開處刑話術——從「人」到「變異體」的再物化

帝國在第三幕前段把「衛生行動」升級成公開處刑公告，對外以「終極變異體」語言建構恐懼（見 [公開處刑公告（陷阱）](../04_timeline_canon.md#event-public-execution-bait)）。  
對操而言，這是第二次身份剝奪：第一次來自家族把她當作品，第二次來自治理體系把她當病灶。此壓力迫使她在後段更堅定「由我決定我停喺邊」的態度，不再把命名權交給父權或國家。

### 最終宣言——三位一體定義性

「我選擇停留在我想停留的位置。這是我的態度。」  
對操而言，呢句唔係世界觀口號，而係奪回命名權：由她自己決定身體、身份同離場方式。

## <a id="section-wnlt"></a>Want / Need / Lie / Truth

**Want（顯性欲望）**：
- 被認同為「完美女性」——外在形式的極致
- 獲得父親的認可——被原生家庭接納
- 維持表演——不讓任何人看到真實的自己

**Need（隱性需求）**：
- 接受殘缺的自己——不完美也有存在價值
- 打破表演牢籠——「真實」比「完美」更有力量
- 學會被愛不需要資格考試

**Lie（核心謊言）**：
- 「我必須完美才有價值」
- 「情緒是弱點」
- 「露出破綻就會被丟棄」

**Truth（最終真相）**：
- 沒有痛覺的完美比地獄更可怕
- 殘缺的身體能流出眼淚——這比完美的空殼更珍貴
- 選擇停留不是退縮，而是主體性聲明：我由我自己定義（見 [態度 vs. 命運](../02_glossary.md#term-attitude-vs-fate)）

## <a id="section-archetype"></a>Archetype & Symbolism

**Archetype 變遷**：破碎的瓷娃娃 (The Cracked Porcelain) → 完美主義者 (The Perfectionist) → 真實的自我 (The Authentic Self)

**象徵**：
- **精緻人偶** — 完美偽裝的具現化 / 內在空洞的映射。操的傀儡戰鬥風格本身就是她人生的隱喻：操控外物，隔離真實
- **貓咪玩偶** — 唯一不需要表演的對象。私下抱貓咪玩偶是操卸下面具的極少數時刻
- **無心完美人偶** — 形式極致的代價。完美身體 = 感覺喪失 = 存在虛無。[Dark Healing](../02_glossary.md#term-dark-healing) 的反面教材

**主題關聯**：子主題 B「[完美的幻象](../00_series_bible.md#section-core-theme)」——「沒有痛覺的完美比地獄更可怕」是此主題的核心台詞。子主題 C「身份的本質」——內在態度比外在形態更能定義存在。

## <a id="section-four-act-arc"></a>四幕弧光

### [第一幕](../05_story_outline_canon.md#act-1)：完美的瓷娃娃

以完美表演的瓷娃娃身份加入隊伍。每一個動作優雅精確，每一句話審慎斟酌。隊友感受到她的距離感，卻無法穿透精密偽裝。強迫性的完美——花數小時整理頭髮衣物、房間一塵不染、物品精確角度——暗示深層的控制焦慮。

### [第二幕](../05_story_outline_canon.md#act-2)：破綻與接納

據點洩露事件——虛榮導致情緒管理局突襲，[美夜子](miyako.md)重傷。操坦白認錯，第一次被接納的是真實的自己而非完美的表演。這是瓷娃娃的第一道裂痕：原來露出破綻不等於被丟棄。

### [第三幕](../05_story_outline_canon.md#act-3)：鏡像破碎之夜

父親背叛（交給帝國）+ [紗夜](../03_character_index.md#char-sayo)犧牲（臨終揭露真相）→ 半[屍骸化](../02_glossary.md#term-magical-corpse)。製作無心完美人偶 → 感受喪失 →「沒有痛覺的完美比地獄更可怕」→ 打碎人偶回到殘缺身體。選擇「停留」在人與屍骸的邊界。

**See also**: [鏡像破碎之夜](../04_timeline_canon.md#event-mirror-shatter-night)

### [第四幕](../05_story_outline_canon.md#act-4)：鋼鐵獨舞與人偶牆

[嘆息之橋](../04_timeline_canon.md#event-bridge-of-sighs)。測量頻率暴增 → 用絲線「整形手術」→ 第 13 天「鋼鐵獨舞」切斷變形的左手 → 最終以「人偶牆」封鎖通道保護隊友。最終宣言：「我選擇停留在我想停留的位置。這是我的態度。」

## <a id="section-behavior-hooks"></a>關鍵習慣（Behavior Hooks）

1. **強迫性完美** — 花數小時整理頭髮衣物。鏡前反覆確認每一個細節——一根亂髮、一條皺褶都是不可接受的「破綻」
2. **表演疲勞** — 極少說話，每句話先在腦中審核三遍。沉默不是高冷，而是精疲力竭的節能模式
3. **貓咪玩偶** — 私下抱貓咪玩偶，唯一放鬆的時刻。被撞見時會面紅耳赤、迅速恢復冷漠面具
4. **優雅的戰鬥** — 追求「優雅」而非效率。寧可承受傷害也不允許姿態狼狽——戰鬥潔癖的極端表現
5. **房間的精確秩序** — 一塵不染，物品以精確角度擺放。玫瑰金軟尺隨身攜帶，戰後瘋狂測量三圍——1mm 誤差就情緒崩潰

## <a id="section-visual"></a>視覺要點

| 欄位 | 內容 |
|------|------|
| **核心關鍵詞** | 黑白、貓、刀刃 |
| **風格** | 現代維多利亞哥德 (Modern Victorian Goth)——束腰立領喇叭袖 |
| **配色** | 黑白雙色如鋼琴鍵 |

### 平民形態（現代維多利亞哥德）

- **髮型**：白髮長髮，保養極好如瀑布
- **服裝**：束腰立領喇叭袖——維多利亞時代的拘束感轉化為美學選擇
- **貓飾物**：貓鈴鐺 Choker + 貓耳髮箍 + 黑貓玩偶（隨身攜帶但不輕易示人）
- **手套**：平民絲綢手套——隔離層。摘下手套 = 最大信任的表現

### 魔法少女形態（傀儡師）

- **傀儡設計**：兩具巨大無臉人偶（「父」「母」），插滿刀刃與手術刀，血跡斑斑——家庭創傷的戰鬥具現化
- **戰鬥風格**：潔癖的指揮家。手指如彈鋼琴般操控傀儡，絕不讓自己的腳接觸地面——用絲線懸吊或在空中滑行
- **手套升級**：魔法蕾絲長手套（更精緻的隔離層）
- **測量強迫症**：玫瑰金軟尺，戰後瘋狂測量三圍。1mm 誤差觸發崩潰——[執念飽和](../02_glossary.md#term-saturation-of-obsession)的徵兆

### 屍骸化過程

測量頻率暴增 → 用絲線對自己進行「整形手術」→ 第 13 天「鋼鐵獨舞」切斷變形左手 → 最終「人偶牆」——操將自己變成最大的傀儡，以身體封鎖通道。

### 視覺演變

| 幕 | 外觀 | 關鍵變化 |
|----|------|---------|
| 第一幕 | 完美維多利亞哥德——白髮如瀑、黑白配色 | 零破綻，精密偽裝 |
| 第二幕 | 偽裝出現裂痕——偶爾衣著不整 | 據點事件後放鬆控制 |
| 第三幕 | 半屍骸化——黑白配色失衡、絲線纏繞 | 無心人偶 → 打碎 → 回到殘缺身體 |
| 第四幕 | 鋼鐵獨舞——絲線全開、自我切割 → 人偶牆 | 以身體封鎖通道，最終形態 |
