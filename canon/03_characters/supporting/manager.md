# CAN-03 Supporting: 晴香的經理人 (Manager)

## 基本資料

> **來源**: [[screenwriter/02_Secondary_Character_Background_Story]]

- **身份**：晴香的經理人、投機賭徒、情緒管理局首席宣傳顧問
- **核心心理**：追求高風險回報的賭徒心理
- **角色弧光**：精明的投資者 → 絕望的拋售者 → 押上靈魂的豪賭者 → 賭徒的末路

## 背景故事

> **來源**: [[screenwriter/02_Secondary_Character_Background_Story]]

他並非單純的貪財，而是個天生的「投機賭徒」。他熱愛風險，享受在不確定性中以小博大所帶來的刺激感。簽下晴香，對他而言就是一場前景光明的賭博；而在晴香失勢後，他的所有行為，也都源於一個賭徒在賭輸後急於回本、甚至加倍下注的瘋狂心態。

**四幕弧光**：
1. **第一幕：精明的投資者** — 在晴香事業上升期，他扮演著完美的經理人角色，為他的「優質資產」規劃著一切
2. **第二幕：絕望的拋售者** — 當晴香身份曝光、社會性死亡後，他視為「投資失敗」。他毫不猶豫地將晴香的肖像權賣給了情緒毒品公司，這不是單純的報復，而是一個賭徒在清算資產、回收賭本的冷酷行為
3. **第二幕後期～第三幕：押上靈魂的豪賭** — 在他最潦倒時，黑奏或情緒管理局向他拋出了橄欖枝，給了他一場新的、更大的賭局——「賭這個世界的未來」。他們承諾的，不僅是金錢，更是能操縱人心的「權力」。他欣然入局，成為情緒管理局的**「首席宣傳顧問」**，享受著玩弄輿論、顛倒黑白的快感
4. **第四幕：賭徒的末路** — 當最終的混亂來臨時，他所依附的體制將毫不猶豫地將他當作棄子。他可能會被自己親手煽動起來的狂熱民眾所吞噬，或是在試圖進行最後一次背叛投機時，被無情地清除

## 故事功能

- **人類之惡的代表**：依附體制、出賣靈魂的投機者
- **晴香社會性死亡的推手**：將肖像權賣給情緒毒品公司
- **輿論操控的執行者**：情緒管理局首席宣傳顧問，玩弄輿論、顛倒黑白
- **賭徒心理的具現化**：從投資者到豪賭者的墮落軌跡
- **諷刺性結局**：滿盤皆輸，被自己親手煽動的民眾吞噬或被體制清除
