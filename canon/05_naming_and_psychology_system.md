## <a id="section-core-premise"></a>核心假設：名字即現實測謊機

### 基礎命題

**晴香創造 Beta 線的一剎那，決定了這個世界的「名字系統」。**

5 歲的連若晴（晴香）目睹家姐死亡，極端創傷下發動「改變現實」。她幼小的心智中，「完美、沒有人受傷的世界」的唯一參考對象，就是電視機播放的**日系魔法少女動漫**。

因此：
- **Beta 線的整個視覺與文化語言系統，源自一個 5 歲女孩對日本動漫的癡迷投射**
- **日文名字，本質上是 Beta 線為了掩蓋 Alpha 線血肉模糊真相而強行笠上去的「動漫濾鏡」**
- **中文名字，代表 Alpha 線的原初現實——無魔法、無帝國、只有殘酷與痛楚**

**敘事推論**：
當菲（夕）在 Act IV 試圖「重建 Alpha 線」時，她無意識地仍然使用了 Beta 線的「動漫濾鏡」——她創造的「假 Alpha 線」中，角色們仍然叫著日文名字。這個細節成為晴香識破幻象的終極證據：**名字本身成為了衡量現實真偽的測謊機**。

**主題含義**：
- 不敢直視真實的痛，就永遠無法抵達真實
- 即使試圖救贖，如果仍然依賴膠布，救贖也是虛假的
- 態度（是否願意面對）決定一切，比力量更根本

## <a id="section-three-layers"></a>三層象徵結構：名字的多重含義

### 第一層：動漫濾鏡（The Anime Filter）

**象徵層級**：名字 = Beta 線的視覺與文化系統

**運作邏輯**：
- Beta 線整體是「5 歲晴香對動漫世界的投影」
- 日文名字是這個投影的語言載體
- 帝國強行推廣「日區」、強制少女改日文名，本質上是「維持晴香幼年逃避幻象」的國家級膠布

**場景應用**：
- 日區的官方廣播、偶像舞台、帝國文件：全部使用日文名
- 夜區的黑話、反抗軍基地、角色的最私密時刻：回歸中文真名

---

### 第二層：創傷性面具（Traumatic Persona）

**象徵層級**：名字 = 角色對痛苦的防衛機制

**運作邏輯**：
- 每個魔法少女的「日文名」都對應她如何「逃避」現實創傷
- **凌心怡 ➡️ 綾瀨凜**：親眼目睹粉絲自殺後，心怡選擇「切除所有感情」。她變成了「凜」——一部冷漠、精準、無感的機器
- **連若晴 ➡️ 春日井晴香**：無法接受「我害死了家姐」的罪疚，她催眠自己成為「帶給全世界希望的太陽」
- **連若星 ➡️ 水無月美夜子**：作為已死者被迫復活，她用帝國賜予的代號來掩蓋「我本不該存在」的絕望

**治癒路徑**：
只有當角色願意**說出真名**、直視創傷，防衛機制才會瓦解，治癒才能開始。

---

### 第三層：情緒農場的商品標籤（Commodity Label）

**象徵層級**：名字 = 帝國資本化少女的手段

**運作邏輯**：
- 帝國不會叫一個屍骸化兵器「連若星」，因為太像一個人
- 帝國會叫她「水無月美夜子」——一個華麗、有距離感的消費品名稱
- 經理人會叫「連若晴」的受傷少女為「春日井晴香」——可以用來賣單張、帶粉絲、採集情感數據的商品

**政治意涵**：
剝奪真名 = 消除人性 = 轉化為商品。這是帝國「情緒資本主義」的最基礎手段。

## <a id="section-character-naming"></a>全角色名字系統與階級光譜

### 分組原則

角色的名字構成遵循一條**階級與命運的光譜**，而非統一模式：

| 名字構成 | 象徵意義 | 代表角色 | 註記 |
|---------|--------|--------|------|
| **中日雙語** | 被資本包裝 / 隱藏身份 | 連若晴 ➡️ 春日井晴香 | 曾經擁有自我，被帝國系統洗走 |
| **純日文名** | 完全被體制吞噬 | 綾瀨凜 | 沒有過去、沒有自我、只有編制代號 |
| **純中文名** | 無法逃避的殘酷現實 | 方曉彤、雷子健 | 夜區底層，連被包裝的資格都沒有 |

---

### 🌟 第一組：被剝奪與隱藏的雙子（有齊真假名）

**系統邏輯**：原本有完整家庭與身份。Beta 線誕生後，一個被帝國洗腦包裝，一個被迫隱姓埋名。

#### **連若晴** ➡️ **春日井 晴香**
- **真實身份**：連家次女，母親東雲血統
- **帝國包裝**：春日井晴香，頂流偶像明星
- **轉變時機**：5 歲創造 Beta 線後，逐步被帝國系統「塑造」
- **象徵**：「若晴」意為「宛如晴空」，但她承受最黑暗創傷；名字越光明，心洞越深
- **治癒路徑**：說出「我叫連若晴，不是春日井晴香」= 撕開第一層膠布

#### **連若星** ➡️ **水無月 美夜子**
- **真實身份**：連家長女，母親東雲血統
- **帝國代號**：水無月美夜子，Unit 01 軍方兵器
- **轉變時機**：Alpha 線死亡 → Beta 線復活 → 軍方改造
- **象徵**：「若星」代表夜晚的星光、隱藏守望；「水無月」是帝國試圖切斷她與過去的冷漠代號
- **獨特性**：唯一在 Beta 線中既保留中文真名身份（用於夜區反抗軍識別），又被迫使用日文代號（用於帝國內部）的角色
- **治癒路徑**：接納「借來的生命」，允許自己在信賴者面前脆弱

#### **菲 (Fei)** 
- **真實身份**：無姓氏。晴香潛意識分裂出的陰影人格
- **帝國地位**：零。因為菲不屬於任何現實層面
- **象徵**：無名之物——代表被壓抑、被否認、被強行切割的自我碎片
- **獨特性**：她沒有日文名，因為她根本不屬於 Beta 線官方系統；她也沒有被「包裝」的需要，因為她本就是逃避的代價

---

### 🎤 第二組：極端轉換的兵器化

**系統邏輯**：這組角色代表「個人創傷」被「帝國系統」最激進地扭曲的結果。

#### **凌心怡** ➡️ **綾瀨 凜**
- **真實身份**：Alpha 線新人偶像，會記住粉絲生日、親手摺星星
- **帝國改造**：被軍方洗腦 → 切除痛覺與感情 → 變成 Unit 00 精準兵器
- **轉變時機**：粉絲自殺事件（Alpha 線創傷）→ 軍方強制改造（Beta 線強行)
- **象徵**：從「心怡」（暖心的女孩）到「凜」（冷漠的刀片），名字本身就是創傷的記錄
- **獨特性**：**唯一完全喪失中文名身份的主要角色**。不是她忘記自己叫什麼，而是帝國給了她一個永久的編制代號，中文名成為被官方宣布「不存在」的身份
- **治癒路徑**：記起「凌心怡」這個名字 = 記起自己曾經能愛人 = 打破 Unit 00 的完美兵器假象

---

### ⚖️ 第三組：階級的兩極

**系統邏輯**：沒有雙語的純極端者——分別代表「體制頂端的囚徒」與「社會底層的無人」。

#### **綾小路 操** （唯一真名，無中文名）
- **身份**：大財閥世家子弟，日區權力金字塔頂端
- **帝國關係**：本身就是帝國統治階層，無需「改名」
- **象徵**：他的「綾小路」姓氏本身就是枷鎖——不是帝國強加，而是被祖先的封建傳統永久綁定
- **獨特性**：相比其他角色被帝國「改名」的被動性，操是被自己的出身血統「命名」的困境
- **劇情功能**：代表「即使身在權力中心，也無法逃脫系統的人」

#### **方曉彤** （唯一真名，無日文名。街頭花名：不知火紫音）
- **身份**：夜區毒品街的窮家女，為照顧細佬而墮落
- **帝國關係**：帝國根本不屑於「包裝」她，她連被系統承認的資格都沒有
- **象徵**：「方曉彤」是夜區最殘酷、最無濾鏡的血肉真實。她的創傷太尖銳，Beta 線的「動漫濾鏡」遮不住
- **獨特性**：她的堅持用中文名，本身就是對帝國「日系美學統治」最無聲的反抗
- **劇情功能**：代表「體制無法同化、註定被放棄的人」——但正因為她清醒而真實，反而成為晴香最難以拯救的道德困境

---

### 👑 第四組：帝國的心臟

**系統邏輯**：統治階層內部的分裂人格與掩蔽。

#### **刑思**（帝國法號）
- **真實身份**：刑思（讀音 Keishi，實為廣東話「思螢」——永遠懷念死去的家姐螢）
- **象徵**：最高的統治者，卻用母語秘密呼喚一個死人——這本身就是最深的膠布
- **獨特性**：她用帝國的名號統治整個世界，卻永遠無法用帝國的語言表達自己最深的悲傷
- **劇情意義**：即使掌握了改變現實的權力，也無法逃脫心理創傷 = 力量無法對抗態度的主題體現

#### **葉語彩**（真實名字，無日文名）

- **象徵**：純中文名代表她永遠停留在「當年夜區小女孩」的狀態，未被帝國化、未被長大
- **獨特性**：她是唯一「被保護得最周密卻最無力」的人
- **劇情功能**：代表「即使躲起來，痛苦也無法被消除」

## <a id="section-act-4-naming-paradox"></a>**「假 Alpha 線名字穿幪」：Act IV 高潮機制**

### 敘事設計的核心伏筆

**菲的終極悲劇**：

當菲在 Act IV 奪取身體控制權，發動「改變現實」試圖重建「完美 Alpha 線」時，她做出了一個致命的無意識選擇——她創造的「假 Alpha 線」中，角色們仍然使用**日文名字**。

**場景推演**：

菲望著眼前復活的家姐，以為自己成功救贖了一切。但家姐走過來，溫柔地叫了一聲：**「晴香，食飯啦。」**

**核爆級的心理諷刺**：

那一刻，聰慧的觀眾會突然冷汗直流：

> 等等……如果這是真正的 Alpha 線，家姐應該叫她**「若晴」**，家姐自己應該叫**「若星」**！
> 
> 為什麼她們還在用日文名？

**答案**：因為**這不是真正的 Alpha 線。這只是菲用 Beta 線的膠布，捏造出來的一個「無痛娃娃屋」。**

**終極真相的揭露**：

菲以為自己徹底清醒，以為只有她才看穿了 Beta 線的幻象。但實際上，**菲跟晴香一樣，根本承受不住真正 Alpha 線（血肉模糊、中文名現實）的痛楚。她潛意識裡依然依賴著那塊名為「日文」的膠布。**

**主題的終極昇華**：

即使試圖救贖，即使試圖還原真實，如果仍然依賴膠布，救贖也是虛假的。**不敢直視真實的痛，就永遠無法抵達真實。**

---

### 晴香真正的覺醒

**不需要魔法，只需要真名**

晴香不是用力量打敗菲的幻象，而是用**「真名」本身**來戳破它。

當晴香的意識甦醒，睜眼看清菲建立的「假 Alpha 線」時，她需要說的只有一句話：

> **「她不叫美夜子。她叫連若星。」**

隨著這三個中文字說出口，整個日系溫馨的幻象空間開始像玻璃般碎裂，露出底下血淋淋的 Alpha 線真實。

**名字本身成為了唯一的武器**——不是魔法力量，而是**直視真實的勇氣**。

## <a id="section-narrative-rules"></a>劇本操作三鐵則

### 規則 1：場景綁定稱呼（Contextual Naming）

**帝國空間 / 官方場景**：
- 電視熒幕、官方廣播、偶像舞台、帝國文件、日區公開場合
- **一律使用日文名**：春日井晴香、水無月美夜子、綾瀨凜、澄川彩
- **效果**：觀眾看到日文名時，潛意識會感受到「被帝國監視」「被系統包裝」的質感

**夜區空間 / 私密時刻**：
- 夜區後巷、反抗軍基地、角色獨處時的極度崩潰、生死關頭的最真誠時刻
- **使用中文真名**：連若晴、連若星、凌心怡、方曉彤
- **效果**：觀眾聽到中文名時，會感到「回到了最真實的人性」「膠布被撕開」

**混雜場景（關鍵轉折）**：
- 角色在帝國與夜區、虛假與真實之間搖擺的時刻
- 可同時出現兩個名字，製造「身份混亂」的戲劇張力
- **例**：晴香被社死後，有時人會叫她「春日井晴香」（舊身份），有時人會用「連若晴」（回歸真實）

---

### 規則 2：不一開始就爆底牌

**Act I & Act II 前期**：
- 觀眾和晴香一樣，只知道角色的「帝國名字」：美夜子、紫音、操、凜
- 故意隱藏中文真名，製造「謎團感」
- 觀眾會無意識地接受「這就是她們的名字」

**Act II 中後期 & Act III**：
- 逐步揭露中文真名（連若星、凌心怡、方曉彤……）
- 每一次真名的「刀割」般的揭露，都會刺痛觀眾
- **因為前面已經對角色產生深厚感情，突然爆出真名時，觀眾不會困惑，只會心痛**

**效果**：
觀眾會慢慢明白「日文名 = 帝國謊言」「中文名 = 真實痛楚」的映射，而不是被動接收設定，而是經歷一場「揭露真相的旅程」。

---

### 規則 3：主角視角的專一性

**晴香始終相信帝國包裝**：
- 被洗腦的晴香由頭到尾都叫對方「美夜子前輩」、「紫音」、「操」、「凜」
- 她無意識地使用帝國名字，代表她仍在膠布保護下

**夜區人的糾正（戲劇衝突）**：
- 莫浩然等夜區人會冷冷地糾正晴香：「她不叫美夜子，她叫連若星。」
- **這種稱呼上的碰撞本身就是戲劇張力**——不是兩個人在討論同一個人，而是在爭奪對「身份定義權」的話語權
- 晴香的困惑 = 觀眾的困惑，晴香的覺醒 = 觀眾的覺醒

**效果**：
名字不只是標籤，而是一場關於「誰有權定義妳是誰」的權力鬥爭。

## <a id="section-implementation-lore-practice"></a>劇本實戰：代號 vs 真名的使用時機

### 【寫大綱 / Working 溝通】使用系統代號

```
Outline: Miyako 為咗保護 Haruka 而擋低一擊，此刻她眼神閃過一瞬熟悉的記憶片段。

Beat Sheet: Haruka 對 Akane 說出心裡話，兩人之間首次產生真正的信任連結。

Dialogue Draft: 「Rin，你冇咁脆弱。你自己都唔知，你有幾堅強。」
```

**原因**：保持工作文件清晰、穩定，避免中途亂改。

---

### 【寫對白 / 角色視角】逐步引入真名

#### **Act I & II 前期**：純用帝國名字
```
晴香問：「美夜子前輩，你點解要一直跟住我？」
美夜子答：「因為妳對戰局有用。」
```

#### **Act II 中後期**：開始出現「中文真名」的碎片
```
朔看著晴香，輕輕說：「連若晴……妳知道自己係誰嗎？」
晴香愣住：「妳……點解這樣叫我？」
```

#### **Act III 關鍵時刻**：真名變成「武器」
```
晴香握住美夜子的手，顫抖地說：「若星……我睇到你了。我睇到真正的你。」
美夜子眼眶發紅，第一次在晴香面前流下眼淚。
```

#### **Act IV 高潮**：真名撕破最後的幻象
```
菲（絕望）：「妳睇下！我做到了！媽媽和美夜子都在這裡！」

晴香（平靜但堅定）：「她不叫美夜子。她叫連若星。她已經死了。
                   妳建的這個世界，只是一座連名字都不敢面對的墳墓。」

（整個日系溫馨的幻象空間開始像玻璃般碎裂。）
```

**效果**：觀眾經歷了「從被騙 → 逐漸發現真相 → 最終被真名刺穿防線」的完整心理弧線。
