## How to Maintain This Fact Map

### When canon files change:

1. **New character fact discovered**: Update CHARACTER_FACTS.md (corresponding character section)
2. **New CDL entry created**: Update WORLD_RULE_FACTS.md or DESIGN_GAPS.md (as applicable) + BUILD_SUMMARY.md (decision log integration count)
3. **New event established**: Update EVENT_FACTS.md (matching timeline period)
4. **New design gap identified**: Update DESIGN_GAPS.md + PROJECT_STATUS.md
5. **Contradiction discovered**: Check 99_decision_log.md for resolution; update relevant fact tables per CF- ruling

### Quarterly audit checklist:

- [ ] Run character facts against latest character sheets (source of truth)
- [ ] Cross-check timeline against 04_timeline_canon.md (source of truth)
- [ ] Verify all CDL entries (CF-XXX) are propagated to fact tables
- [ ] Scan canon/ files for new "btd" / "待定" markers → add to DESIGN_GAPS.md
- [ ] Confirm PROJECT_STATUS.md outline versions match fact map documentation
