## 一、個底（已傾定）

1. 個世界個樣 = 啲情緒本身，唔係情緒嘅裝飾（唯識宇宙 / AC-10）。
2. 被人好好安慰過、睇見過嘅情緒，會化成老香港嗰種有煙火氣嘅質感（真暖），或者變「微弱的感謝」燃料。
3. **冇人安慰過、冇人睇見過**嘅情緒，唔會消失（情緒守恆：債務必回流）——佢會積埋、變硬、結晶。
4. 晴香五歲創世嗰下，寫咗「呢個世界啲得人驚嘅嘢，個樣係黑色哥德鐵」——**佢淨係定咗個形狀語言**，冇整出啲痛。
5. 所以：**哥德 = 集體「冇人睇過」嘅痛，用晴香寫落嘅哥德語言結晶出嚟嘅樣。**
6. 哥德濃度 = 呢個世界有幾多痛苦係冇人睇見過嘅一個 readout。

## 二、哥德唔係一款，係跟住「呢舊痛點樣被拒絕」而生成唔同個樣（D-5，已傾定）

**原則**：一舊痛之所以冇人睇見，係有特定心理原因嘅。情緒變成樣嗰個機制，冇理由掉走呢個原因。所以個樣要帶住「呢舊痛係點樣被拒絕」嘅指紋。

**「一款黑鐵行天下」= 將好多句可讀嘅訊息壓成一句 = 失敗做法。**

下面五種係**例子，唔係封死嘅清單**。遇到新嘅心理情況，可以長新形態，只要跟返「形態 = 拒絕方式嘅指紋」呢個原則。

| 呢舊痛點樣被拒絕 | 黑鐵個樣 |
|---|---|
| **收埋**（扮冇事、唔畀人知） | 生喺睇唔到嘅位——牆入面、地板下、天花隙。表面睇落好地地，敲一敲先知實心。 |
| **割開 / 麻木**（同啲感覺切斷） | 邊緣好乾淨，但駁唔到落任何嘢，浮喺度。尖塔冇腳、欄杆兩頭懸空。 |
| **賴落第二個人度**（喺自己度唔認、喺人哋度先睇到） | 黑鐵唔生喺個場，生喺**第二個人**身上。佢自己乾乾淨淨，同佢嗌交嗰個手臂爬緊黑鐵。 |
| **一直翻、停唔到**（冇解決所以 loop） | 同一個花紋無限複製——一格變成成面牆、成塊地、成片天。 |
| **被要求扮靚、見得人** | 太完美、太對稱、乾淨到似陳列室。（= canon 已有嘅「絕對對稱」，而家有咗意思。） |

**兩個 canon 舊嘢因此有咗解釋：**
- 「絕對對稱」= 「被要求扮靚」嗰種，喺賣情緒 / 賣偶像嗰半個世界（維多利亞之淚、光幕、晴香個直播頻道）落得最重。
- 「哥德食光」＋「日區冇鏡、排斥反光（無鏡之城）」= 同一件事：「唔好望我，我都唔會望自己」。被抽乾嘅日區同結晶爆嘅夜區，係同一句心理嘅兩個面。canon 現時當兩件事，可以合返一件。

## 三、哥德可以變質、唔可以退返（D-3，已傾定）

- **唔可以純粹消失。** 成套嘢嘅主題係「被人睇見之後，仲願意行落去」，唔係「問題冇咗」。黑鐵見到有人安慰就縮返冇 = 廉價希望，同主題相反。
- **可以變質接金繼。** 一場戲入面真係有人被睇見、被陪住（見證守則 CDL-392）——佢附近嗰啲黑鐵會：停止生長 → 冇晒吸光嗰種死黑 → 開始有紋理 → 裂縫度長出金線（金繼；接返 canon 已有嘅「裂痕係勳章、破碎都可以係美」）。
- 意思：**嗰舊痛冇消失，但由「冇人睇過」變咗「有人陪住我睇過」，個樣就唔同。** 呢個係「拒絕訊號」倒返轉頭嘅「痊癒訊號」。

## 四、心房入面嘅哥德（D-4，順住成立）

- 街上嘅哥德 = 一大班人「冇人睇過」嘅痛，出面版。
- 一個人心房入面嘅哥德 = **嗰一個人自己**收埋 / 割開 / loop 緊嘅痛，入面版。同樣嗰套形態，只不過源頭得一個人。
- 同一個機制、兩個尺度，成套打通。

## 五、導演語言點用

1. **形態對照表**（上面第二節嗰張的完整版）：
   一場戲嘅情緒內容 → 呢舊痛係點被拒絕 → 對應嘅哥德形態 → 鏡頭 / 走位 / 美術提示。
   美術部查表就推到，唔使逐場靠靈感。

2. **層級切換文法**：
   - 甜嘢底下見到黑（願望層跌落恐懼層）
   - 老香港質感頂穿塊布（宿主層上浮，即真嘢露返出嚟）
   - **邊種形態浮出嚟 = 話你知係邊個角色嘅債入咗個場。**

3. **見證嘅反面 tell**（見第三節）：
   場戲有真見證 → 附近哥德停生長、起金線。觀眾睇十幾個鐘，拒絕訊號同痊癒訊號兩邊都學識讀。

4. **晴香嘅字典係天花板、唔係泉源**：
   佢只寫咗「用哥德呢種形狀語言」。美術部被鎖死喺哥德詞彙入面——但詞彙入面所有形態都有得用。唔可以躲懶用一款黑鐵。
