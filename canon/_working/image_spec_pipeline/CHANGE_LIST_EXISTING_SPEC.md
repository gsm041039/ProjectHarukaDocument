3. **角色專屬視覺語言誤用擴展到凜嘅第二個形態（圖46）**：之前批次已發現凜嘅「烏鴉形態」被提前誤用，本批發現凜嘅「孔雀形態」亦被誤讀為「監視工具」——同其設計本意（殘留Alpha線偶像明亮面）完全相反。呢個模式現時已確認覆蓋凜嘅兩種形態、彩/黑奏、愛莉、夕——建議之後任何涉及「多形態/雙重意義視覺系統」角色嘅場景都要對照角色檔案原始設計意圖，唔可以假設「聽落合理」嘅詮釋就係canon本意。
