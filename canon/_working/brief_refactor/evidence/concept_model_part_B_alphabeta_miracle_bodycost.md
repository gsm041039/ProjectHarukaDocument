## 1. Alpha/Beta

**A. 一句核心**
Alpha 線係事件層嘅真相（發生咗乜），Beta 線係態度層嘅真相（點樣回應嗰件事）——兩條線係同一個唯識宇宙喺唔同集體潛意識存取權限（靜默 vs 激活）下嘅兩種形態，唔係真假對立。

**B. 屬於邊一層**
世界物理（唯識宇宙存取權限、L1-L3 連動） + 敘事原則（事件真相 vs 意義真相的雙軌結構） + 角色命題（各角色嘅 Alpha 原傷 → Beta 修正 → 守恆反噬五步模板）。唔屬於 Gameplay embodiment 本身（Gameplay 只消費呢個設定嘅結果，例如絕對共感 UI）。

**C. 同其他concept關係**
- **causes**：晴香帝國歷102年「改變現實」（奇蹟）→ 觸發 Alpha→Beta 分歧本身
- **manifests as**：護甲（CDL-402，Alpha 線因果牽連者嘅代價補償）、Beta 修正個人詛咒（美夜子避難所詛咒、夕嘅誕生、晴香情緒增幅器）
- **is interpreted through**：Alpha 原傷五步模板（CF-T19：原傷→童願→Beta修正→守恆反噬→態度缺口）
- **constrains**：奇蹟三項硬限制（唔可以真正復活死者、因果債必須歸還、唔可以覆寫原始情感記憶）直接由呢個雙軌結構推導出嚟
- **contrasts with**：Alpha 線死亡（物理終結/熵增）vs Beta 線死亡（靈魂困禁/哥德侵蝕）

**D. 而家喺Brief點表達**
用 grep 搵齊「Alpha」「Beta」223 次出現（跨 1 個檔），核心解釋段落分佈：
- **5519-5638**（`世界觀速覽 §Alpha 線與 Beta 線：事件真相 vs 態度真相`）——用「車禍已發生 vs 點樣面對餘生」比喻，明確寫「唔係真世界vs假世界」、列三個常見誤讀、附 Beta 線回填歷史說明、附晴香原罪對每個角色嘅命運改變表（5579-5637）→ **CURRENT_AND_CLEAR**，同 canon `rule-alpha-beta` / `section-alpha-beta-truth` 口徑一致，甚至比 canon 更易讀。
- **11540-11565**（附錄 §「Alpha vs Beta 並非對立世界，而係同一個唯識宇宙在不同存取權限下嘅兩種形態」）——呢個係 CDL-248 唯識宇宙嗰一層嘅正確表達，但**只出現喺附錄**，同 5519 嗰段主敘述完全冇互相連結（無反向連結、用詞唔同：一個講「事件/態度」，一個講「存取權限」）→ **TOO_FRAGMENTED**：讀者好可能睇完 5519 就以為自己已經完全理解 Alpha/Beta，唔會意識到仲有一層更底層嘅物理解釋收埋喺附錄。

- **10132-10166**（時間線圖例）——Alpha 線／Beta 線回填歷史／創造點作為時間軸分類，同上面定義一致，屬於「切面引用」用法，冇問題。

- **Deep form**：11618-11637 嗰個對照表可以刪除，改為喺附錄用一句「完整版見上面 §Alpha 線與 Beta 線」連結返 5519，避免同一條表格兩個地方各自維護、容易走數。

## 2. Miracle / Debt / Conservation Chain（情緒守恆因果鏈）

**A. 一句核心**
奇蹟（現實覆寫）製造情緒失衡 → 情緒守恆定律強制將呢份失衡記做痛苦轉移，唔會消失 → 轉移嘅痛苦以情緒廢料形式沉積集體潛意識 → 廢料超過閾值觸發緋潮（世界免疫系統強制清算）；同一條法則喺個體層面嘅呈現，就係魔法少女嘅心之器耗損進程，終局係魔法屍骸化。

**B. 屬於邊一層**
世界物理（情緒守恆定律本身係「客觀物理事實，非角色哲學詮釋」，CDL-248 明文）+ 心理物理（心之器耗損、屍骸化係心理創傷嘅具現化）+ 敘事原則（膠布哲學係法則之下嘅個人態度技術，唔係並列法則）。呢條鏈本身唔屬於角色命題層——佢係全部角色命題共用嘅底層引擎。

**C. 同其他concept關係（因果鏈本身）**
```
奇蹟（現實覆寫，晴香5歲創世）
  → 情緒失衡（因果債產生：三項硬限制之一「因果債必須歸還」）
  → 情緒守恆定律（機械式核數，唔理會加害者悔意——CDL-394 秋穗個案已證明）
  → 情緒被壓抑/轉移（魔法少女施法＝將負面情緒推入集體潛意識；維多利亞之淚＝將日區痛苦抽壓入夜區）
  → 情緒廢料累積於集體潛意識（L1回聲層 → L2留存海 → L3冥河，三層連動壓力）
  → 集體潛意識超載（L3冥河壓力滿溢）
  → 緋潮（滲漏表徵，世界免疫系統強制清算）
      同時
  → 個體層：心之器裂痕累積 → 魔法屍骸化（執念碎片鎖死靈魂於肉體，1%控制力 vs 99%情緒廢料）
```
- **causes**：奇蹟 causes 情緒失衡；情緒失衡 causes 守恆定律介入
- **manifests as**：緋潮（社會規模）、魔法屍骸化（個體規模）係同一條法則嘅兩個規模呈現，唔係兩件獨立嘢
- **is interpreted through**：膠布哲學（個人態度技術，降格為框架下嘅回應策略）
- **contrasts with**：緋潮（世界免疫系統排斥反應）vs 現實塌陷（靈魂地基流失嘅物理崩潰）——machanism 唔同，容易混淆
- **supports**：情緒資本主義（帝國將呢條鏈工業化：情感採集系統 → Emo-Visor → 市民成癮 → 需要更多兵器嘅自我強化循環）

## 3. Body Cost × Debt

**A. 一句核心**
身體代價（肉身可見症狀：牙齦出血、手震、黑色眼淚、哥德尖刺）同債務（情緒經濟隱喻：欠債、利息、強制執行）係同一條情緒守恆定律喺個人／社會兩個規模嘅**導演語言翻譯**，唔係另一條世界規則。

**B. 屬於邊一層**
**導演語言**（Brief 5760 原文明寫「全劇導演語言的核心公式」）——呢一點好緊要：呢個 concept 喺 canon 世界物理層唔存在獨立條文，佢係一個跨部門（表演/美術/鏡頭）共用嘅**翻譯層**，將情緒守恆定律、膠布哲學、光環處決等已有世界規則，轉譯做觀眾唔需要理解魔法就睇得明嘅兩個世俗詞（代價／債）。呢個定位同 `.claude/story_system` 入面 `story-directing-language-architect` skill 嘅自我定位完全一致（「發現而唔係發明」、「永遠唔會將呢條 concept 升格做 Theme」）。

**C. 同其他concept關係**
- **is interpreted through / dramatizes**：情緒守恆定律（世界物理層）→ 身體代價×債務（導演語言層），單向翻譯，唔係反過來
- **manifests as**：牙齦出血、手震、黑色眼淚、哥德尖刺（個人身體代價實例，同 canon `rule-magic-cost` 四層代價體系一致）；維多利亞之淚「情緒經濟中央銀行」隱喻（社會債務規模）
- **causes**：奇蹟簡易療傷（CDL-362，貼膠布式療傷）——每次走捷徑療傷，代價直接匯入呢個角色已有嘅身體崩壞線，即係話「療傷」本身都係一種借新債還舊債
- **constrains**：唔可以將呢個 concept 錯誤提升做同「情緒守恆定律」並列嘅獨立世界規則——canon 冇呢條規則，佢純粹係表達手法

**D. 而家喺Brief點表達**
- **4759-4804**（`§身體代價 × 債務——全劇導演語言的核心公式`）——**CURRENT_AND_CLEAR**：明確自稱「導演語言」、有個人/社會兩規模對照表（4773-4798）、有制度錨點具體例子（身份證明文件續期，4799-4801）、有心理鏈（傷口→需要→救援/交換→債務→索取權→自我剝奪，4803）。呢段係全 Brief 對呢個 concept 表達得最精準、層級最清楚嘅地方——冇混淆做世界物理硬規則。
- **6030 起「變身代價全圖」（第一維度：身體代價，四階段進程表）**——呢個係身體代價嘅**具體機制表**（唔係導演語言介紹，而係實際四階段症狀進程：黑色眼淚/哥德尖刺等），同 canon `rule-magic-cost` 對應。屬於「切面引用」，用法正確——一個講「呢個 concept 係乜嘢層級」，一個講「具體點樣發生喺個角色身上」，冇重疊。
- **未見有第二個地方重新解釋「身體代價×債務」呢個框架本身**——唯一定義入口就係 4759，無 duplication 問題。
- 潛在風險（唔算現存 drift，但值得記錄）：4770「這期未清」「利息算埋」呢類世俗化比喻語言，讀者可能會誤讀做世界內真係有一套「利息計算」嘅正式金融機制（同「情緒經濟中央銀行」比喻疊埋一齊），而 canon 入面情緒守恆定律嘅實際運作係「機械式核數，唔理會悔意」（CDL-394），唔涉及真正嘅利率/複利概念——呢點喺 4759 段落本身冇講錯，但如果讀者跳讀漏咗開頭嗰句「全劇導演語言的核心公式」，就有機會將隱喻當成世界規則本身。**判讀：FACTUALLY_CURRENT_BUT_CONCEPTUALLY_AT_RISK_OF_MISREAD**（唔係 drift，係表達層冇問題但缺一個更顯眼嘅「呢個係比喻唔係硬規則」提示）。

**E. Brief最終應該點表達**
- **Primary Home**：維持 4759-4804，唔需要大改，已經係全 Brief 表達得最乾淨嘅其中一個 section。
- **Short form**：喺 4762 開頭句「這兩個字是全劇導演語言的共同度量單位」之後，可以加多一句更直接嘅提示：「呢兩個字唔係世界入面真係存在嘅金融/會計機制——實際運作規則見『情緒守恆定律』」，減低同世界物理層混淆嘅風險。
- **Deep form**：6030「變身代價全圖」維持現狀做具體症狀進程表，唔需要改動；亦唔需要同 4759 互相連結得更緊密，兩者現時嘅分工（框架 vs 具體症狀）已經算清晰。
