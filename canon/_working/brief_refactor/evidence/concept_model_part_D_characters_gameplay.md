## 2. Gameplay Embodiment 重新檢查

### 絕對共感視界
- **承載嘅 concept**：晴香嘅「管理員權限」式全知，係詛咒唔係天賦——佢永遠睇穿人哋，但永遠冇人可以睇穿佢，令佢喺關心人嘅同時愈嚟愈孤獨。
- **Concept → Action → Response → Consequence**：
  - Concept：全知帶嚟結構性不平等同孤獨
  - Player action：睇到 NPC/敵人情緒數據、弱點
  - System response：HUD 顯示情緒條/心之隙縫，隨劇情逐幕崩潰降級（第三幕完全崩潰）
  - Emotional consequence：玩家經歷「工具喺關鍵時刻失效」，體會晴香失去確定感嘅感受；UI 崩潰本身就係佢「唔再可以靠睇穿人嚟保持安全距離」嘅具現
- **Brief 評估**：已寫入實質 concept 語句（L11170「其他魔法少女看不到這些 UI，這個真相在第三幕才揭露」+ UI 降級表），但冇明寫「呢個能力令佢孤獨」呢層——呢層講法喺 `c-haruka` 角色卡入面有（L6798 附近），遊戲系統章節冇重申。屬 CURRENT，可以補強跨章節呼應但唔算 stale。

### 雙軌數值系統（Kill / Purify / Extract）
- **承載嘅 concept**：情緒守恆定律——痛苦唔會消失，只會轉移；「有效率」嘅解法（Kill）會將代價轉嫁去第三幕 Boss 身上，逼玩家喺遊戲機制層面親身體驗「快靚正嘅解決方法其實冇解決任何嘢」。
- **Concept → Action → Response → Consequence**：
  - Concept：情緒守恆／代價轉移（CDL-402/403 護甲=情緒守恆定律具現）
  - Player action：三選一擊殺方式
  - System response：EXP 高低相反排列（Kill 最高 EXP 但累積負債；Extract 零 EXP 但收集「微弱的感謝」）
  - Emotional consequence：第三幕 Boss 無限再生（L11248「你在第一至三幕的每一次 Kill，就是 Boss 的再生燃料」）直接懲罰玩家貪快嘅選擇，將主題變成可玩懲罰而唔係旁白說教
- **Brief 評估**：CURRENT_AND_CLEAR，且係整個 gameplay 章節入面主題扣連最強、最直接嘅一個系統。`10_gameplay_bible.md` L355「淡淡的感謝」段落補充咗 Extract 嘅完整主題意義（「最真實的貨幣」「玩家一個都冇收集過，黑暗中的孤立是自己選擇的」）——Brief 現有表達（L11238-11244）冇寫到呢層深度，只講咗「0 EXP／收集微弱的感謝／第四幕揭曉其真正價值」，讀者未必睇得出呢個「真正價值」係咩。屬 CURRENT_AND_CLEAR 但可以加深，唔算 stale。

### 社會風評三階段弧
- **承載嘅 concept**：假甜 vs 真暖——公眾崇拜嘅係濾鏡幻象（維多利亞天使期），濾鏡穿幫即刻反噬（裂痕期→魔女狩獵期），對應「舞台化奇蹟——被看見的不可能」（CDL-379）同情緒資本主義嘅商品化邏輯。
- **Concept → Action → Response → Consequence**：
  - Concept：公眾嘅愛建基於幻象，唔係真身
  - Player action：完成王道式任務（救人/護送/清場）
  - System response：光幕濾鏡遮蓋真容 → 濾鏡穿幫 → 委託條件收緊 → 完全被通緝
  - Emotional consequence：玩家親歷「被崇拜」到「被排斥」嘅落差，體會晴香團隊「被消費嘅英雄」處境
- **Brief 評估**：CURRENT_AND_CLEAR，表格本身（L11253-11282）已經清楚將任務性質同玩家處境對照，主題扣連唔使外加解讀。

- **承載嘅 concept**：部分有、部分冇——要分開睇：
  - **葡萄糖注射槍**：有實質連結。魔力=血糖值（CDL-114）令「戰鬥」直接掛鈎「身體代價」——呢個係「身體代價 × 債務」導演語言公式（Brief L4760）喺 gameplay 層面嘅直接具現，代價唔係抽象數值而係真實生理資源。
  - **替死鬼假人**：有實質連結，但 Brief 冇寫出嚟。`10_gameplay_bible.md` L369 已經明文「『替身』與『犧牲』的隱喻」——Brief L11296-11298 現有表達純粹寫功能（「低級屍骸優先攻擊人形物」），完全冇提呢層隱喻，屬於 STALE／未同步（canon 已有嘅主題意義冇反映落 Brief）。

- **Concept → Action → Response → Consequence**（僅適用於葡萄糖注射槍）：
  - Concept：魔力嘅代價係身體本身，唔係抽象資源
