## 0. 本輪討論目的

先將「舞台 × 傷口」一輪完整討論落檔，再繼續逐層深化。今輪不是直接改 Canon，而是整理目前已形成的方向、概念關係、設計推論與仍需回答的問題。

使用者提出的新方向是：

## 1. 已確認的主題底線

### 1.1 核心主題

Project Haruka 的核心仍然是：

> 面對不可控的命運時，態度是唯一的自由。

亦可具體化為：

> 命運有代價；真正重要的是一個人怎樣面對這份代價。

因此，「舞台 × 傷口」不能取代「態度 vs 命運」，而應該是把主題轉成可反覆看見、聽見、操作及感受到的導演語言。

### 1.2 代價不是指定犧牲者

不能把全作硬改成「某個人被指定獻祭、代大家付出」的單一結構。獻祭可作為解鎖儀式、帝國語言或角色信念，但不升格為全作唯一主題。

「債務」應保留為代價累積、轉移、承接及埋單的運作機制；不是故事最表面的核心名詞。

### 1.3 希望不是消除傷口

沿用的深層方向是：

> 希望不是治好傷口，而是停止消費傷口。

更準確地說：

> 有人看見你受傷，卻不要求你把傷口變成力量、表演、教訓、希望或別人的財產。

這不代表所有觀看、掌聲、愛或表演都必然虛假；真誠的觀看也可以存在，並且可以真正救到人。問題在於：感動不會自動產生索取權。

## 2. 「舞台 × 傷口」的暫定核心命題

### 2.1 舞台不是單純的表演地點

舞台是一個把私人痛苦加工成公共可見形式的系統：

```text
私人傷口
→ 被看見
→ 被解讀
→ 被加工成美麗／希望／榮耀／娛樂
→ 被交換、重播、記錄或使用
→ 產生新的期待
→ 代價回到某個人的身體、心理或關係上
```

所以舞台最黑暗的地方不是「甜美下面藏住黑暗」，而是：

> 舞台把黑暗加工成甜美，令觀眾可以安心食落去。

### 2.2 「傷口壓成花」

「花開得最燦爛的那一刻，觀眾才發現花瓣其實是由某個人的痛苦壓製出來」是本輪最有潛力的導演意象。

它不是單純的黑暗／甜美反差，而是一套因果關係：花之所以完整、漂亮、可愛，正因為痛苦被壓平、加工及隱藏在花瓣內。

可暫時拆成：

| 意象 | Project Haruka 中的功能 |
|---|---|
| 傷口 | 命運留下的、不能被完全抹走的痛苦 |
| 壓力 | 制度、期待、身體代價、內化目光、公共要求 |
| 花 | 被加工成可愛、榮耀、希望或英雄形象的痛苦 |
| 舞台 | 令花可以被觀看、解讀、交換、重播的公共系統 |
| 觀眾 | 可以陪伴，也可以要求花繼續開的觀看位置 |
| 態度 | 傷者如何交出、命名、保留、拒絕或停止自己的花 |
| 債務 | 花被維持後，必須由某人承受的身體／心理／關係代價 |

### 2.3 舞台與主題的連接

命運決定角色會否受傷、傷口從何而來，以及世界對她施加甚麼壓力；態度決定角色如何處理傷口，以及是否讓傷口被加工成花。

因此主題問題不是：

> 這朵花是否漂亮？

而是：

- 誰壓出了這朵花？
- 誰決定它應該開成甚麼樣子？
- 誰有權解釋這個傷口？
- 傷口仍不仍然屬於受傷的人？
- 誰得到安慰、力量、娛樂或權力？
- 誰最後埋單？
- 傷者有沒有權叫它停止綻放？

這令「態度」不再只是角色口頭上說自己選擇了甚麼，而是具體表現在：她如何面對被觀看、如何處理代價，以及如何界定自己的傷口是否可以被交出去。

## 3. 「觀眾」的重新定義

### 3.1 觀眾不等於剝削者

之前把「自己成為自己的觀眾」直接推成自我剝削，判斷過快，已修正。

「觀眾」首先是一個觀看位置，不是固定的道德身份。觀眾至少包含：

1. 看見某種表現或傷口。
2. 對所見作出解讀。
3. 可能對被觀看者產生期待、要求、壓力或陪伴。

它可以有不同態度：

| 觀看位置 | 可能的態度 |
|---|---|
| 消費式觀眾 | 因為我被你感動，所以我有權要求你再給我一次 |
| 審判式觀眾 | 不斷檢查自己夠不夠好、夠不夠自然、值不值得被愛 |
| 理解式觀眾 | 看見痛苦，但不急於替對方定義 |
| 陪伴式觀眾 | 知道對方受傷，卻不要求對方把傷口變成表演 |
| 見證式觀眾 | 記得事情發生過，但不把記錄變成擁有權 |

### 3.2 魔法少女互相成為觀眾

魔法少女之間不會自動因為互相看見而成為觀眾；當其中一人開始表演某種「自己」，另一人又對這個表演進行解讀、期待、拆穿或陪伴，觀眾位置才成立。

例子：

- 晴香看見彩笑容背後的不舒服，成為彩的觀眾。
- 紫音拒絕接受晴香的完美笑容，成為拒絕被餵食假象的觀眾。
- 操拍下別人的痛苦，可能是保存者，也可能逐步變成剝削者。
- 美夜子看見晴香，卻把真正的關心解釋成計算，成為拒絕承認自己看見了甚麼的觀眾。

魔法少女同時可能是：

- 舞台上的表演者
- 舞台內觀看隊友的人
- 公共直播的被觀看者
- 觀看其他隊伍或觀眾反應的人
- 承接或拒絕承接傷口的人

### 3.3 自己可以是自己的觀眾

自己可以成為自己最殘酷的觀眾，也可以成為第一個真正尊重自己的觀眾。

前者會問：

- 我笑得自然嗎？
- 我有資格哭嗎？
- 我的痛會不會令別人失望？
- 我還能不能繼續上台？
- 我是否仍然值得被需要？

後者不是自我放任，而是：

> 我看見自己的痛苦，但不逼自己即刻解釋、修好、合理化，或把它變成有用的東西；之後由我決定要不要行動、求助、上台，或者暫時不開花。

### 3.4 陰影可以成為自己的觀眾

陰影不必固定等於壞觀眾。它可以是最殘酷的內在批評者，也可以是最清楚知道「為了表演成這個人，自己刪走了甚麼」的內在見證者。

陰影可以經歷：

```text
殘酷批評者
→ 被遺棄但一直觀看的部分自我
→ 記得傷口來源的見證者
→ 不再要求表演、只容許存在的內在觀眾
```

對晴香而言，菲／陰影相關設計不應只被寫成「黑化自我」；更有力的方向是：她是最早、最清楚、最不接受晴香把自己變成答案的觀眾。

## 4. 直播的重新定位

### 4.1 直播不是單一媒介功能

直播不應只用來提供：

- 偶像感
- 世界觀交代
- 一次失控事件
- 帝國事後剪片抹黑晴香

直播更深層的功能是：

> 將個人痛苦轉化成公共觀看、公共期待、公共消費，最後將代價送回某個人身上。

即使後期不再有傳統意義上的即時直播，以下東西仍可延續直播所建立的「被觀看狀態」：

- 舊直播片段、截圖與剪輯
- 帝國官方宣傳及重新解讀
- 粉絲模仿、二次創作、紀念表演
- 城市螢幕、光環與公共儀式
- 其他人代替某位少女再現她的形象
- 觀眾對缺席者仍要求她繼續出現

### 4.2 本輪新增方向：後期繼續直播

使用者認為後期仍然可以繼續魔法少女直播，而且這可能更好：

> 直播不只在前期作為設定或事件出現，而是貫穿後期，成為完整的導演語言。

這個方向的價值是：

1. 令「舞台 × 傷口」不只是一個比喻，而是可持續發生的故事機制。
2. 令魔法少女的私人痛苦持續面對公共目光、解讀及期待。
3. 令「奇蹟」不只是戰鬥或世界規則層面的超自然現象，而可成為舞台上被觀看、被命名、被期待及被消費的事件。
4. 令 Act I–IV 可以共享同一套表演／觀看 grammar，但每一幕改變「誰在看、看見甚麼、誰能控制意義、誰埋單」。
5. 令後期即使劇情已進入更大規模的帝國、奇蹟及現實改寫，仍可保留一個具體而可感知的觀看介面。

目前只確認「值得沿此方向深化」，尚未確認每一幕的直播形式、直播是否合法、誰控制頻道、觀眾是否仍在場、以及直播與既有劇情節點的精確接合。

### 4.3 直播應該令大劇情發生變化

每次直播或直播延伸事件，至少應實際改變以下其中兩項：

- 誰第一次看見某個傷口。
- 觀眾對少女產生甚麼新要求。
- 誰得到安慰、希望、力量或娛樂。
- 誰因此承受身體、心理、關係或身份代價。
- 直播內容如何被截取、重播、扭曲或利用。
- 少女如何開始監視自己或重新取回觀看權。
- 奇蹟如何被觀眾理解為祝福、商品、證據、威脅或救贖。

如果直播只增加氣氛而不改變上述任何關係，它仍然只是裝飾，不算真正的導演語言。

## 5. 直播與「傷口」及心靈／性剝削

### 5.1 公開不等於剝削，失去解釋權才是核心危險

不應把「更多少女痛苦被放到公眾眼前」簡化成單純增加崩潰場面。更有力的設計是：傷口只露出一部分，觀眾看見了，卻未必有能力正確理解。

例子：

- 表演時手震，被觀眾當成「脆弱感」或可愛特質。
- 聲線斷裂，被剪成感動名場面。
- 某人拒絕笑，被解讀成耍大牌或欺騙粉絲。
- 隊友突然接過鏡頭，被觀眾只看成默契演出。
- 晴香已經崩潰，觀眾卻要求安可。
- 一次真誠表露，被固定成下一次必須重現的內容。

核心不是「痛苦被公開」本身，而是：

> 傷者失去了解釋自己傷口的權利；別人替她決定傷口代表甚麼，並要求她再次提供同一種感動。

### 5.2 心靈／性剝削的深層形式

最極端的地方不一定是有人把少女身體色情化，而是觀眾開始相信：

> 既然你令我感動，我就有權接近你、解讀你、要求你再痛一次。

被要求交出的不只是身體，也包括：

- 脆弱
- 眼淚
- 私人秘密
- 創傷
- 親密感
- 「真正的自己」

剝削的語言可能是：

- 你越痛，越證明你真誠。
- 你不肯講，就代表你欺騙粉絲。
- 你既然曾經給過一次，之後就應該繼續給。
- 你令我感動，所以你的秘密、身體、影像及感情都應該向我開放。

因此「性剝削」可不只落在色情化畫面，而落在「親密權被公眾視為應得」：少女不能再決定誰可以接近自己的身體、影像、秘密與情感。

### 5.3 甜美與黑暗的因果關係

甜美不是黑暗的反面，而是黑暗可以被接受、被消費及被合理化的包裝：

- 心形、糖果色、亮片、笑容，把痛苦包裝成可愛。
- 掌聲，把剝削包裝成愛。
- 粉絲應援，把佔有包裝成支持。
- 變身，把肉身消耗包裝成榮耀。
- 光環，把被抽取的情緒重新神聖化。
- 直播，把崩潰包裝成「珍貴的真實」。
- 帝國制度，把集體痛苦包裝成秩序及治癒。

## 6. 「維持／承接／埋單」如何成為直播 grammar

既有導演語言骨架：

```text
入場 → 維持 → 失衡 → 承接 → 交接 → 退場 → 埋單
```

套入直播，可形成一個暫定的公共觀看循環：

| 狀態 | 直播中的暫定表現 |
|---|---|
| 入場 | 開播、變身、進入鏡頭、接受觀眾目光 |
| 維持 | 維持笑容、節奏、戰鬥形象、隊伍士氣及觀眾情緒 |
| 失衡 | 手震、呼吸亂、聲線斷、畫面失焦、反應慢半拍、鏡頭捕捉到不應公開的東西 |
| 承接 | 隊友接過鏡頭／台詞／敵人／情緒；觀眾或制度替少女解釋傷口 |
| 交接 | 傷口被剪成片段、標題、數據、宣傳材料、紀念物或奇蹟敘事 |
| 退場 | 直播結束、鏡頭關閉、少女離開舞台，但觀看狀態未必結束 |
| 埋單 | 身體代價、心理後果、關係裂痕、身份被固定、債務落到某人身上 |

最重要的戲劇錯位是：

> 觀眾看到的是花開的一刻；真正的埋單可能在鏡頭關閉之後才發生。

後期如果繼續直播，就可以反覆改變「承接」與「埋單」由誰負責：晴香自己承受、隊友共同承接、夕代行、帝國轉嫁、黑奏試圖取消痛苦，或某人拒絕再替全世界埋單。

## 7. 奇蹟與舞台的連接方向

### 7.1 既有基礎

既有設定中，奇蹟是改寫現實規則的力量，並已連接魔法少女、屍骸、帝國剝削系統、情緒守恆及維多利亞之淚。

因此今輪不是新增一個無關的「舞台奇蹟」，而是探索：奇蹟如何在公共觀看系統中被呈現、被命名、被期待及被索取。

### 7.2 暫定連接命題

可先記為：

> 奇蹟是舞台上被看見的「不可能」；但奇蹟成立所需的代價，未必會在同一個鏡頭內被看見。

或者：

> 舞台令奇蹟成為公共事件；觀眾的期待令奇蹟從一次例外，變成必須重現的責任。

這裡的危險不是奇蹟本身必然邪惡，而是：

- 奇蹟救到人，觀眾真心感動。
- 奇蹟因此建立希望及信任。
- 觀眾開始期待下一次奇蹟。
- 制度或群體把一次不能免費重現的奇蹟，當成少女應履行的固定職責。
- 代價被藏在表演外，並逐步形成債務。

這樣可以保留「美好是真實的，只是它不是免費的」：奇蹟可以是真的，救援可以是真的，愛也可以是真的；但它們不會因為是真實，就自動取消代價或給予他人索取權。

### 7.3 需要避免的錯誤

- 不要把奇蹟簡化為觀眾按讚、打賞便直接換取的娛樂效果。
- 不要把所有觀眾的希望寫成單純共犯或愚民。
- 不要把少女的每次表演都寫成被迫剝削；她們仍然可能主動選擇把痛苦化成歌、戰鬥、保護或希望。
- 不要用奇蹟抹走傷口，否則會破壞「與傷口共存」及「態度 vs 命運」的核心。
- 不要令舞台成為抽象漂亮意象，必須在劇情中改變觀看權、代價分配或角色選擇。

## 8. 後期直播的 Act 級方向（暫定，不是完整 outline）

這裡先保存目前可用的結構假設，之後要再逐幕以 Canon、事件及角色狀態核對：

| 階段 | 直播／舞台的觀看問題 | 導演語言的轉變 |
|---|---|---|
| Act I | 魔法少女第一次由私人存在變成被觀看的存在；隊友開始互相觀看 | 舞台建立；傷口仍有機會被誤認為可愛或勇敢 |
| Act II | 直播把痛苦變成流量、證據及宣傳材料；帝國開始控制觀看方式 | 觀眾的解讀權被制度化；花被加工及交換 |
| Act III | 直播／公開觀看成為審判、群體壓力、身份固定及共痛網絡的一部分 | 角色不只面對敵人，也面對誰有權觀看及定義她 |
| Act IV | 即使晴香沉睡二十年、夕代行或世界進入更大規模奇蹟，直播仍可持續；世界繼續要求「晴香」出現 | 本人、替代者、舊影像與觀眾之間的所有權衝突被推到最高；直播結束後仍不能退出舞台 |

Act IV 的核心問題可暫記為：

> 晴香本人不在場時，誰有權使用她的傷口、形象、名字及人生？

這也可連接晴香沉睡二十年與夕代行：夕不是單純代替一個功能，而是在一個仍然要求「晴香」持續出現的舞台上，代替她維持身份、希望及世界秩序；代價、責任及所有權因此產生新的債務。

## 9. 既有角色與「舞台 × 傷口」的可用種子

這些是現有設定中的種子，不代表本輪新增事件：

| 現有元素 | 可連到的舞台／觀看／傷口功能 |
|---|---|
| 晴香偶像、直播失控 | 最甜美的公共形象被真實肉身撕開；「為人哋喊，為自己唔喊」成為被觀看的不對稱 |
| 膠布哲學 | 把傷口遮住，令自己可以繼續上台；膠布本身也成為舞台服裝及表演的一部分 |
| 操影相成長線 | 記錄可以保存真實，也可以把最痛一刻永久商品化；父親的攝影陷阱直接摧毀其正面成長 |
| 紫音嗤笑遮痛 | 痛不開花，而以笑聲、暴力及嘲諷滲漏；觀眾可能將防禦誤讀成角色魅力 |
| 秋穗手震 | 結果論舞台被身體拆穿；專業穩定形象與良心代價同框 |
| 彩把信藏入熊公仔 | 保留一個不讓制度、鏡頭或觀眾進入的私人傷口；不是所有傷口都必須公開 |
| 光環／維多利亞之淚 | 被抽取的痛苦經過精煉後重新賣回成神聖希望 |
| 夕代行晴香人生 | 一個人代替另一個人維持舞台；身份替代本身逐漸成為傷口 |
| 凜自願兵器化 | 「我自己選擇」與「我被利用成可用之物」同時成立 |
| 奇蹟／現實改寫 | 不可能被公開呈現並成為希望；代價與觀看權需要被明確化 |

## 10. 已暫定的導演運作規則

以下四條規則由本輪討論形成，可作後續場景審核入口：

1. 每一場舞台都要問：誰為這次美麗埋單？
2. 每一種甜美都要包住一樣具體的痛，而不只是色彩對比。
3. 每一個被公開的傷口都要問：誰有權觀看、解釋及擁有它？
4. 每一個希望都要產生一個不被消費的時刻。

新增一條直播／奇蹟檢查規則：

5. 每一次奇蹟或直播都要問：它令誰看見了甚麼、令誰產生了甚麼期待，以及代價是否被錯誤地藏在舞台之外。

暫定總結句：

> 舞台把命運留下的傷口壓成花，讓奇蹟成為可被看見的美麗；真正的態度，不是把傷口變得美麗，而是決定這朵花由誰命名、是否仍然屬於受傷的人，以及何時可以停止綻放。
