# Theme Conflict Expression Table

**Layer: 表達層**
**Purpose:** 記錄主題如何透過立場衝突 + 後果在事件中被撞出嚟。

核心原則：
> 主題唔係靠說教表達，而係靠立場衝突 + 後果表達。
> 唔係角色「感受到咩」，而係「哪兩種立場真正交鋒，交鋒完產生什麼後果，觀眾從後果理解到什麼」。

Status 說明：
- EVENT_CARRIED = 已有具體事件承載衝突
- DIALOGUE_ONLY = 只靠對白，未有行為/選擇/後果層面體現
- MISSING = 尚未有事件承載
- CANDIDATE = 候選 event，待作者確認
