# Ideology / Theme Stance Matrix

**Layer: 立場層**
**Purpose:** 記錄每個主要角色、反派、關鍵副角色、群體、制度、世界機制代表者的主題立場。

⚠️ Hard rule：
> 故事對一種 stance 的處理，不等於角色本人對該 stance 的理解。
> AI 必須分清：角色自己信咩 vs 故事揭示佢真正信咩 vs 作者最終想觀眾點睇呢種 stance。

狀態：
- AC = Author Confirmed
- SS = Source Supported
- BK = Blocked

**最後更新：2026-04-14 | Round 023 | 18-angle Act I 掃描**
