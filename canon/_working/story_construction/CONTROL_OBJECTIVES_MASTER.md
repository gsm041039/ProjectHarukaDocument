# Control Objectives Master

**Layer: 全作控制層（最高層）**
**Purpose:** 全作控制任務總表。記錄每條 control line 的目標狀態、當前進度、承載媒介、及是否已有事件承載。

呢張表係最高層視角，回答：「今輪應優先推進哪條 control line？」

與其他四張表的關係：
- `INDIVIDUAL_CHARACTER_GROWTH_TRACKER.md` → 提供角色層細節
- `IDEOLOGY_THEME_STANCE_MATRIX.md` → 提供立場層細節
- `GROUP_WORLDVIEW_CONFLICT_MAP.md` → 提供群體層細節
- `THEME_CONFLICT_EXPRESSION_TABLE.md` → 提供表達層細節

**呢張表唔重複細節，只追蹤控制任務的完成狀態和優先級。**

---

## 使用規則

- 每條 control line 獨立一列
- Priority 要真實反映當前 pipeline 狀態（唔係固定的，要隨 acts 進度更新）
- Carrier 要具體：主線 beat / side quest / text prop / 非戰鬥段 / 環境敘事 / etc.
- Event Covered 欄：有確定事件承載就填 event ID，否則填 MISSING 或 CANDIDATE
