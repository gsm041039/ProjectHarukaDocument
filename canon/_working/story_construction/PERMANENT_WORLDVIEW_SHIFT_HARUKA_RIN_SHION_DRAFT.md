> **[DRAFT / 暫定 — 唔係 canon，唔 writeback]** 2026-10-25。作者提出主題想法，並更正方向：係**心理同點睇世界嘅永久改變，有好有壞**（唔係身體／行為上嘅痕）；作者揀「改變係中性事實」「角色知唔知因角色而異」。

## 0. 原則草稿（作者 2026-10-25 批准記成「主題原則候選」，仍為 DRAFT，未入 canon）

1. 苦難之後，人睇自己／睇人／睇世界嘅方式永久轉變，**同一個轉變通常好壞一齊來、拆唔開**。
2. 好嘅一面係**副產品**，唔係苦難換到嘅獎勵，亦唔可以拎嚟證明苦難值得（守反美化苦難守則）。
3. **換返檢驗**：如果可以揀，佢會唔會用呢個改變換返冇苦難？「會，但返唔到轉頭」＝合格；「唔會，因為我而家更好」＝好嘅一面變咗辯護，要重寫。
4. 角色對呢個轉變知唔知，因角色而異（見 §4）。成長仍然記喺**選擇**上，唔記喺轉變本身。

## 1. 晴香

| 項 | 內容 |
|---|---|
| 轉變前 | Act I：真心善意、冇面具，相信努力可以拯救。【S】 |
| 壞（永久） | ①永遠帶住「我幫人係咪都有自私核心」嘅疑。【S】②自己嘅痛「唔算得咩」，冇資格擺出嚟。【S】③唔再信成人／制度（被秋穗、經理人出賣）。【S】④睇到自己嘅痛苦可以被當商品消費。【S】 |
| 好（永久） | ①由「離地嘅同情」轉做真正理解人哋嘅痛。【S】②識得誠實承認自私核心，仍然揀繼續幫人（唔再靠幫人證明自己值得存在）。【S】③第一次識得為自己喊、肯望返自己嗰格警號。【S】④「痛係證據」由逃避工具變成真正活用嘅價值。【I】 |
| 同一轉變嘅兩面（例） | 「唔再相信自己嘅善係乾淨」＝壞（永遠自疑）＋好（善變成誠實嘅揀擇）。「痛係證據」＝對桐生健係溫暖，對夕係強迫剝奪止痛幻象，canon 已寫成雙面。【S】 |
| 自知程度 | **中後段知、結局故意糊**：二十年守望後清楚自己有自私核心【S】；Act I 至中段係「有能力睇到自己警號，但選擇唔望」【S】；融合係自由揀定債務推住，連晴香自己都分唔清，故事不予確認【S】。 |
| 換返？ | **作者 2026-10-25 揀（PROVISIONAL）：會換，但返唔到轉頭。** 佢寧願冇呢份理解，只要隊友冇受苦。 |
| 風險 | 角色檔寫「用血換返嚟嘅真正理解」，同「好命係用其他人苦難換嚟」連埋讀，最易滑向「苦難換來嘅獎勵」。要寫成：理解係佢目擊隊友受苦之後避唔開嘅副產品，唔係隊友受苦嘅價值。 |

## 2. 凜

| 項 | 內容 |
|---|---|
| 轉變前 | Alpha 線：用歌聲同溫暖救人，相信溫柔有用。【S】 |
| 壞（永久） | ①接收善意嘅能力死咗（快樂、溫暖、希望只剩語義）。【S】②相信「我嘅溫柔冇意義，甚至有害」。【S】③「只有痛覺能證明存在」。【S】④自己嘅位置隨時可被取代。【S】⑤用被動語態睇自己：「人哋加喺我度」。【S】 |
| 好（永久） | ①對痛苦嘅理解係全劇最清醒嗰批（將痛苦神聖化，同黑奏形成對照）。【S】②高度自我覺察，睇得清自己冰封同放棄。【S】③對人釋出嘅溫柔仍然真實；動作留低，「呢件事仲有意義」嘅信念死咗。【S】④自願兵器化嗰刻第一次用主動語態講自己。【S】 |
| 同一轉變嘅兩面（例） | 「痛覺係存在證明」＝壞（自毀）＋好（最誠實嘅理解）。溫柔動作留低但信念死咗＝仍可以對人好，同時接收唔到。 |
| 自知程度 | **高自知但郁唔到自己**：清楚睇到自己冰封【S】；只有少數盲點，例如想透過傷令人留意【S】；結局連凜自己都未必知揀啱定錯，故事刻意唔代佢肯定【S】。 |
| 換返？ | **canon 唯一有「想換返」嘅角色**：意識清零前嗰扇短窗，佢第一次重新想要返治癒，但冇能力講、冇能力改。【S】完全符合「會，但返唔到轉頭」，而且故事唔畀答案。 |
| 缺口（候選） | 【I】「好」嘅一面主要係仍然外放嘅溫柔。苦難令佢**睇人嘅方式**得到咩，未明寫。候選：做公務員時，對市民崩潰特別準，而且唔急住安慰。 |

## 3. 紫音

| 項 | 內容 |
|---|---|
| 轉變前 | 14 歲前後：夜區生存，保護弟弟。 |
| 壞（永久） | ①世界嘅嘢會被奪走：病態囤積、永恆警戒。【S】②「給予」可以殺人（糖→弟弟）。【S】③被理解＝威脅，會反彈。【S】④「我只配獨自承受」。【S】⑤用笑代替喊（家族傳承）。【S】 |
| 好（永久） | ①成癮崩潰雷達：睇得穿人快崩，並擋喺前面。【S】②對冇人要嘅嘢溫柔（野狗、屍骸）。【S】③判斷式節制：沉默係判斷，唔係麻木。【S】④最終「畀出」比索取填得更滿。【S】 |
| 同一轉變嘅兩面（例） | 「太熟悉靈魂壞掉嘅味道」＝壞（避唔開睇人崩）＋好（第一個擋前面）。糖＝毒死弟弟嘅嘢，亦係最終糖果山護盾嘅嘢。 |
| 自知程度 | **分層**：①能力層知（知道自己識睇崩潰，會主動用）；②意義層唔知（從未理解成「我係細心嘅人」，canon 禁止 Act I 自覺正面標籤）；③創傷層知（自認兇手）；④結局終於語言化：「我唔想再一個人食飯」。地下室「唔打」故事不定性。【S】 |
| 換返？ | **最清晰「會換」**：佢會用雷達換返弟弟。【I】符合檢驗，而且角色檔本身要求佢唔認「好」。所以呢個角色嘅「好」一定要由觀眾見到，佢自己唔認。 |
| 風險 | 自爆死亡係「畀出」嘅出口。要靠自爆前已有嘅留一份、餵狗等非死亡載體，避免「犧牲＝唯一態度出口」（現有守則已禁）。【S】 |
