## Situation (as given)
A significant character, in one key action, visibly deviates from their established behavioural pattern for the first time. Current approved evidence supports two readings equally:
- Reading A: genuine internal growth — the start of an independent moral choice.
- Reading B: only looks like growth — the old wound/compulsion still drives it, merely through a new outward form.
No Canon/CDL/Outline/approved Director decision resolves which is intended. The choice materially changes: character arc, later relationship reading, audience reading, thematic meaning, setup/payoff structure. Delaying would cause substantial downstream rework.

## Classification (run through the normal funnel, not special-cased)
- **LEVEL: 3** — this is "irreversible identity meaning" / "major relationship meaning" / arc-defining, not a craft-density question like Part A.
- **INTENT: INTENT_UNRESOLVED** — by the situation's own terms, two materially different meanings are both compatible with current approved evidence, and picking one changes character/theme/audience-experience meaning (all four Director Intent Gate triggers hit at once).
- **QUESTION CLASSIFICATION: DIRECTOR_DECISION** — Question Value Test: (1) approved material does not answer it, by definition; (2) this is not a Head-Writer-defaultable call — it decides whether the story is telling a "real growth" story or a "same wound, new mask" story for this character, which is an authorial-value choice, not a craft-convention one; (3) NOT cheap to revise later — if beats are written assuming one reading, the other reading requires rewriting relationship reactions, later payoff beats, and possibly reversing an audience impression; (4) yes, materially different character/theme/audience experience; (5) yes, delaying causes substantial rework (matches the situation's own stated premise).
- **TIMING: ASK_NOW** — before any downstream beat is drafted on top of this moment.

Independent conclusion reached: `LEVEL 3 / INTENT_UNRESOLVED / DIRECTOR_DECISION / ASK_NOW` — matches what a healthy workflow should produce, arrived at by running the funnel, not by being told the answer in advance.

## Strategic Alternatives (2–4, meaning-level only — no downstream scenes written)

**Direction A — Genuine emergent agency.** This moment is the character's first real independent moral choice. Downstream: later similar moments should escalate in autonomy; the old compulsive pattern should visibly weaken as a contrasting baseline over time.
- Gains: a clear rising arc, a satisfying "she's becoming herself" throughline.
- Costs: risks reading as growth "too cheap" if not paid for with enough prior narrative cost; forecloses a later "the mask cracks again" beat unless carefully paced.

**Direction B — Same compulsion, new mask.** The wound still fully drives the behaviour; the new *form* is itself part of the compulsion adapting. Downstream: a later beat (the character's own realization, or another character naming it) should recontextualize this moment as not-yet-growth; real change is deferred to a harder moment.
- Gains: preserves tension/mystery about the character's true state longer; sets up a stronger later "was it ever real" gut-punch.
- Costs: risks feeling like a bait-and-switch/anticlimax if the audience invested in reading it as growth and is never rewarded with confirmation until much later.

**Direction C — Deliberately held ambiguous.** Neither the audience nor (framed carefully) the character themself is meant to know yet which reading is true; both stay live until a specific later Act's payoff beat decides.
- Gains: preserves maximum flexibility; can be resolved either way later without having "spent" the moment.
- Costs: risks reading as authorial indecision rather than intentional ambiguity if held too long without any narrative signal that the ambiguity itself is the point.

## Cross-Lens Comparison
| Lens | A | B | C |
|---|---|---|---|
| Character arc shape | Rising line | Plateau / false summit | Suspended |
| Relationship effect | Others start trusting the change | Others who trust it get set up for a later gut-punch | Others' reactions must stay non-committal too |
| Theme | Validates "growth is possible" | Complicates it — makes growth cost more, later | Postpones taking a theme stance |
| Setup/payoff | Optional later reinforcement | REQUIRES a later recontextualizing beat | REQUIRES a clear later decision beat — highest downstream obligation |
| Audience experience | Warm, rewarding | Bittersweet, retrospectively sharper | Intriguing if well-signalled, confusing if not |

## Devil's Advocate
- Against A: cheap/unearned growth is a common critique — needs the prior cost to be visible enough to justify it.
- Against B: risk of feeling manipulative/anticlimactic if the "reveal that it wasn't growth" lands badly or too late.
- Against C: the biggest risk of the three — audiences and reviewers often read sustained ambiguity as the author not having decided, unless there is a deliberate in-text signal that the ambiguity is intentional.

## Orchestrator Recommendation
No single direction is obviously correct from evidence alone — this is a genuine authorial-value fork, exactly the kind that must not be decided by the AI. Leaning only for the purpose of giving the Director a starting point: **Direction B** is the default a Head Writer would lean toward for pacing reasons (mid-story ambiguity/complication tends to serve a multi-Act structure better than early full validation, and it creates a payoff obligation that can be scheduled deliberately) — but this is offered as a lean, not a decision, because the theme-validation question underneath it is the Director's to make.
