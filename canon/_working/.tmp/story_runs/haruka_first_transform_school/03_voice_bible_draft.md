## 3. 語言形成原因

### 3.1 晴香

| 心理成因 | 觀察到嘅語言行為（唔止心理標籤） |
|---|---|
| 5 歲喪母嘅缺失 + 「我害怕再次失去」信念 | 見到「痛即將被抹走」會即時、無預警咁介入阻止（H-1/H-3）——唔係經思考後嘅道德判斷，而係近乎生理反射嘅語言/行動反應 |
| 拯救者情結 + 討好型人格（極端） | 對外人／衝突對象用「輕鬆化解」語氣代替對抗語氣（H-2：「笑但眼神不讓」）——用笑意包裝立場，唔用嚴肅對抗，因為佢對「造成衝突」本身有本能迴避 |
| 膠布哲學（每日對自己嘅痛做「蓋住扮冇事」動作） | 對自己嘅需求/痛楚，語言層面完全空白（H-4）——唔係唔識講，而係佢每日對自己實踐緊「將痛苦抹走」，所以冇建立「講出自己痛」呢種語言能力 |
| 對美夜子（貓形態守護者）嘅信任但未知全貌 | 服從先於理解（H-5）——因為佢潛意識將美夜子放喺「一直保護緊我、我唔需要問點解」嘅位置，呢個信任結構令佢語言上唔會質疑，只會邊做邊確認 |
| CDL-337 擇善固執核心——認得「痛正被人拎走」呢個動作，因為自己每日經歷緊 | H-3 嘅句式「唔可以咁輕易被抹走」帶被動語態、強調「畀人做」而非「我唔想」——呢個唔係修辭選擇，而係因為佢自己每日都被同一個動作（抹走自己嘅痛）困住，所以佢講呢句話時，語言結構自然指向「阻止呢個動作發生」而唔係「表達我點感受」 |

## 6. 同一功能、不同對象比較 — 「叫對方停低 / 拒絕」

本場兩個角色都有一次「叫另一個人停低某個行為」嘅時刻，適合直接比較：

| | 晴香阻止美夜子（H-1/H-3） | 桐生健阻止晴香？（不適用——桐生健本場冇「叫人停」嘅台詞） |
|---|---|---|
| 對象關係 | 對信任、依賴嘅權威角色（貓形態守護者） | 不適用 |
| 句式 | 「等等——」（先打斷）+「[原則陳述句]」（後補理由，被動語態強調「唔可以被抹走」而非「我唔畀你」） | 不適用 |
| 語氣 | 輕、快，冇對抗性用詞，但動作已經係實際阻止（先貼膠布，行動先於語言完成） | 不適用 |
| 心理根源 | 認得「痛正被抹走」呢個動作，因為自己每日對自己做緊同一件事（H-3 成因） | 不適用 |

更貼切嘅同功能比較，係桐生健嘅「拒絕/防衛」（Beat 0c）同晴香嘅「拒絕/防衛」（同一場景，回應桐生健嘅挑釁）：

| | 桐生健拒絕介入者（K-1） | 晴香拒絕退讓（H-2，同一場景，回應桐生健） |
|---|---|---|
| 觸發 | 有人打斷佢正在進行嘅欺凌行為 | 桐生健質問佢「關你事」 |
| 句式 | 雙重反問，不等答案，展示地盤感 | 單句反問式回擊，但用「你知」開頭——把答案交返俾對方自己想，唔直接自報身份 |
| 語氣 | 對抗、防衛性強 | 笑意包裝，唔對抗但唔退 |
| 為何唔同 | 桐生健用語言確立支配位置（欺凌者慣性）；晴香用語言化解對抗感但保留立場（拯救者情結 + 討好型人格底層的「唔想製造衝突」傾向，同時佢嘅 CDL-337 企硬核心令佢實際唔會讓步）——兩人語言功能表面都係「唔退」，但一個係攻擊性確立地盤，一個係防衛性但用溫和包裝，反映兩人呢一刻嘅權力感完全相反：桐生健自覺有主導權，晴香自覺冇必要對抗但有底線 |

## 7. 例句庫

### 7.1 晴香 — 「阻止痛苦被抹走」方向

- **CANON QUOTE**：「等等——」／「記憶同真相，唔可以咁輕易被抹走。」（`ACT_I_BEAT_SHEET.md` [SQ-A]）
- **SUPPORTED EXTENSION**：「唔好，畀佢自己揀。」（沿用 H-1/H-3 嘅「阻止 + 短句原則」結構，未展開解釋，符合已確認規則）
- **BOUNDARY EXAMPLE**：「痛係……證據嚟㗎，你唔記得就真係好似冇發生過咁。」（略長，開始帶少少解釋成分，接近界線但仍可接受——因為保留咗被動語態「唔記得就好似冇發生過」呼應 H-3；風險係比 canon 句式長）
- **WRONG VOICE**：「我知道你需要記住這份痛苦，因為創傷是身份認同的一部分。」——錯誤原因：完全違反 H-4（晴香從不會用分析性/心理學語言講自己嘅原則，`haruka.md` 明確講明佢「不是『睇穿』桐生健需要保留呢個痛」而係「單純不肯妥協」）；呢種語言屬於故事後期（治療語言／自省語言），Act I 太陽期唔應該出現，屬「後期語言提前使用」嘅錯誤示範。

### 7.2 晴香 — 「介入衝突但輕鬆化解」方向

- **CANON QUOTE**：「你知我係咩人囉。」（`ACT_I_BEAT_SHEET.md` Beat 0c）
- **SUPPORTED EXTENSION**：「唓，咁緊張做咩，我淨係唔鍾意人恰人啫。」（保持輕鬆語氣、唔正面對抗，符合 H-2）
- **BOUNDARY EXAMPLE**：「你要咁樣先開心？」（帶少少質問性，比原句更直接對抗，接近界線）
- **WRONG VOICE**：「你嘅行為已經構成校園欺凌，我要求你即刻停止。」——錯誤原因：太正式、太制度化語言，完全脫離晴香「笑但眼神不讓」嘅輕鬆包裝風格，亦不符合佢呢個階段仲未有任何「制度對抗」意識（呢種語言更似 Act II/III 覺醒後嘅社會批判語氣）。

### 7.3 桐生健 — 「防衛質問」方向

- **CANON QUOTE**：「你係咩人？關你事？」（`ACT_I_BEAT_SHEET.md` Beat 0c）
- **SUPPORTED EXTENSION**：「行開啦，唔關你事嘅。」（延續 K-1 短促、地盤感語氣，冇加新資訊，風險低）
- **BOUNDARY EXAMPLE**：「你以為你係邊個，走出嚟教訓我？」（更長、更具體嘅挑釁，接近界線但未超出「欺凌者確立地盤」嘅功能範圍）
- **WRONG VOICE**：「其實我都唔想咁樣㗎，但係……」——錯誤原因：呢句已經帶自我辯解/內疚語言，同 QQ-80「桐生健冇隱藏創傷，係普通 Beta 線校霸」嘅設定矛盾——喺 Beat 0c 呢個時間點，佢仲未經歷任何令佢反思嘅事件，呢種語言係將 [SQ-A] 之後先可能出現嘅心理轉折提前搬到欺凌現場，違反 §4「後期語言唔可以提前使用」規則。

### 7.4 桐生健 — 「戰後低聲陳述」方向

- **CANON QUOTE**：「痛係證據。咁先知道自己係真實嘅。」（`ACT_I_BEAT_SHEET.md` [SQ-A]）
- **SUPPORTED EXTENSION**：（暫緩提供——因為呢句本身已經係全劇桐生健最重要嘅單一台詞，任何「延伸」都有過度詮釋風險。建議直接沿用原句，唔做擴寫，等作者決定要唔要加後續反應句。）
- **BOUNDARY EXAMPLE**：（同上，暫緩——單一樣本句唔足以安全推導邊界例句）
- **WRONG VOICE**：「多謝你救咗我，我以後都會記住呢件事。」——錯誤原因：太完整、太有自覺性嘅感謝語言，違反 grounding draft §2.5 標明「呢句話對佢嚟講可能係一個未被佢自己完全理解嘅種子」——桐生健呢一刻嘅語言應該保持「低聲、簡短、唔展開」，一句完整嘅感謝宣言會令呢個「種子」變成「已完成嘅道德覺醒」，同 Act II「無名盟友」嘅漸進式軌跡設計矛盾。

## 9. Scene Speaking State — 本場專用

**精確故事時期與轉變點**：Act I 早期，晴香偶像期太陽全開狀態；桐生健仍係未受任何超自然衝擊嘅普通欺凌者狀態；本場本身就係桐生健嘅轉變點（唯一一場），亦係晴香「膠布哲學第一層」首次語言化嘅場景。

**啱啱經歷咗咩**：
- 晴香：由「介入日常欺凌」嘅熟悉情境，突然跳入「首次變身 + 未知裝置 + 戰鬥」，然後喺腎上腺素未退嘅狀態下面對美夜子準備洗桐生健記憶。
- 桐生健：由「欺凌現場主導者」跌落成「本能後退嘅普通人」，中途做咗一個連自己都未必消化到嘅救人動作，然後受傷、目睹超自然變身全過程、被陌生人（美夜子）打算動用某種手術式手段處理自己嘅記憶。

**身體/情緒/關係狀態**：
- 晴香：手震氣促（變身後遺留生理反應）；情緒上仍係「不知道自己在做什麼」但拯救者衝動被強烈命中（「對的感覺」）；對桐生健由「阻止欺凌」關係，轉為「共同經歷咗一場戰鬥」嘅微妙連結，但兩人未有任何言語確認呢個轉變。
- 桐生健：手臂帶血，感官超載、驚魂未定；剛剛目睹一個佢先前欺凌現場阻止過自己嘅女仔變身戰鬥；對晴香嘅感受由「阻止我嘅陌生人」轉為未命名嘅複雜情緒（敬畏/愧疚混合，`grounding draft` 弧線：厭惡→目睹→恐懼→敬畏→愧疚）。

**對住今場對象想得到／隱瞞咩**：
- 晴香：冇意識咁「想」任何嘢——佢阻止美夜子純粹係反射（H-1 根源），並冇隱瞞任何嘢俾桐生健，只係佢自己都未必解釋得到自己點解要咁做（呢個同桐生健嘅「未必消化到」形成鏡像對照）。
- 桐生健：想隱瞞（推論）自己撿椅子嗰下嘅動作同動機——佢冇打算話俾人知，亦都冇被問；佢對晴香嘅「敬畏/愧疚」情緒本身可能都未被自己命名。

**場頭／受壓／轉折／場尾點變**：
- 場頭（欺凌僵局）：桐生健＝K-1 攻擊性反問；晴香＝H-2 輕鬆化解但企硬。
- 受壓（屍骸破門、戰鬥中）：兩人都冇語言，全部係本能行動（晴香拯救衝動；桐生健求生後退→反射救人）。
- 轉折（美夜子準備洗記憶）：晴香語言首次企硬介入（H-1/H-3）；桐生健沉默接受照顧（膠布）。
- 場尾：桐生健語言首次軟化（K-2 低聲陳述）；三人共同選擇沉默收尾，冇人再開口解釋。

**今場可以用邊啲長期規則**：H-2（晴香輕鬆包裝立場）、H-5（晴香服從美夜子但邊做邊問）、K-1（桐生健欺凌姿態，僅限場頭）。
