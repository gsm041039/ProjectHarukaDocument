## M1：見到晴香隊打得亂，宣布接手屍骸

Canon 原句（CANON_DIRECT，不改）：「真難看。這種低級的戰鬥簡直污染我的眼睛。這隻獵物歸我。」

### 0. 舊 A/B/C 狀態：SUPERSEDED（唔夠）
- 舊 A/B/C 係未做分析就寫，之後先補語料對照；冇做 Gate 測試、冇 Speech Analysis Card。
- 三個都直接口語化，**丟失咗 canon 句本身嘅語域標記**（書面式冷語）；C 仲加咗 canon 冇嘅動作「行開」。
- 作者「C 最似」只係對「短同直接」嘅反應，唔可以當成語域已決定。保留為記錄，唔採用。

### 2. 語料對照（CantoCaptions；只作手法參考，唔抄句）
- 功能：接手／命令／貶低。實例手法：「等我…」「由我𢱕啦」「行開啦」「垃圾！」「我就覺得你喺度嘥時間囖」——強勢角色句短、助詞輕或冇。
- **書面語域喺配音稿嘅用法**：只作角色標記，或嵌入口語語法（在下就係…喇、豈有此理吖、不過…、竟然…喎、必須）；純書面句法（這種…簡直…）幾乎冇出現；「的」3 對「嘅」21／150。→ 結論：粵語配音要令一個角色似「講書面」，做法係「書面詞彙＋口語語法／助詞」，即**半書面**，唔係逐字朗讀書面句。
- 未查到：貴族／冷嘲審美判斷角色嘅實例。
- 限制：字幕冇聲調、停頓，殺氣／距離感要靠聽感。

### 3. Speech Analysis Card（§8B）
| 維度 | M1 觀察／設計 |
|---|---|
| 功能 | 宣告接手（佔有）＋貶低對方打法；**唔係救人、唔係幫手** |
| 心理 | 完美形象維持者：先評「形」（難看）再宣告「權」（歸我）；輕蔑係保護——先判人，免被判 |
| 句長 | 三句遞進：短（3–4 字）→ 長（10–14 字）→ 短（4–5 字）；長句係「審美潔癖」，係最似佢嘅一句 |
| 停頓 | 「真難看」之前先睇一睇（無聲）；「歸我」之前收音，唔追加解釋 |
| 語域 | canon＝純書面；廣東話候選＝半書面（詞彙書面，語法／助詞口語） |
| 稱呼 | **無稱呼**：唔叫晴香／美夜子，唔將對方當對話對象（對象係「獵物」同「戰鬥」）；`妳／庶民` 留到 M3 |
| 助詞 | 全句無或最多一個；「歸我。」硬收尾＝宣告；加「喇」會變成收工語氣，失去佔有感 |
| 情緒出口 | 對外冷靜；破綻（形式主義、怕被發現係假）唔喺 M1 露 |
| 禁止 | 解釋原因、講「幫你哋」、任何關心 |

## M3：欠人情，勉強答應指導（場5）— 已定 T1

### Evidence triage
- 場5 兩句 CANON_DIRECT：(a)「…為了還這份人情，我勉強答應暫時指導妳們這些庶民。」（書面）；(b)「唔係入隊。係臨時指導。」（口語，被質疑「即係入隊？」之後）。(b) 已係口語，**照留，唔改**；M3 只處理 (a) 嘅粵語自然化候選。
- 功能：(a) 用「還人情」包裝入隊＝將「想留低」講成「交易」，同時貶低對方（庶民）；(b) 被戳到即劃界。心理：傲嬌＝先降低對方，免自己顯得需要。沿用 M1／M2：先判人再宣告；被追問先沉落口語。

### 語料檢索（tools/cantonese_corpus.py）
| 詞 | 結果 | 結論 |
|---|---|---|
| 還人情 | 真人用「爭人情」（欠）＝10 行／6 套：「爭你一個人情」「就當我爭你人情喇」；「還咗…人情」僅 1 行 | 「欠人情」口語用**爭**；「還」可以，但「爭咗你哋個人情」更貼地 |
| 勉強（答應） | 語料「勉強」只見「唔好勉強自己」；「勉為其難」未搜到有效用例；功能對應詞係**唯有**（18 套／115 行，audit 更正原寫 20 套；多用例：「唯有去…啦」「就唯有解決你啦」） | 「勉強答應」譯成「我唯有…」較自然，但語氣由「屈就」變「冇辦法」，略少傲 |
| 庶民 | 只 2 行（Bread Barbershop「呢班庶民」、Re-Zero「一般庶民」）＝罕見書面詞，但有「你哋呢班＋貶稱」句型（「你哋呢班潔癖族人」「你哋呢班卑鄙嘅人類」） | 保留「庶民」可做角色標記；句型用「你哋呢班庶民」自然 |
| 暫時指導 | 「暫時」自然（多例）；「指導」有例（Demon Slayer「我會喺度指導你」） | 「暫時」「指導」可用 |
| 妳們 | 字幕一律「你哋」；本 repo「妳」屬女性書寫慣例 | 口語稿用「你哋」，書面稿保留「妳們」 |
- 語料冇覆蓋：冷貴族傲嬌口調。
- 自然度（score）：爭咗你哋個人情 24；我唯有指導你哋呢班庶民一陣 20；呢個人情，我還 51；指導你哋一陣，就咁多 16。全部落喺合理範圍（>10），未見翻譯腔旗號；「未見於語料」三連字只係搭配新鮮，唔係錯。
