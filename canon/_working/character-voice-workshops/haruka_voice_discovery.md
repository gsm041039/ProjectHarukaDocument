## 0. 本輪做咗咩、發現咗咩（一頁摘要）

### 做咗
- **Round 0**：將既有 23 句 canon 引句 + 33 句工作坊候選句逐句過 Source Authority × Line Function triage。
- **Round 1**：建 5 個固定微場景，每個做 V0/V1/V2 三層改寫 + 完整互動回路 + Same-Intent-Contrast（操／紫音同場版）+ Swap / De-characterization / Compression 測試。
- 由通過測試嘅句子反推 **9 個 Voice Engine 候選**，其中 **3 個被自己淘汰**（swap test 失敗或只係戲劇通則），保留 **6 個候選**。
- 建 6 句 Forbidden Direct Sentence + 跨時期繞路表；建 1 條嫉妒 Emotion Mislabel Path。

### 三個要作者留意嘅發現（唔係例句層面，係框架層面）

**發現一：既有 Voice Bible §3「子規則三：關心嘅語言目的往往唔要求回應」同 canon 引句直接衝突。**
K房場景三句連續對話（`10_gameplay_bible.md` L226-236）示範嘅**完全相反**——晴香係一路追問落去、對方冷淡都唔收手、最後仲要加碼提出「下次唱我嘅歌」。呢個唔係「唔要求回應」，係「唔識讀對方唔想答」。本輪判斷：**子規則三應該撤回或大幅改寫**，因為佢削走咗 CDL-355/356 個盲點，將晴香寫得太體貼、太有分寸。實際 canon 支持嘅係一個更有戲、更有缺陷嘅版本（見 Engine E3）。

**發現二：既有 33 句候選句入面，大部分（16 句）通唔過 swap test。**
主要問題係「善良／元氣／自我犧牲」呢類人格形容詞直接生成句子，冇經過佢個感知偏差。呢批句子唔係錯，係 `FUNCTIONALLY VALID BUT NOT YET CHARACTERISTIC`——換咗做任何一個善良角色都完全成立。

**發現三：晴香最強嘅辨識度唔喺句子層，喺「一句嘢喺互動入面嘅位置」。**
佢單句拆出嚟好易同其他溫柔角色撞；但佢成個回路（身體先入場 → 只講得出狀態 → 對方否認 → 唔退、改為提出共同未來計劃 → 自己嗰格永遠唔入句）冇一個現有角色行得到。所以本檔以微場景／互動回路為主體，唔以功能分類例句為主體。

### 微場景／變數規劃備註（同任務指示嘅一處修正）
任務指示列咗「對象 = 操 vs 彩 vs 紫音 vs 綾小路」四選——但 **綾小路操（Ayakomoji Misao）同「操」係同一個人**（`canon/03_characters/ayakomoji_misao.md`）。本檔實際使用嘅對象變數係：**操 / 彩（實為黑奏偽裝）/ 紫音 / 美夜子**。用美夜子頂替重複項，因為佢係 canon 明文確認晴香唯一會展露脆弱嘅對象（CDL-324），對照價值最高。

## 微場景 1 — 隊友明顯低落但話自己冇事

**固定設定**
- 場面：日常、非戰鬥，隊友剛到／剛坐低，狀態明顯唔妥。
- 事件：晴香嘅絕對共感視界見到對方情緒 UI 異常（狀態可見，**成因唔可見**）。
- 對話功能：確認對方狀態，令對方知道「我見到你」。
- 晴香想完成嘅事：唔好等佢一個人揦住。
- 對方第一個反應：「冇事。」

### 三層改寫（基準版：對象 = 操，時期 = Act I）

```
功能版：
「你冇事吧？睇你今日好似唔係好精神喎，有咩事可以同我講。」

角色版：
（已經行咗埋去坐低）「你今日好攰咁喎。」
（對方：「冇事。」）
（唔追問，將自己啲嘢分一半過去）「呢個食唔食？」

關係／時期版（對象＝操，Act I）：
（唔坐對面，坐隔籬，同一方向）「你今日慢咗好多喎。」
（操：「我冇事。」，坐姿即刻校正返完美）
「哦。」
（頓）「……聽朝等埋我先啦。唔好又淨係飲咖啡。」

角色版增加咗咩：
- V0 有「有咩事可以同我講」——晴香根本冇呢個能力：佢見到狀態，見唔到成因，所以佢問唔出「咩事」，只能講返個狀態本身。V0 嗰句係心理輔導員，唔係佢。
- V1 冇問號。「喎」＋「都」係觀察陳述，唔係審問，亦保留咗對方否認嘅空間。
- V1 嘅身體先於句子：坐低係第一動作，句子係第二動作。
- V1 對方否認之後，晴香冇退，亦冇重複追問——佢轉去「畀件實物」。

仍然太普通嘅位置：
- 「呢個食唔食？」單獨睇任何一個溫柔角色都講得出。要靠前面「唔追問」同後面「下次」先夾出辨識度。
- 「哦。」呢個接法太乾，讀出聲會似冷淡，需要現場動作補（見 Read-aloud）。

可能太刻意嘅位置：
- 舊版「下次早半個鐘出嚟食早餐啦，我請」資訊太齊、似編劇安排。口語版改成「聽朝等埋我先啦。唔好又淨係飲咖啡。」：先用關係習慣，再用眼前具體問題。
```

### 變數 A：對象改為彩（Act I）

```
關係／時期版（對象＝彩）：
「你今日怪怪哋喎。」
（彩：「冇呀。」，笑）
「……」（唔出聲，但冇走開）
「下次一齊去食嘢吧。」
```
**點解唔同**：對操佢敢坐埋去（有戰鬥同生共死嘅身體距離）；對彩佢仲喺「想埋身但未夠熟」嘅階段，所以第一句係句子唔係動作，第二策略係**約將來**唔係**遞實物**。`「下次一齊去食嘢吧」` 係 CANON_DIRECT（原句保留；自然口語候選可測「下次一齊去食嘢囉」／「下次一齊食嘢啦」）（`ACT_I_BEAT_SHEET.md` [NC]，CDL-082）。
**反諷層（唔可以喺 Act I 講穿）**：呢一刻晴香嘅共感視界照住嘅係黑奏偽裝出嚟嘅假 UI，佢一片真心餵緊嘅係採集器。呢個對照唔應該由對白提示，只可以由玩家事後回望發現。

### 變數 B：對象改為紫音（Act I）

```
關係／時期版（對象＝紫音）：
（直接將珍寶珠遞過去，唔講開場白）
「食粒糖先啦，雖然無魔法咁好味，但係會飽肚㗎。」
（紫音：唔應／擰開面）
（唔收手，就咁擺喺佢隔籬地下）
「……我坐一陣得唔得？」
```
**點解唔同**：紫音係全隊最抗拒被睇見嘅人，所以晴香唔用句子開場，直接用物件開場（canon：CDL-052 餵珍寶珠）。被拒絕之後佢嘅第二策略唔係加碼講嘢，係**縮細要求**——由「你食嘢」縮到「我坐一陣」。呢個係佢少數會將要求縮細嘅關係。
**盲點暴露位（CDL-355/356）**：對一個戒斷抽搐嘅人講「會飽肚㗎」，係善意但完全唔對板——晴香唔知道紫音而家個問題唔係肚餓。呢句 canon 原句本身就已經係盲點嘅示範，唔使另外寫。

### 變數 C：對象改為美夜子（Act I，K房場景延伸）

```
關係／時期版（對象＝美夜子）：
「前輩……妳唱得好投入啊！」
（美夜子：淡淡帶開）
「欸？那為什麼妳能唱得這麼……這麼『痛』？」
（美夜子：唔答／收聲）
「那……下次我們唱我的歌吧！唱完心情就會變好了！」
```
**呢三句係 CANON_DIRECT，唔係新寫嘅測試句**（`10_gameplay_bible.md` L226-236），本檔將佢當作 Engine E3 嘅**最強證據**引用。
**點解呢個變數最重要**：佢證明「對方否認之後晴香會點做」——唔係退開，係**加碼提供一個更光嘅版本嚟蓋住對方嗰個暗嘅版本**。呢個係佢最有戲、最有代價嘅機制，直通 CDL-341（強行拆走夕嘅止痛幻象）。

### 變數 D：時期改為創世真相揭露之後（對象＝操，同一情境）

```
關係／時期版（罪疚累積後）：
（見到 UI 異常，第一反應係望開；停半秒；手指按咗一下自己手臂上嘅膠布）
（行埋去，遞嘢過去）「……喺度。」
（操：「我冇事。」）
（唔追問，唔約下次，坐低，唔出聲）
```
**點解唔同**：多咗一層「我有冇資格介入」嘅猶豫（CDL-357 貼膠布前因動作 + 自我盲點）。句子縮到最短、冇問句、冇將來式——因為「下次一齊」呢個機制需要佢相信自己仲有將來、仲配得起同人一齊。呢層一冧，佢就只剩返動作。
**Period Leakage 警告**：呢一版**唔可以**喺 Act I 出現。Act I 版必須有句子、有下次、有問號式關心。

### 變數 E：晴香自己同時受傷／攰爆（對象＝操，Act I）

```
關係／時期版：
（自己肋骨中過一下，行路一拐一拐）
（照樣行埋去）「你今日好攰咁喎。」
（操：「你自己隻腳。」）
「呢個？冇嘢呀。」（順手貼多一塊膠布，繼續講）「你今日食咗嘢未？」
```
**呢個變數係 Engine E4 最乾淨嘅測試**：對方將話題掉返轉，晴香用一個**指示代詞**（「呢個？」）將自己個傷降格成一件現場小物件，然後即刻用問句將焦點彈返去對方度。佢唔係拒絕，佢係**接唔到**。

### 完整互動回路（基準版，對象＝操，Act I）

| 步 | 內容 |
|---|---|
| 晴香先察覺／行動 | 見到 UI 異常 → 行埋去坐低（身體先於句子） |
| 第一句 | 「你今日好攰咁喎。」（狀態陳述，冇成因；句法較自然） |
| 對方否認 | 「我冇事。」＋坐姿校正 |
| 第二策略 | **唔重複追問**，改為遞實物／提出共同未來計劃 |
| 對方再反應 | 敷衍接受／再次帶開 |
| 晴香堅持、退讓、改用行動或離開 | **唔走**，但將要求縮細（由「講畀我聽」縮到「我坐一陣」）；容許沉默存在 |
| 對話殘留 | 「下次一齊……」呢個約定；對方冇答應亦冇拒絕 |

### Same-Intent-Contrast（同一場景，操／紫音各自點做）

**操會點做**：
```
（唔行埋去，隔一張枱嘅距離）「你今朝份報告我幫你交咗。」
（對方：「我冇事。」）
「嗯。」（唔追問，將話題轉去下一項安排）「三點集合，你早十分鐘到就得。」
```
操處理低落嘅方式係**移除低落嘅後果**，唔係命名低落本身——佢保住對方個面，因為佢自己最驚俾人睇穿。佢永遠唔會講「你今日都幾攰喎」，因為講出嚟等於指出對方表演有破綻，而佢自己嘅整套生存策略就係「破綻唔可以被指出」。

**紫音會點做**：
```
（唔問）（將自己份嘢推過去）「食。」
（對方：「我冇事。」）
「食咗先講。」
```
紫音處理低落嘅方式係**餵食**（Alpha 線餓死記憶嘅補償），唔命名、唔約將來、唔容許拒絕。同晴香表面最似（都係遞食物），但機制完全唔同：紫音係命令式、當下式、唔畀人拒絕；晴香係邀請式、未來式、容許對方唔應。

**呢個對照證明咗咩**：三個人都會「遞嘢」，所以「遞嘢」本身唔係辨識點。辨識點係**遞完之後嗰半秒做咩**——操收返手轉去做安排、紫音企喺度睇住你食、晴香坐低唔出聲然後講「下次」。

### 測試結果

| 測試 | 結果 |
|---|---|
| **Swap Test** | 「你今日好攰咁喎。」交畀操 → **失效**（操唔會指出對方破綻）。交畀紫音 → **失效**（太婉轉、太多語尾助詞）。交畀美夜子 → 部分成立，但美夜子會用更冷嘅陳述且會直接講出成因。**判定：需要改感知同策略先能移植 = 有角色性。** |
| **De-characterization** | 普通版：「你冇事吧？有咩事可以同我講。」角色版增加咗：冇成因、冇問號、身體先入場、被拒絕後唔退但唔重複。 |
| **Compression Test** | 「你今日好攰咁喎。」→ 壓成「你今日……」＋眼神。**更似佢**——因為佢本來就講唔出下半句。**判定：原句略長，作者版建議保留完整句畀 Act I（真心期敢講完），Act III 用壓縮版。** |
| **Read-aloud** | 「哦。」單獨讀出聲太冷，必須配「冇走開／坐低」嘅動作，否則會讀成賭氣。標記 `PERFORMANCE_DEPENDENT`。 |
| **Period Leakage** | 變數 D 版本（望開＋按膠布＋淨返動作）**嚴禁**用喺 Act I。 |

## 微場景 2 — 有人喺佢面前否定／抹走另一個人嘅痛

**固定設定**
- 場面：多人在場，有第三者係「痛嘅擁有人」。
- 事件：有人講咗一句貶低／抹除嗰個人痛苦嘅說話。
- 對話功能：叫停。
- 晴香想完成嘅事：唔准呢件事發生。
- 對方第一個反應：唔覺得自己有問題（「我為佢好啫」）。

### 三層改寫（基準版：輕度輕視）

```
功能版：
「唔好咁講啦，佢都好辛苦㗎。」

角色版：
（已經行咗埋去中間）「……佢唔係冇事。」

關係／時期版（對象＝一個以為自己出於好意嘅隊友，Act I）：
（行埋去，企喺兩個人中間，唔望講嘢嗰個，望住當事人）
「佢唔係冇事。」
（對方：「我又冇話佢有事——」）
「你唔可以逼佢話冇事。」

角色版增加咗咩：
- V0 係求情（「唔好咁講啦」＋幫對方解釋「佢都好辛苦」）。晴香唔幫人解釋——佢直接更正一個事實。
- V1 冇「啦」冇「都」冇軟化詞：呢個開關一開，佢啲語尾助詞會即刻消失（同 Act I 其他場景嘅「囉」「㗎」「啊」形成可聽見嘅對比）。
- V1 身體先於句子（canon 支持：擋喺桐生健與彩之間、用身體擋屍骸救操）。
- V2 佢望嘅係當事人唔係施害者——因為佢真正想完成嘅唔係贏場辯論，係令當事人知道「有人見到你」。

仍然太普通嘅位置：
- 「你唔可以逼佢話冇事」單句拎出嚟，任何一個正義感角色都講得出。要靠「唔加解釋、唔講道理、講完就唔再講」呢個節奏先分得出。

可能太刻意嘅位置：
- 如果連續兩句都用「唔可以」，會變成口號。建議一場戲只用一次。
```

### 變數 A：升級為「有人逼受害者當場表演『我冇事』」

```
（唔講嘢，直接行埋去企喺受害者前面，背向施害者）
（隔咗一秒）「唔准。」
（對方：「我同佢講緊嘢啫。」）
「你嬲我就嬲我，唔好逼佢扮冇事。」
```
**呢度出現咗佢全劇罕有嘅長句**。規則：晴香只有喺「真係嬲到要解釋埋原因」嗰刻先會講超過八個字嘅句。呢個長度本身就係情緒刻度，唔可以濫用（建議全劇上限 3 次）。

### 變數 B：升級為「有人判定某個受害者嘅苦『係值得嘅』」

```

### 變數 C：同一場景，對象係夕（Act III/IV，CDL-341）

（同一個動作、同一種語氣，冇任何改變）
「……你唔可以就咁當佢哋冇死過。」

**呢個變數係本場景最重要嘅一個**，因為佢證明晴香呢個開關**唔識分對象**——同一個機制用喺桐生健身上係救人，用喺夕身上係未經同意剝奪佢僅有嘅止痛幻象。作者已標記呢個陰暗面唔可以被下游簡化為溫暖（CDL-341）。
**寫作警告**：呢一場**唔可以**畀晴香有任何「我知我而家好殘忍」嘅自覺台詞——佢唔知。佢真心以為自己喺度救緊人。自覺一出現就毀咗個反諷。

### 完整互動回路

| 步 | 內容 |
|---|---|
| 察覺／行動 | 身體先入場（擋／企埋去／背向施害者） |
| 第一句 | 一句更正事實，冇軟化詞，冇解釋 |

| 晴香 | 唔逐點反駁；極端情況下先講出一句帶原因嘅長句 |
| 對話殘留 | 佢唔會追加、唔會事後解釋、唔會同人覆盤呢件事 |

### Same-Intent-Contrast

**操**：「我哋出去講。」——先移走觀眾，保住雙方體面，之後私下處理。操處理衝突嘅第一原則係**唔可以有場面**。
**紫音**：唔講嘢，一拳。或者「你講多次。」——直接進入暴力預備狀態。
**分別**：三個人都會介入，但**介入嘅單位唔同**——操介入「場面」，紫音介入「肉體」，晴香介入「敘述」（佢要更正嘅係一句話，唔係一個人）。呢個係本場景最乾淨嘅辨識點。

| 測試 | 結果 |
|---|---|
| **Swap Test** | 「你唔可以逼佢話冇事。」交畀操 → **完全失效**（操自己就係逼自己扮冇事嗰個，講呢句會即刻自爆）。交畀紫音 → **失效**（紫音會直接動手，唔會用「唔可以」呢種規範式語言）。**判定：高角色性。** |

可能太刻意嘅位置：
- 如果每次收到多謝都問「你食咗嘢未」，會變成 gimmick。**頻率上限：食物式轉移全劇每幕不多於 2 次**，其餘用其他實物／其他關於對方嘅問題。
```

### 變數 A：時期改為罪疚累積期

```
（對方：「多謝你。」）
（唔答，冇笑）
「……嗯。」
（行開，去做嘢）
```
**呢一版係 CDL-347 唔對稱嘅語言證明**：佢仍然照顧到人，但接唔到人照顧佢。分別喺——Act I 版本佢係**接唔到但仍然快樂**，呢個版本佢係**接唔到而且痛**。同一個行為，兩種完全唔同嘅讀法，唔可以互換。

### 變數 B：對方唔收貨、堅持要佢接受（Act I）

```
（操：「唔係——我係真係想同你講多謝。」）
「……」
（望開）
「……你都幫過我好多㗎。」
```
**呢度出現咗佢嘅第二策略：對稱化。** 佢接唔到單向嘅好意，所以會即刻搵一個「你都有幫我」嚟令條數平返。呢個唔係謙虛，係**佢受唔起欠人**——因為欠人即係佢冇做夠，而佢個存在價值就係靠做夠嚟證明（Lie：「幫人係無私嘅」底下嗰個自私核心）。

### 變數 C：對象＝美夜子（唯一例外）

```
（美夜子：「……你做得好好。」）
（好耐冇出聲）
「……真㗎？」
```
**呢個係全檔唯一一句晴香容許自己接收嘅版本**，而且佢用咗一個細路仔式嘅確認句。理由：CDL-324 明文確認美夜子係佢罕有會展露脆弱嘅對象。呢個變數證明「接唔到安慰」係 **RELATIONSHIP_SPECIFIC 有例外**，唔係鐵板一塊嘅 GLOBAL_STABLE。

### 完整互動回路（Act I 基準）

| 步 | 內容 |
|---|---|
| 察覺 | 慢半拍（「欸？」）——關於自己嘅資訊處理速度明顯慢過關於別人嘅 |
| 第一句 | 唔接收、亦唔否認，將個讚轉成一件公認嘅事 |
| 對方堅持 | 「我係真係想同你講多謝。」 |
| 第二策略 | 對稱化（「你都幫過我好多㗎」）——將單向變雙向 |
| 對方再反應 | 或者收貨，或者更堅持 |
| 晴香 | 更堅持嘅話 → 轉問句（關於對方嘅） → 最後靠行開／做嘢 |
| 殘留 | 對方嗰句好意**冇落地**；晴香自己唔覺得有咩事發生 |

### Same-Intent-Contrast

**操**：會優雅、完整、得體咁收落（「多謝你咁講。」）——**操接得到，但接落嘅係表演層**，佢真正嘅自己冇收到。表面同晴香相反，底層一樣接唔到。
**紫音**：會惡（「使咩多謝。」）或者當冇聽到。紫音接唔到嘅原因係佢覺得自己唔配。
**三人分別**：操**收得太好**，紫音**打返轉頭**，晴香**彈返去對方度**。呢三個反應係本檔最乾淨嘅三角對照，建議升做 Voice Distance Map 嘅其中一條軸。

### 測試結果

| 測試 | 結果 |
|---|---|
| **Swap Test** | 「吓？……你今日食咗嘢未？」交畀操 → **失效**（操唔會有「欸？」呢個失儀嘅空白，亦唔會突然轉話題）。交畀紫音 → **失效**。**判定：高角色性，主要靠「慢半拍 + 轉身問句」嘅組合。** |
| **De-characterization** | 普通版「多謝你咁講，我好開心」。角色版增加咗：處理速度不對稱、唔接收亦唔否認、第二策略係對稱化、最後靠行動離場。 |
| **Compression** | 「吓？……你今日食咗嘢未？」→「欸？……你今日食咗嘢未？」**明顯更似佢**——刪走中間句令個轉身更突兀，反而更貼「佢真係接唔到所以直接跳咗」。**建議採用壓縮版。** |
| **Blind Attribution（自評）** | 呢個回路（慢半拍 → 轉成公認事實 → 對稱化 → 轉問句 → 行開）目前**冇第二個主角做得出**，係本檔第二有把握嘅辨識點。 |

## 使用規則
- 對白讀出聲有 kick，就算分析成立，都標記 `CHARACTERISTIC IN THEORY, NOT YET NATURAL CANTONESE`。
- 每句至少做三個 Native Paraphrase，再揀最似晴香嗰個。
- 優先刪主語、抽象情緒名詞、完整因果同書面對偶。
- 唔以加「啦／喎／㗎」代替真正口語化。
- 真正採用前要由作者或香港粵語演員朗讀。

### Voice Engine Candidate

**核心名稱**：只講得出狀態，講唔出成因
**一句定義**：佢見到「你有事」，但見唔到「發生咩事」，所以佢嘅第一句永遠係一個唔完整、冇診斷、冇追問權嘅事實陳述。
**角色首先注意到**：情緒／身體狀態嘅異常本身（UI 血條、圖標、手指嘅小動作、笑容同狀態嘅落差）——**唔係**事件、唔係關係、唔係原因。
**第一衝動**：將見到嘅嘢講返出嚟，令對方知道「呢樣嘢係睇得見嘅」。
**常見語言出口**：陳述句 + 「喎」／「都」等軟化詞；冇問號；冇「係咪因為」；冇「我知你……」。例：「你今日怪怪哋喎。」「你隻手指……捽緊袖口喎。」
**常見行動出口**：坐埋去、遞嘢、望住當事人而唔望施害者。
**對方拒絕後嘅第二策略**：**唔重複同一句、唔追問成因**（佢問唔到，佢冇料）——轉去實物或者「下次一齊」（交棒畀 E3）。
**最容易同邊個角色撞**：美夜子（都會直接指出）。**分別**：美夜子指得出成因並且會用成因施壓；晴香只指得出狀態，所以佢嘅指出係無害嘅、有時甚至係失禮嘅。
**Canon 支持**：絕對共感視界（`haruka.md` §關鍵習慣 #3，CANON_DIRECT，明文只列「血條、情緒圖標」，冇成因層）；「佢誤以為自己同理心強」；CDL-347（對「笑住收埋痛」呢個訊號特別敏感）。
**跨場景支持**：K房場景（察覺到「痛」但要問返對方點解）、CDL-347（見到人笑住藏痛即刻爆喊）、E-02 救操後即刻留意到條裙。
**成功微場景**：微場景 1（全部五個變數）、微場景 2 第一句。
**失敗／反例**：一旦佢講中成因（「我知你係因為你細個……」）＝ 呢個 engine 崩潰，角色即刻變成治療師。既有 Voice Bible 嘅「全期通用語言禁止清單」已有對應禁令，本輪確認該禁令正確並建議保留。
**故事時期變化**：Act I 講得出口且講得直接；罪疚累積期起，佢會見到但唔敢講（因為講出嚟等於要介入，而佢開始懷疑自己有冇資格介入）——語言縮短、改用動作。
**可信程度**：高（機制 CANON_DIRECT；語言化 CANON_INFERRED）
**作者狀態**：候選

**核心名稱**：身體先入場，句子細過動作
**一句定義**：佢嘅第一反應永遠係將自己個身體放去中間／將一件實物交出去，句子係第二拍，而且永遠細過佢啱啱做咗嘅嘢。

### Voice Engine Candidate

**核心名稱**：自己嗰格永遠唔入句
**一句定義**：「我」喺佢句子入面只可以做動作嘅主語，唔可以做狀態嘅主語——佢講得出「我會補返」，講唔出「我好痛」。

**第一衝動**：當有人將焦點指向佢，即刻將焦點彈返去對方／彈去一件現場物件／彈去一個任務。
**常見語言出口**：
- 彈返對方：「我？我冇事呀，你先。」「我唔攰，你哋食咗嘢未？」

**對方拒絕後嘅第二策略**：對稱化——「你都幫過我好多㗎」（將單向好意變雙向，令自己唔使欠）。

## C5. Emotion Mislabel Path — 嫉妒

```md
### Emotion Mislabel Path

真正情緒：嫉妒（想被揀、想有人為咗我留低、想成為某個人最重要嗰個）

角色最初以為：唔係情緒——佢連「我有情緒」呢一步都跳咗過。佢察覺到嘅係「我隻手已經喺度執緊嘢」。如果被逼命名，佢會命名成「我今日做少咗嘢」。

第一個補償行動：攞多一份工／揹最重嗰袋／喺唔使佢出手嘅場合搶住去擋／對自己嘅風險評估放鬆（CDL-356 明文行為）

第一個語言出口：一個任務認領句，唔係一個感受句——「你哋去啦，我搞掂呢邊。」

對方拒絕後（「使唔使幫手？」）：過快、過大聲嘅否認 →（自己聽到自己嘅音量）→ 補一句軟化版。「唔使！」（頓）「……真係唔使。」**呢個速度差係佢唯一嘅洩漏點。**

遮掩失敗：講到一半自己收返——「你哋咁開心……幾好呀。」／「我都想……算啦。」句子唔完整，但佢唔會補完。

首次半承認：用一個比實情細好多嘅詞去接近件事——「我頭先係咪扭計咗？」（用小朋友嘅詞，因為呢個係佢唯一容許自己有嘅慾望規格）

後期正確認知：「其實……你哋坐多陣都得㗎。」——仍然以現場安排代替直接需要；**呢個已經係佢喺接納完成之前嘅上限**。真正用「妒忌」兩個字，要等接納過程完成（CDL-356 定位喺 Alpha 線幾日 + 二十年守望之後）。

極端狀態錯誤版本：崩潰期嘅嫉妒唔會變成指控，會變成**加倍嘅自我剝奪**——搶住做最危險嗰份，然後受咗傷都唔講。呢個係壓抑稅最重嗰種施力方式（CDL-357），會直接餵大夕。**即係話：晴香嘅嫉妒最終唔係傷害對方，係餵養自己嘅陰影。**
```

## C6. Voice Distance Map（初稿，只作相對比較）

| 軸 | 晴香 | 操 | 紫音 |
|---|---|---|---|
| 直接指出感受 ←→ 迴避感受 | **指出（但只指得出狀態）** | 極度迴避（指出＝暴露破綻） | 唔用語言處理感受 |
| 先行動 ←→ 先分析 | 極端先行動（身體先入場） | 先分析、先安排 | 極端先行動（暴力） |
| 完整句 ←→ 斷句 | Act I 完整，後期斷 | 永遠完整、永遠得體 | 極短、命令式 |
| 主動填沉默 ←→ 容許沉默 | **容許沉默但唔離開**（獨特位置） | 用安排填沉默 | 直接離場 |
| 抽象概念 ←→ 具體小事 | 具體小事＋現場指示詞（「呢個」） | 抽象秩序、程序 | 具體肉體 |
| 承認自己需要 ←→ 外包成團隊需要 | 極端外包（「我哋」） | 極端否認（「我唔需要」） | 極端先撇（「我唔要你哋」） |
| 對方拒絕後堅持 ←→ 縮細要求／離開 | **堅持但縮細要求，唔走** | 退開、改期、保住體面 | 加壓或者離場 |
| 收到好意時 | **彈返去對方度** | 收得太好（收落表演層） | 打返轉頭 |

> 最後一行（「收到好意時」）係本輪最乾淨嘅三角對照，建議升做主要辨識軸。
