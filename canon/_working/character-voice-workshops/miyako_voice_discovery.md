## 2. Speech Analysis Card（demo 用）
| 維度 | 設計 |
|---|---|
| 功能 | 命令／警告／事實陳述；**護主但唔承認** |
| 心理 | 用功能包裝保護（我只係要戰局有效）；情感只漏喺停頓（…）同咬唇 |
| 句長 | 極短：1–3 字一句；洩漏時先出現長句＋省略號（凜信息） |
| 停頓 | 命令前無停頓（急）；提及凜嗰句中間有停頓＝洩漏 |
| 語域 | 純口語短句；canon 書面詞（它、現在）口語化 |
| 稱呼 | 唔叫名，冇「你哋」（避免同操撞）；對晴香直接下指令 |
| 助詞 | 全無；加「啦」＝催促／撒嬌，唔啱 |
| 禁止 | 解釋原因、講「我擔心」、講「我唔會走」（Act II 先出）|
| 同操分別 | 操評「形」（唔襯、難睇）；美夜子只講「事」（後面、用呢個）|

## 3. 微場景

### MY1：場3 情緒連結（貓形態遞裝置＋凜信息）
Canon 兩句，固定；只處理書面詞嘅自然化候選。
| 版本 | 配音稿 | 說明 |
|---|---|---|
| Y1a | 用呢個。而家。／（停）我以前……同一個人試過。應該有效。 | 「它→呢個」「現在→而家」；後句 canon 原句 |
| Y1b | 用佢。而家。／同上 | 「佢」指物件，較貼字面但易誤會指人（貓面對晴香）|
| Y1c | 用啦。即刻。／同上 | 加「啦」＝催促，減冷感；不採用 |
- Head Writer 傾向：**Y1a**。Swap：交畀操→操會評「好難睇」；交畀晴香→會問「你冇事吖嘛」。→ 通過。
- Compression：「用呢個。而家。」已極短；凜信息句刪走「應該有效」會失去功利包裝（洩漏＋掩蓋並存），唔刪。
- Interaction Loop：美夜子（命令）→ 晴香「呢個係——？」（見晴香檔）→ 美夜子唔解釋，重複「用」＝縮細再行動；殘留：咬唇。
- 貓形態講嘢邊個聽到？**待作者**（見合併問題）。

### MY2：場2 戰鬥中警告（VOICE_CANDIDATE，canon 冇逐字句）
| 版本 | 配音稿 | 說明 |
|---|---|---|
| Y2a | 後面。 | 事實警告，最短；貓形態最似 |
| Y2b | 唔好郁。 | 阻止衝前；同咬唇動作並用 |
| Y2c | （無台詞，只冰壁／爪擊） | 貼「用行動代替語言」GLOBAL_STABLE；demo 內語言＝罕有出口 |

- Swap：Y2a 交畀操→操唔會報事實，會評；交畀晴香→晴香會喊「小心！」。→ 通過（但辨識度依賴「無評語」）。
- 撞聲風險：中（同操「過嚟」）。拉開：美夜子只講方位／動作，唔叫人做事。

### MY3：場5–7 對操／擋鏡頭
- Canon：貓擋鏡頭（場1、場7）；對新人操：信任圈外＝防備姿態（CDL-408），唔會主動熱情。
- 候選：Y3a 完全無台詞（擋鏡頭＝動作）；Y3b 一句冷淡短語（例：「唔拍。」score 5，罕用，唔推薦）。
- Head Writer 傾向：**Y3a**。同操 M4「批評＋動手」拉開：美夜子只用身體擋，唔評語。

## 7. 作者風格校準 R2（2026-09-29，AUTHOR_STYLE_DIRECTION，優先於上文候選）
作者：美夜子說話應更**功能向**——**白同直**，用詞具體，**唔講「應該有效」呢類含糊詞**，**唔講大話**；有語言藝術，但只係**細**、唔直講心事。
- 上文 Y1 系列嘅「應該有效／應該有用」**作廢**（CDL-084 該句只係示例 wording；功能要求＝極簡、帶情感色彩、一瞬猶豫，唔要求「應該」）。
- 猶豫／情感洩漏改由**停頓（……）、省略、過去式事實**承擔，唔靠含糊詞。
- 「細語言藝術」手法（只作候選）：①感受換成事實（「有用」代替「我信」）②對仗短句③省略主語／對象④結果先行⑤唔用反問／驚嘆（原稿「妳想被扭斷嗎？」係反問＋誇張，唔啱）。
