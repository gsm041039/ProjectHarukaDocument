> 關聯討論：`2026-09-27_BETA_ENVIRONMENT_RESPONSE_AND_STAGE_LANGUAGE_DISCUSSION_LOG.md`

---

## Pipeline 原則

1. **一張 sheet 只解一個主要問題。**
2. **同一研究 sheet 盡量固定 camera / blocking，避免多變因一齊改。**
3. **規則先行，motif 後行。** 金魚／哥德唔可以代替機制。
4. **先證明 mechanism，再追求 key visual 完成度。**
5. **最後先做 composite。**
6. **本 pipeline 係 visual-development track，唔推進 Scene Architecture / Script；Round 196 Sequence-layer freeze 不受影響。**

---

## P00 — Core Statement

**目的**：定作品環境反應嘅一句話藍本。

當前候選（未鎖）：
- 在 Beta，情感會被整理成一幕。
- 強烈反應時，願望與恐懼會同步過曝。
- 甜不一定代表保護；有時甜與恐怖會一齊放大。

**交付**：1頁文字 brief，無須生圖。

---

## P01 — Environment Base

**目的**：先回答「Beta 平時到底長點」。

優先場景：
1. Classroom — wish-heavy
2. Dessert Shop — host-heavy

只研究：
- 香港宿主生活
- location-dependent wish filter
- Beta-only ambient weirdness
- 基本仿生／準有機設備

暫時唔研究：
- extreme lighting
- Gothic escalation
- hard Soul-stage
- Dual Overexposure

**交付**：ENV BASE SHEET（多 view / layout / set dressing）。

---

## P02 — Spatial / Stage Grammar

**目的**：只研究空間同人物位置，唔靠燈光救場。

候選測試：
- Wrong Orientation
- Distance Extension
- Zoning Misalignment
- Frontstage Pocket
- Witness Background
- Backstage Margin
- No Backstage
- Entrance / Exit Cue
- Role-casting Layout

**交付**：固定 camera 或同一 camera family 嘅 layout test；可用灰模／plan view。

---

## P03 — Lighting / Color Response

**目的**：固定空間，只改光、value、color、focus。

候選：
- Beta Everyday
- Wish-biased light
- practical focus
- abnormal beauty
- processed focus / administrative spotlight
- overexposed sweetness

作者提供「時光小偷 MV」只作唯美／不安 feel 參考；綠 tint、高光暗對比等係例子，唔係 mandatory palette。

**交付**：6–10 格 color/light key strip。

---

## P04 — Environment Behavior

### P04A Ambient Weirdness
研究 Beta 日常一兩件 Alpha 不會有但居民當正常嘅東西：
- 仿生交通
- 公共設備
- 城市基建
- quasi-organic 行為

### P04B World Response
研究環境喺情感場面點參與演出，避免照搬其他作品「巧合打光」公式。

**交付**：behavior sheet / short sequence thumbnails。

---

## P05 — Motif Dialects

逐套獨立測：
- Goldfish / water / soft life
- Gothic / fixation / containment
- Wish sweetness / idealized happiness
- Stage / gaze / focus
- Bionic city / living infrastructure

**規則**：motif 係口音，唔係 trigger。

**交付**：一頁一 dialect，列 use / don't overuse / range。

---

## P06 — Response Mechanism

同一 shot 分拆：
0. Base
1. Wish only
2. Fear only
3. Stage only
4. Composite

核心測試：
**Dual Overexposure** 是否真係可以做到「越甜、同時越恐怖」，而唔淪為「粉紅＋黑色」配色。

**交付**：mechanism sheet，箭嘴＋短註解＋同鏡頭對照。

---

## P07 — Composite Imageboard

前面通過測試先做：
- Environment
- Space
- Lighting
- Environment behavior
- Motifs
- World response
- Story tone

一次過合成。

**交付**：真正 IMAGEBOARD / key visual / art-direction board。
