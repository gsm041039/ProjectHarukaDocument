### 1.4 Programmatic / Functional Spatial Logic
作者補充一條重要、較通用嘅空間原則，並明確唔希望拆成幾個固定候選分類：

> **Beta 空間可按「人怎樣生活、流動、聚集、感受」重新組織，而唔只服從工程／規劃理性。**

作者同意：
> **功能直覺可以凌駕規劃邏輯。**

五歲晴香式 childlike urban logic 候選理解：
- 想買嘢 → 附近應該有舖
- 想去某處 → 應該有車
- 想同朋友傾偈 → 應該有可停留位
- 想睇下面 → 應該有高位
- 秘密地方 → 應該藏喺樓入面

因此城市／建築可以出現「理所當然但越諗越唔合理」嘅空間使用。

作者例子（**只係例子，唔係 category**）：
- 80–90 年代公屋三十多層中段突然存在商業使用；
- 後樓梯／服務空間異常放大成街道尺度；
- 住宅中層／後樓梯可接入火車站；
- 正式規劃嘅路／通道最後係死胡同；
- 課室完整地板消失，只剩空中石屎橫樑承載枱椅，梁與梁之間有 gap / 高低差。

「No Floor / In the Air」作者明確指出：
- **唔係新 category**；
- 只係用嚟表示同一空間語言可以推到幾極端；
- 少少型格可以，但 baseline 最好仍然 **用得到**；
- 強烈情緒反應時可以再將既有空間邏輯推過 usability threshold，變得難以使用／暫時不可用。

## 6. P03 重新定向：唔係一般 Atmosphere Moodboard

作者想要更強、更「討厭」嘅空間 vibe，參考方向包括：
- 《魔法少女小圓》魔女結界／《叛逆物語》日常被非日常侵蝕；
- 《Digimon Adventure 02: Hurricane Touchdown!! / The Golden Digimentals》後段持續窒息／nightmare-like state；
- 延伸研究：Serial Experiments Lain、Adolescence of Utena、Angel's Egg、Sonny Boy、Perfect Blue。

研究抽出嘅方法（**借方法，唔借具體 icon**）：
1. **Semantic Wrongness**：熟悉事物存在，但「點解會喺呢度／點解咁用」唔合理。
2. **Medium Wrongness**：某部分世界開始用另一套 graphic / movement / representation method。
3. **Temporal Wrongness**：movement lag、重覆、停住、節奏錯位。
4. **Sensory Pressure**：低頻、silence、聲音距離、空氣重量。
5. **Normalisation**：觀眾覺得怪，但角色把異常當日常；呢條特別適合 Haruka「所有人都係真實靈魂」嘅世界。
6. **No Release**：氣氛建立後唔一定即刻用 action / joke / bright cut 幫觀眾放鬆。

工作方向建議改做：
**P03 — Affective Environment / Uncanny Pressure**
而唔係普通「天氣／霧／夜晚」Atmosphere。

## 8. Visual-language tracking method

本輪正式建立「Visual Language Register」概念。

一個項目需要入 Register，當：
- canon/world rule 有視覺後果但 production rule 未設計；
- 會跨多場／多地點重覆；
- 會改變觀眾點讀畫面；
- 同其他語言容易混淆；
- 係 signature / high-risk system；
- 不先定規則會令 downstream 每場自由發揮。

每個 item 追蹤：
ID / Layer / Source State / Pipeline Owner / Design State / Core Question / Dependencies / Minimum Test / Exit Gate / Open Risks / Last Updated。

Stop Rule：
> 核心問題已答、有 2–4 個可用方向、新測試主要只加 variation → 過 gate，進下一 subsystem。
