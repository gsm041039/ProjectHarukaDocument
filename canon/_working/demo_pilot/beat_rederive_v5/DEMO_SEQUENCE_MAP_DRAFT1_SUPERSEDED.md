## 1. 建議分四場（全部 PROVISIONAL）

| 場 | 白話名 | 功能（一句） | 入場狀態 | 出場狀態 | 人 |
|---|---|---|---|---|---|
| A | 首戰後夜晚·接受使命 | 令零前情玩家明白「已發生大事」，晴香接受使命但未知代價 | 晴香剛打完首戰（戰外，觀眾未見） | 晴香收咗葡萄糖注射槍＝接受；知現象、唔知代價 | 晴香、美夜子 |
| B | 街頭大戰·操入隊 | 教核心玩法，操由陌生變臨時隊友，晴香用身體擋令操第一次覺得有人在乎「佢」 | 兩人有槍、冇隊友 | 三人臨時組隊，未熟；暖但有距離 | 晴香、美夜子、操 |
| C | 紫音入隊·補給見底 | 第四人入隊；最後一支槍用完，推基地行動 | 三人隊、神秘身影已埋鋪墊 | 四人、補給歸零 | 四人 |
| D | 基地夜潛·甜品局 | 建立「我哋嘅地方」；牙伏筆；真暖收尾 | 補給見底、想要冇大人嘅地方 | 四人分食甜嘢，冇人想走；操有事冇講 | 四人 |

## 2. 角度分析（TARGETED，揀 11 個）
揀嘅理由：分場層決定功能分配、知情、教學負擔、節奏、人數同伏筆位置。略過：台詞／動作型角度（beat 以下先用）。

| 角度 | 對分場嘅要求（證據） | 攻擊 | 設計回應 |
|---|---|---|---|
| 結構功能 | 四場要各有不可取代功能（修正版同 BATCH2 已有 N→R→R→R/O 分佈） | 場 C 只得一個 beat，容易變過場 | 場 C 獨立保留：入隊＋補給見底兩件事綁埋一場，BATCH2 已論證減一個獨立場景製作量 |
| 觀眾知情 | 首戰缺席，觀眾只見結果（修正版 N1 靠膠布、倒影） | 玩家以為晴香「平白接受使命」，動機斷 | 場 A 要提供「為咗邊個／咗乜」嘅理解材料；是否加極短首戰回憶留 Stage 3 比較 |
| 角色知情 | 晴香唔知牙、唔知代價；操知牙唔講（修正版知情表） | 美夜子猶豫嗰下無後續，變死線 | 場 A、B 各留一次「美夜子欲言又止」，明確標 demo 唔回收 |
| 玩法／能動性 | 要教攻擊閃避、血糖槍、隊友視窗、連結（修正版 B2、B3） | 場 B 一場教四樣，過載 | 場 A 用「交槍」預教血糖；場 B 只教視窗＋連結；攻擊閃避放場 B 開頭 |
| 節奏 | 暖（A）→ 重戰（B）→ 小戰（C）→ 緩（D）；範圍表原估 16–21 分鐘 | 場 B、C 連續兩場戰，疲勞；總長冇人量過 | 場 C 戰鬥設為短戰；時長等 Stage 3 beat 清單後先估 |
| 氣氛／張力 | 好暖＋少少不安（D-13） | 暖得太平均，不安冇位置 | 不安只放喺場 B 尾（操否認被打動）同場 D（牙），其餘場保持暖 |
| 埋位／回收 | 神秘身影（B 尾）→入隊（C）；牙（C 補給血跡→D）；美夜子猶豫（A/B） | 牙喺 C 同 D 都出現，提前重複 | 牙只喺 D 出現主畫面；C 最多一個血跡細節，Stage 4 再定 |
| 關係動態 | 晴香→操（擋）、晴香→紫音（餵糖）、美夜子擋操（暗地） | 兩次「晴香用善意收服」重複（擋操、餵紫音） | 要喺 Stage 3 分化：操係被擋、紫音係被餵，機制唔同（保護 vs 食物） |
| 主題（態度 vs 命運） | 修正版 B6：系統冇為操開視窗，晴香反而衝前 | 主題只靠一個玩法細節 | 場 D 要有一次延續：同一組人唔需要系統就肯留低（甜品局冇人想走） |
| 製作量 | 範圍表 NEED_AUTHOR 缺口（貓形態戰鬥、直播 UI、屍骸消散）未答；四人要四套動作 | 場 B 加場 C 兩場戰需要兩種屍骸 | 場 C 用較細屍骸、重用同一套系統 |
| 跨幕影響 | 牙次序、紫音入隊前提（BATCH2 範圍變更聲明） | 場 C 紫音戒斷提前 Act I 暗示 | 戒斷只讀作低血糖，真相留 Act II（BATCH2 已守） |

自檢：刪走任何三個角度結論會變——知情決定場 A 要唔要加回憶；玩法決定教學分配；埋位決定牙只放場 D。
