# Finalists for premise audit（只列候選，冇推薦）
每題 2 個 finalist；描述＝Beat 層，冇對白／鏡頭／timing。共用已定：range、無紫音、好暖＋少少不安、真跌牙操知收埋、基地喺街戰幾日後（以「又一場戰後最後一支葡萄糖槍用完、三人手震」開場）、0d 無台詞並含熱可可＋幽靈重量（倒影慢半拍、身體沉重）＋日常藉口、驚由天台晴香／美夜子對話帶出（0d 只有晴香一人）。

## MP1 街戰次序
- F1-A：晴香＋美夜子唔夠打 → 美夜子提兩人連結（凜一句＋一瞬猶豫）→ 力量暴增；入侵＝兩人當下情緒一瞬互相透明，冇記憶畫面 → 之後操高處到場 → 中陷阱 → 晴香用身體擋 → 傲嬌入隊。操唔喺連結。
- F1-B：操先到場 → 中陷阱 → 晴香趕唔切 → 美夜子提兩人連結 → 增幅令晴香衝得到去擋 → 入隊。操唔喺連結。

## MP2 屍骸態度示範
- F2-A：只帶「正面消散」：大型人形屍骸被打倒嗰刻，最後一瞬似放鬆／有人樣，然後消散，同時 UI 彈 Likes；「反面奪舍被阻」留範圍外 [NC]，標 REVALIDATE。
- F2-B：兩樣都唔帶，demo 只有預設消散，全部延後。

## MP3 地點／牙因果
- F3-A：全場日區（直播＋光幕）；牙＝操既有崩壞線累積，demo 唔解釋原因。
- F3-B：全場日區；另加操入隊前嘅獨行獵喺覆蓋範圍外（鏡頭外），令代價自留、加速牙線。

## MP4 天台接受嘅觸發
- F4-A：E-01 作先行 cost signal（延遲反應有效例外）；天台冇新事件；俯視城市作環境載體；接受用行為載體＝晴香按一按身上膠布（佢助人前慣性動作 H:289）。
- F4-B：講解途中遠處屍骸警報 → 晴香即刻要去 → 接受＝跑向危險，天台同日直接接街戰。

## MP5 晴香講驚
- F5-A：晴香手震被美夜子平平哋點出 → 晴香即刻認（冇面具）但即刻自己縮細 → 驚＝佢嚟搞清楚嘅理由。
- F5-B：晴香自己直接講驚（唔講事件），美夜子解說口吻接，唔安慰。

## MP6 牙前兆＋掉落
- F6-A：前兆＝陷阱時操唔肯狼狽閃避，下顎被擦一下（觀眾讀成戰傷）；掉落＝基地甜品局，全場注意力集中晴香（晴香搞合照／出洋相）嗰刻，操咬一啖甜嘢、牙跌、收埋、強忍扮正常；美夜子注意力喺晴香（錨點）。
- F6-B：前兆＝表演時（入隊一刻）舌頂到牙鬆、繼續表演；掉落＝同 F6-A。

## 其他已定（一併審）
- 因果鎖：操救路人（入場一擊順手）→ 晴香見到 → 晴香擋 → 入隊。
- 晴香擋操＝玩家戰術視窗「掩護」親手做。
- 街戰前段迫玩家用一次葡萄糖槍（教學＋plant）。
- 戰後：操避鏡頭；路人道謝操否認；操私下整理被觸碰位（量尺強迫，Act I 讀做執著儀態）；晴香問點解操會出現 → 美夜子講燈塔效應。
- 基地：美夜子潛行開路兼暗地照住操；操嫌灰塵監控閉路；晴香把風肚咕嚕；保安巡邏險些撞上。
- 結尾：牙跌之後，操返入笑聲，以真暖收尾（牙唔係最後畫面）。
