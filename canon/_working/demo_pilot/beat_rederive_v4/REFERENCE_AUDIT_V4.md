# Reference Audit：v4.1（由頭重推）vs v3.2（舊修補版）
誠實聲明：orchestrator 寫過 v2–v3.2，推導時有記憶接觸；來源 agent／質疑 agent 冇讀舊表。重合位要當「可能受記憶影響」，但每個重合元素喺 v4 都有獨立來源鏈（見 DERIVATION_V4）。
**一致（獨立推返同一結論）：** 連結先、兩人、操唔喺連結；救路人早過擋；正面消散做態度示範一半；美夜子交注射槍；牙喺基地甜品局人前悄悄跌、操收埋；結尾唔停喺牙；0d 熱可可＋幽靈重量。
**唔同（v4.1 改咗）：**
1. 晴香講驚：v3.2＝被身體出賣／漏口；v4.1＝直接講（CDL-355 冇面具；v3 用咗後期「為自己唔喊」）。
2. 天台：v3.2 加遠景警報做觸發；v4.1 唔加事件（N/A＋E-01 延遲反應），三拍併兩拍。
3. 牙因果：v3.2＝戰後口角血（同場）；v4.1＝M1 短戰後口角血、成因明寫魔法消耗；外傷說法刪。
4. 基地時間：v3.2＝首戰後不久可同晚；v4.1＝幾日後，用可玩短戰串交代（同晚因果唔成立）。
5. 合照：v3.2＝晴香搞合照、美夜子望晴香；v4.1＝美夜子擋鏡＋操避鏡嘅鬧劇（CDL-125），唔影成；結尾改「冇人講要走」。
6. 擋操：v3.2＝一次性按鍵互動；v4.1＝系統唔開視窗、玩家按閃避晴香反而撲出去（視窗只對隊友＝主題）。
7. 新增：戰術視窗教學（B2 美夜子）；血糖用身體感知提示；燈塔移去基地決定；CDL-322 第三重解讀；B8 改「有錯位嘅暖」；學校／屋企非日區（CANON_FACT_GAP）。
8. 刪：B10 路人道謝做暖收束主體（改 B8 錯位）；下顎擦傷；N1 召喚。
**結論：** 主幹（事件次序、牙形式、交槍）同 v3.2 收斂；差異集中喺角色心理準確度（講驚、CDL-083）、因果時間（基地）、canon 對位（CDL-125/322/064）同玩法（視窗、血糖）。
