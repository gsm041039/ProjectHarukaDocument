# 魔法圖案構成方法 v0.2
RESEARCH_ONLY／候選「偏口抱脊」。液脊與留白保留作材料筆法；本文件新增能重畫的形狀和組合。不是共同施法流程。已有不顯形能力不強加痕跡。

## 共同核心與精確起稿
一條連續背脊，同側不等長雙肩；只有長肩向內回鉤一次，短肩尖收，兩端錯位形成斜側口；白腔必須通向背景。
12u × 8u 格，原點左下，依次填黑：
(0,0) → (8,0) → (7,2) → (3,2) → (3,6) → (9,6) → (9,4.5) → (11,4.5) → (12,8) → (0,8) → 閉合。
背脊3u，長肩伸至12u，短肩8u。數值是施工起點，不是 canon 或驗收門檻。可圓化、壓窄、沿動作彎曲；白腔没有無我／吸收／靈魂容器功能。

## 三個母構
A 疊肩脊（推薦）：三細胞沿背脊方向上下排列，尺寸1/.8/.65，口同向。只在相鄰背脊端加約1u短頸，不跨白腔、不把肩尖接到下一細胞。整體一條骨幹、三個斜開白腔。優勢是可沿動作彎曲；代價是可能像羽翅／魚骨。
B 中央對抱：兩等大細胞鏡像，口向中央，最近鉤端先留4u。互不相接，中央上下開放。不另加主軸線。保留莊嚴對稱，代價是像紋章、可能壓過角色既有標記。
C 三向旋抱：三等大細胞旋轉120度，口朝空心，口中點距中心先取8u。互不相接，三白色通道接外界。不預設外圓，數量無神學含義。儀式花飾強，但容易像通用陣營徽記；沒有既有效果就不強套。

## 角色變體
晴香：A 沿既有拳路彎曲，肩與腔圓化約1u，回鉤及斜口保留，負形讓拳套／前臂先讀。不新增護盾、吸收、施法完成時序。
操：只一細胞，沿已有單絲拉長，起稿寬長約1:6；是同一實線的局部輪廓，不新增平行線、分叉、控制端點。近景容得下才試，遠景不足就退乾淨單線並註圖案識別失效。
紫音：兩個較大細胞沿既有鎚路，厚背脊、45度斜切、短硬回鉤；每細胞一主折，不全邊鋸齒。不新增爆炸、元素、半徑。
三者應以輪廓差別先成立，不只換色。角色來源沿已核 haruka L323–336、ayakomoji_misao L352–365、iwakura_akane L252–265；其他排除與來源見 PROPOSALS.md、EVIDENCE.md。

## 三載體
VFX：背脊跟既有動作軌跡，先輪廓再流體高光／既有結晶；高光不能填滿白口。
布邊：A 分離裝飾版，16u高游離布帶放約8u單元，上下約4u休息；一色印花或刺繡，接縫在單元間。不直接採用於角色服裝。
心匣：B 做獨立淺浮雕試片；黑形凸起，白腔是完整原殼面，無貫穿孔或新介面，外緣留一背脊寬。尚未證明正式資產適配。若壓過原標記，候選改單細胞邊飾，不能刪原標記。

## 最小母樣與反例
單細胞施工圖＋A/B/C等占幅純黑母構＋三角色輪廓＋A簡化版＋三載體局部。簡化先刪高光碎片，再三細胞減一，保留不等肩／單鉤／斜口。縮小後只剩彎線即記識別失效。
強反例：相同占幅與三節，改等長肩、删鉤、封口成白孔，再用相同色與液體高光。漂亮也不符合本輪核心。把 A 畫成操三根真正控制線同樣越界。
