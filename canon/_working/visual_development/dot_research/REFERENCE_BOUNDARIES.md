# 本輪佛教參考的核對與轉譯界線
2026-10-10重新讀取三個既有來源，範圍只支援眼前比較，不擴張圖庫審查。

[Met須彌山宇宙圖](https://www.metmuseum.org/art/collection/search/39738) 明載中央須彌山以倒金字塔表示，四方有四洲；不是所有佛教宇宙圖都等同華嚴互含。本作先前倒山／方圓構圖是形式借用，沒有沿用完整神祇或宇宙地理。

[Met星曼荼羅](https://www.metmuseum.org/art/collection/search/78283) 明載五同心圈與外圈人物，內部分配北斗、九曜、黃道等群組。可研究有序分組與中心／環列關係；把它改成三個深度層的非均勻星群是新的美術設計，不是原作品的星數、功能或法則。

[SEP華嚴條目](https://plato.stanford.edu/entries/buddhism-huayan/) 用椽與屋、因陀羅網說明相依與整體／部分關係，並將其與慈悲的倫理理解相連。這是有學術作者的宗教哲學綜述，不是本作canon。物理湮滅不等於佛教空性；資料亦提醒佛教空性與斷滅論有別。

本輪將互含轉成單張構圖的內外翻轉，只是一個原創視覺譬喻。非歐幾何既不是華嚴的唯一含義，也不是作品intent-level美術的新必要條件。握住他人作為局部有效行動可以與相依的倫理解讀對話，但不得據此聲稱宗教來源已驗證某個劇情或整個宇宙由握手控制。

若生成圖只像巨環／星空廳，失敗的是這一具體圖像轉譯；不代表佛教參考本身無用，也不代表要降低宇宙強度來安全過關。
