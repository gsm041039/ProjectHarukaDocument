# Haruka v27 — 同場景宗教取材實圖比較

2026-10-10。研究候選，非作者採用。下文為用戶已收到的分析；最終評圖差異與實驗紀錄補於文末。

今次實圖令我修正咗之前「佛教方向優先」嘅判斷：呢組入面，最值得繼續發展嘅係 C 混合版，同 D 原創版，而唔係 A 單一佛教取材版。

但要講準：A 畫出嚟偏向一般星象圖，未充分呈現佛教星宿構圖嘅獨特優勢，所以今次唔能夠下結論話「佛教輸咗」。

我會優先深化 C，保留 D 作對照。呢個係下一步研究取捨，未係正式採用混合宗教。

1. 今次實際比較咗咩

同一場景：兩個魔法少女隔住巨大宇宙裂隙互相伸手，前景少女托住一塊有缺口嘅鏡片。

固定咗人物、衣服、姿勢、鏡頭、主要裂面位置；改背景組織、宗教圖式同節點。四個版本之外，另外做咗 B2 修訂，所以總共五張。

人物係測試替身，唔係角色改造稿。呢輪係有實圖嘅美術比較，唔係真人 A/B 測試，亦冇盲測。

2. A：佛教星宿取材版

最成功：
• 宇宙由「一堆巨大碎片」變成有層次、有排列嘅秩序
• 星點分組、環圈同不同距離，令觀眾覺得世界有一套唔完全明白嘅規律
• 比 B 更少現實建築聯想，保留非現世感

主要問題：
• 實圖嘅金色星星、珠串同環圈，首先令人聯想到星象／天文魔法，佛教來源嘅獨特組織法未夠突出
• 好多細亮點分散注意力，鏡片同人物動作冇咁集中
• 宇宙似係已經排好嘅美麗系統，睇唔出少女點樣介入佢

適合：
宇宙秩序、命運排列、遠近關係、不同意志共存嘅場面。

代價：
細星點同細線如果變成動態，可能有閃爍、追蹤同畫面雜訊問題。呢個係製作風險估計，唔係已量度成本。

結論：
值得保留「分組同間距」，唔值得照搬目前滿佈金色星飾嘅做法。呢張未足以支持我之前畀佛教方向較高嘅排序。

3. B1：基督教取材初版

最成功：
• 宗教美術來源最容易辨認
• 尖拱、花窗、十字節點，迅速帶出神聖權威同既定秩序
• 同現有鏡面／哥德元素接得上，唔需要另外發明一套材質

主要問題：
• 重複窗框太多，第一眼好容易讀成「巨大哥德窗飄喺宇宙」
• 細線同金光搶戲，背景比手同鏡片更熱鬧
• 原本想測試嘅「打開、揭示、轉向」未有真正畫出嚟，畫面主要得到嘅係花窗外觀

適合：
制度、禁忌、權威、被規定嘅位置，以及神聖同不安並存嘅場面。

代價：
如果全作都用呢個密度，好容易變成通用哥德奇幻。佢仍然係開放宇宙，唔係真係一間室內教堂；問題係建築聯想太強。

結論：
B1 係今組最弱嘅成品，但唔足以判定基督教來源唔適合。

4. B2：減少重複後嘅基督教版

呢張有實質改善，唔係只係「少啲嘢」。

保留咗：
• 幾個清楚嘅花窗／十字結構節點
• 巨大黑色裂面嘅重量
• 宗教式權威感
• 人物同背景之間嘅黑色空位

犧牲咗：
• B1 密集、華麗、近乎儀式殿堂嘅壓迫
• 大量可辨識嘅哥德節奏

得到嘅好處：
宗教感仍然喺度，但唔再由一整排窗框統治幅圖。證明「收斂」可以保住力量。

新問題：
• 少咗花紋之後，剩低個十字反而特別搶眼，要小心佢變成無意中嘅主焦點
• 裂面變得較似斑駁石材／拼片，鏡面身份弱咗
• 呢次同時改咗密度、光色同部分材質呈現，不能話改善完全由「少 70% 花紋」造成

結論：
B2 已經係有競爭力嘅候選。佢證明之前輸得咁多，至少部分係用量同執行問題。

5. C：混合版

我最想繼續深化呢張。

最成功：
• 星點唔係另外貼喺花窗上，而係同尖形支架、邊線、節點共用一套排列
• 比 A 多咗結構重量，比 B1 少咗建築裝飾感
• 保住冷黑，同時令宇宙似有一套具體但陌生嘅秩序
• 「尖形支架＋星點節點」有機會縮成施法母樣，再放大成宇宙圖案

佢點解唔只係兩種宗教堆埋？
因為同一條邊線同時負責支撐形狀同組織星點，唔係左邊佛教、右邊基督教兩套裝飾各做各。

不過，目前只證明視覺上整合得較好，未證明兩種來源喺故事或者魔法操作上有必要一齊存在。

主要問題：
• 仍然可能變成普通「宇宙機械＋星象裝飾」
• 畫面冇交代節點究竟做乜，唔能夠因為佢有規律，就當已經有一套好設定
• 接近鏡片嘅線可能讀成吊住鏡片，反而削弱「少女主動控制」嘅感覺
• 比 D 多一套需要維持一致嘅構成規則

適合：
你要嘅非現世宇宙、可重用魔法圖案，以及人物同世界秩序對齊嘅畫面。

結論：
今組最有潛力成為長期美術語彙嘅候選。但要靠反覆可用嘅構成方法成立，唔係靠「混合兩種宗教所以更深奧」。

6. D：原創對照版

佢唔係陪跑，兩位 AI 都將佢排第一。

最成功：
• 巨大黑色裂面、尖銳亮邊、人物大小差，已經有好強宇宙尺度
• 手、鏡片同兩個女仔之間嘅關係最直接
• 冷、危險、空曠，唔需要宗教裝飾先做到高強度
• 附加圖案最少，主要靠大形同材質說話

主要問題：
• 「原創對照」只係測試名稱，唔代表已經有 Haruka 獨特身份
• 碎鏡＋宇宙巨構本身都可以好通用
• 比 A/C 少咗「世界有一套排列規律」嘅感覺
• 冇大量花紋唔等於製作便宜，破碎反射幾何一樣有成本

適合：
崩塌、斷裂、無法填補嘅距離，以及需要人物優先嘅高強度畫面。

結論：
D 證明宗教元素必須帶來額外價值，唔應為咗有宗教而加。佢亦係 C 最重要嘅對手。

7. 三個 AI 點樣爭論？

初次各自睇圖：
• 兩位：D > C > A > B1
• 一位：C > A 約等於 D > B1

真正分歧係：
「強度」係咪應該主要指危險同破壞感？

支持 C 嗰位指出：A/C 增加嘅係秩序感同有規律嘅關係，唔應因為冇 D 咁尖銳就扣分。另兩位接受呢點，但認為 C 仲未證明多出來嘅規則有實際用途。

B2 出嚟後，三位都認為明顯改善；其中一位將佢提升到 A 之前，另一位將佢放入接近 A/D 嘅第二梯隊。冇人再用 B1 嘅表現直接否定基督教取材。

最後保留嘅分歧：
D 係最有力、最清楚嘅當前單張；
C 係最值得發展成可重用系統嘅候選。
呢兩個判斷可以同時成立。

8. 今輪未解決、亦唔可以假裝驗證咗嘅問題

五張都較似「少女托住／召喚鏡片」，未清楚呈現「佢一轉手，遠方宇宙因此改變」。靜圖亦無法證明先後因果。

另外：
• B/D 有遠方紅色裂痕，A/C 生成時漏咗，所以唔可以用嗰條裂痕證明某宗教更能表現力量傳遞
• 各版亮度同材質唔完全一致
• 全部由 D 底圖修改，對共同比較有幫助，但亦限制咗其他來源重新組織空間嘅能力
• 一張 A 唔代表所有佛教美術，一張 B 亦唔代表所有基督教美術

所以我而家嘅具體建議係：
先深化 C 嘅「支架與星點共用一套構成」，同 D 比較佢究竟增加咗乜；B2 保留為少量宗教符號就有重量嘅另一條路。暫時唔再畀「佛教」呢個大分類自動排第一。

今批已完成五張實圖、三位 AI 同題評圖與互相反駁、一輪修訂後重評。正式採用、真人反應、動態因果同實際製作成本都未驗證。

## 修訂後的最終三方判斷

- 評圖者一：D > C > B2 > A > B1；D/C/B2 接近。
- 評圖者二：D > B2 > C > A > B1；D/B2/C 接近，B2 為其最偏好的借用版本。
- 評圖者三：C 優先；A/D/B2 第二梯隊，各有不同優勢；B1 最弱。
- Root：C 作下一個可重用構成研究候選，D 作強力對照，B2 仍有競爭力。不是三位一致支持 C，不是投票決定作者美術。

B2 多獲一次修訂，因此排名是目前可用成品的偏好，不是相同生成預算的宗教來源效能比較。B2 同時改動密度、光色與材質，只能稱整體實現改善。各版本皆未展示清楚可核實的手部動作→遠方世界變化；不得把文字描述當作畫面已證明。

## 實驗紀錄

INTENT：讓觀眾先讀到一個少女的主動動作與另一個少女的獨立回應，繼而感到巨大而陌生的宇宙秩序；保持魔法少女身份。

LOCKED（意圖）：人物身份替身、服裝、姿勢、鏡片、鏡頭、主要斜向巨大裂面位置、前後尺度、冷黑低彩與少量紅點。
VARIABLE：遠方裂面的圖式組織、星群與裝飾／節點；B2 為多因素修訂。實際並非所有鎖定項完全維持，尤其遠方紅裂痕、亮度、材質與微小尺寸。
