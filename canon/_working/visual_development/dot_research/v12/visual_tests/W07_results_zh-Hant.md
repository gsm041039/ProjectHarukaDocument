# W07 少量腥紅落點：三張實際輸出的結果

## 結論

本輪沒有足夠依據宣稱加紅優於無紅。我會暫留 C0 作為最完整的基準；C1 的袖口紅可讀，但主要是微弱的動作端點提示。C2 沒有準確落到指定石面，而且紅量與明度不相當，不能用它證明石面落點失敗或袖口落點勝出。

這只是此張宇宙圖的局部觀看比較，不採納角色全局配色，也不替腥紅指定固定含義。

## 實際觀看

- **C0 無腥紅控制**：巨大黑岩、白色宇宙層帶與黑色間隔仍主導全幅。左下人物的臉、手部膚色與剪影已能辨認，伸手不靠紅也成立。沒有額外彩色目標，是本輪最少干擾的版本。
- **C1 啞面腥紅袖口**：紅停在伸手袖口及緊鄰的小段衣料，胸前與環境沒有跟著染紅；沒有新增紅光或連線。宇宙巨構仍主導，袖口讓已找到人物的視線較容易停在伸手端點。但它沒有明確改寫全幅層級，也可被讀成普通服裝點綴。這個小幅提示不能當成加紅的必然收益。
- **C2 啞面腥紅石面**：實際紅斑出現在更偏左上方的岩面。深暗、獨立的斑塊沒有清楚承接手勢；放大注意到時也可能像石上的染斑，未必像原生材質轉折。它沒有形成紅色光束、長線或散點，但落點與色量控制均未達標。

上述為對實際影像的視覺判讀，不是受試者測試或眼動測量。未以紅色象徵替效果補充理由。

## 有效性與混淆

1. **C0 並非像素鎖定控制。** 既有紅褐袖口及胸前衣料已中性化，人物姿態、完整裁幅和主要巨岩配置大致保留；但星點、石紋、星雲與部分亮核細節已重繪。全幅平均明度近似原圖，不等於局部明暗完全相同。相對原圖，約 14.2% 像素至少一個 RGB 通道變動超過 10／255。
2. **兩個紅版也有非局部漂移。** 相對共同 C0，同一粗略差異指標為 C1 約 8.6%、C2 約 7.0%；宇宙與岩石細節變動遠超過小色塊範圍。故不能將觀感差異全部歸因於紅的落點。
3. **C2 偏位。** 預定尋址區為橫向 47–52%、縱向 47–53%；實際紅斑中心約為橫向 46.8%、縱向 44.6%，未落在指定近場轉折面。
4. **紅量與明度未配平。** 在各自局部範圍內，以相同啟發式紅色門檻估計，C1 約 465 像素，C2 約 638 像素，C2 多約 37%。紅區加權 sRGB 明度平均約為 26.3 與 13.0／255，石面版約為袖口的一半。這不是精確分割或校準亮度，但足以提醒不能把它們當成等量、等值的落點對照。
5. **材質仍是混淆。** 袖口與石面各有不同表面、形狀、局部背景反差；即使生成更準，也只能比較這兩種具體配置，不能宣稱隔離了純位置因果。

本輪以三張原始輸出為上限，沒有補亮、擴色、手工重染、修圖或再生成來救回 C2。C2 應標記為「未合格的落點實作」，不列入成功方案排名。C0 可以保留，C1 留作可選的微弱動作提示。

另一位提出的「既有小星系中灰外圈」方案仍是合法、未測試的備選；本輪沒有生成它，也沒有以這次石面產物否定它。

## 產物與流程

三張均為 1672 × 941，保留原始完整近 16:9 畫面。
- C0_no_crimson_control.png：直接由 v07 的 C1_body_cosmos_same_tension.png 編修。
- C1_matte_crimson_cuff.png：獨立引用 C0 編修。
- C2_matte_crimson_stone.png：獨立引用同一 C0 編修，沒有接續 C1。
- C0_prompt.txt、C1_prompt.txt、C2_prompt.txt：每次提交的完整原文提示。
- inspection_metrics.json：唯讀像素檢查結果及 SHA-256。
- generation_manifest.json：輸入／輸出關係及原始生成檔對照。

使用內建 imagegen，恰好三次生成。輸出以原始 PNG 位元組複製保存，沒有安裝套件、使用額外 API 或手工改色。數值檢查只讀取影像，不改寫影像。
