# 1 秒四格時序實測

狀態：RESEARCH_ONLY／未指派角色的 2D 呈現研究。只比較既有 round 母樣的 A 窄揭示／追尾清除與 B 分布增厚／回落，各配原 control，沒有第三法。

## 有條件結論

B 在 600 ms 停格仍留一個縮小內回，A 同刻已失去內回、較接近普通 C 弧。這支持「B 在本組參數保留該局部特徵較久」，不足以判定 B 的筆法較好或更黏稠。B 的初末細帶有線繩／洩氣字標的風險，而且實際取樣出現微小黑分量。A 的窄前緣保留大段原寬，但較早清掉身份特徵。兩法的共同最大仍明顯有 C 字標歧義；本輪沒有選出合格的物理媒介或正式動作。

已查看原生 SVG 的實際 PNG、關鍵格及 128／64 px 凍結樣本。64 px 的 B 600 ms 內回很弱，不能把 420 px 的凍結可見直接換算成小尺寸即時辨識。128／64 px 只是本地展示尺度，不是遊戲、TV 或全局門檻。

沒有完成真人盲測或 1× 感知觀看。已裝 Chromium 的本地啟動遭 socket 權限阻擋，沒有繞過限制。GIF 已完整解碼、驗證幀數與總時間；HTML 內的 JavaScript 計算以明示 DOM stub 對照原生幀，這不是瀏覽器播放驗證。

## 實際幾何與編碼結果

- 四格的最大均直接引用 v05 原 path d；移除最大格不必要的重複 clip 後，420 px 原最大參照的 alpha 差全部為 0。
- F0–F60 共 61 個 60 Hz 標記，另核臨界時刻。各取樣均無原母樣零 alpha 區域外的像素、無封閉白孔、中心探針 (6,4) 可連背景；未檢出嚴格 polygon 交叉。這是取樣，不是連續時間／自交全類型的證明。
- A 非空取樣至多 1 個黑分量。B 在 alpha≥128、黑 8 連通檢查下至多 6 個黑分量，出現在初／末薄帶；必須記作點陣化連通性失敗，不能宣称全程單塊。沒有用加粗、模糊或修形藏掉它。
- 0 ms 與 900–1000 ms 的必要取樣全空白。
- 峰值前後 ±1 μs 仍有渲染邊界限制：過渡的母樣裁切會重複抗鋸齒，而最大直接畫原樣；切換處最大單像素 alpha 差 64/255，候選墨面約差 0.680%、control 約差 0.956%。幾何端點 gate 已連續，不等於點陣切換完全無差。此差兩法共同存在，未作美學優劣證據。
- 最終 GIF 為 50 格 × 20 ms，編碼一輪恰為 1000 ms。原生公式最大仍為 333.333–433.333 ms；GIF 的採樣保持將 literal branch 顯示為 340–440 ms。不要把 GIF 當成分數毫秒精確的量測檔；播放器亦可能有自己的計時行為。

## 面積×時間，不作勝負分數

以每格自身原最大面積正規化，60 Hz 梯形估算：

- A control：0.496017 s；A candidate：0.491939 s
- B control：0.498361 s；B candidate：0.500769 s

候選 B 整輪比 A 約多 1.8% 墨面時間；消退區間約多 6.5%。B 保內回較久仍與暴露時間、寬度分布耦合。不能從較清楚推論 B 機理優越；也不能把近似相等的整輪積分當成局部閱讀條件相等。

## 保留的限制與停止點

母樣、中心線、壓力表、PCHIP、座標、黑白、位置、縮放、1 秒及最大停留均固定。原 14×10 視窗亦保留，包括 candidate 在左界原有約 0.12 單位裁切；未補邊、平移或修美。過渡只在移動的零寬支撐邊界插入取樣點，中心線／法線採原樣本內插，壓力仍按原 PCHIP 或 control ramp；詳見 rebuild.py 與 manifest。

最強反例是兩者都仍可被讀作不同寫入／洩氣方式的字標。未測的「同 gate、先慢後快清除」仍只是下一個問題，本輪不自動追加第三法。只補 W10／W11 的短時筆法存活與代價，沒有執行原 20 項測試、完成 W10／W11、驗收黏度／重量／力量、指派角色或把最大當作命中。
