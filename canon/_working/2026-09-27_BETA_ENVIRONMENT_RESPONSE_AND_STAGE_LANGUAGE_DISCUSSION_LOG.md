## 0. 本輪真正問題

作者要搵嘅唔係單純「畫風」或者「加幾件超現實物件」，而係一套可以由世界本體、晴香五歲創世心理、香港宿主生活、日系動畫願望投射、歌德恐懼、舞台×傷口、唯識宇宙一路推導落畫面嘅**環境導演語言**。

核心要求：

1. 喜歡《小圓》「現實又唔現實」及世界好似活住、會配合演出嘅感覺，但**唔可以抄其具體表演方式／拼貼語言／奇怪行人語言**。
2. Beta 世界要有自己日常基線；唔可以只有「普通香港」同「一有戲就變超現實」兩檔。
3. 環境設計本身係重要導演語言，需同空間、舞台、燈光、城市生命性、心理學具現化連成一套。
4. 最後要有 production-style pipeline：先分開測空間、燈光、env 行為、motif，再合成 final composite，而唔係每張圖一次過塞晒。

## 1. Alpha / Beta 基線修正

### AC-1 — 仿生交通／活體城市語言係 Beta-only

作者明確確認：

- **Alpha 線**仍然係正常運作、未受五歲晴香創世意志改寫嘅世界；唔應預設出現 Beta 嗰套仿生交通／準有機城市設備。
- **Beta 線**創世後，先可以自然出現仿生交通、準有機公共設施、城市設備帶生命節奏等現象。

呢個係 Alpha/Beta 視覺差異之一，唔係「全宇宙本來就有仿生車」。

### AC-2 — Beta 第一眼仍然偏香港，只係有少量「動畫理想日本」覆層

作者確認 Beta baseline：
- **偏香港**，生活密度、空間使用、人情、街道、糖水舖、課室等仍由宿主生活層主導。
- 只係有少量「香港小朋友／五歲晴香由日系動畫得到嘅理想日本固定印象」覆上去。
- 呢個唔係 literal Japan。

### AC-3 — 願望化程度係 location-dependent

作者確認：
- **學校／課室、公園**：五歲晴香印象強，係最願望化區域之一。
- **糖水舖**：更接近宿主生活層，係「真暖／坐低／相處」嘅好試驗場。

## 2. Ambient Weirdness：Beta 日常本身 already strange

### AC-4 — 每個 Beta establishing shot 可以有少量 Alpha 不會有、居民完全當正常嘅東西

作者接受方向：
- 普通 Beta 日常 establishing shot 可以有約一兩件「Alpha 根本唔會出現，但 Beta 居民完全當正常」嘅環境元素。
- 呢啲唔一定有劇情含義，唔需要每件都係心理學 symbol。
- 目的係令 Beta 真正似另一個已生活多年嘅世界，而唔係「主角有情緒先臨時變怪」。

### 設計護欄

為減少《小圓》影子，Haruka 嘅 Ambient Weirdness 優先來源應係：
- 城市基建
- 仿生交通
- 公共設備
- 城市物件嘅準有機行為
- 奇怪但 functional 嘅生活系統

而唔係大量使用：
- 奇怪人形路人
- 雜亂異質角色
- 拼貼式童話物件
- unrelated surreal symbols

### DRAFT — 背景怪 vs 焦點怪

本輪提出、待後續實測：
> **背景可以自由地怪；焦點異常必須有敘事理由。**

即 ambient weirdness 可以純 worldbuilding；但畫面主焦點嘅不可能事件最好扣返情緒／關係／世界規則。

## 3. 仿生交通與準有機城市

### AC-5 — 仿生交通三種程度全部可用，但平時以 quasi-organic 為主

作者確認 Q2：
- 結構似生物
- 外觀帶生物感
- 運作方式似生物
三者可以同時存在，但程度可因物件／地區而變。

### AC-6 — 常態係「有準有機行為、冇自主意識」

平時 Beta：
- 城市設備／交通工具可以有呼吸節律、群體避讓、休眠／喚醒、脊椎式接駁、鰓／眼瞼式門件等 quasi-organic 行為。
- **唔代表佢哋有完整靈魂或人格**。
- 先以「B：準有機行為但冇意識」為 default。

### AC-7 — 特定後期世界狀態可以升格至更 soul-like response

作者確認可能性：
- 去到某些重大情節／世界本體鬆動時，可以由 B 升至近似 C：環境出現似「望返人／作出選擇性回應」嘅 soul-like reaction。
- **具體觸發、時期、機制未定**，唔可自行當成日常能力。

## 4. 「怪」嘅真正思路：改規則，多過加奇物

### AC-8 — 熟悉事物可以突然按另一條規則運作

本輪確認方向：
- 場景身份可以保留：課室仍然係課室、糖水舖仍然係糖水舖。
- 異常優先出現喺：
  - 距離
  - 分區
  - 朝向
  - public / private 關係
  - 功能
  - 觀看方式
  - 連接方式
而唔係先加入大量 unrelated fantasy objects。

### 已確認有感嘅測試語彙

作者特別喜歡／確認有用：
- **反轉坐位 / Wrong Orientation**：例如晴香反轉坐喺課室椅，人物朝向同空間功能失配。
- **距離延長**：課室內原本近嘅兩點變成情感上／空間上唔合理地遠。
- **座位排列／分區唔對**：秩序仍然存在，但開始似替人 assign role。
- 「被擺上台」＋「咦，有啲唔對路」＋「地方似有生命」。

### DRAFT — functional misalignment

本輪工作詞：
> 怪唔係因為物件唔熟；係熟悉物件仍然喺度，但功能／關係唔再跟日常預期。

後續需用 layout test 驗證，而唔係只靠 mood art。

## 6. 舞台唔係裝飾：空間開始替情感整理位置

### AC-10 — 舞台感要成為環境導演語言

作者希望舞台唔只係：
- 紅幕
- 真劇院
- literal audience
- 一盞硬 spotlight

而係可以透過空間同燈光關係反覆出現。

### 已確認／強烈偏好嘅舞台語彙

- Wrong Orientation（錯向）
- Frontstage / Backstage
- Witness background（背景位置變成觀看／見證位置）
- Role-casting layout（空間似替人分配角色）
- Distance extension
- No-backstage / 無退場位
- practical source focus（合理光源形成類 spotlight）
- entrance / exit cue
- 環境 timing 參與表演

### AC-11 — spotlight / focus 可以成為重要 language，但唔應每次直白使用真舞台燈

作者提出「被 focus 有 spotlight 照」可成為特色導演語言之一。
本輪護欄：
- everyday / soft stage 優先由 practical light、窗光、交通燈、設備燈等形成 focus。
- 真正 hard spotlight 留俾更高強度場面，避免一有情緒就 literal stage cue。

## 7. Environmental Choreography：世界「參與演出」

### 參考出發點

作者指出《小圓》電影版有一種重要魅力：
- 世界平時存在嘅元素會「剛好」參與感情場面，例如空中飛行物嘅燈光剛好成為人物背光。
- 作者喜歡「世界好似活住」呢個層次，但唔想 Haruka 直接沿用同一種 statement / 表演方法。

### DRAFT — Haruka 自己嘅方向

本輪幾個候選工作句，**未全部定案**：
- 「在 Beta，情感會被整理成一幕。」
- 「世界唔只配合情感，而係將情感整理成可被看見嘅形式。」
- 「Response is not mood-matching; it can become over-interpretation.」

作者要求下一步要喺呢個層次搵到**同本作主題有關、可以無限延伸**嘅 statement，而唔係單純複製「世界偶然配合人」。

## 8. 本輪最重要新增：Dual Overexposure（願望／恐懼雙向過曝）

### AC-12 — 強烈世界反應唔係只變恐怖；會「極端甜 + 極端心理恐怖」同步上升

作者明確指出：
- 如果世界對某件事反應夠強，唔應只係變得更黑、更恐怖。
- **甜同恐怖應該一齊上升。**
- 可以係極端幸福、可愛、漂亮、好人／值得被保護嘅少女，偏偏同時遭遇極殘酷、極冷漠、極剝奪主體性嘅對待；正因甜仍然成立，殘酷先更加痛。

### AC-13 — 呢個唔係「甜先出現，然後裂開露出黑」

兩種演出都可以存在：
- 故事揭露節奏仍可用「甜下見黑」。
- 但**世界強反應模式**可以係「願望與恐懼同時過曝」。

即：
- 甜度 ↑
- 可愛／祝福感 ↑
- 舞台精準度 ↑
同時
- 恐懼 ↑
- 哥德／囚禁 ↑
- 被觀看／無退路 ↑

### AC-14 — 極端甜源自晴香五歲對「幸福」嘅幻想

Beta 既然由五歲晴香極端狀態重寫：
- 她對「甜／幸福／魔法少女動畫式好日子」嘅想像理應寫入願望側。
- 世界強烈回應時，願望層唔只係粉色，而係會努力將場面整理成「幸福應該長成嘅樣」。

### 敏感內容護欄

作者以極端剝削作情緒標尺，並提到腦中有更涉及性剝削程度嘅畫面，但冇提供具體內容。
本記錄只保留**設計層意思**：
- 身體定義權被奪
- 私密權被奪
- 拒絕權／停止權被奪
- 傷口被重新命名、包裝、展示、消費
- 畫面越甜，主體性剝奪可以越刺眼

涉及少女角色時，後續視覺執行**不可靠性化未成年角色**去達成呢層殘酷；用舞台、觀看、身體自主／私密／停止權、制度處理等語言處理。

## 9. 三種「甜」必須分清

### AC-15 — 真暖（Host Warmth）

來源：人。
- 分享食物
- 糖水舖
- 留低陪伴
- 幫對方整理
- 有地方坐低呼吸

真暖唔應被作品反轉成「全部都係假」。

### AC-16 — 願望甜（Wish Sweetness）

來源：五歲晴香創世願望層。
- 動畫理想化
- 青春畫面
- 可愛、漂亮、略過度適合故事發生
- 學校／公園等印象強區域更明顯

願望甜本身唔一定邪惡。

### AC-17 — 過曝甜（Overexposed Sweetness）

當世界反應過強：
- 可愛得太準
- 幸福構圖太精準
- 光線太像祝福
- 一切過度適合被觀看
- 甜同恐懼同步加強

呢個係本輪希望發展成 signature 嘅區域。

## 11. 哥德：Fear dialect，唔係「一有異常就黑鐵」

### AC-20 — 歌德要 under 同一個 world-response system

作者要求歌德唔可以同本輪系統分開。

新定位：
- 歌德仍保留 Beta-only、晴香恐懼寫入、CDL-412 惡化／不可退可變質等既有 canon。
- 喺環境反應層，**歌德係 Fear-side motif dialect / output language**。
- 唔等於每一個異常都必須長黑鐵。

### Fear-side 功能候選

歌德更適合表示：
- 固化
- 過度對稱
- containment
- 囚禁
- 吸光
- 將一刻固定
- 移除退路

而唔只係「黑暗裝飾」。

### 與 Dual Overexposure 嘅關係

極端狀態可以：
- 願望甜仍然甜
- 哥德恐懼仍然哥德
- **兩者同時變強，而唔係甜腐爛成黑**

  - identify
  - classify

  - isolate
  - expose
  - remove
  - record
  表現。

- 舞台 focus 可以同行政 focus 接線：被照亮既可以係「有人看見你」，亦可以係「系統鎖定你」。

此為 directing research reference，唔係新世界機制。

## 18. Production / Visual Development workflow research 結論

本輪查 industry visual-development 做法後，收斂：

1. **Imageboard / mood key**：先證明世界有冇 feel。
2. **Layout / spatial grammar**：固定 camera，研究空間、人物、透視、距離。
3. **Color / light keys**：固定 set，只改 lighting / value / color。
4. **Environment behavior / ambient world**：研究世界本身點生活、點活動。
5. **Motif studies**：金魚、歌德、甜、舞台等逐套獨立測。
6. **Mechanism study**：同一 shot 分拆 Wish only / Fear only / Stage only。
7. **Composite imageboard**：最後先將已驗證元素合埋。

完整 provisional pipeline 見 `BETA_VISUAL_DEVELOPMENT_PIPELINE_DRAFT.md`。
