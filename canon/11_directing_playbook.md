## <a id="section-theme-core"></a>主題中樞（不可偏離）

**本作唯一主題中樞**：**態度 vs 命運**

《晴香》不是靠打贏命運來完成治癒，而是靠角色在不可控命運面前，仍然選擇以什麼態度活下去。

**黑暗治癒的作品立場**：

| 現實 | 作品立場 |
|-----|---------|
| 痛苦不會被消除 | 仍然承認痛苦的重量 |
| 命運不因善良而放過人 | 仍然呈現殘酷的真實 |
| 力量不會免費 | 仍然要求代價的可見性 |
| 連結也不保證好結局 | 仍然相信連結的意義 |

**演出禁忌**：導演手法不得令觀眾誤會「溫柔有罪」、「希望有罪」、「脆弱有罪」。

**本作打出的核心感覺**：世界很殘酷，但人與人之間的小小承接，仍然有重量。

> 另見：[Narrative Design Bible §態度 vs 命運](08_narrative_design_bible.md#section-attitude-destiny)、[Narrative Design Bible §黑暗療癒系統](08_narrative_design_bible.md#section-dark-healing)（完整機制定義）

## <a id="section-director-reading"></a>導演層角色閱讀

**核心鏡頭語言**：主角群是被需要、然後被寄託、最後幾乎被消費的人。

此句作為演出與場景設計時的閱讀框架，**不升格為世界觀核心術語**。

**導演層的具體詮釋**：

| 行為模式 | 解釋 |
|---------|------|
| 主動壓抑，不讓崩壞太明顯 | 她們比正常人更早學會把情緒壓後 |
| 把整理姿態優先於表達痛 | 功能性活著的外在體現 |
| 先安慰人，後來才自己崩 | 情緒延遲的根本原因 |
| 不自覺把痛延後 | 代價的滯後性 |

**導演功能**：
- 解釋角色「功能性活著」的機制
- 解釋角色為何先整理自己、後來才崩
- 解釋「維持姿態」比「即刻發洩」更常見
- 解釋承接儀式的重要性

## <a id="section-three-verbs"></a>三個導演主詞

全作導演語言統一在三個動詞：**維持 / 承接 / 埋單**

### <a id="verb-maintain"></a>維持（Maintain）

**定義**：不是體面，不是漂亮。是：明明快散，仍然要整理成可以被看見、被依賴、被使用的樣子。

| 具體表現 | 導演讀法 |
|---------|---------|
| 整理儀容、拉正領口、綁絲帶 | 可愛由天真變成戰鬥姿態 |
| 戴好手套、擦乾淨血、固定姿勢 | 壓迫感轉化成一套熟練程序 |
| 試笑、試聲、深呼吸後抬頭 | 「她不是沒事，只是做熟了」 |

**設計鐵則**：「維持」動作必須令觀眾感受到：她不是沒事，只是先處理了應該扮成的樣子。

---

### <a id="verb-receive"></a>承接（Receive）

**定義**：不是拯救，不是修好，不是立刻治療成功。是：在一個人快散的時候，幫她撐多一下。

| 具體表現 |
|---------|
| 漱口、遞水、扶住坐下、托住後頸 |
| 抹血、梳頭／綁頭髮 |
| 幫她講出口、陪著走 |
| 吵架後仍然留下 |

**導演功能**：這是本作**最重要的治癒語言**。不是「我令你不痛」，而是「你不必一個人痛」。關係建立不靠台詞，而靠可重複的具體動作。

---

### <a id="verb-pay"></a>埋單（Pay the Tab）

**定義**：不是懲罰機制。是：最後總有人要承受後果——問題是，是否永遠都是同一個人。

| 具體表現 |
|---------|
| 身體代價：嘔吐、掉牙、失聲、手震 |
| 夢境／記憶污染 |
| 情緒回聲、拖延後的崩壞 |
| 由別人代受、代站、代答、代頂 |

**導演功能**：令「用力拯救」不會變得免費。令「承接」成為真正有重量的行為，因為總要有人埋單。

## <a id="section-first-layer"></a>第一層氣氛手法

**核心法則**：本作最重要的氣氛手法不是對比，而是：

> **重覆變奏 / 延遲 / 錯位**

這三者是第一層手法，因為它們最直接作用於觀眾的感官與心理不安。

---

### <a id="technique-repetition"></a>重覆變奏（Repetition with Variation）

**定義**：同一個動作、儀式、說話、構圖不斷出現；但每次的情緒意義都變深、變痛、變扭曲。

**為什麼重要**：《晴香》的痛不是一次性 twist，而是同一種東西不斷回來：同一種溫柔、同一種姿態、同一種代價、同一種無法好好退場的狀態。

**設計原則**：

| 出現次序 | 功能 |
|---------|------|
| 第一次 | 建立 |
| 第二次 | 加深 |
| 第三次 | 扭曲 |
| 最後一次 | 回收，變成心碎 |

**最適合重覆變奏的元素**：梳頭、綁絲帶、整領口、試笑、漱口、抹血、上台前停一秒、「坐好先」、陪著走一段

**禁止**：
- 同一動作只重覆不變奏 = 符號濫用
- 每次都比上次更誇張 = 過度刻意
- 重點是「同一個動作，意義被時間與關係改寫」，而非數量

---

### <a id="technique-delay"></a>延遲（Delay）

**定義**：角色的情緒、痛楚、代價，不在當下完全爆出，而是被迫延後。

**為什麼重要**：這是本作壓迫感的核心之一。正常人先痛、先亂、先反應；本作角色先撐住、先處理人、先整理自己，之後才痛。

**延遲的三個方向**：

| 方向 | 模式 | 例子 |
|-----|------|------|
| **情緒延遲** | 先安慰人，之後才崩；先笑，後散 | 場面話說完，轉身才手抖 |
| **身體延遲** | 戰鬥完沒事，一落台才嘔；先處理現場，之後才掉牙／失聲 | 與正常受傷反應相反 |
| **理解延遲** | 當下麻木，後來才意識到發生什麼；夢裡、夜裡、既視感時，才真正中招 | 遲來的衝擊時刻 |

**導演功能**：令觀眾感到她們連崩潰都沒有權利即刻崩。令代價有「回頭追上」的感覺。令「先做功能，再做自己」成為作品的壓迫節奏。

**禁止**：不可每次都完全延遲，否則角色變成機械。必須保留少量當下裂痕，讓觀眾知道她不是無感覺。

---

### <a id="technique-misalignment"></a>錯位（Misalignment）

**定義**：應該同步的東西，不同步。嘴與眼、身體與語言、溫柔與傷害、舞台與戰場，永遠差半拍。

**與對比的區別**：
- **對比**：A vs B（分開呈現）
- **錯位**：A 與 B 同時存在，但無法完全咬合

| 錯位方向 | 例子 |
|---------|------|
| 笑容已出來，眼神未到 | 情緒比表情慢半拍 |
| 說「沒事」時手其實震緊 | 語言與身體不同步 |
| 少女式動作仍然優雅，但身體已開始壞 | 美感與代價同框 |
| 照顧場面很溫柔，但杯裡有血 | 溫柔與傷害共存 |
| 舞台燈光甜美，但人正在功能性活著 | 表象與內在不同步 |

**導演功能**：令觀眾覺得「她還在，但某部分已經不在」。令作品不止是甜美 vs 噁心，而是兩種狀態卡在同一個身體裡。

**禁止**：錯位不等於混亂。要精準地錯半拍，而不是所有東西都歪掉。最有效的錯位，通常發生在最平靜、最日常、最應該自然的時刻。

## <a id="section-second-layer"></a>第二層結構手法

第二層手法負責強化主題、製造前後呼應、建立 Alpha/Beta 回聲、整理角色關係。它們不是第一下就製造不安，而是令整體結構有意義。

### <a id="technique-contrast"></a>對比（Contrast）

**功能**：講清楚作品想說什麼，而不是直接製造恐懼感。

| 對比軸 |
|-------|
| 正常人 vs 主角群 |
| 私人的我 vs 公共的我 |
| 假糖 vs 真暖 |
| 被需要 vs 被消費 |
| 日區烏托邦表象 vs 真實情緒壓迫 |

---

### <a id="technique-mirror"></a>鏡像（Mirror）

**功能**：強化命運回響、讓關係的承接有結構、讓作品有「所有事都在回流」的感覺。

| 鏡像模式 | 例子 |
|---------|------|
| 動作回還 | 我幫你梳頭，之後你幫我梳頭 |
| 台詞回還 | 某句話被另一人返還 |
| 位置回還 | 上次你扶我，今次我扶你 |
| Alpha 扭曲回聲 | Alpha 的姿態在 Beta 以扭曲方式重現 |
| 可能性映照 | 某角色與自己的另一種可能性互相映照 |

---

## <a id="section-ritual-framework"></a>共同儀式框架

**核心定義**：儀式不是零碎小動作的清單，而是角色從一個狀態切換到另一個狀態的結構。

| 儀式 | 狀態切換 | 具體動作 |
|-----|---------|---------|
| **入場儀式** | 私人 → 公共 | 上台、入光區、報位、整理、試聲 |
| **維持儀式** | 完整 → 撐住 | 抹血、整領、綁帶、站直、固定姿勢 |
| **失衡儀式** | 撐住 → 開始壞 | 手震、耳鳴、失焦、喉嚨不對、想吐、停一秒 |
| **承接儀式** | 一個人硬頂 → 被另一個人接住 | 漱口、遞水、托後頸、梳頭、扶住 |
| **交接儀式** | 我頂 → 我們頂 | 代站、代答、代受、擋目光、說場面話 |
| **退場儀式** | 功能狀態 → 做回自己 | 坐下、卸下某物、肩跌落去、終於肯讓人扶 |
| **埋單儀式** | 借力 → 承後果 | 自我檢查、記錄、避開某物、夢境污染、還債行動 |

**設計鐵則**：每個儀式場景必須清楚標示「正在發生哪種狀態切換」，而不是把動作作為裝飾。

## <a id="section-functional-living"></a>表情麻木與功能性活著

**核心定義**：本作的壓抑氣氛不是角色沒有情緒，而是角色比正常人更早學會把情緒壓後、把姿態放前。情緒沒有死，只是未被准許出現在臉上。

**與正常人的差異**：

| | 模式 |
|-|------|
| **正常人** | 先情緒，再動作 |
| **主角群** | 先功能，再情緒 |

**三種麻木類型**：

| 類型 | 表現 |
|-----|------|
| **功能性麻木** | 笑得出，眼神未到；說話正常，臉太靜 |
| **斷線式麻木** | 望著你，但人好像不在；當下無感，之後才中招 |
| **卡住式麻木** | 表情停在錯誤位置；微笑停太久、瞳孔太定、嘴角未收回 |

**使用原則**：
1. 先用「細微不對路」建立
2. 再用「明顯卡住」加深
3. 不要一直用最重版本

## <a id="section-cost-visibility"></a>代價上鏡原則

**兩層代價結構**：

| 層次 | 類型 | 頻率 | 內容 |
|-----|------|------|------|
| **第一層（主）** | 身體代價 | 常見 | 喉嚨乾、手震、失焦、牙齦出血、耳鳴、嘔心、嘔吐、掉牙 |
| **第二層（副）** | 夢境／記憶代價 | 少用 | 現實感被偷走、記憶真假不明、Alpha 幸福感滲入造成空心感、夢裡的自己比現實更完整、醒來更痛 |

**原則**：
- 身體代價不應一開始就最重；必須累積
- 夢境代價不應太密，否則搶掉身體恐怖的效果
- 施法代價是肉身性的；連結與主題的重量是關係性的

> 另見：[World Rules §代價系統](01_world_rules_and_costs.md)、[Narrative Design Bible §代價設計原則](08_narrative_design_bible.md#section-cost-design)

## <a id="section-atmosphere-guideline"></a>不安氣氛總方針

《晴香》的不安，不靠大驚嚇，也不靠單純反差。它主要來自：

> **重覆變奏、延遲與錯位，令角色的溫柔、功能、崩壞與姿態，永遠差半步同步。**

**具體感覺**：

| 外在狀態 | 實際狀態 |
|---------|---------|
| 她仍然在笑 | 笑得不對 |
| 她已經受傷 | 但沒有資格即刻痛 |
| 她被照顧 | 但仍想自己坐直 |
| 她做著最溫柔的動作 | 但整個人快散 |
| 她退場了 | 但某部分仍然未退場 |

## <a id="section-director-slogans"></a>導演工作標語

以下句子作為分鏡、劇本、遊戲事件設計時的內部對焦語句：

> 最殘酷的不是受傷，而是受傷之後還要整理好自己。

> 真正的治癒不是治好對方，而是不再讓最願意承擔的人一個人埋單。

> 她不是沒事，她只是先處理了自己應該扮成的樣子。

> 本作的不安，來自一切都差半拍同步。
