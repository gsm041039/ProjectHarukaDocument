## <a id="section-theme-core"></a>主題中樞（不可偏離）

**本作唯一主題中樞**：**態度 vs 命運**

《晴香》不是靠打贏命運來完成治癒，而是靠角色在不可控命運面前，仍然選擇以什麼態度活下去。

**黑暗治癒的作品立場**：

| 現實 | 作品立場 |
|-----|---------|
| 痛苦不會被消除 | 仍然承認痛苦的重量 |
| 命運不因善良而放過人 | 仍然呈現殘酷的真實 |
| 力量不會免費 | 仍然要求代價的可見性 |
| 連結也不保證好結局 | 仍然相信連結的意義 |

**演出禁忌**：導演手法不得令觀眾誤會「溫柔有罪」、「希望有罪」、「脆弱有罪」。

**本作打出的核心感覺**：世界很殘酷，但人與人之間的小小承接，仍然有重量。

## <a id="section-body-debt-axis"></a>身體代價 × 債務——全劇世俗概念主軸（CDL-365，暫定）

> ⚠️ **狀態：暫定（Tentative）**。本節係作者同AI長篇討論嘅收斂結果，用嚟回答「主題點樣變成一睇就認得出嘅獨特導演語言」，參照 WH40K「血肉 × 信仰」嘅方法論——**唔係一件裝飾符號，而係兩個唔使解釋、人人已經識嘅世俗概念，喺個人同社會兩個規模同時運作**。作者明確話「暫時用」，日後可以再修正，唔屬於不可逆嘅硬決定。

### 核心公式

**血肉半 ＝ 身體代價（唔使magic vocabulary）**——已有嘅[代價上鏡原則](#section-cost-visibility)：牙齦出血、手震、掉牙、嘔吐、失焦、耳鳴。呢啲係純肉身現象，觀眾唔使識心之器/情緒結晶呢類魔法機制都即刻感受得到，同WH40K「血肉」嘅零門檻程度對等。

**信仰半 ＝ 債務（唔使magic vocabulary）**——已有嘅制度骨架：[維多利亞之淚](07_entities_and_devices.md#section-org-victoria)係「情緒經濟體系的中央銀行」；[潘朵拉協議](01_world_rules_and_costs.md#rule-pandora-protocol-mechanics)將剝削包裝做表演義舉；`02_glossary.md` Alpha線＝債權人、Beta線痛苦＝情緒債務。呢個係人人一聽「呢筆數要還」「利息計埋」就明嘅世俗概念。

**唔係核心嘅嘢**：情緒結晶/心之器/光環呢類魔法詞彙唔係「血肉」本身，佢哋只係世界觀入面解釋「點解身體會咁樣爛」嘅內部機制（好似WH40K都有warp/machine spirit呢類玄學解釋，但主視覺始終係血肉同教堂）。**偶像**（晴香/凜嘅還債表演形式）只係魔法少女專屬嘅**最窄一層**，唔係世界觀主軸，唔應該套用落其他角色。

### 命運＝最闊嘅普世層

情緒守恆定律（代價一定存在、唔會消失只會轉移）先係人人都食到嘅底層——包括普通人、魔法少女、魔法屍骸。「身體代價×債務」係呢條普世定律喺個人／制度規模嘅具體顯化形式。

### 債務嘅心理運作鏈（CDL-380，正式）

> 作者2026-08-11確認：呢條鏈**唔係另一條底層規則**，係「身體代價×債務」入面「債務」半嘅心理機制細節，負責講清楚傷口點樣一步步變成索取權同自我剝奪。源自2026-08-10討論記錄§6.1，經9-agent審核後由作者正式收編入本節。

```text
傷口／缺口
→ 需要
→ 救援／意義／控制／連結
→ 交換
→ 債務
→ 索取權／解釋權／使用權
→ 自我監視／自我剝奪
```

呢條鏈套用範圍唔限於魔法少女制度或直播——家庭、隊友、身份、戰鬥、魔法、奇蹟、制度、UI、玩家互動都適用，同下面「債務生成嘅兩種心理機制」（逃避型/成癮型）係同一層級嘅互補描述，唔互相取代。

### 債務生成嘅兩種心理機制（唔係全部都係逃避）

- **逃避型（被動）**：唔想面對傷口，戴人格面具頂住（Persona＝變身，已有 [Jungian具現化系統](12_philosophy_and_systems.md#section-jung-individuation)），債喺背後靜靜雞累積。大部分角色/日區市民屬呢種。
- **成癮型（主動，「瘋癲借」）**：明知有代價，但控制唔到自己要再借——已有正式機制：[心防內化裝置第三層「成癮性代償回饋」](07_entities_and_devices.md#section-trauma-cage)（「只有在摧毀時才能暫停痛苦」嘅病理代償循環）；紫音「毒品化」coping同父母嘅情緒膠囊成癮係活人示範。兩種機制心理質感唔同（唔望 vs 望到都要撲埋去），唔可以混為一談。
- **候選第三種（未夠肯定）**：代人還債／犧牲型（明知透支都要幫第二個人扛，晴香拯救者情結/美夜子守護姿態疑似屬此類）——未經充分查證，唔落實。

### 個人規模 vs 社會規模——同一條邏輯嘅兩個尺度

| 規模 | 戴面具（借債） | 陰影（未還本金） | 逃避太耐嘅強制執行 |
|---|---|---|---|
| **個人** | 變身／表演（Persona） | 未處理嘅創傷（夕／陰影） | [屍骸化](02_glossary.md#term-magical-corpse)（個人債務違約，尤其「求救型/贖罪型」屍骸——生前逃避罪疚，死後被迫不斷重複同一個未完成嘅還債動作） |
| **社會** | 「一切受控，交畀帝國」嘅集體迷思（日區） | 夜區承受嘅歌德侵蝕／集體創傷 | [緋潮](02_glossary.md#term-scarlet-tide)（社會債務違約，「膠布發炎」） |

### 普通人嘅債務（唔止偶像先食到）

- **Emo-Visor 民用網絡**：全城市民情緒每日被自動收割（已有機制，`07_entities_and_devices.md`§心防內化裝置），普通人唔知情況下已經被「扣糧」。
- **奇蹟販賣所**（CDL-364）：普通人主動走入去嘅債務交易，本金未還先孭利息。
- **夜區居民**：結構性繼承嚟嘅債，冇借過錢但要還。
- **日區居民**（**已確認，CDL-366**）：主觀相信自己幸福滿足（新增，非表演），疊加「客觀表情麻木、被過濾掉活力」（`06_visual_bible.md`原有描寫，唔改動）——兩者角色自己接唔埋，代價每時每刻寫喺自己塊面度，但佢哋自己唔認得。

### WH40K式吸引力手法（已篩選，否決咗唔啱嘅一招）

- **裝飾隨代價累積更精緻**：唔使新機制，直接用返現有[三階段鏡像系統](06_visual_bible.md#section-magical-girl-mirror-stages)（夢幻鏡→裂縫鏡→囚獄鏡），扣返債務語言講。
- **日常語言滲透財務術語**：對白入面滲入「呢期未清」「利息計埋」呢類詞彙，唔淨係大場面先用。
- **觀眾/粉絲共犯化**：候選方向，愛意/應援本身可以讀做只還得起利息、還唔到本金嘅資源。
- **❌ 已否決：「用建築規模令個人渺小」**——直接違反[不安氣氛總方針](#section-atmosphere-guideline)已有嘅核心感覺聲明（世界很殘酷，但人與人之間的小小承接，仍然有重量）。**正確做法**：規模對比嘅落點必須贏返去細動作嘅重量，唔係證明個人幾渺小。

### <a id="section-body-debt-stress-test"></a>十輪壓力測試後嘅精修版（CDL-369）

> 完整推理過程（包括全部被推翻嘅候選同推翻理由）記錄喺 [`REASONING_LOG.md` Round 127續](_working/REASONING_LOG.md#round-127-續-2026-08-04-身體代價債務主軸壓力測試10輪sub-agent討論完整推理過程cdl-369)。本節只保留最終落實嘅三件事同兩條guardrail。

上面嘅框架經過十輪獨立agent對話壓力測試之後，收斂做**三件事**（原本六個候選被砍剩三個），因為原版本嘅缺口係「身體代價」同「債務」大部分時間係兩條並排嘅描述線，而唔係一件同時做緊兩份工嘅實物（唔似WH40K servitor＝血肉+勞動+崇拜三合一）。

**保留（non-negotiable）**：
1. **核心公式**——身體代價×債務，見上節，冇佢就冇框架。
2. **個人／社會規模對稱**——人格面具→陰影→屍骸化（個人）鏡照集體迷思→吸收→社會總崩潰（社會），**呢個先真正贏得返同WH40K嘅比較**——冇呢層，成套嘢只係一個角色心理框架加代價機制，唔係世界運作系統，「規模」先係成個比較嘅前提。

**保留並升格做主要道具/制度規模錨點**：
3. **強制續期嘅身份證明文件**——市民定期用自己收割落嚟嘅痛苦當墨水，簽署/續領身份文件；**必須係佢自己嘅痛苦入佢自己嘅文件（自我指涉、單一），唔可以係匿名底層階級嘅工業墨水供應**（否則打返做可替換商品，重開結晶做貨幣個陷阱）；窮區全額付款且痛，富區有補貼、幾乎冇痛，令呢件官僚道具同時係②社會不公引擎嘅實體證據，唔止係「有間office存在」；辦公室嘅貪污文員係地下經濟情報嘅實際漏料源頭，令合法/非法抽取係同一條稅嘅兩條喉，唔係兩件巧合相似嘅事。

**降格做免費附帶規則（唔使獨立場景/資源）**：
- 逃避型／成癮型債務生成心理——做author-facing嘅一致性透鏡，寫任何角色嘅代價場面時應用。
- Tell固定文法（咬嘴唇/嗤笑彈開/手震喺**主動俾緊代價**嗰刻變成固定次數、固定節奏，非「主動俾嘢」時維持有機可變）——係表演/導演指示，唔係scripted beat，可以疊落上面三件事要求嘅任何場景，唔使加新資產。

**降格做劇情推進裝置（唔claim做signature）**：
- 央行建築本身（維多利亞之淚）隨全城債務浮現可見年輪/分段——保留做非語言嘅act-break/升級全城賭注觸發器（扣連Consequence-Driven Progression Law對外部cost signal嘅要求），但唔係道具規模嘅簽名，因為冇指定年輪係有機物質組成就只係一個裝喺建築度嘅資訊圖表。

**已否決（proof-of-concept設計筆記保留，唔升級做production commitment）**：
- 情緒結晶做流通貨幣——可替換性陷阱，直接違反「代價=傷口必須不可替換」嘅原則。
- 認名酒莊式黑市交易（單一角色被唔知情噉「追捧」）——揭發咗一個有價值嘅角度（可以商品化非自願可見性，觸及成日避開鏡頭嗰批角色）同一個心理設計（「想被想要嘅一閃即逝，先俾人拆穿要嘅係傷口唔係自己」，比乾淨嘅侵犯感更狠），但作為production commitment太貴（自己嘅subplot/cast）、覆蓋太窄（一個角色）——而家嘅身份證明辦公室已經用更平嘅方式做到同一個功能（強制/普世/非自願，透過官僚式恐懼觸及逃避型角色）。
- 獨立嘅「數手指」還債儀式手勢——太通用（讀成安撫stim），仲會扁平化現有已分化嘅角色tell；已用「固定文法/可變詞彙」原則取代。

### 兩條production guardrail（可checkable，唔係抽象提醒）

**Guardrail一——身份證明辦公室場景**：佢喺場入面嘅行為必須同一個普通人喺度填例行文件冇分別——悶、可能仲因為等得耐有啲燥、玩緊電話。**如果任何一個take note/剪接指示/走位note叫佢「表現出啲感受」，呢個就係場戲走樣嘅信號**。原因：呢場戲嘅論點（沉悶比宏偉更能收埋恐怖）依賴住場入面冇任何人（包括佢自己）將呢件事當成有意義；一旦有一格可見嘅「認知」，就即刻同觀眾講咗「佢知道」，直接推翻已確立嘅心理設定（佢唔知道，呢個先係悲劇所在）。呢個係接近default嘅失敗模式（導演「克制」遠遠難過導演「強調」），寫Beat Sheet時要明文警告。

**Guardrail二——個人/社會fractal**：任何一場戲（個人定社會規模）都要通過「**邊個最終埋單，佢當初有冇得揀？**」呢條check——必須係「俾緊代價嘅一方唔係製造呢筆代價嘅一方，而且呢筆款係之後先、非自願噉被追討」。如果受苦嘅人同造成代價嘅人係同一個、而且而家清醒自願噉俾緊——嗰係另一種合理嘅故事邏輯，但唔係呢條fractal，已經漂去「種瓜得瓜」嘅普通因果，唔係逃避驅動嘅置換。**捕捉條件係「置換+延遲+非自願」三者缺一不可**——呢層冇單一場景可以綁死嘅guardrail，要靠寫作時人手check，屬於多編劇製作最容易靜靜雞流失嘅嘢，須特別留意。

## <a id="section-stage-language"></a>舞台×傷口——顯式導演語言（CDL-380，正式確認）

> ✅ **狀態：正式確認**（2026-08-11，作者就QQ-210正式拍板），源自2026-08-10作者討論記錄（`_working/2026-08-10_STAGE_WOUND_LIVESTREAM_MIRACLE_DISCUSSION_LOG.md`）經9-agent審核（`_working/2026-08-11_STAGE_WOUND_MULTI_AGENT_AUDIT_REPORT.md`）後由作者定案。**本節係[身體代價×債務](#section-body-debt-axis)嘅顯式呈現層，唔係平行嘅底層規則**——舞台×傷口用嘅仍然係現有維多利亞之淚／潘朵拉協議／情緒經濟系統，負責回答「呢條底層公式喺鏡頭、服裝、剪接、聲音、招式上實際睇落係點」。討論記錄提出嘅七步鏈已正式收編入[身體代價×債務§債務嘅心理運作鏈](#section-body-debt-axis)，唔係另一條獨立doctrine；完整層級關係見[全劇導演語言層級圖](#section-layer-map)。

### 舞台做緊咩

私人傷口被睇見 → 被解讀 → 被加工成美麗／希望／榮耀／娛樂 → 被交換、重播、記錄或使用 → 產生新期待 → 代價回到某個人身上。

呢個唔係新增系統，係將已經存在嘅機制用同一套鏡頭/表演語言講出嚟：[Reality Show戰鬥直播](01_world_rules_and_costs.md#rule-pandora-protocol-mechanics)、[光幕濾鏡](02_glossary.md#term-light-veil)、[維多利亞之淚](07_entities_and_devices.md#section-org-victoria)、[膠布哲學](02_glossary.md#term-band-aid-philosophy)。

**核心問題唔係「呢個表演靚唔靚」，而係**：
- 邊個整理出呢個形式？
- 邊個有權觀看、解讀、使用、保留或者重新命名佢？
- 代價最後落到邊個度？
- 表演者有冇取回停止權？

### 最小舞台grammar：成形 → 裂口 → 結算／取回

> 呢套三拍**唔取代**[三個導演主詞](#section-three-verbs)（維持/承接/埋單），係舞台×傷口專用嘅最小事件節奏描述，兩套並存、各司其職。第三拍正式定名「結算／取回」（唔叫「埋單」），避免同三個導演主詞撞字。

| 拍子 | 核心問題 | 同三個導演主詞嘅關係 |
|---|---|---|
| **成形** | 邊個整理出可觀看/可使用嘅形式？ | 約等於[維持](#verb-maintain)，但唔完全等同——維持係持續動作，成形強調「被整理成形式」呢個結果狀態 |
| **裂口** | 傷口／矛盾點樣穿過形式露出？ | 係[共同儀式框架](#section-ritual-framework)「失衡儀式」被睇見、被外化嘅階段 |
| **結算／取回** | 代價落喺邊個度？表演者攞唔攞返停止權？ | 包含原有[埋單](#verb-pay)概念（代價落點），並加多「取回停止權」呢層新意思——原有「埋單」動詞唔改，只係舞台grammar第三拍改用呢個新名 |

三拍可以由任何一拍開始，可以只出現兩拍，或刻意留白；審核時要辨認留白是設計選擇還是缺漏。

### 劇內觀看位置

> 舊稱「觀眾」，2026-08-11就QQ-210正式改名，避免同[AKS系統](13_major_events_relationship_impact.md)嘅「觀眾」（戲外讀者敘事認知狀態）撞名。「觀眾」一詞喺本文件以外**保留做一般敘述用語**，唔再作正式系統術語使用；正式系統術語一律用「劇內觀看位置」。

劇內觀看位置係一個觀看位置，唔係固定嘅道德身份，包括角色自我觀看：

| 觀看位置 | 可能的態度 |
|---|---|
| 消費式 | 因為我被你感動，所以我有權要求你再給我一次 |
| 審判式 | 不斷檢查自己夠不夠好、夠不夠自然、值不值得被愛 |
| 理解式 | 看見痛苦，但不急於替對方定義 |
| 陪伴式 | 知道對方受傷，卻不要求對方把傷口變成表演 |
| 見證式 | 記得事情發生過，但不把記錄變成擁有權 |

同一個角色可以同時處於多個觀看位置（例如舞台上嘅表演者、同時係觀看隊友嘅人）；自己可以係自己嘅觀眾，陰影可以係最早最清楚嘅觀眾。

> 「見證式」觀看位置嘅完整心法、四個變質陷阱同beat級檢驗問題，見[Narrative Design Bible§見證守則（CDL-392）](08_narrative_design_bible.md#section-witness-principle)。

### 兩個時期dialect——即時直播 vs 殘留影像（CDL-382，正式）

> 作者2026-08-12就QQ-209①正式拍板，解決「後期繼續直播」同[維多利亞之淚摧毀](07_entities_and_devices.md#section-org-victoria)（CDL-321）+隊伍匿藏（CDL-203）嘅表面衝突。完整硬限制見[維多利亞之淚§摧毀後果](07_entities_and_devices.md#section-org-victoria)。

| 時期 | 舞台形式 | 同已confirm設定嘅關係 |
|---|---|---|
| 113年7-8月至114年5月（維多利亞之淚摧毀前） | 即時直播／光幕系統仍運作 | 隊伍匿藏但基建未壞，即時觀看可以存在，唔撞匿藏設定 |
| 114年5月之後（摧毀後） | 殘留影像舞台——舊片段回放、二次創作、帝國重新解讀、城市螢幕重播 | 唔可以重新建立同等即時直播基建（硬限制）；角色已經唔喺場，但傷口仍然被觀看/解讀/消費 |

摧毀之後嘅「殘留影像舞台」反而更貼近舞台×傷口嘅核心命題：表演者唔需要親身在場，都可以持續被加工、被交換、被索取。

### 三重疊材料

舞台畫面可以由以下三種材料組成，可以只出現部分，唔使每次齊全：

| 材料 | 功能 | 現有先例 |
|---|---|---|
| 完整美學 | 華麗、精準、可愛、神聖，像成功演出的表面 | 破碎的美學、三階段鏡像系統夢幻鏡（`06_visual_bible.md`） |
| 傷口 | 被壓住、遮掩、滲出或突然暴露的個人代價 | [代價上鏡原則](#section-cost-visibility)、服裝的失控顯化（`06_visual_bible.md`） |
| 怪物 | 傷口被外化、放大，或被制度／命運塑造成可攻擊的形體 | 屍骸視覺系統、GAP-56裝置使用者複合視覺（`06_visual_bible.md`） |

**設計鐵則**（比照GAP-56「不可只呈現一層」嘅硬規則）：三重疊唔可以淨係得符號對比（例如純粹「靚外表+突然嘅黑暗」），必須連住一個具體代價落點——邊個身體、幾耐、換嚟咩；「怪物仍然漂亮」呢類意象必須連住GAP-56人性殘響規則，避免扁平怪物化、淪為純美術炫技。

### 身體凝視限制

有限度使用身體凝視嘅場面，核心必須係：

> 角色發現自己的身體不再由自己定義，反而成為別人判斷、解釋、使用及要求的證據。

執行前必須逐項自問：
- 角色是否失去拒絕權？
- 是否失去解釋自己身體／傷口的權利？
- 是否失去保留私人部分的權利？
- 是否失去停止提供自己的權利？
- 身體反應是否被別人重新命名為可愛、真誠、證據、娛樂或責任？

可用材料：失控呼吸、手震、站姿、聲線、傷勢、疲勞、數據、服裝限制、想遮住卻被看見的反應。**唔可以用性感展示取代呢層心理描寫**。現有安全先例：操GAP-76變身1幀臨床白光（用瞬間閃光+手術室語境做到「身體被凝視」而唔靠停留鏡頭，`06_visual_bible.md`）；凜變身「身體不完全是她的身體」（`03_characters/rin.md`）。

**已知缺口（留待後續設計，唔阻本節生效）**：鏡頭時長/角度嘅明確節制規則未定；著裝過程半透明布料貼身（`06_visual_bible.md`）配合身體凝視鏡頭時嘅風險緩解，未有硬性上限規定。

## <a id="section-director-reading"></a>導演層角色閱讀

**核心鏡頭語言**：主角群是被需要、然後被寄託、最後幾乎被消費的人。

此句作為演出與場景設計時的閱讀框架，**不升格為世界觀核心術語**。

**導演層的具體詮釋**：

| 行為模式 | 解釋 |
|---------|------|
| 主動壓抑，不讓崩壞太明顯 | 她們比正常人更早學會把情緒壓後 |
| 把整理姿態優先於表達痛 | 功能性活著的外在體現 |
| 先安慰人，後來才自己崩 | 情緒延遲的根本原因 |
| 不自覺把痛延後 | 代價的滯後性 |

**導演功能**：
- 解釋角色「功能性活著」的機制
- 解釋角色為何先整理自己、後來才崩
- 解釋「維持姿態」比「即刻發洩」更常見
- 解釋承接儀式的重要性

## <a id="section-three-verbs"></a>三個導演主詞

全作導演語言統一在三個動詞：**維持 / 承接 / 埋單**

### <a id="verb-maintain"></a>維持（Maintain）

**定義**：不是體面，不是漂亮。是：明明快散，仍然要整理成可以被看見、被依賴、被使用的樣子。

| 具體表現 | 導演讀法 |
|---------|---------|
| 整理儀容、拉正領口、綁絲帶 | 可愛由天真變成戰鬥姿態 |
| 戴好手套、擦乾淨血、固定姿勢 | 壓迫感轉化成一套熟練程序 |
| 試笑、試聲、深呼吸後抬頭 | 「她不是沒事，只是做熟了」 |

**設計鐵則**：「維持」動作必須令觀眾感受到：她不是沒事，只是先處理了應該扮成的樣子。

---

### <a id="verb-receive"></a>承接（Receive）

**定義**：不是拯救，不是修好，不是立刻治療成功。是：在一個人快散的時候，幫她撐多一下。

| 具體表現 |
|---------|
| 漱口、遞水、扶住坐下、托住後頸 |
| 抹血、梳頭／綁頭髮 |
| 幫她講出口、陪著走 |
| 吵架後仍然留下 |

**導演功能**：這是本作**最重要的治癒語言**。不是「我令你不痛」，而是「你不必一個人痛」。關係建立不靠台詞，而靠可重複的具體動作。

---

### <a id="verb-pay"></a>埋單（Pay the Tab）

**定義**：不是懲罰機制。是：最後總有人要承受後果——問題是，是否永遠都是同一個人。

| 具體表現 |
|---------|
| 身體代價：嘔吐、掉牙、失聲、手震 |
| 夢境／記憶污染 |
| 情緒回聲、拖延後的崩壞 |
| 由別人代受、代站、代答、代頂 |

**導演功能**：令「用力拯救」不會變得免費。令「承接」成為真正有重量的行為，因為總要有人埋單。

---

## <a id="section-first-layer"></a>第一層氣氛手法

**核心法則**：本作最重要的氣氛手法不是對比，而是：

> **重覆變奏 / 延遲 / 錯位**

這三者是第一層手法，因為它們最直接作用於觀眾的感官與心理不安。

---

### <a id="technique-repetition"></a>重覆變奏（Repetition with Variation）

**定義**：同一個動作、儀式、說話、構圖不斷出現；但每次的情緒意義都變深、變痛、變扭曲。

**為什麼重要**：《晴香》的痛不是一次性 twist，而是同一種東西不斷回來：同一種溫柔、同一種姿態、同一種代價、同一種無法好好退場的狀態。

**設計原則**：

| 出現次序 | 功能 |
|---------|------|
| 第一次 | 建立 |
| 第二次 | 加深 |
| 第三次 | 扭曲 |
| 最後一次 | 回收，變成心碎 |

**最適合重覆變奏的元素**：梳頭、綁絲帶、整領口、試笑、漱口、抹血、上台前停一秒、「坐好先」、陪著走一段

**禁止**：
- 同一動作只重覆不變奏 = 符號濫用
- 每次都比上次更誇張 = 過度刻意
- 重點是「同一個動作，意義被時間與關係改寫」，而非數量

---

### <a id="technique-delay"></a>延遲（Delay）

**定義**：角色的情緒、痛楚、代價，不在當下完全爆出，而是被迫延後。

**為什麼重要**：這是本作壓迫感的核心之一。正常人先痛、先亂、先反應；本作角色先撐住、先處理人、先整理自己，之後才痛。

**延遲的三個方向**：

| 方向 | 模式 | 例子 |
|-----|------|------|
| **情緒延遲** | 先安慰人，之後才崩；先笑，後散 | 場面話說完，轉身才手抖 |
| **身體延遲** | 戰鬥完沒事，一落台才嘔；先處理現場，之後才掉牙／失聲 | 與正常受傷反應相反 |
| **理解延遲** | 當下麻木，後來才意識到發生什麼；夢裡、夜裡、既視感時，才真正中招 | 遲來的衝擊時刻 |

**導演功能**：令觀眾感到她們連崩潰都沒有權利即刻崩。令代價有「回頭追上」的感覺。令「先做功能，再做自己」成為作品的壓迫節奏。

**禁止**：不可每次都完全延遲，否則角色變成機械。必須保留少量當下裂痕，讓觀眾知道她不是無感覺。

---

### <a id="technique-misalignment"></a>錯位（Misalignment）

**定義**：應該同步的東西，不同步。嘴與眼、身體與語言、溫柔與傷害、舞台與戰場，永遠差半拍。

**與對比的區別**：
- **對比**：A vs B（分開呈現）
- **錯位**：A 與 B 同時存在，但無法完全咬合

| 錯位方向 | 例子 |
|---------|------|
| 笑容已出來，眼神未到 | 情緒比表情慢半拍 |
| 說「沒事」時手其實震緊 | 語言與身體不同步 |
| 少女式動作仍然優雅，但身體已開始壞 | 美感與代價同框 |
| 照顧場面很溫柔，但杯裡有血 | 溫柔與傷害共存 |
| 舞台燈光甜美，但人正在功能性活著 | 表象與內在不同步 |

**導演功能**：令觀眾覺得「她還在，但某部分已經不在」。令作品不止是甜美 vs 噁心，而是兩種狀態卡在同一個身體裡。

**禁止**：錯位不等於混亂。要精準地錯半拍，而不是所有東西都歪掉。最有效的錯位，通常發生在最平靜、最日常、最應該自然的時刻。

---

## <a id="section-second-layer"></a>第二層結構手法

第二層手法負責強化主題、製造前後呼應、建立 Alpha/Beta 回聲、整理角色關係。它們不是第一下就製造不安，而是令整體結構有意義。

### <a id="technique-contrast"></a>對比（Contrast）

**功能**：講清楚作品想說什麼，而不是直接製造恐懼感。

| 對比軸 |
|-------|
| 正常人 vs 主角群 |
| 私人的我 vs 公共的我 |
| 假糖 vs 真暖 |
| 被需要 vs 被消費 |
| 日區烏托邦表象 vs 真實情緒壓迫 |

---

### <a id="technique-mirror"></a>鏡像（Mirror）

**功能**：強化命運回響、讓關係的承接有結構、讓作品有「所有事都在回流」的感覺。

| 鏡像模式 | 例子 |
|---------|------|
| 動作回還 | 我幫你梳頭，之後你幫我梳頭 |
| 台詞回還 | 某句話被另一人返還 |
| 位置回還 | 上次你扶我，今次我扶你 |
| Alpha 扭曲回聲 | Alpha 的姿態在 Beta 以扭曲方式重現 |
| 可能性映照 | 某角色與自己的另一種可能性互相映照 |

---

## <a id="section-ritual-framework"></a>共同儀式框架

**核心定義**：儀式不是零碎小動作的清單，而是角色從一個狀態切換到另一個狀態的結構。

| 儀式 | 狀態切換 | 具體動作 |
|-----|---------|---------|
| **入場儀式** | 私人 → 公共 | 上台、入光區、報位、整理、試聲 |
| **維持儀式** | 完整 → 撐住 | 抹血、整領、綁帶、站直、固定姿勢 |
| **失衡儀式** | 撐住 → 開始壞 | 手震、耳鳴、失焦、喉嚨不對、想吐、停一秒 |
| **承接儀式** | 一個人硬頂 → 被另一個人接住 | 漱口、遞水、托後頸、梳頭、扶住 |
| **交接儀式** | 我頂 → 我們頂 | 代站、代答、代受、擋目光、說場面話 |
| **退場儀式** | 功能狀態 → 做回自己 | 坐下、卸下某物、肩跌落去、終於肯讓人扶 |
| **埋單儀式** | 借力 → 承後果 | 自我檢查、記錄、避開某物、夢境污染、還債行動 |

**設計鐵則**：每個儀式場景必須清楚標示「正在發生哪種狀態切換」，而不是把動作作為裝飾。

## <a id="section-functional-living"></a>表情麻木與功能性活著

**核心定義**：本作的壓抑氣氛不是角色沒有情緒，而是角色比正常人更早學會把情緒壓後、把姿態放前。情緒沒有死，只是未被准許出現在臉上。

**與正常人的差異**：

| | 模式 |
|-|------|
| **正常人** | 先情緒，再動作 |
| **主角群** | 先功能，再情緒 |

**三種麻木類型**：

| 類型 | 表現 |
|-----|------|
| **功能性麻木** | 笑得出，眼神未到；說話正常，臉太靜 |
| **斷線式麻木** | 望著你，但人好像不在；當下無感，之後才中招 |
| **卡住式麻木** | 表情停在錯誤位置；微笑停太久、瞳孔太定、嘴角未收回 |

**使用原則**：
1. 先用「細微不對路」建立
2. 再用「明顯卡住」加深
3. 不要一直用最重版本

## <a id="section-cost-visibility"></a>代價上鏡原則

**兩層代價結構**：

| 層次 | 類型 | 頻率 | 內容 |
|-----|------|------|------|
| **第一層（主）** | 身體代價 | 常見 | 喉嚨乾、手震、失焦、牙齦出血、耳鳴、嘔心、嘔吐、掉牙 |
| **第二層（副）** | 夢境／記憶代價 | 少用 | 現實感被偷走、記憶真假不明、Alpha 幸福感滲入造成空心感、夢裡的自己比現實更完整、醒來更痛 |

**原則**：
- 身體代價不應一開始就最重；必須累積
- 夢境代價不應太密，否則搶掉身體恐怖的效果
- 施法代價是肉身性的；連結與主題的重量是關係性的

> 另見：[World Rules §代價系統](01_world_rules_and_costs.md)、[Narrative Design Bible §代價設計原則](08_narrative_design_bible.md#section-cost-design)

## <a id="section-atmosphere-guideline"></a>不安氣氛總方針

《晴香》的不安，不靠大驚嚇，也不靠單純反差。它主要來自：

> **重覆變奏、延遲與錯位，令角色的溫柔、功能、崩壞與姿態，永遠差半步同步。**

**具體感覺**：

| 外在狀態 | 實際狀態 |
|---------|---------|
| 她仍然在笑 | 笑得不對 |
| 她已經受傷 | 但沒有資格即刻痛 |
| 她被照顧 | 但仍想自己坐直 |
| 她做著最溫柔的動作 | 但整個人快散 |
| 她退場了 | 但某部分仍然未退場 |

## <a id="section-director-slogans"></a>導演工作標語

以下句子作為分鏡、劇本、遊戲事件設計時的內部對焦語句：

> 最殘酷的不是受傷，而是受傷之後還要整理好自己。

> 真正的治癒不是治好對方，而是不再讓最願意承擔的人一個人埋單。

> 她不是沒事，她只是先處理了自己應該扮成的樣子。

> 本作的不安，來自一切都差半拍同步。
