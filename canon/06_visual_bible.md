## <a id="section-visual-philosophy"></a>Visual Philosophy（視覺哲學）

### <a id="section-tender-cruelty"></a>核心情感矛盾體：溫柔的殘酷 (Tender Cruelty)

**視覺準則**：用最唯美、最詩意的視覺語言呈現最殘酷的命運與最痛苦的靈魂撕裂；希望的展現必須克制、真實且有重量。這種反差是核心敘事武器。

**指導原則**：「美麗」是「痛苦」的放大器。絕不使用廉價驚嚇或純粹感官刺激的血腥。所有殘酷的視覺呈現都必須被悲劇性美感包裹，引發觀眾的「憐惜」、「不安」與「心碎」。

- **畫面範例**：少女的崩潰不是猙獰哭號——而是灑滿午後陽光的寧靜房間裡，平靜微笑的臉上無聲流下結晶化淚珠，墜地時發出清脆心碎的碎裂聲
- **聲音範例**：最慘烈的戰鬥中，背景音樂是溫柔的童謠色彩鋼琴曲

### <a id="section-what-is-real"></a>核心存在主義詰問：何為真實？(What is Real?)

視覺呈現必須不斷挑戰觀眾對「真實」的感知。世界存在兩個可相互滲透的層面：

- **表象現實**：穩定、清晰、符合常規物理光學。色調可能壓抑，但形態可被理解
- **底層真實**：當鏡頭揭示底層真實時（透過[鏡像法則](01_world_rules_and_costs.md#rule-mirror-law)、情緒失控、潛意識空間），畫面應變得「不可靠」——大量運用訊號干擾 (Glitch Art)、色差 (Chromatic Aberration)、不合邏輯的空間扭曲、幀率微妙變化

### <a id="section-aesthetics-of-flawed"></a>核心美學觀點：破碎的美學 (Aesthetics of the Flawed)

最高美學追求不是「完美」，而是**不完整性、傷痕與裂痕本身蘊含的淒涼美感**。完美無瑕的存在是可疑的、虛假的。

**哲學參照**：角色「腐蝕」過程應參考瓷器龜裂（哥窯「開片」）與修復（日本「金繼」）。裂痕蔓延如冬日冰花或水墨渲染；接納創傷時，裂痕中透出微光，如金繼中的金漆。

<a id="section-corruption-stages"></a>
### <a id="section-law-corruption"></a>支柱一：法則·腐蝕 (The Law of Corruption)

> 法則敘事口徑見 [World Rules：屍骸化與修正力](01_world_rules_and_costs.md#rule-corpseification)；本節只保留演出層規格。

**視覺規格**：崩壞以「概念裂解」呈現，而非寫實腐敗。核心是讓觀眾看見「身份與自我正在剝落」。


**第一階段：結晶化/靈魂剝落**
- [情緒結晶](02_glossary.md#term-emotional-crystal)從裂紋破體而出
- 皮膚像瓷器碎片剝落
- [魔法屍骸](07_entities_and_devices.md#section-magical-corpse)的起源

#### 戰鬥的華彩樂章

所有華麗魔法特效的演出核心：少女們的心匣在高速碎裂時飛散的、燃燒著的情緒結晶。每一次絢爛攻擊都是靈魂的獻祭。戰鬥後地面散落的美麗結晶，是這場獻祭無法挽回的證據——完美詮釋[溫柔的殘酷](#section-tender-cruelty)。

### <a id="section-law-entropy"></a>支柱三：法則·熵增 (The Law of Entropy)

> 法則敘事口徑見 [World Rules：情緒系統](01_world_rules_and_costs.md#section-emotion-system)；本節只定義「混沌態」畫面語法。

**視覺規格**：把熵增拍成「秩序失去邊界」的過程，重點是延遲、黏滯、不可回復感。

- **混沌態視覺**：非單純黑色黏液，而是如**虹彩色油污**或**半凝固七彩樹脂**——美麗、緩慢、無法名狀，象徵所有定義與界線的消解
- **常見入鏡情境**：角色嚴重偏離心匣核心認同時，或[集體潛意識](02_glossary.md#term-collective-unconscious)能量洩漏區域
- **與腐蝕的結合**：心匣出現裂紋後、碎片（結晶）徹底剝落之前，黏稠的混沌態物質從裂縫中緩慢滲出——比裂紋更令人不安的動態崩壞

---

### <a id="section-law-mirror-visual"></a>支柱四：法則·鏡像 (The Law of the Mirror) — 視覺規格

> 規則條文見 [World Rules: 鏡像法則](01_world_rules_and_costs.md#rule-mirror-law)。本節收斂其視覺呈現規格。

**核心視覺**：任何完美反光面（鏡子、靜止水面、拋光金屬）如同靈魂X光片，映照底層真實。

#### 四項視覺應用

1. **魔法的缺席**：僅由情緒力量渲染的物體（火焰劍、隱形結界），在鏡中無倒影。充滿反光面的環境 = 幻術的刑場
2. **情緒的顯色**：鏡中倒影色彩即時反映真實情緒——「希望」= 柔和金色光暈；「絕望」= 吸光的啞光紫黑
3. **本質的反向映照**：鏡像映照與表象完全對立的內在主導真實
   - 猙獰屍骸若殘存人性意志 → 鏡像映照生前人形
   - 外表「活人」若靈魂被創傷主導 → 鏡像映照死去原始肉身
   - 內在陰影 (Shadow Self)：意志薄弱時在鏡中短暫浮現，與本人形象重疊閃爍
4. **缺席的倒影**：自我認同完全瓦解時，鏡中什麼都看不到——只有一片空白。「內在」徹底虛無化
5. **法則崩壞的異常 (Anomalies of a Collapsing Law)**：（僅在故事後期或極端情況下使用）當世界規則本身被動搖時，鏡像出現異常——倒影自主行動，甚至「腐蝕」並取代現實

### <a id="section-law-rejection"></a>支柱五：法則·生理排斥 (The Law of Physiological Rejection)

> 法則敘事口徑見 [World Rules：生理排斥法則](01_world_rules_and_costs.md#rule-physiological-rejection)；本節只定義排斥在鏡頭上點樣被觀眾感知。

**視覺規格**：把「排斥」拍成可連續讀取的三層訊號（精神、感官、肉體），讓狀態轉壞有可追蹤節奏，而唔係突然失控。

#### 排斥的三重奏 (The Trio of Rejection)

**第一樂章：誘因·精神的欺騙**
- 諧振的狂喜 (Ecstasy of Resonance)：力量初始體驗必然是精神極樂與全能感
- 可視作世界法則為誘使靈魂打開大門而設的「甜蜜陷阱」

**第二樂章：後果·感官與肉體的懲罰**
- 感官反噬：靈魂延遲 (Soul Lag)——視覺殘影、聽覺針刺感，感官系統「重啟」的痛苦悲鳴
- 肉體排斥：身體本能試圖「排出」非自然能量
  - 嘔吐：最直接的排出行為
  - 肢體扭曲 (Somatic Distortion)：肌肉與神經在能量流衝擊下失控，做出違反人體工學的非自主扭動——角色正在失去對身體控制權的恐怖證明

**第三樂章：終曲·精神的解離**
- 狂喜的痛苦 (Ecstatic Agony)：精神為逃避無法承受的雙重痛苦而啟動極端解離
- **視覺表現**：身體正經歷最恐怖異變（龜裂、扭曲），臉上卻浮現極度幸福的狂喜笑容
- **核心**：不是享受痛苦，而是精神已徹底斷線，退回到唯一美好的初始記憶中。「表情」與「現實」的極致反差是整個視覺體系最令人不安的景象

## <a id="section-derived-principles"></a>Derived Principles（派生原則）

### <a id="section-env-manifestation"></a>法則的物理顯化原則 (Environmental Manifestation)

核心法則不僅作用於個體，更塑造整個文明的物理形態。

- **[日區](02_glossary.md#term-sun-district)「無鏡之城」**：大量啞光、吸光粗糙材質；刻意避免開闊水域；上流時尚以避免高反光金屬或寶石為榮
- **[夜區](02_glossary.md#term-night-district)「鏡像之城」**：潮濕街道、老舊玻璃幕牆、坑窪積水，處處是揭示底層真實的畫布

### <a id="section-ritual-transformation"></a>轉變的儀式原則 (Ritual Transformation)

任何本質性轉變絕不突兀。必須透過充滿象徵意義的視覺儀式完成：

- 自然覺醒嚴格遵循「鏡中的承諾」儀式——角色與自我倒影從對峙、交流到契約達成
- 外力導致的轉變（帝國改造）有對應的、充滿痛苦與非人化過程的視覺儀式

### <a id="section-industrial-exploitation"></a>工業化剝削原則 (Industrial Exploitation)

情緒本質應自由流動，任何「量化/儲存/工業化」的科技本質上是靈魂剝削。

- 帝國情緒力量裝置設計美學：冰冷、非人道，類似過時醫療刑具或精密屠宰場設備
- 「靈魂之刺」收割過程：外科手術般的精確 + 血淋淋的痛苦，直接控訴技術的殘酷本質

### <a id="section-art-night"></a>夜區遺民 (Night District)

**核心概念**：混沌的生命力

| 項目 | 規格 |
|------|------|
| 環境 | 九龍城寨美學：潮濕街道、密密麻麻招牌、錯綜電線、冒蒸氣路邊攤 |
| 服飾基底 | HK 80s：牛仔褸、皮褸、花恤衫、喇叭褲 |

### <a id="section-art-sun"></a>日區居民 (Sun District)

**核心概念**：奢華、壓抑、虛假、統一

- 服飾：剪裁精良、面料高級，但缺乏個性——如同昂貴制服
- 色彩：柔和高雅但飽和度偏低，被「過濾」掉活力
- 姿態：表情麻木，儀態優雅但僵硬
- 細節：遵循「無鏡之城」原則——服飾配飾刻意避免高反光金屬或鏡面材料

### <a id="section-art-empire-agents"></a>帝國人員 (Imperial Agents)

**核心概念**：秩序、非人化、冰冷、高效

- 服飾：稜角分明，強調對稱與直線。冰冷合成纖維或裝甲，抹消所有個人特徵
- 色彩：黑、白、灰或極深藍，強烈壓迫感
- 是[工業化剝削原則](#section-industrial-exploitation)的執行者

**情緒管理局制服規格**（Bureau Uniform）：

| 項目 | 規格 |
|-----|------|
| 款式 | 純白緊身西裝；剪裁極度合身，甚至有點限制活動 |
| 材質 | 啞光 (Matte) 布料——不反光，給人冷漠、吸收光線的感覺 |
| 造型語言 | 絕對對稱：釦子、領帶夾、站姿嚴格保持中軸線對稱 |
| 紀律訊號 | 任何「歪斜」都被視為情緒失控的外顯訊號 |
| 整體效果 | 布料一塵不染，像雕塑一樣的完美感與非人性 |

### <a id="section-halo"></a>Halo（光環）

**視覺用途**：光環用作魔法少女狀態讀取的主視覺層；術語口徑見 [Glossary：光環](02_glossary.md#term-halo) 與 [World Rules](01_world_rules_and_costs.md)。

**核心特性**：
- 材質：非物質純能量體，不可觸碰
- 光學：自發光，微弱粒子飄散
- 動態：隨[心匣](07_entities_and_devices.md#section-heart-container)「心跳」輕微脈動
- 個人化：形狀、位置、顏色因人而異

**狀態變化**：

| 狀態 | 視覺表現 |
|------|---------|
| 健康 | 穩定發光，輪廓清晰，規律脈動 |
| 疲勞 | 光芒減弱，偶爾閃爍 |
| 損耗嚴重 | 出現裂紋/缺口，光芒不穩定 |
| 屍骸化 | 光環碎裂或熄滅 |

**光環→光環齒輪（屍骸化轉化）**：

| 元素 | 魔法少女 | 魔法屍骸 |
|-----|---------|---------|
| 核心符號 | 光環（非物質能量體） | 光環齒輪（實體金屬） |
| 位置/動態 | 自由漂浮，發光脈動 | 固定在後腦；停止或強制運轉 |
| 象徵 | 「仍然連結著」 | 「被困在系統中」 |

**光環鈣化殘留**：結晶化終末期，光環鈣化殘留會以「生鏽齒輪嵌入」形式外露。晶瑩結晶簇與鏽蝕金屬齒輪交錯，是自然法則與人工干預雙重詛咒的視覺象徵。

### <a id="section-transformation-visual"></a>變身序列 (Transformation Sequence)

遵循[轉變的儀式原則](#section-ritual-transformation)——「鏡中的承諾」三階段鏡像系統：

1. **對峙**：角色面對鏡中倒影，倒影映照底層真實
2. **交流**：角色與倒影建立情感連結，倒影回應
3. **契約**：角色接受自我，倒影與本人融合，變身完成

### <a id="section-dressing-process"></a>著裝過程（Dressing Process）

> 本段只定義視覺節奏，不重述世界規則。

1. **內層顯形**：基礎服裝先以半透明能量布料貼合身體輪廓，避免「瞬間完成」造成廉價感。  
2. **功能件鎖定**：武裝/配件（手套、護具、武器接口）按角色習慣逐件完成，形成個人化節奏。  
3. **身份件收束**：最後才出現最具角色身份的元素（例如髮飾、披肩、徽記），作為「我係邊個」的視覺句號。

### <a id="section-shackle-visual"></a>枷鎖的表現（Shackle Mark Visual）

> 術語定義見 [Glossary](02_glossary.md#term-shackle-mark)；此處為畫面規格。

- **平時狀態**：枷鎖紋應該像被皮膚吸收的暗紋，只有在逆光或情緒激發時微亮。  
- **高壓狀態**：紋理向四肢末端擴散，伴隨細碎「瓷裂」高光，提示[情感耗損](02_glossary.md#term-emotional-erosion)上升。  
- **臨界狀態**：枷鎖紋與[光環](#section-halo)出現相位不同步（脈衝錯拍），作為高風險代價前的最後視覺警報（條文見 [World Rules](01_world_rules_and_costs.md#section-irreversible)）。

### <a id="section-audio-design"></a>聽覺設計（Audio Design）

視覺與聲音必須共同承擔「溫柔的殘酷」：  
- **日常層**：細密環境音（風扇、鞋底、課室噪音）維持現實觸感。  
- **異常層**：當底層真實滲出時，先改變頻段而非直接放大音量（高頻消失、低頻壓迫）。  
- **崩壞層**：關鍵瞬間採「抽空」策略（近乎靜音 + 單一殘響），讓觀眾感知角色主觀失真。

### <a id="section-transform-sfx-anomaly"></a>變身音效的異常（Transformation SFX Anomaly）

- **正常變身**：三段音色（啟動脈衝 → 共鳴層疊 → 定型落點）完整且連續。  
- **異常變身**：出現節拍跳針、音高漂移、尾音斷裂，對應「身份認同未完成」。  
- **臨界變身**：視覺仍華麗但音色變薄，僅剩機械節拍與呼吸聲，形成「外表成功、內在崩壞」反差。

### <a id="section-corruption-on-girls"></a>腐蝕在魔法少女身上的體現

每位角色的腐蝕三階段都有獨特的視覺設計：
- 結晶化形態反映心匣核心情緒
- 整體過程應被當作「視覺詩歌」處理，參照[破碎的美學](#section-aesthetics-of-flawed)

## <a id="section-character-design"></a>Character Design Framework（角色設計框架）

### <a id="section-duality"></a>雙重性原則 (Principle of Duality)

每個角色設計包含兩個層面：
- **表象 (The Shell)**：符合社會身份的外觀
- **本質 (The Core)**：細節中不經意流露的心匣真實狀態（如總是微笑但眼神毫無光彩）

### <a id="section-shape-language"></a>基礎造型語言

| 幾何 | 代表意義 | 適用 |
|------|---------|------|
| 倒三角形 | 力量、威脅、攻擊性 | [朱音](03_characters/iwakura_akane.md)、帝國高級特工 |
| 矩形/直線 | 中性、堅定、壓抑 | 帝國普通人員（非人化統一性） |
| 正三角形 | 柔和、穩定、被動 | 溫柔角色、[秋穗](03_characters/akiho.md)日常形象 |

**線條語言**：
- 尖銳/角度：剛烈、攻擊性、痛苦中（[夕](03_characters/yu.md)、[黑奏](03_characters/antagonist.md)）
- 圓潤/曲線：溫和、天真、平靜（[晴香](03_characters/haruka.md)偶像服飾）

**對稱性**：
- 完全對稱 = 秩序、理性、非人化（帝國制服）
- 不對稱 = 混亂、自由、內心矛盾（魔法少女設計）

### <a id="section-color-language"></a>情緒色彩語言

- 角色主配色與其主導情緒物質/心匣本質色彩相關
- 彩度 (Saturation) 直接與精神活力掛鉤——[情感耗損](02_glossary.md#term-emotional-erosion)使整體飽和度顯著降低，趨向灰色
- 冷暖對比對應性格核心（[晴香](03_characters/haruka.md) = 暖色調；[美夜子](03_characters/miyako.md) = 冷色調）
- 內心矛盾時，特效或服飾細節出現強烈補色

### <a id="section-shape-and-color"></a>造型語言與配色（Shape & Color）

| 維度 | 規格 | 敘事用途 |
|---|---|---|
| 輪廓 | 先辨識大形（遠景 1 秒內可認） | 保證角色在混戰中仍有主體性 |
| 色群 | 1 個主色 + 1 個輔色 + 1 個警示色 | 避免資訊過載，保留情緒焦點 |
| 材質對比 | 至少一組「軟 vs 硬」並置（布/金屬） | 對應角色「脆弱 vs 防衛」內在矛盾 |
| 發光節制 | 發光元素不超過畫面關鍵點 3 處 | 防止特效掩蓋表演 |

### <a id="section-form-design-details"></a>形態設計細節（Form Design Details）

- **頭肩線**：決定第一印象（開放、壓迫、退縮）；不可只靠服裝花紋補救。  
- **手部語言**：手勢是角色心理狀態最快的讀取點（抓緊、攤開、顫抖、收拳）。  
- **重心線**：角色站姿重心偏移應與弧光一致；成長後重心通常更穩，不再飄忽。  
- **破損邏輯**：服裝/裝備損壞必須有因果方向（受力點、磨耗點），避免裝飾性破損。

### <a id="section-visual-deception"></a>視覺欺騙與反差

角色第一印象應服務於劇情反轉或內在矛盾：
- [黑奏主人格](03_characters/antagonist.md)：極致無害化、圓潤線條、柔和色彩——積蓄揭露時的認知衝擊
- [美夜子](03_characters/miyako.md)貓形態：強調可愛弱小，與人形冰冷高效形成強烈反差

### <a id="section-personal-motifs"></a>個人母題與演變符號

核心角色被賦予象徵性母題，隨心路歷程視覺演變：

| 角色 | 母題 | 象徵 |
|------|------|------|
| [晴香](03_characters/haruka.md) | 小熊 | 童真、渴望被保護 |
| [美夜子](03_characters/miyako.md) | 貓 | 獨立、神秘、自我封閉 |
| [朱音](03_characters/iwakura_akane.md) | 食人花/荊棘 | 侵略性、頑強生命力 |

## <a id="section-narrative-visual"></a>Advanced Narrative Design（進階敘事視覺設計）

### <a id="section-posture-theatrics"></a>姿態與表演性

在充滿謊言與自我欺騙的世界裡，許多角色的日常姿態本身就是「表演」。當內心動搖導致「表演失誤」（不符角色的顫抖或猶豫），是窺見真實內心的敘事節點。


### <a id="section-negative-space"></a>負空間與缺席 (Negative Space & Absence)

最強烈的恐怖與悲傷來自「沒有什麼」：

- **缺席的倒影**：自我認同瓦解時，鏡中只有空白
- **缺席的聲音**：最劇烈痛苦時剝奪所有音效，只留微弱呼吸或完全靜音
- **缺席的色彩**：[情感耗損](02_glossary.md#term-emotional-erosion)最終階段，角色主觀視角變成黑白

### <a id="section-mirror-presentation"></a>鏡子的表現（Mirror Presentation）

- **材質分級**：平整鏡面 = 高可信映照；粗糙反光面 = 斷裂映照；液面 = 延遲映照。  
- **鏡位優先**：鏡面在畫面中不只作背景，需具備敘事功能（揭露、誤導、對照）。  
- **鏡像延遲**：在心理不穩定段落，允許 2-6 幀延遲以製造「我唔係我」的不安。

### <a id="section-reflection-interaction"></a>倒影的互動（Reflection Interaction）

- **對話式互動**：角色看向鏡面時，倒影可先於本體作出微表情，提示底層情緒。  
- **衝突式互動**：當角色否認自我時，倒影可呈現相反姿態（本體靜止、倒影顫動）。  
- **和解式互動**：角色完成承擔時，本體與倒影動作重新同步，作為段落收束標誌。

### <a id="section-trinity-visualization"></a>三位一體的視覺化（Trinity Visualization）

> 規則分層見 [World Rules](01_world_rules_and_costs.md#rule-trinity-spectrum)；此處只定義演出。

- **人類相**：皮膚與眼神保留溫度，光環脈衝規律，動作有猶豫與修正。  
- **中間相**：枷鎖紋活化、呼吸節奏不穩、鏡像偶發錯位，呈現「還在選擇中」。  
- **屍骸相**：輪廓硬化、光澤金屬化、音色乾裂，但保留一個「人性殘響」細節，避免扁平怪物化。

### Alpha 線視覺標誌

**核心美學**：老香港（戰前嶺南）——有機、手作、時光留痕。

| 元素 | 規格 |
|------|------|

### Beta 線視覺標誌

**核心美學**：黑暗維多利亞（帝國加工的殖民遺產）——秩序、壓迫、人工完美。

| 元素 | 規格 |
|------|------|

| 材質 | 大理石、黑色鑄鐵、高光拋光木；人工感強，刻意消除自然紋理 |
| 光線 | 人造燈光為主；帝國建築以強光從高處垂照，強調壓迫感 |

## <a id="section-scene-visual"></a>Scene Visual Language（場景視覺語法）

### <a id="section-supernatural-phenomena"></a>超自然環境現象

**情緒結晶苔 (Emotion Crystal Moss)**
- 重大悲劇或長期情緒浸泡之處生長的微小[情緒結晶](02_glossary.md#term-emotional-crystal)苔蘚
- 微光下散發幽幽光芒，色彩對應吸收的情緒（悲傷藍、憤怒暗紅）
- 直接觸碰極度危險——積累的情緒殘響瞬間湧入觸碰者腦海

**記憶迴響的雨 (Rain of Echoing Memories)**
- [集體潛意識](02_glossary.md#term-collective-unconscious)邊界薄弱時，無主記憶碎片溶入水汽
- 雨水打在皮膚上，可能突然聽見愛人呢喃、看見陌生孩子的畫面、或感受不屬於自己的悲傷
- 撐傘不再是為了保持乾爽，而是保護精神不受「污染」的儀式

## <a id="section-illustration-style"></a>Illustration Style Guide（插畫風格指南）

**美術風格定位**：Modern Japanese Light Novel / Gacha Game Art Style

### <a id="section-line-art"></a>線條處理 (Line Art)

- 輪廓：乾淨、細膩、無雜線

- **基礎**：賽璐璐 (Cel-Shading) — 色塊分明，清晰明暗交界線

- **材質**：皮膚半透明次表面散射；布料細膩褶皺；金屬/魔法道具高光銳利

### <a id="section-vfx"></a>視覺特效 (VFX)

| 類型 | 應用 |
|------|------|
| 粒子特效 | 魔法光點、能量粒子、自然元素 |
| 發光效果 | 武器/魔法陣發光邊緣、眼睛微光、背景光暈 |
| 環境特效 | 光束/光柱、能量波紋、氛圍霧氣 |

**目標**：「SSR 稀有卡面」精緻感。特效強化角色魅力，不喧賓奪主。

- 頭身比：6-7 頭身（纖細少女感）
- 眼睛佔比極大，虹膜如寶石，2-3 個高光點

| 項目 | 規格 |
|------|------|

## <a id="section-cinematography-grammar"></a>鏡頭語法與分鏡規範（補齊）

### 情緒鏡頭三段法
1. **狀態建立**：先給中景與環境聲，確認角色當下的「社會姿態」。
2. **失衡揭露**：切近景（眼、手、呼吸），以微延遲或不連續動作表現內在裂縫。
3. **代價落地**：回到空間全景，保留破壞痕跡或沉默空白，避免用台詞解釋。

### 構圖禁忌
- 禁止把創傷場面拍成英雄海報式「勝利姿態」。
- 禁止在角色崩潰時使用炫技鏡頭奪走角色主體。
- 禁止在關鍵承擔場景以高速剪輯取代情緒停留。

### 推薦鏡頭語法
- **鏡像場景**：優先固定鏡 + 緩推，讓觀眾自行比對表象與底層真實。
- **共感場景**：優先雙人同框，不切反應鏡頭，維持情緒連續性。
- **社會暴力場景**：優先遠景與群像，凸顯「制度性」而非單一惡人。
