## <a id="section-visual-philosophy"></a>Visual Philosophy（視覺哲學）

### <a id="section-tender-cruelty"></a>核心情感矛盾體：溫柔的殘酷 (Tender Cruelty)

**視覺準則**：用最唯美、最詩意的視覺語言呈現最殘酷的命運與最痛苦的靈魂撕裂；希望的展現必須克制、真實且有重量。這種反差是核心敘事武器。

**指導原則**：「美麗」是「痛苦」的放大器。絕不使用廉價驚嚇或純粹感官刺激的血腥。所有殘酷的視覺呈現都必須被悲劇性美感包裹，引發觀眾的「憐惜」、「不安」與「心碎」。

- **畫面範例**：少女的崩潰不是猙獰哭號——而是灑滿午後陽光的寧靜房間裡，平靜微笑的臉上無聲流下結晶化淚珠，墜地時發出清脆心碎的碎裂聲
- **聲音範例**：最慘烈的戰鬥中，背景音樂是溫柔的童謠色彩鋼琴曲

### <a id="section-what-is-real"></a>核心存在主義詰問：何為真實？(What is Real?)

視覺呈現必須不斷挑戰觀眾對「真實」的感知。世界存在兩個可相互滲透的層面：

- **表象現實**：穩定、清晰、符合常規物理光學。色調可能壓抑，但形態可被理解
- **底層真實**：當鏡頭揭示底層真實時（透過[鏡像法則](01_world_rules_and_costs.md#rule-mirror-law)、情緒失控、潛意識空間），畫面應變得「不可靠」——大量運用訊號干擾 (Glitch Art)、色差 (Chromatic Aberration)、不合邏輯的空間扭曲、幀率微妙變化

### <a id="section-aesthetics-of-flawed"></a>核心美學觀點：破碎的美學 (Aesthetics of the Flawed)

最高美學追求不是「完美」，而是**不完整性、傷痕與裂痕本身蘊含的淒涼美感**。完美無瑕的存在是可疑的、虛假的。

**哲學參照**：角色心之器龜裂的過程應參考瓷器龜裂（哥窯「開片」）與修復（日本「金繼」）。裂痕蔓延如冬日冰花或水墨渲染；接納創傷時，裂痕中透出微光，如金繼中的金漆。

### <a id="section-law-corruption"></a>支柱一：靈魂碎裂法則 (Law of Soul Fracture)

> 法則敘事口徑見 [World Rules：屍骸化與修正力](01_world_rules_and_costs.md#rule-corpseification)；本節只保留演出層規格。

**視覺規格**：崩壞以「概念裂解」呈現，而非寫實腐敗。核心是讓觀眾看見「身份與自我正在剝落」。

**心之器龜裂：結晶化/靈魂剝落**
- [情緒結晶](02_glossary.md#term-emotional-crystal)從裂紋破體而出
- 皮膚像瓷器碎片剝落
- [魔法屍骸](07_entities_and_devices.md#section-magical-corpse)的起源

#### 戰鬥的華彩樂章

所有華麗魔法特效的演出核心：少女們的心之器在高速碎裂時飛散的、燃燒著的情緒結晶。每一次絢爛攻擊都是靈魂的獻祭。戰鬥後地面散落的美麗結晶，是這場獻祭無法挽回的證據——完美詮釋[溫柔的殘酷](#section-tender-cruelty)。

### <a id="section-law-entropy"></a>支柱三：意識解離視覺法則 (Law of Identity Dissolution)

> 法則敘事口徑見 [World Rules：情緒系統](01_world_rules_and_costs.md#section-emotion-system)；本節只定義「混沌態」畫面語法。

**視覺規格**：把意識解離拍成「秩序失去邊界、自我邊界消融」的過程，重點是延遲、黏滯、不可回復感。

- **混沌態視覺**：非單純黑色黏液，而是如**虹彩色油污**或**半凝固七彩樹脂**——美麗、緩慢、無法名狀，象徵所有定義與界線的消解
- **常見入鏡情境**：角色嚴重偏離心匣核心認同時，或[集體潛意識](02_glossary.md#term-collective-unconscious)能量洩漏區域
- **與心之器龜裂的結合**：心匣出現裂紋後、碎片（結晶）徹底剝落之前，黏稠的混沌態物質從裂縫中緩慢滲出——比裂紋更令人不安的動態崩壞

### <a id="section-law-mirror-visual"></a>支柱四：法則·鏡像 (The Law of the Mirror) — 視覺規格

> 規則條文見 [World Rules: 鏡像法則](01_world_rules_and_costs.md#rule-mirror-law)。本節收斂其視覺呈現規格。

**核心視覺**：任何完美反光面（鏡子、靜止水面、拋光金屬）如同靈魂X光片，映照底層真實。

#### 四項視覺應用

1. **魔法的缺席**：僅由情緒力量渲染的物體（火焰劍、隱形結界），在鏡中無倒影。充滿反光面的環境 = 幻術的刑場
2. **情緒的顯色**：鏡中倒影色彩即時反映真實情緒——「希望」= 柔和金色光暈；「絕望」= 吸光的啞光紫黑
3. **本質的反向映照**：鏡像映照與表象完全對立的內在主導真實
   - 猙獰屍骸若殘存人性意志 → 鏡像映照生前人形
   - 外表「活人」若靈魂被創傷主導 → 鏡像映照死去原始肉身
   - 內在陰影 (Shadow Self)：意志薄弱時在鏡中短暫浮現，與本人形象重疊閃爍
4. **缺席的倒影**：自我認同完全瓦解時，鏡中什麼都看不到——只有一片空白。「內在」徹底虛無化
5. **法則崩壞的異常 (Anomalies of a Collapsing Law)**：（僅在故事後期或極端情況下使用）當世界規則本身被動搖時，鏡像出現異常——倒影自主行動，甚至「龜裂蔓延」並取代現實

#### <a id="section-shadow-surreal-passion"></a>內在陰影的超現實受難（Shadow's Surreal Passion）

> 本節係「本質的反向映照 — 內在陰影 (Shadow Self)」的深化規格；屬高情緒 / 自我破壞型心理的鏡中表現，不更動「法則崩壞 anomaly」與[三階段囚獄鏡](#section-magical-girl-mirror-stages)的倒影自主行動條款（兩者層次不同）。

**核心定義**：當角色陷入「沉溺苦難 / 拒絕成長 / 拒絕自救」一類自我破壞心理時，鏡中的內在陰影會以**超越現實生物學邏輯**的劇烈動作，將該心理具現為對自身的施虐。此非獨立魔法機制，而係榮格式「陰影 / 小我」自我內耗的視覺直譯。

**機制條目**：
1. **表裡割裂**：現實肉體維持社會性或克制（微細、可被否認的小動作）；所有狂態鎖在鏡中。現實越平靜，鏡中越劇烈。
2. **形式超越現實**：陰影不受痛覺休克 / 失血致死限制——自殘係「符號化操作」，動作速度與傷害程度可達現實不可能之量（用以呈現精神內耗本身的無底線）。
3. **心理對應，非力量裝置**：陰影自殘的意義係小我「用痛楚合理化苦難」，藉維持傷口切斷自救與成長的可能。其情緒劇烈化若帶來魔法輸出變化，係循[情緒強度與魔法輸出](01_world_rules_and_costs.md#rule-emotion-intensity-output)、[光環](01_world_rules_and_costs.md#section-irreversible)既有代價，而非新增規則。
4. **觸發**：高情緒 / 高衝突 + 完整反射面（同[鏡像法則](01_world_rules_and_costs.md#rule-mirror-law)觸發條件一致）。

**應用錨點**：凜（鏡中陰影挑紅線 / 嵌金屬扣）、操（鏡中陰影絲線狂縫胸口血洞）。

### <a id="section-law-rejection"></a>支柱五：法則·生理排斥 (The Law of Physiological Rejection)

> 法則敘事口徑見 [World Rules：生理排斥法則](01_world_rules_and_costs.md#rule-physiological-rejection)；本節只定義排斥在鏡頭上點樣被觀眾感知。

**視覺規格**：把「排斥」拍成可連續讀取的三層訊號（精神、感官、肉體），讓狀態轉壞有可追蹤節奏，而唔係突然失控。

#### 排斥的三重奏 (The Trio of Rejection)

**第一樂章：誘因·精神的欺騙**
- 諧振的狂喜 (Ecstasy of Resonance)：力量初始體驗必然是精神極樂與全能感
- 可視作世界法則為誘使靈魂打開大門而設的「甜蜜陷阱」

**第二樂章：後果·感官與肉體的懲罰**
- 感官反噬：靈魂延遲 (Soul Lag)——視覺殘影、聽覺針刺感，感官系統「重啟」的痛苦悲鳴
- 肉體排斥：身體本能試圖「排出」非自然能量
  - 嘔吐：最直接的排出行為
  - 肢體扭曲 (Somatic Distortion)：肌肉與神經在能量流衝擊下失控，做出違反人體工學的非自主扭動——角色正在失去對身體控制權的恐怖證明

**第三樂章：終曲·精神的解離**
- 狂喜的痛苦 (Ecstatic Agony)：精神為逃避無法承受的雙重痛苦而啟動極端解離
- **視覺表現**：身體正經歷最恐怖異變（龜裂、扭曲），臉上卻浮現極度幸福的狂喜笑容
- **核心**：不是享受痛苦，而是精神已徹底斷線，退回到唯一美好的初始記憶中。「表情」與「現實」的極致反差是整個視覺體系最令人不安的景象

## <a id="section-derived-principles"></a>Derived Principles（派生原則）

### <a id="section-env-manifestation"></a>法則的物理顯化原則 (Environmental Manifestation)

核心法則不僅作用於個體，更塑造整個文明的物理形態。

- **[日區](02_glossary.md#term-sun-district)「無鏡之城」**：大量啞光、吸光粗糙材質；刻意避免開闊水域；上流時尚以避免高反光金屬或寶石為榮
- **[夜區](02_glossary.md#term-night-district)「鏡像之城」**：潮濕街道、老舊玻璃幕牆、坑窪積水，處處是揭示底層真實的畫布

### <a id="section-ritual-transformation"></a>轉變的儀式原則 (Ritual Transformation)

任何本質性轉變絕不突兀。必須透過充滿象徵意義的視覺儀式完成：

- 自然覺醒嚴格遵循「鏡中的承諾」儀式——角色與自我倒影從對峙、交流到契約達成
- 外力導致的轉變（帝國改造）有對應的、充滿痛苦與非人化過程的視覺儀式

### <a id="section-industrial-exploitation"></a>工業化剝削原則 (Industrial Exploitation)

情緒本質應自由流動，任何「量化/儲存/工業化」的科技本質上是靈魂剝削。

- 帝國情緒力量裝置設計美學：冰冷、非人道，類似過時醫療刑具或精密屠宰場設備
- 「靈魂之刺」收割過程：外科手術般的精確 + 血淋淋的痛苦，直接控訴技術的殘酷本質

### <a id="section-art-night"></a>夜區遺民 (Night District)

**核心概念**：混沌的生命力

| 項目 | 規格 |
|------|------|
| 環境 | 九龍城寨美學：潮濕街道、密密麻麻招牌、錯綜電線、冒蒸氣路邊攤 |
| 服飾基底 | HK 80s：牛仔褸、皮褸、花恤衫、喇叭褲 |

| 色彩 | 大地色深色基底，被霓虹燈映照出斑斕色彩 |

### <a id="section-art-sun"></a>日區居民 (Sun District)

**核心概念**：奢華、壓抑、虛假、統一

- 服飾：剪裁精良、面料高級，但缺乏個性——如同昂貴制服
- 色彩：柔和高雅但飽和度偏低，被「過濾」掉活力
- 姿態：表情麻木，儀態優雅但僵硬
- 細節：遵循「無鏡之城」原則——服飾配飾刻意避免高反光金屬或鏡面材料

### <a id="section-art-empire-agents"></a>帝國人員 (Imperial Agents)

**核心概念**：秩序、非人化、冰冷、高效

- 服飾：稜角分明，強調對稱與直線。冰冷合成纖維或裝甲，抹消所有個人特徵
- 色彩：黑、白、灰或極深藍，強烈壓迫感
- 是[工業化剝削原則](#section-industrial-exploitation)的執行者

**情緒管理局制服規格**（Bureau Uniform）：

| 項目 | 規格 |
|-----|------|
| 款式 | 純白緊身西裝；剪裁極度合身，甚至有點限制活動 |
| 材質 | 啞光 (Matte) 布料——不反光，給人冷漠、吸收光線的感覺 |
| 造型語言 | 絕對對稱：釦子、領帶夾、站姿嚴格保持中軸線對稱 |
| 紀律訊號 | 任何「歪斜」都被視為情緒失控的外顯訊號 |
| 整體效果 | 布料一塵不染，像雕塑一樣的完美感與非人性 |

### <a id="section-vfx-essence"></a>魔法特效物理本質

**所有戰鬥魔法特效的物理本質 = 心之器高速碎裂時飛散出的燃燒情緒結晶碎片。**

| 特效類型 | 美觀層 | 物理真相 |
|---------|--------|---------|
| 魔法光柱/光束 | 純能量爆發 | 心之器碎裂噴發的高溫情緒結晶流 |
| 魔法粒子散射 | 星塵/能量點 | 情緒結晶燃燒後的殘渣碎屑 |
| 魔法爆炸圓形 | 衝擊波 | 心之器快速受壓後的碎裂波前 |
| 每次變身光效 | 美麗儀式 | 靈魂撕裂的能量釋放 |

**設計含義**：魔法少女越強大，心之器碎裂速度越快，特效越絢爛——特效的美麗與靈魂損耗成正比。這個物理真相不應明說，但應通過視覺細節讓二周目觀眾自行發現。

### <a id="section-halo"></a>Halo（光環）

**視覺用途**：光環用作魔法少女狀態讀取的主視覺層；術語口徑見 [Glossary：光環](02_glossary.md#term-halo) 與 [World Rules](01_world_rules_and_costs.md)。

**核心特性**：
- 材質：非物質純能量體，不可觸碰
- 光學：自發光，微弱粒子飄散
- 動態：隨[心匣](07_entities_and_devices.md#section-heart-container)「心跳」輕微脈動
- 個人化：形狀、位置、顏色因人而異

**狀態變化**：

| 狀態 | 視覺表現 |
|------|---------|
| 健康 | 穩定發光，輪廓清晰，規律脈動 |
| 疲勞 | 光芒減弱，偶爾閃爍 |
| 損耗嚴重 | 出現裂紋/缺口，光芒不穩定 |
| 屍骸化 | 光環碎裂或熄滅 |

**光環→光環齒輪（屍骸化轉化）**：

| 元素 | 魔法少女 | 魔法屍骸 |
|-----|---------|---------|
| 核心符號 | 光環（非物質能量體） | 光環齒輪（實體金屬） |
| 位置/動態 | 自由漂浮，發光脈動 | 固定在後腦；停止或強制運轉 |
| 象徵 | 「仍然連結著」 | 「被困在系統中」 |

**光環鈣化殘留**：結晶化終末期，光環鈣化殘留會以「生鏽齒輪嵌入」形式外露。晶瑩結晶簇與鏽蝕金屬齒輪交錯，是自然法則與人工干預雙重詛咒的視覺象徵。

### <a id="section-transformation-visual"></a>變身序列 (Transformation Sequence)

遵循[轉變的儀式原則](#section-ritual-transformation)——「鏡中的承諾」三階段鏡像系統：

#### <a id="section-magical-girl-mirror-stages"></a>三階段鏡像系統（Three-Stage Mirror System）

每次變身都涉及鏡子的進化，從最初的「自我承認」演進至「身份改造」再至「靈魂囚禁」：

| 階段 | 名稱 | 視覺語言 | 心理狀態 | 觸發機制 |
|------|------|--------|--------|---------|
| **Stage 1** | 夢幻鏡（Dream Mirror） | 化妝室暖光、完美自信倒影、光環如珠寶飾品、清脆鈴聲 | 擁抱角色最理想的自我形象 | 初次變身，純粹的自我承認 |
| **Stage 2** | 裂縫鏡（Cracked Mirror） | 畫面 Glitch、鏡框裂紋、倒影反應遲疑；穿越鏡面有阻力感「像踏入深水」；光環扣上有微弱鎖定聲 | 發現現實與理想的落差；開始感受到「被改造」的過程 | 重複變身，疑惑開始滲透 |
| **Stage 3** | 囚獄鏡（Prison Mirror） | 四面鏡牆、高反差冷光；倒影無表情或詭異笑容，主動抓住少女而非邀請；鏡片碎裂刺入身體成為盔甲；光環聲變成沉重鎖鏈聲；最終姿勢完美但眼神死去 | 完全臣服於被改造的命運；自我已被工具化 | 頻繁變身、心匣耗損到臨界 |

**敘事進度與鏡像對應**：
- Act I：Stage 1 居多（新手興奮）
- Act II：Stage 2 逐漸顯現（開始懷疑）
- Act III：Stage 3 主導（靈魂囚禁感）
- Act IV：可能回溯至 Stage 1 或超越鏡像系統（取決於角色覺醒）

**視覺執行細節**：

**Stage 1 — 夢幻鏡**：
- 顏色：暖色調（金色、玫瑰金、珍珠白）
- 光源：柔和擴散光，強調輪廓光暈
- 倒影動作：比本人稍晚 0.3 秒反應（彷彿在「考慮」）
- 音頻：高頻清脆鈴聲（玻璃或風鈴），音量清晰
- 視覺節奏：流暢、優雅

**Stage 2 — 裂縫鏡**：
- 顏色：色溫開始下降（金色→白色），出現藍色冷調
- 光源：聚焦光，開始出現陰影
- 倒影動作：反應延遲至 0.8 秒；眼神與本人不完全同步
- 鏡子物理：邊緣出現細微裂紋；穿越鏡面時有「水波阻力」視效
- 音頻：高頻開始有電子滋滋聲干擾；鎖定聲從清脆變為金屬感
- 視覺節奏：出現停頓、跳幀、小小的 Glitch

**Stage 3 — 囚獄鏡**：
- 顏色：冷色調主導（藍白、灰白、冰藍）；倒影可能泛紅或發黑
- 光源：高對比直射光，產生深重陰影
- 倒影行為：不再被動反應，開始主動「抓住」本人（倒影的手穿出鏡面）
- 鏡子物理：大型裂紋；碎片刺入角色身體，成為戰鬥盔甲的一部分
- 音頻：低沉金屬鎖鏈聲；呼吸聲變重；音高壓低
- 視覺節奏：機械、刻板、不可逆轉

---

**傳統敘事層次**（不限於Stage 1-3）：
1. **對峙**：角色面對鏡中倒影，倒影映照底層真實
2. **交流**：角色與倒影建立情感連結，倒影回應
3. **契約**：角色接受自我，倒影與本人融合，變身完成

### <a id="section-dressing-process"></a>著裝過程（Dressing Process）

> 本段只定義視覺節奏，不重述世界規則。

1. **內層顯形**：基礎服裝先以半透明能量布料貼合身體輪廓，避免「瞬間完成」造成廉價感。  
2. **功能件鎖定**：武裝/配件（手套、護具、武器接口）按角色習慣逐件完成，形成個人化節奏。  
3. **身份件收束**：最後才出現最具角色身份的元素（例如髮飾、披肩、徽記），作為「我係邊個」的視覺句號。

### <a id="section-shackle-visual"></a>枷鎖的表現（Shackle Mark Visual）

> 術語定義見 [Glossary](02_glossary.md#term-shackle-mark)；此處為畫面規格。

- **平時狀態**：枷鎖紋應該像被皮膚吸收的暗紋，只有在逆光或情緒激發時微亮。  
- **高壓狀態**：紋理向四肢末端擴散，伴隨細碎「瓷裂」高光，提示[情感耗損](02_glossary.md#term-emotional-erosion)上升。  
- **臨界狀態**：枷鎖紋與[光環](#section-halo)出現相位不同步（脈衝錯拍），作為高風險代價前的最後視覺警報（條文見 [World Rules](01_world_rules_and_costs.md#section-irreversible)）。

### <a id="section-audio-design"></a>聽覺設計（Audio Design）

視覺與聲音必須共同承擔「溫柔的殘酷」：  
- **日常層**：細密環境音（風扇、鞋底、課室噪音）維持現實觸感。  
- **異常層**：當底層真實滲出時，先改變頻段而非直接放大音量（高頻消失、低頻壓迫）。  
- **崩壞層**：關鍵瞬間採「抽空」策略（近乎靜音 + 單一殘響），讓觀眾感知角色主觀失真。

### <a id="section-transform-sfx-anomaly"></a>變身音效的異常（Transformation SFX Anomaly）

- **正常變身**：三段音色（啟動脈衝 → 共鳴層疊 → 定型落點）完整且連續。  
- **異常變身**：出現節拍跳針、音高漂移、尾音斷裂，對應「身份認同未完成」。  
- **臨界變身**：視覺仍華麗但音色變薄，僅剩機械節拍與呼吸聲，形成「外表成功、內在崩壞」反差。

### <a id="section-corruption-on-girls"></a>心之器碎裂在魔法少女身上的體現

心之器龜裂是一個連續過程，視覺上沿「裂紋顯現 → 虹膜封印 → 結晶剝落」的方向推進，但並無固定階段邊界——每個人的崩壞軌跡都不同。


**結晶化/靈魂剝離（不可逆）**：
- 皮膚質感：血肉感 → 玻璃質感 → 陶瓷質感；肘關節、膝蓋、肋骨處首先透光
- 結晶突起形狀與個體情緒相關：朱音（糖果形尖刺）；美夜子（冰柱或晶洞）
- 運動特徵：關節僵硬、動作機械化、表情凍結
- 最終狀態：肉身仍存活但心匣已空；軀殼變成精美的陶瓷娃娃

**與破碎美學的統一**：
整個過程應被當作「視覺詩歌」處理，參照[破碎的美學](#section-aesthetics-of-flawed)——心之器龜裂不是醜陋的敗壞，而是一種殘酷的精緻化。結晶化的瞬間往往是最視覺上「完美」的時刻，但那種完美正是靈魂喪失的證明。

## <a id="section-character-design"></a>Character Design Framework（角色設計框架）

### <a id="section-duality"></a>雙重性原則 (Principle of Duality)

每個角色設計包含兩個層面：
- **表象 (The Shell)**：符合社會身份的外觀
- **本質 (The Core)**：細節中不經意流露的心匣真實狀態（如總是微笑但眼神毫無光彩）

### <a id="section-shape-language"></a>基礎造型語言

| 幾何 | 代表意義 | 適用 |
|------|---------|------|
| 倒三角形 | 力量、威脅、攻擊性 | [朱音](03_characters/iwakura_akane.md)、帝國高級特工 |
| 矩形/直線 | 中性、堅定、壓抑 | 帝國普通人員（非人化統一性） |
| 正三角形 | 柔和、穩定、被動 | 溫柔角色、[秋穗](03_characters/akiho.md)日常形象 |

**線條語言**：
- 尖銳/角度：剛烈、攻擊性、痛苦中（[夕](03_characters/yu.md)、[黑奏](03_characters/aya.md#section-kurokane)）
- 圓潤/曲線：溫和、天真、平靜（[晴香](03_characters/haruka.md)偶像服飾）

**對稱性**：
- 完全對稱 = 秩序、理性、非人化（帝國制服）
- 不對稱 = 混亂、自由、內心矛盾（魔法少女設計）

### <a id="section-color-language"></a>情緒色彩語言

- 角色主配色與其主導情緒物質/心匣本質色彩相關
- 彩度 (Saturation) 直接與精神活力掛鉤——[情感耗損](02_glossary.md#term-emotional-erosion)使整體飽和度顯著降低，趨向灰色
- 冷暖對比對應性格核心（[晴香](03_characters/haruka.md) = 暖色調；[美夜子](03_characters/miyako.md) = 冷色調）
- 內心矛盾時，特效或服飾細節出現強烈補色

### <a id="section-shape-and-color"></a>造型語言與配色（Shape & Color）

| 維度 | 規格 | 敘事用途 |
|---|---|---|
| 輪廓 | 先辨識大形（遠景 1 秒內可認） | 保證角色在混戰中仍有主體性 |
| 色群 | 1 個主色 + 1 個輔色 + 1 個警示色 | 避免資訊過載，保留情緒焦點 |
| 材質對比 | 至少一組「軟 vs 硬」並置（布/金屬） | 對應角色「脆弱 vs 防衛」內在矛盾 |
| 發光節制 | 發光元素不超過畫面關鍵點 3 處 | 防止特效掩蓋表演 |

### <a id="section-form-design-details"></a>形態設計細節（Form Design Details）

- **頭肩線**：決定第一印象（開放、壓迫、退縮）；不可只靠服裝花紋補救。  
- **手部語言**：手勢是角色心理狀態最快的讀取點（抓緊、攤開、顫抖、收拳）。  
- **重心線**：角色站姿重心偏移應與弧光一致；成長後重心通常更穩，不再飄忽。  
- **破損邏輯**：服裝/裝備損壞必須有因果方向（受力點、磨耗點），避免裝飾性破損。

### <a id="section-visual-deception"></a>視覺欺騙與反差

角色第一印象應服務於劇情反轉或內在矛盾：
- [黑奏主人格](03_characters/aya.md#section-kurokane)：極致無害化、圓潤線條、柔和色彩——積蓄揭露時的認知衝擊
- [美夜子](03_characters/miyako.md)貓形態：強調可愛弱小，與人形冰冷高效形成強烈反差

### <a id="section-personal-motifs"></a>個人母題與演變符號

核心角色被賦予象徵性母題，隨心路歷程視覺演變：

| 角色 | 母題 | 象徵 |
|------|------|------|
| [晴香](03_characters/haruka.md) | 小熊 | 童真、渴望被保護 |
| [美夜子](03_characters/miyako.md) | 貓 | 獨立、神秘、自我封閉 |
| [朱音](03_characters/iwakura_akane.md) | 食人花/荊棘 | 侵略性、頑強生命力 |

## <a id="section-narrative-visual"></a>Advanced Narrative Design（進階敘事視覺設計）

### <a id="section-posture-theatrics"></a>姿態與表演性

在充滿謊言與自我欺騙的世界裡，許多角色的日常姿態本身就是「表演」。當內心動搖導致「表演失誤」（不符角色的顫抖或猶豫），是窺見真實內心的敘事節點。


### <a id="section-negative-space"></a>負空間與缺席 (Negative Space & Absence)

最強烈的恐怖與悲傷來自「沒有什麼」：

- **缺席的倒影**：自我認同瓦解時，鏡中只有空白
- **缺席的聲音**：最劇烈痛苦時剝奪所有音效，只留微弱呼吸或完全靜音
- **缺席的色彩**：[情感耗損](02_glossary.md#term-emotional-erosion)最終階段，角色主觀視角變成黑白

### <a id="section-mirror-presentation"></a>鏡子的表現（Mirror Presentation）

- **材質分級**：平整鏡面 = 高可信映照；粗糙反光面 = 斷裂映照；液面 = 延遲映照。  
- **鏡位優先**：鏡面在畫面中不只作背景，需具備敘事功能（揭露、誤導、對照）。  
- **鏡像延遲**：在心理不穩定段落，允許 2-6 幀延遲以製造「我唔係我」的不安。

### <a id="section-reflection-interaction"></a>倒影的互動（Reflection Interaction）

- **對話式互動**：角色看向鏡面時，倒影可先於本體作出微表情，提示底層情緒。  
- **衝突式互動**：當角色否認自我時，倒影可呈現相反姿態（本體靜止、倒影顫動）。  
- **和解式互動**：角色完成承擔時，本體與倒影動作重新同步，作為段落收束標誌。

### <a id="section-trinity-visualization"></a>三位一體的視覺化（Trinity Visualization）

> 規則分層見 [World Rules](01_world_rules_and_costs.md#rule-trinity-spectrum)；此處只定義演出。

- **人類相**：皮膚與眼神保留溫度，光環脈衝規律，動作有猶豫與修正。  
- **中間相**：枷鎖紋活化、呼吸節奏不穩、鏡像偶發錯位，呈現「還在選擇中」。  
- **屍骸相**：輪廓硬化、光澤金屬化、音色乾裂，但保留一個「人性殘響」細節，避免扁平怪物化。

## <a id="section-alpha-beta-visual"></a>Alpha/Beta 雙線視覺語言（CF-T24）

### Alpha 線視覺標誌

**核心美學**：老香港（戰前嶺南）——有機、手作、時光留痕。

| 元素 | 規格 |
|------|------|
| 建築 | 唐樓 / 騎樓 / 嶺南瓦檐；磚牆裂紋、竹製趟攏門、霓虹字牌（廣東話書法） |
| 材質 | 自然木紋、生鏽鐵件、水磨石地板、油漆剝落牆面 |
| 光線 | 濾過骯髒玻璃的午後斜光；霓虹燈管的嗡嗡暖橘 |
| 色調 | 大地色底（黃褐、青磚灰）；霓虹點綴多色但飽和度不均 |

**Alpha 視覺鐵律**：Alpha 線空間**絕對不出現**哥德元素——任何尖拱窗、蕾絲花邊、維多利亞齒輪裝飾 = 該空間已受 Beta 侵蝕的警告訊號。

### Beta 線視覺標誌

**核心美學**：黑暗維多利亞（帝國加工的殖民遺產）——秩序、壓迫、人工完美。

| 元素 | 規格 |
|------|------|
| 建築 | 哥德式尖拱 / 巴洛克巨柱 / 工業齒輪裝飾 |
| 材質 | 大理石、黑色鑄鐵、高光拋光木；人工感強，刻意消除自然紋理 |
| 光線 | 人造燈光為主；帝國建築以強光從高處垂照，強調壓迫感 |
| 色調 | 黑 + 金（帝國主色）；暗紫點綴；整體上重下輕（頂部壓迫） |

### Alpha/Beta 視覺侵蝕識別規則

| 視覺線索 | 解讀 |
|---------|------|
| Alpha 空間出現蕾絲 / 尖拱 / 齒輪裝飾 | **Beta 意識形態侵蝕**正在發生 |

### <a id="section-alpha-beta-grammar-table"></a>Alpha/Beta 四維視覺語法對照表（GAP-34/35）

> 本表補充以上美學描述的精確操作規格，供動畫/遊戲製作使用。

| 維度 | Alpha 線 | Beta 線 | 過渡信號 |
|-----|---------|---------|---------|
| **顏色溫度** | 暖色低對比（黃褐/赭石/暖磚紅）；飽和度不均，邊緣偏灰 | 冷色高對比（黑/金/冰藍）；飽和度精準，邊緣銳利 | 暖色中出現單點冷色亮光 = Beta侵蝕；冷色中出現磚牆質感 = Alpha滲出 |
| **光源特性** | 散射光為主（骯髒玻璃過濾的午後光、霓虹反射光）；光源來自側面或低角度 | 聚焦光為主（從頂部垂照的人工燈）；強調壓迫感，陰影方向統一 | 散射光突然聚焦 = 帝國力量介入；聚焦光突然漫射 = Alpha記憶覆蓋 |

| **音頻語法** | 有機音效（木材、水聲、街道環境音）；音樂帶有民謠/粵曲底色；回憶閃回時音軌有**半秒的音量驟降（dropout）**，然後淡入 | 機械音效（齒輪、鐘錶、帝國號角）；音樂結構嚴謹（和諧→不和諧的精確計算）；Alpha侵入Beta場景時音軌出現短暫靜電雜音 | 驟降是Alpha線真相正在「浮出水面」的音頻告知 |

緋潮不是靜態的視覺元素，而是隨敘事進程動態升級：

|------|---------|----------|
| 第一至二幕 | 模糊輪廓，無辨認特徵 | 只是「人形」 |
| 第三幕 | 輪廓開始可辨：髮型、身形、姿勢逐漸清晰 | 隱約辨認出某些特徵對應現有角色 |
| 第四幕 | 完整臉孔短暫浮現 | 觀眾可確認：這些是被抹除的版本 |

### <a id="section-aya-kurosou-foreshadowing"></a>彩／黑奏漸進伏筆微規則— GAP-48

在黑奏身份揭示之前，以下四類微規則必須出現在彩的登場場景中，讓第二幕揭示時觀眾回想起曾經看見的線索：

**視覺伏筆**：彩說話或情緒波動的瞬間，背景陰影中出現 0.5 秒的白色輪廓閃爍——不是完整人形，只是邊緣輪廓；閃爍後消失，不引起任何角色注意。

**道具伏筆**：熊公仔在彩情緒激動的場景中，眼睛出現短暫的（1 幀以內）紫色微光，然後恢復普通。任何人都可以將其解釋為光線反射。

**構圖伏筆**：以彩為主體的畫面中，攝影角度偶爾選用萬花筒式的對角線疊影構圖——看似是美學選擇，但對熟悉萬花筒的觀眾暗示雙重人格的幾何語法。

**行為伏筆**：彩在無意識狀態下（如思考或放空時）觸碰自己的頭部，動作習慣與黑奏一致（黑奏在集中思考時慣用的手勢）；眼神在某個瞬間短暫銳化（持續 0.3 秒），然後恢復怯懦。

**伏筆密度規則**：
- Act I：每集最多 1–2 個伏筆，且不同類型不重複（避免太明顯）
- Act II 前半：伏筆頻率開始上升，觀眾開始「覺得哪裡怪了但說不出來」
- Act II 後半：四類伏筆可在同一場景共現，但仍各自保持 plausible deniability

### <a id="section-haruka-color-arc"></a>晴香三階段顏色弧光規則— GAP-49

晴香的外觀顏色跟隨她的心理狀態在四幕中系統性變化：

|----|---------|-----------|---------|

### <a id="section-heart-chamber-interior"></a>心房室內視覺設計語言（空間心理建築學）

心房的內部空間係角色心理防禦層次的建築具現化。所有心房場景均以香港唐樓劏房美學為基底，但形態可因角色創傷程度產生高度扭曲或缺失。以下係六種空間的視覺語法參考框架（設計參考，唔係絕對結構）：

| 空間 | 心理對應 | 視覺語法基調 | 扭曲徵兆（防禦崩潰時） |
|---|---|---|---|
| **前門/鐵閘** | 對外界線與防禦程度 | 材質、鏽蝕程度、鎖具數量直接反映封閉程度；光源從門縫滲入 | 門縫滲出黑水、鎖具生長出肉質觸感、鐵閘在無風中微顫 |
| **客廳** | 社交面具（Persona） | 過度整潔、過飽和色彩、光源均勻無陰影；呈現「理想我」的佈置 | 牆角滲出黑色液體、裝飾品細節失真、燈光頻閃、倒影唔對稱 |
| **廚房** | 情感滋養與匱乏狀態 | 爐火、冰箱、食物殘留反映情感供給是否充足 | 食物腐爛具現化為執念攻擊體、水管持續滲漏情緒廢料、黴菌作為匱乏的環境傷害 |
| **臥室** | 私密自我與心之器所在 | 最隱蔽的空間；隱藏通道或封閉房門；光源昏暗、物件具強烈個人記憶感 | 鏡子反映錯誤形象、心之器龜裂線延伸至牆壁、床鋪無法進入（身體下沉或拒絕接觸） |
| **地下室** | 潛意識與陰影（Shadow） | 無自然光源；連接集體潛意識暗渠；積水映照昏黃霓虹殘光 | 水位持續上升、鎖鏈具現化阻擋入侵者、被壓抑創傷記憶作為戰鬥體出現 |
| **天台/閣樓** | 高層思想與逃避幻想 | 最接近天空但結構搖搖欲墜；視野開闊但地板不穩 | 完美對稱幻象碎裂、高度感失真引發墜落恐懼、雲層壓低形成密室效果 |

**跨空間視覺規則：**
- 心房的整體光源色溫反映角色情緒主調（絕望 → 藍紫冷光；憤怒 → 橙紅暖光；創傷封存 → 永遠的昏黃白熾燈）
- 集體潛意識的情緒廢料可從地板縫隙或牆壁滲入，代表個人潛意識與集體潛意識之間的邊界滲漏
- 心之器龜裂程度越嚴重，心房物理結構越不穩定（天花板剝落、地板下陷、牆壁收窄）
- 被完全壓抑的記憶會令對應空間消失或被磚牆封死

### <a id="section-static-cradle-sequence"></a>晴香最終形態「靜止搖籃」視覺序列— GAP-77

> 定局設定見 [Story Outline §static-cradle-ending](05_story_outline_canon.md#director-static-cradle-ending)；本節只收斂視覺執行規格。

**明確情感框架**：靜止搖籃不是神聖升天，不是英雄化——她是「被釘在世界底部的容器」。視覺必須同時呈現「沉靜」與「代價」，避免任何光榮化或受難聖像化。

**13 步視覺序列**：

1. 晴香雙臂從兩側緩慢伸展——手指先，然後手腕，然後前臂；動作極慢，如樹枝生長
2. 手指延伸至超過正常關節角度，但不是骨折——是靈魂與物質邊界的溶解
3. 延伸繼續往指尖傳播，皮膚輕微透光（光從內部向外）
4. 頭髮從頭頂開始向下延伸，越過腳底，繼續延伸至地面，然後開始「生根」——頭髮觸地後變為細根狀纖維，向四面擴散
5. 雙腳離地（非英雄式飄浮——是被向上托起，而非主動上升）
6. 戰鬥服的顏色開始褪去：粉色→珍珠白→灰白→灰燼色（但服裝本身完整，不破損）
7. 枷鎖紋在全身蔓延，但不是龜裂的意象——是「根脈」，是連結世界的絲線
8. 眼睛仍然睜著，但焦距消失——不是空洞，是視線同時看向所有地方
9. 偶爾（每 30–60 秒），眼睛短暫閃爍粉色微光——美夜子在一旁時頻率更高
10. 根脈繼續向外擴散，觸及已逝角色曾站立的位置，在那裡微微發光
11. 最後的面部表情：嘴角極輕微地向上，角度不超過 0.5 度（如同知道有人在陪伴）
12. 所有環境音漸漸靜止，只剩一個極低頻的長音（心跳和世界脈動的融合）
13. 靜止搖籃完成——晴香成為世界的情緒濾網，美夜子守在她旁邊，畫面以她們的距離收束

**禁忌**：不得使用聖光效果、羽毛掉落、或任何宗教升天意象。視覺語言是「植物性的」（生長、根脈、有機延伸），不是「神性的」（光暈、羽翼、高度）。

### <a id="section-transformation-phases"></a>變身美學設計：蜜月期 vs 宿醉期— GAP-79

本作變身序列採用兩個命名的美學階段，在四幕中對應角色心理狀態：

**蜜月期（Honeymoon Phase）**：
- 傳統魔法少女美學——粉色、光、閃亮、喜悅
- 服裝顯得輕盈、合身、如同節日禮服
- 音效：高頻清脆（鈴聲、風聲、玻璃音）
- 情緒：喜悅、力量感、「我做得到」
- 出現時機：Act I 主導；Act IV 晴香最終覺醒場景的前半段

**宿醉期（Hangover Phase）**：
- 恐怖片美學——同樣的變身序列，但音效替換、色溫下降、速度變慢
- 服裝顯得更重、更緊——像枷鎖，而非衣服
- 音效：骨骼聲、關節聲、深呼吸聲、金屬低頻
- 情緒：沉重、必要性（「我必須變身，而不是我想要變身」）
- 出現時機：Act II 後半開始滲入；Act III 主導

**過渡期規格**：同一場景中，蜜月期→宿醉期的轉換不能用剪輯完成——必須在一個連續鏡頭內，讓顏色溫度、音效性質、動作速度在變身過程中漸變（如水墨在水中化開，不是「剪切到另一個版本」）。

### <a id="section-alpha-personal-visual"></a>四角色 Alpha 線個人視覺/音頻簽名— GAP-75

各角色的 Alpha 線殘留表現不同，各有專屬視覺和音頻簽名：

**操（Misao）**：
- 視覺簽名：去飽和白色 / 臨床白；場景中所有顏色暫時流失，只剩操在白底中
- 觸發場景：見到手術刀、聽見父親聲線、或觸碰玻璃
- 三階段鏡像異常：鏡中的「臨床白操」比現實更早做出動作 → 鏡中是「完美人偶版的操」而不是正在掙扎的她 → 最終鏡像在操崩潰時消失（鏡中沒有人了）
- 音頻簽名：金屬鈴聲（像手術工具碰撞），持續 0.5 秒後消失

**朱音（Akane）**：
- 視覺簽名：低飽和黃褐色；像舊照片的色溫；所有現代元素瞬間「老化」
- 觸發場景：看見孩子、聞到某種特定食物氣味、夜區的某些街角
- 三階段鏡像：鏡中的朱音更消瘦（飢餓版本） → 鏡中的朱音沒有牙（Alpha 線餓死時的狀態）→ 鏡中空白
- 音頻簽名：糖果包裝紙聲（空罐子聲），持續約 0.3 秒

**凜（Rin）**：
- 視覺簽名：冰藍色疊影；現實中的暖色被降溫，空氣「結凍感」
- 觸發場景：被關在密閉空間、聽到寂靜、某些旋律的特定音符
- 三階段鏡像：鏡中凜的嘴在動但沒有聲音 → 鏡中凜的眼神是 Alpha 線死前的「終於完成任務」神情 → 鏡中凜的紅線開始延伸爬出鏡框
- 音頻簽名：破冰聲（一聲，然後靜默），持續 0.3 秒

**晴香（Haruka）**：
- 視覺簽名：高對比紅黑疊影；正常畫面瞬間反色，像底片反轉
- 觸發場景：重大情感衝擊、試圖改變現實、夕「靠近」時
- 三階段鏡像：鏡中出現 Alpha 線的晴香（失去家人後的空洞少女） → 鏡中晴香眼睛變黑（極憤怒狀態）→ 鏡中晴香對著現實中的晴香伸手
- 音頻簽名：心跳聲一下，然後撕裂聲（0.5 秒），然後靜默

**通用規則**：Alpha 線視覺簽名**不超過 2 秒**，且每幕出現次數有上限（Act I ≤ 2 次/角色，Act II ≤ 4 次，Act III 無上限，Act IV 由角色選擇）。

### <a id="section-alpha-transformation-pollution"></a>各角色變身序列的 Alpha 線污染規格— GAP-76

每個角色的變身序列中，Alpha 線在特定時刻入侵，形成「記憶痕跡」的視覺/音頻干擾。這些入侵必須**在變身序列中**出現，而非獨立觸發，且必須使用各角色的個人簽名元素（見 §section-alpha-personal-visual）。

**操（Misao）**：
- 視覺入侵點：變身中段，「脫去日常服裝」的瞬間——1 幀的臨床白底出現，像在手術室燈光下被檢視
- 音頻入侵點：光環附上手腕時，金屬鈴聲（0.3 秒）
- 完成 glitch：變身完成的最後畫面以「水平掃描線 glitch」閃爍 0.5 秒，然後畫面穩定——彷彿TV訊號被干擾後重新鎖定
- 設計意圖：每一次變身都是操重新「選擇進入囚籠」的視覺複述

**朱音（Akane）**：
- 視覺入侵點：食物道具（糖果/電鋸）具現化的瞬間——低飽和黃褐色疊影出現 0.5 秒，Alpha 線餓死版的手握住同一件道具
- 音頻入侵點：光環附上時，空罐子聲（0.2 秒）
- 完成 glitch：變身完成後微笑的嘴角在最後 1 幀過度上揚（超出正常範圍），然後回正——朱音的嘴從來不完全屬於她
- 設計意圖：朱音的力量來自她沒能解決的那件事

**凜（Rin）**：
- 視覺入侵點：裝置啟動時（胸口光環發光瞬間）——冰藍色疊影在身上閃過，像另一個「未被改造的凜」重疊其上
- 音頻入侵點：改造部件運作聲起動前 0.5 秒，破冰聲（一聲）
- 完成 glitch：改造手臂的機械部分最後落定的角度偏移 3 度，然後自我修正——機械記憶的微小不完美
- 設計意圖：凜的變身每次都重演「她的身體不完全是她的身體」這一事實

**晴香（Haruka）**：
- 視覺入侵點：金色光服展開時——高對比紅黑 1 幀底片反轉，Alpha 線晴香的空洞表情出現在展開中的光服背面
- 音頻入侵點：武器具現化時，心跳聲一下（0.2 秒）
- 完成 glitch：最終姿勢成形後有 0.3 秒的「停滯感」——像她本人需要確認這個身體確實是她的

### <a id="section-sun-district-materials"></a>日區服裝材質規格— GAP-73

> 補充 §section-art-sun 的材質層——態度/顏色已在 §section-art-sun 定義，本節補充物理材質規格。

**日區服裝材質三元組**：
- **PVC 透明材料**：外套、手袋、雨衣等配件使用 PVC——廉價繁榮感，看似高檔但實為工業批量產品；在雨天或水反光場景中格外突出
- **全息布料**：特定服裝面料使用全息印刷，在日區人工太陽下閃爍多色光芒——「廉價的奢華感」；不同角度看到不同顏色，象徵日區居民的自我欺騙能力
- **透明塑料配件**：飾品、鞋跟、包包夾等以透明塑料製作——看似現代感，實際上是空洞的展示；透明材質意味著「沒有什麼可隱藏，因為也沒有什麼真實的核心」

**日區材質禁忌**：天然皮革、手工紡織品、不規則紋理——這些材質有「歷史」和「有機感」，與日區「永晝永新永完美」的意識形態衝突。

**與夜區對比**：夜區材質（牛仔布、皮褸、毛織物）有磨損感和歷史感——兩區材質語言代表「活過的痕跡」（夜區）vs「沒有痕跡的人工生命」（日區）。

### <a id="section-device-user-corpse-visual"></a>裝置使用者屍骸複合視覺規則— GAP-56

> 補充 §section-corruption-on-girls 的特殊案例。

前裝置使用者屍骸的視覺必須同時包含**兩層**視覺元素——它們不是替代關係，而是疊加：

**層一（靈魂碎裂結果）**：標準結晶覆蓋，遵循心之器龜裂視覺規格（見 §section-corruption-on-girls）

**層二（裝置印記遺留）**：鈣化光環殘餘以「齒輪嵌入皮膚」形式外露；嵌入深度因使用時間不同而異；齒輪紋路與結晶突起交錯，形成「雙重枷鎖」美學

**視覺統一語法**：晶瑩結晶簇（有機）與鏽蝕金屬齒輪（工業）的對比，是「自然死亡法則」與「人工干預代價」雙重刻寫在同一身體上的視覺聲明。

**複合視覺禁忌**：不可只呈現一層——沒有裝置痕跡的純結晶屍骸適用於從未使用裝置的角色；沒有結晶的純齒輪形態只適用於完全機械化的帝國兵器，不是魔法少女屍骸。

### <a id="section-mirror-intent-criterion"></a>鏡面法則意圖判定基準（精確版）— GAP-57

> 補充 §section-law-mirror-visual 的「魔法的缺席」規則（更精確版本）。

**精確判定規則**：鏡中是否出現魔法構造物，取決於**施法者的真實意圖**，而非單純的「情緒力量渲染」：

| 施法意圖 | 鏡中表現 | 說明 |
|---------|---------|------|
| **真心創造**（防護、治癒、連結） | **出現在鏡中**，且可能比現實中更清晰 | 鏡子揭示真實，真實意圖創造的護盾也是「真實的」 |
| **欺騙目的**（誘餌、偽裝、操控） | **鏡中缺席**，原位置是空白 | 謊言沒有倒影；欺騙性魔法在鏡子面前原形畢露 |
| **模糊意圖**（自欺 / 半真心） | **鏡中出現殘影或輪廓**，不完整，邊緣模糊 | 自欺的結界只有半個倒影——提示施法者自己的矛盾 |

**應用案例**：黑奏以慈悲之名施展的「保護」結界，若其真實意圖是控制，鏡中會缺席，讓曾目睹的晴香留下無法解釋的疑惑（在揭示前作為隱性伏筆）。

**現有規則補充說明**：此精確標準**不取代**舊規則，而是更精確地替代「所有情緒力量渲染的物體都沒有倒影」這個過於粗糙的舊表述。

## <a id="section-cinematography-grammar"></a>鏡頭語法與分鏡規範（補齊）

### 情緒鏡頭三段法
1. **狀態建立**：先給中景與環境聲，確認角色當下的「社會姿態」。
2. **失衡揭露**：切近景（眼、手、呼吸），以微延遲或不連續動作表現內在裂縫。
3. **代價落地**：回到空間全景，保留破壞痕跡或沉默空白，避免用台詞解釋。

### 構圖禁忌
- 禁止把創傷場面拍成英雄海報式「勝利姿態」。
- 禁止在角色崩潰時使用炫技鏡頭奪走角色主體。
- 禁止在關鍵承擔場景以高速剪輯取代情緒停留。

### 推薦鏡頭語法
- **鏡像場景**：優先固定鏡 + 緩推，讓觀眾自行比對表象與底層真實。
- **共感場景**：優先雙人同框，不切反應鏡頭，維持情緒連續性。
- **社會暴力場景**：優先遠景與群像，凸顯「制度性」而非單一惡人。
