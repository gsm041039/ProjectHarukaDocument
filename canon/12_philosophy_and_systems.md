## <a id="section-haruka-savior"></a>一、傲慢救世主模式 / 態度剝奪詛咒

**Hubristic Savior Mode / Attitude Deprivation Curse**

### 定義

晴香的救贖衝動本身攜帶一個自毀機制：她試圖「代替他人承擔痛苦」的行為，客觀上剝奪了他人**面對自身痛苦、形成自己態度**的機會。

> 「我帶回來的希望，親手殺死了我最愛的人。」

### 機制

| 行為 | 表面意圖 | 實際後果 |
|------|---------|---------|
| 為他人吸收負面情緒 | 減輕他人痛苦 | 剝奪他人處理痛苦的機會 |
| 創造 Beta 線（改變現實） | 保護美夜子/母親 | 創造出魔法少女系統、屍骸、情緒毒品等所有悲劇 |
| 主動融合成為「三位一體永恆守護者」（CDL-326/327/344） | 讓世界繼續運轉 | 成為世界的痛苦容器，永久失去普通人生活資格（融合後意識存續狀態故事刻意不明寫） |

### 核心悖論

善意本身不能免除責任。「我是為了你好」不等於「這對你好」。最大的傲慢，是相信自己有能力替別人決定他們應該承受什麼。

### 適用角色

| 角色 | 傲慢救世主表現 |
|------|--------------|
| 晴香 | 創世、三位一體永恆守護者 |
| 黑奏 | 強制共振（「我幫你們把神經線駁埋一齊」） |
| 秋穗 | 為拯救愛莉而利用晴香 |
| 夕 | 強迫晴香面對真相（自以為是的揭露） |

**See also**: [態度 vs. 命運](02_glossary.md#term-attitude-vs-fate) | [晴香 Canon Sheet](03_characters/haruka.md) | [未授權救贖](#section-unsanctioned-salvation)

## <a id="section-alpha-beta-truth"></a>二、Alpha/Beta 哲學定義

**Alpha = 事件的真相；Beta = 態度的真相**

### 精確定義

| 時間線 | 哲學本質 | 敘事功能 |
|--------|---------|---------|
| **Alpha 線** | 事件層的真相——「發生了什麼」的客觀記錄 | 提供「真正發生過的事」的基準現實 |
| **Beta 線** | 態度層的真相——「面對發生的事，我們如何選擇回應」 | 提供「在謊言之上，仍可建立真實態度」的可能性 |

### 核心意涵

Alpha 線未必比 Beta 線「更真實」，它只是「未被改寫的版本」。但 Beta 線也未必是謊言——它是晴香那一刻態度的物理化。

**真正的問題不是「哪條線是真的」，而是「在任何一條線裡，態度能否仍然屬於自己」。**

這比現有 [Glossary：Alpha/Beta 線定義](02_glossary.md#term-alpha-line) 多一個哲學層次：Glossary 說明事件機制，本條說明時間線的意義論基礎。

**See also**: [Glossary：Alpha 線](02_glossary.md#term-alpha-line) | [Glossary：Beta 線](02_glossary.md#term-beta-line)

## <a id="section-unsanctioned-salvation"></a>三、未授權救贖（Unsanctioned Salvation）

### 定義

任何未經當事人同意、以「拯救/修復」為名對他人施加的干預，都是對其主體性的侵犯——無論意圖多麼善良。

### 三個層面

**一、行動層**：物理上替他人做了他們沒有要求的事
**二、情緒層**：代替他人感受他們應該自己去感受的痛苦
**三、現實層**：改變世界的結構以「保護」特定人——即晴香的創世行為

### 適用矩陣

| 角色 | 未授權救贖行為 | 被侵犯的主體 |
|------|-------------|------------|
| 晴香 | 改變現實、吸收他人情緒 | 全世界 / 美夜子 |
| 黑奏 | 強制建立共振網絡 | 全人類 |
| 秋穗 | 在愛莉不知情下把她變成實驗錨點 | 愛莉 |
| 夕 | 強迫晴香面對不願承認的真相 | 晴香 |

### 與「態度 vs. 命運」的關係

未授權救贖的本質是把「命運」強加於他人——即使包裝成「愛」。真正的尊重是允許對方選擇如何面對自己的命運。

**See also**: [態度 vs. 命運](02_glossary.md#term-attitude-vs-fate) | [傲慢救世主模式](#section-haruka-savior)

## <a id="section-eternal-trap"></a>四、黑奏「永恆陷阱」機制

**The Eternal Trap Mechanism**

### 定義

黑奏的能量循環並非被動的副作用，而是**設計意圖**：她必須持續製造讓晴香絕望的條件，才能在下一個循環中再次收割因果能量。

### 循環結構

```
晴香在絕望中改變現實
    ↓
因果能量逸散
    ↓
黑奏收割能量（跨時間線）
    ↓
黑奏在新循環中獲得力量
    ↓
黑奏製造新的絕望
    ↓（回到頂部）
```

### 悲劇深度

**黑奏越成功，她就越需要晴香繼續痛苦。** 這使得黑奏對晴香的任何「關心」（哪怕是真實的）都必然服務於傷害晴香的目標——她的愛與她的惡意無法分離。

### 與「夕-黑奏共犯結構」的關聯

夕每次「強迫晴香面對真相」，都在客觀上為永恆陷阱提供動能——兩個都聲稱「是為了晴香」的力量，在結構上共同構成對晴香的剝削。

## <a id="section-mirror-tactic"></a>五、黑奏「放置鏡子」戰術（G-E14）

**The Mirror Placement Tactic**

### 定義

黑奏透過工程化環境設計，迫使晴香使用或暴露負面情緒，然後在關鍵時刻「放置鏡子」——讓晴香直視自己在恐懼或憤怒中的面容。

### 戰術三步驟

1. **環境設計**：製造晴香無法單純依靠正面情緒解決的處境
2. **情緒引爆**：迫使晴香動用她最恐懼使用的力量（負面情緒/怒氣/絕望）
3. **鏡像呈現**：在晴香剛剛使用這些力量後，呈現其後果或鏡像——「妳也和姊姊一樣，被感情這種病毒腐蝕了腦子」

### 心理目標

讓晴香相信「使用負面情緒 = 變成怪物」，從而陷入自我否定循環。這不只是戰術傷害，而是對晴香世界觀的根本性攻擊。

## <a id="section-emotion-farm"></a>六、情緒資料農場框架

**The Emotional Data Farm Framework**

### 定義

魔法少女不是戰士，而是情緒數據農場。黑奏把魔法少女系統設計為精密的「壓力測試環境」——目的不是讓她們戰勝屍骸，而是讓她們在絕望中掙扎，產出「極限情感數據」。

### 農場邏輯

| 農場元素 | 魔法少女系統等效物 |
|---------|-----------------|
| 農場 | 魔法少女系統（整個 Beta 線架構） |
| 農作物 | 魔法少女的情緒數據（恐懼、絕望、崩潰邊緣的能量） |
| 收割 | 黑奏的能量收割機制 |
| 「放養」策略 | 不直接殺死魔法少女——活著的痛苦比一次性死亡產出更多數據 |
| 最高品質原料 | 瀕死體驗、精神崩潰、被迫殺死同伴 |

> 「她們的每一份痛苦，都在餵養敵人。」

### 敘事意義

使魔法少女的處境更加絕望：她們不只是被利用的工具，而是被刻意折磨以「產出數據」的活體實驗品。這對「態度 vs. 命運」主題形成終極壓力測試——在連痛苦本身都被他人收割的環境下，態度的自由是否還有可能？

**答案並非單方向肯定（CDL-374修正）**：紫音、操的最終選擇證明咗態度可以係一種自由——佢哋自己講得出口、故事亦同佢哋一齊肯定。但凜嘅結局提醒觀眾，呢種自由唔保證帶嚟解脫，甚至唔保證連當事人自己都感受得到——喺意識清零前嘅最後一扇窗，凜可能悔恨過自己揀 Unit00 呢個選擇，但嚟唔切講出嚟，故事亦刻意唔代佢肯定呢個悔意算唔算數。三個人嘅選擇同樣真實、同樣屬於自己，但故事對佢哋嘅「回報」唔一致——呢個唔一致本身，先係呢部作品對「態度 vs. 命運」呢條問題最誠實嘅答案：態度永遠屬於自己，但故事唔承諾佢會帶嚟安慰。

## <a id="section-jung-individuation"></a>七、榮格個體化過程具現化系統（CDL-066）

**Jung Individuation Concretization System**

### 定義

本作故事核心 = 晴香的「個體化過程 (Individuation)」。本作採用「具現化心理學」方法論：心理概念成為真實的物理現象，不是文學隱喻。

### 具現化對應

| 榮格心理學概念 | 本作具現化形式 |
|-------------|-------------|
| **Persona（人格面具）** | 魔法少女變身——晴香為逃避創傷建立的防衛面具，外化為變身形態 |
| **Shadow（陰影）** | 夕——被5歲晴香強行切割出去、物理分離的內在陰影人格 |
| **Collective Unconscious（集體潛意識）** | 超現實物理空間——後巷/唐樓 + 魔法能量流動海洋，可進入的真實地點 |

### 核心諷刺

晴香的「改變現實」= 將內在問題投射到外在（Beta 線），問題無法被解決。真正的治癒只能向內接納陰影（夕整合，CDL-069）。外在現實的改寫，反而是逃避個體化的最徹底方式。

### 陰影人格化光譜（CDL-395新增）

呢個「Persona/Shadow」對應表用晴香/夕做最完整嘅示範案例，但Shadow呢一項本身唔係晴香專屬機制——[魔法少女](02_glossary.md#term-magical-girl)嘅定義本身已經通用咁講明「成為魔法少女的契約儀式本質是人格解離」，[鏡中的承諾](02_glossary.md#term-mirror-promise)一樣係全體通用嘅起源儀式。夕（晴香）同[黑奏](03_characters/aya.md#section-kurokane)（彩）係呢個通用機制行到極端、完全人格化嘅兩個已知案例，唔係例外規則；絕大部分魔法少女嘅「鏡中倒影」理論上一樣有得完全成形，只係佢哋嘅創傷未去到夕（5歲被強行切割）或者黑奏（彩靈樹戰爭嘅崩潰）嗰種極端程度，所以停留喺未成形／半潛伏狀態——唔係唔存在，淨係未有名有樣、未有自主行動能力。[鏡像法則](01_world_rules_and_costs.md#rule-mirror-law)已記錄「美夜子、夕、操在高壓段落出現反向映照」，證明呢啲未成形嘅鏡中自我一樣會喺高壓時刻閃現，唔止限於晴香/彩。

呢啲未成形嘅陰影棲息喺集體潛意識入面，同夕/黑奏最終棲息嘅係同一個空間性質。[愛莉](03_characters/aeri.md)作為集體潛意識入面唯一嘅常駐節點，佢嘅濾心負擔正式定性為主要嚟自呢啲未成形陰影嘅溢出／滲漏，佢嘅守門人職責亦包括保護呢啲脆弱、冇自主能力保護自己嘅陰影碎片。

### 方法論原則

「具現化心理學」：所有榮格概念在本作中都是**物理真實**，而非隱喻。觀眾感受到的不是「晴香的心理旅程」，而是「晴香字面意義上穿越了潛意識空間」。
