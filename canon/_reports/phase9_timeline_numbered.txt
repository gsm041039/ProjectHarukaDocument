  42: ## <a id="event-alpha-divergence"></a>II. Alpha 線分歧事件（帝國歷 102 年）
  43: 
  44: > **世界分裂為 [Alpha](02_glossary.md#term-alpha-line)/[Beta](02_glossary.md#term-beta-line) 兩條時間線的關鍵時刻。**
  45: > 關於 102 年的裁決，見 [Decision Log CF-002](99_decision_log.md#decision-cf002)。
  46: 
  47: ### <a id="event-alpha-original"></a>Alpha 線原初現實
  48: 
  49: - 5 歲的[晴香](03_characters/haruka.md)（97+5=102）與 26 歲的[美夜子](03_characters/miyako.md)（76+26=102）為感情深厚的親姊妹
  50: - <a id="event-sisters-execution"></a>**姊妹的處刑**：[黑奏](03_characters/antagonist.md)在晴香面前殺害花子和美夜子
  51: - <a id="event-first-reality-change"></a>**第一次[改變現實](02_glossary.md#term-reality-change)**：晴香的悲痛撕裂時空，創造 Beta 線高魔世界
  52: - 晴香的天真願望「如果家姐變做貓仔就唔會受傷」被刻入世界法則，成為美夜子的[避難所詛咒](02_glossary.md#term-shelter-curse)
  53: 
  54: ### <a id="event-beta-reset"></a>Beta 線重設
  55: 
  56: - 花子死因改為難產；美夜子在帝國歷 92 年「意外身亡」（冰封）
  57: - <a id="event-yu-birth"></a>**[夕](03_characters/yu.md)的誕生**：晴香的 Alpha 線記憶被剝離，具現化為潛意識人格
  58: - [靈魂滲漏](02_glossary.md#term-soul-leakage)開始：世界出現「悲慟風暴」現象

 180:   - **第二段：月下窗台的存在確認測試**：美夜子嘗試以純生理刺激確認「自己是否仍然活著」，但測試失敗，無法帶來存在感與安定感
 181:   - **第三段：晴香的擁抱與崩潰大哭**：晴香以身體接觸與情感承接把她從解離邊緣拉回，美夜子首次容許自己失控痛哭。晴香亦在此階段確定黑貓就是自己的姊姊
 182: - <a id="event-rin-final-battle"></a>**凜的最終戰：遲來的介錯**：美夜子以人類戰士身份履行血之約定，槍擊 Unit 00 核心。凜死前只發出氣音，無法留下遺言
 183: - <a id="event-liberation-battle"></a>**解放之戰**：晴香團隊攻入維多利亞之淚核心，停止人造太陽
 184: - <a id="event-hope-betrayal"></a>**希望的背叛**：全城斷電，黑奏將晴香塑造為毀滅元兇；民眾的「希望」反轉為「惡意」洪流
 185: - <a id="event-imperial-plaza-battle"></a>**帝國廣場決戰**：世界因[靈魂滲漏](02_glossary.md#term-soul-leakage)即將崩潰
 186: - <a id="event-truth-revealed"></a>**真相揭露**：黑奏揭露 [Alpha 線](02_glossary.md#term-alpha-line)真相與晴香「創世者」身份——「妳以為妳救活了她？不，晴香。妳只是在她屍體上貼了一塊叫做『魔法世界』的膠布。」
 187: - <a id="event-aya-internal-revolution"></a>**彩的內部革命**：彩（主人格）抱住黑奏，說：「唔需要啦⋯⋯黑奏。我已經大個女啦。」黑奏防禦力場瞬間消失
 188: - <a id="event-yu-takeover"></a>**夕的完全接管**：晴香精神崩潰，夕完全接管，發動[改變現實](02_glossary.md#term-reality-change)
