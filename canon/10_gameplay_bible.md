## <a id="section-core-loop"></a>Core Gameplay Loop：動態干預系統 (Dynamic Intervention System)

**遊戲願景**：你不是在「打怪」，而是在「終結魔法少女們持續複製的噩夢」。

> 本檔只定義玩家可見機制結果與操作壓力；規則條文解釋統一委派至 [World Rules](01_world_rules_and_costs.md)。

### <a id="section-tactical-window"></a>戰術視窗 (Tactical Window) 觸發機制

玩家作為晴香在戰鬥中觀察隊友，系統動態生成最佳干預時機：

- **威脅感知**：隊友即將受到致命攻擊，晴香可插入掩護/嘲諷
- **戰術發現**：晴香察覺敵人弱點，可提示隊友利用或自己執行
- **移動機遇**：空間出現有利位置，可命令隊友移動或自己搶位
- **弱點暴露**：敵人架勢崩潰，可指揮集火或接近執行靈魂抽離
- **玩家主動**：隨時暫停進入戰術視角，手動規劃 3 秒內行動序列

### <a id="section-tactical-threat-tiering"></a>威脅分級與反應資源（Threat Tiering）

戰術視窗是有限資源，不是每次受擊都觸發。系統以「威脅等級 + 觸發頻率」控制節奏：

| 威脅層級 | 範例 | 是否觸發戰術視窗 | 設計意圖 |
|---|---|---|---|
| 普通威脅 | 雜兵普攻、可預期中段攻擊 | 否 | 保留即時操作壓力，避免視窗濫用 |
| 高風險威脅 | 精英蓄力、視線外偷襲、Boss 斷招點 | 是 | 提供「以判斷換生存」的關鍵決策 |
| 複合威脅 | 兩個以上致命威脅同時逼近 | 合併為單一視窗 | 迫使玩家做「一次解兩危機」的路線選擇 |

**反應不及規則**：短時間連續出現多個致命威脅時，系統可能只開第一個視窗。若玩家未在視窗內脫離危險，後續傷害直接結算。  
這是用規則呈現「主角也會反應不及」，避免戰術視窗變成無限保命。

### 四階段流程

1. **佈局** — 觀察隊友狀態（情緒條、架勢條、戰鬥風格）與敵人模式
2. **觸發** — 系統偵測關鍵時機彈出「戰術視窗」慢動作（子彈時間）
3. **決策** — 選擇介入方式：保護/增幅/組合攻擊/靈魂抽離/戰術物品
4. **執行** — 晴香執行指令，隊友回應（信任度影響成功率與配合度）

**設計理念**：玩家並非「控制全隊」，而是「有限度地影響已失控的戰場」。

## <a id="section-empathy-interface"></a>絕對共感視界 (Absolute Empathy Interface)：晴香專屬情報系統

**核心設定**：因晴香是世界創造者，她能直觀「看見」他人情緒與意圖（但無法改變）。

### UI 元素

- **情緒條 (Emotion Gauge)**：每位隊友頭頂顯示當前情緒飽和度（平靜藍→激動橙→失控紅）
- **架勢條 (Posture Bar)**：敵我雙方戰鬥姿態穩定度（滿→易被打斷，空→可處決）
- **仇恨線 (Aggro Threads)**：紅線連接敵人與目標，粗細代表威脅優先級
- **範圍警告 (AoE Prediction)**：敵人蓄力攻擊時地面提前顯示傷害範圍（橙色→紅色倒計時）
- **心之隙縫 (Soul Fissure)**：[魔法屍骸](07_entities_and_devices.md#section-magical-corpse)架勢破碎時胸口出現金色裂縫標記（可抽離靈魂）
- **情緒圖標 (Emotional Icons)**：隊友頭頂浮現即時情緒符號（憤怒/恐懼/悲傷/麻木）
- **對話提示 (Dialogue Cues)**：戰鬥中隊友呼叫晴香時，對應選項附帶「預測回應效果」標籤

### <a id="section-interface-progression"></a>與遊戲進程的關係

| 幕 | 介面狀態 | 敘事意義 |
|---|---------|---------|
| **第一幕** | 完整運作，晴香擁有「上帝視角」優勢 | 玩家相信自己掌控一切 |
| **第二幕** | [夕](03_characters/yu.md)的干擾導致雜訊（情緒條失準、仇恨線錯亂） | 開始質疑系統可靠性 |
| **第三幕** | 大規模失效，晴香被迫「像普通人一樣戰鬥」 | 失去特權，面對真實 |
| **第四幕** | 恢復，但晴香已學會不依賴它 | 成為「象徵性輔助」而非必需 |

## <a id="section-dual-system"></a>雙軌數值系統：假象與真實 (Dual Progression System)

**核心詭計**：遊戲刻意誤導玩家相信「殺死屍骸」是最優解，直到真相揭示。

### 假系統（遊戲前期呈現）

| 行動 | 獲得 EXP | 表面邏輯 |
|-----|---------|---------|
| **殺死** | 1000 | 「快速清場，高效升級」 |
| **淨化** | 200 | 「道德選項，但效率低」 |
| **靈魂抽離** | 0 | 「浪費時間的儀式」 |

### 真系統（遊戲後期揭示）

- **殺死**：短期效率高，但在長線回饋上會推高世界層債務（規則口徑見 [World Rules：情緒守恆](01_world_rules_and_costs.md#rule-emotion-conservation)）
- **淨化**：提供戰術緩衝，不等同長線解決（狀態口徑見 [Entities：魔法屍骸](07_entities_and_devices.md#section-magical-corpse)）
- **靈魂抽離**：屬高門檻但高價值的終局處理（流程口徑見 [§ 靈魂抽離機制](#section-soul-extraction)）

### <a id="section-system-failure"></a>系統失靈的四階段

| 階段 | 戰術視窗準確度 | 情緒條可信度 | 獎勵系統 | 象徵意義 |
|-----|-------------|------------|---------|---------|
| **完整運作** | 90%+ | 準確 | 假系統生效 | 玩家相信「殺戮有效」 |
| **輕微失靈** | 70% | 偶爾錯位 | 假系統開始穿幫 | 「為何屍骸越來越多？」 |
| **明顯失靈** | 40% | 嚴重延遲/反向 | 獎勵與結果脫鉤 | 玩家被迫質疑機制 |
| **完全崩潰** | 介面消失 | 無法讀取 | 數值無意義 | 晴香必須「憑感覺」行動 |

## <a id="section-soul-extraction"></a>靈魂抽離機制 (Soul Extraction Mechanic)

**核心體驗**：將戰鬥變為「心理干預」——玩家需理解屍骸生前痛苦，找到正確「解脫方式」。

### 三階段流程

1. **架勢破碎 (Posture Break)**
   - 持續攻擊或利用弱點使屍骸架勢條歸零
   - 胸口出現金色「心之隙縫」標記，進入可抽離狀態（8 秒時限）

2. **共感連結 (Empathy Link)**
   - 晴香靠近並按住互動鍵，進入靈魂對話場景
   - 玩家需從 3-4 個對話選項中選擇「最能安撫該靈魂」的回應
   - **[求救型](07_entities_and_devices.md#section-mc-psychology)**（藍色光暈）：選項偏向「理解/陪伴/承諾記住」→成功率高
   - **[拒絕型](07_entities_and_devices.md#section-mc-psychology)**（紅色光暈）：選項偏向「尊重選擇/不強迫/留有退路」→需多次嘗試

3. **靈魂抽離 (Extraction)**
   - 成功：靈魂化為光點消散，屍骸肉體崩解，獲得「記憶碎片」（解鎖 codex 條目）
   - 失敗：屍骸進入短暫「暴怒狀態」（攻擊力 +50%，移動速度 +30%，持續 15 秒）

### 隊友參與系統

部分屍骸需「特定隊友」參與抽離才能成功：
- **例**：前維多利亞之淚成員 → 朔參與成功率 +40%
- **例**：被軍方改造的少女 → 美夜子參與可解鎖隱藏對話

## <a id="section-social-system"></a>社交系統：風評三階段 (Social Reputation System)

**核心設定**：晴香的偶像身份與魔法少女身份存在矛盾，玩家行動會影響公眾認知。

### 階段一：維多利亞天使期（第一幕）

- **[光幕濾鏡](02_glossary.md#term-light-veil)**：玩家只看到「被美化後」的社會回饋；底層機制條文見 [現實縫合機制](01_world_rules_and_costs.md#rule-reality-stitching)。
- **任務類型**：「拯救迷路小貓」「阻止銀行搶劫」「慈善活動護衛」
- **NPC 反應**：崇拜/感激/請求簽名合照
- **遊戲體驗**：輕鬆愉快，玩家享受「被需要」的錯覺

### 階段二：裂痕與質疑期（第二幕）

- **濾鏡穿幫**：現實縫合開始失效，旁觀者偶爾「看見不該看見的」
- **任務變質**：「清理廢棄工廠屍骸」「處決失控的前隊友」「阻止真相傳播」
- **NPC 反應**：困惑/恐懼/開始在網路上發布「詭異目擊」
- **風評指標**：開始出現「負面新聞」計數器，影響部分 NPC 對話與商店價格

### 階段三：魔女狩獵期（第三幕高潮）

- **濾鏡破碎**：全城同時看見魔法少女與屍骸的真實面目
- **任務崩壞**：「鎮壓平民暴動」「保護被圍攻的隊友」「委託人是屍骸」
- **NPC 反應**：尖叫/逃跑/投擲石塊/呼叫軍方
- **巔峰場景**：晴香演唱會變成公審大會，觀眾席空無一人或充滿敵意

## <a id="section-ig-chronicle"></a>IG 敘事線 (Instagram Chronicle)

**設計目的**：透過社交媒體模擬「少女們試圖維持正常生活假象」的悲劇。

### 四階段演變

| 階段 | 時期 | 特徵 |
|-----|------|------|
| **強行營業期** | 第一幕前半 | 晴香高頻更新，其他角色帳號幾乎無更新 |
| **閃耀的日常** | 第一幕後半～第二幕前半 | 集體活躍但刻意迴避「魔法少女」話題，隱藏細節暗示異常 |
| **數位墓碑** | 第二幕後半～第三幕 | 隊友帳號逐一停更，每人發布「意味深長的最後貼文」 |
| **結局的迴響** | 第四幕後 | 倖存者重新發文，死去角色帳號變「數位墓碑」，全員存活解鎖合照彩蛋 |

### <a id="section-ig-reputation-mapping"></a>IG 敘事線 × 社會風評對照

| IG 階段 | 主要社會風評 | 玩家可觀測信號 | 玩法影響 |
|---|---|---|---|
| 強行營業期 | 維多利亞天使期 | 正面熱搜、NPC 主動合照 | 商店折扣、支援事件高觸發 |
| 閃耀的日常 | 裂痕前緣 | 留言區出現零星質疑 | 支線評價開始分化 |
| 數位墓碑 | 裂痕期→魔女狩獵前夜 | 帳號停更、黑粉詞頻上升 | 任務聲望懲罰加重、救援壓力提升 |
| 結局的迴響 | 覺醒後新秩序 | 幸存者發文重建敘事 | 結尾語氣、彩蛋與收束演出分歧 |

## <a id="section-girl-psychology-extended"></a>少女心理維度延展（第 6-11 點）

> 「她們經歷了那麼多殘酷，但依然是十幾歲的少女。」這份「不合時宜的幼稚」是讓觀眾意識到「天啊，她們還只是孩子啊」的關鍵敘事手段。

**設計哲學**：透過「少女日常」與「殘酷命運」之間的強烈反差（Gap），令觀眾同時感受角色的可愛與悲劇性。這種錯位本身就是最有力的敘事武器。

在現有五維度基礎上，新增以下六個維度：

### **維度 6：外貌與身體的病態關注（Body Image & Dysmorphia）**

| 角色 | 具體表現 | 心理分析 |
|-----|---------|---------|
| 晴香 | 生死戰鬥後，第一件事是對鏡確認劉海與腿上瘀青（明天要穿短裙上台） | 「專業偶像的自覺」vs「戰士的傷痕」之間的衝突 |
| 操 | 病態護膚、脫毛，對任何「男性化」特徵（喉結、骨架）極度恐懼 | 對「正確形式」的執著延伸到身體層面 |
| 朱音 | 嘴上說不在意，但偷偷買便宜指甲油塗在用來揍人的拳頭上 | 僅存的一點「少女心」的微小表達 |
| 美夜子 | 對身體完全漠視，但會下意識遮住研磨斷刃留下的傷痕 | 不是怕醜，是怕被人看到「軟弱的證據」 |

### **維度 7：同儕間的微妙嫉妒（Subtle Peer Jealousy）**

少女友誼往往伴隨嫉妒——不一定是惡意的，但很真實。在這個扭曲的世界，她們比較的是「誰更被需要」：
- 晴香成為全城英雄時，朱音心裡除了替她高興，會有一瞬間的酸楚：「為什麼只有她是光，而我們都在陰影裡？」
- 晴香反過來羨慕朱音的「自由」和「強大」，覺得自己只是被包裝的玩偶
- 操羨慕晴香「天生就是女生」的理所當然

**描寫技巧**：眼神迴避、讚美對方時的一瞬間停頓、私下模仿對方的某個小動作

### **維度 8：末日下的「小確幸」執著（Obsession with Trivial Joys）**

越是高壓環境，少女越對微不足道的小事產生執著——這是心理防禦機制：只要還在做這些蠢事，就覺得自己還活在「日常」裡，還不是怪物。
- 剛殺完屍骸、全身是血和灰塵，但幾個人為了「便利店最後一個布丁」而認真猜拳
- 朱音可能因為不小心弄壞朋友送的便宜髮夾而大哭，但面對斷手斷腳的傷勢卻一聲不吭
- 晴香對限量版甜點的執著，看得比「消滅屍骸」還重

### **維度 9：對「大人」的矛盾心理（Ambivalent Attitude Towards Adults）**

青春期反叛，但在這個故事裡「大人」大多是加害者（經理人、父母、皇帝）。她們被迫早熟，看透了大人的骯髒，但內心深處依然是「想要被大人摸摸頭、誇獎說做得好」的孩子：
- **晴香**：明知經理人在利用她，但當對方偶爾展現一點「關心」（哪怕是偽裝的），她還是忍不住想依賴那個父親般的背影
- **愛莉**：她的叛逆和毒舌，其實是為了引起母親（秋穗）注意的手段
- **美夜子**：對軍方「長官」有複雜的服從心理，即使知道自己被當工具

### **維度 10：秘密基地與「無人知曉的自己」（Digital / Private Sanctuary）**

- **晴香的匿名小號**：只有 5 個粉絲，裡面全是負能量、罵髒話、或者只是拍路邊的野貓。在那裡她不是偶像，只是個普通的厭世少女
- **朱音的小閣樓**：夜區骯髒角落有秘密空間，藏著弟弟生前的玩具與她搜集的可愛貼紙——「誰進來就殺誰」的聖域

### **維度 11：對「死亡」的獨特理解（Romance with Death）**

中二病少女有時對死亡有唯美的幻想，尤其在絕望的世界觀下：
- **操**：幻想自己像睡美人一樣死去，保持最完美的狀態，而不是變成醜陋的屍骸
- **凜**：對她來說，死亡可能是「終於可以休息了」的甜蜜誘惑
- **朱音**：「反正活著也是等死」的虛無主義，但又矛盾地執著於「死前至少要吃飽」

## <a id="section-k-room-scene"></a>K 房場景：美夜子唱《雨天》

**場景設定**：K 房，燈光閃爍，桌上堆滿飲料零食。晴香剛才又唱又跳《Happy Sugar Magic》，氣氛熱烈。輪到美夜子時，她切掉歡快伴奏，點了孫燕姿的《雨天》。

**美夜子的演繹**：縮在沙發角落，雙手握著麥克風，盯著螢幕歌詞。聲音低沉、乾淨，帶著讓人想哭的壓抑感。唱得投入，仿佛每個字都在咀嚼自己的命運。

**核心對話**：

> **晴香**（好奇湊近）：「前輩……妳唱得好投入啊！歌詞好慘喔，全是失戀被拋棄的感覺。妳以前是不是受過很重的情傷？」
>
> **美夜子**（放下麥克風，表情恢復淡然）：「沒有。我沒有談過戀愛，也沒時間搞那些。」
>
> **晴香**：「欸？那為什麼妳能唱得這麼……這麼『痛』？就像親身經歷過一樣？」
>
> **美夜子**（看著已經黑掉的螢幕）：「這就是音樂的厲害之處。作詞和作曲的人把那種『痛』具象化了……晴香，『失去』的感覺是通用的。不管是失去戀人，還是失去戰友，或者是……失去自己原本應該有的人生。雖然我沒失戀過，但我懂那種感覺。聽著這些歌，我會覺得……至少有人懂這種痛，哪怕只是歌裡面的人。」

**衝突點——對「陽光」的排斥**：

> **晴香**：「那……下次我們唱我的歌吧！《閃亮亮☆流星雨》！唱完心情就會變好了！」
>
> **美夜子**：「不要。」（直視晴香）「妳的歌……太亮了。太過正面積極，太過耀眼。對於一直待在陰影裡的人來說，那種光芒不是救贖，而是刺眼。聽著妳的歌，我只會更清楚地意識到——我和妳不是同一個世界的人。妳在陽光下，我在雨天裡。這種對比……反而讓我更累。」

**主題意義**：
- **Sun vs Rain**：晴香相信努力能改變未來（「鼓舞」）；美夜子接受命運殘酷，習慣隱忍，喜歡的歌是用來「撫慰」傷口的
- **伏筆**：晴香後來才明白，要陪伴美夜子，不是強行把她拉到陽光下，而是陪她在雨裡坐一會兒

## <a id="section-daily-cruelty-contrast"></a>日常殘酷對比：六大表現方向

「她們用 IG 濾鏡遮蓋傷口，用 OOTD 隱藏戰損，用美食打卡掩飾味覺喪失——這不是虛偽，而是求生本能。」以下六種表現方向，呈現「背負太多卻仍是少女」的悲劇感：

| # | 方向 | 核心對比 | 敘事功能 |
|---|------|---------|---------|
| 1 | **P圖作為心理防禦** | 數位自我 vs 物理真相（朱音P走手臂潰爛傷口，晴香用貼圖遮住血絲，美夜子拒絕拍自己） | 展示她們如何用虛擬世界逃避現實；最殘酷：朱音花半小時P掉傷口，發出去只有3個讚 |
| 2 | **OOTD 下的戰損隱喻** | 時尚穿搭 vs 戰場傷痕（美夜子高領遮頸部勒痕、朱音寬鬆衣遮體型消瘦、操蕾絲手套遮殘留紋路） | 「可愛」背後的代價；粉絲讚美操的手套，不知道那雙手套下面是什麼 |
| 3 | **美食打卡的味覺喪失** | 美食享受 vs 感官喪失（晴香拍蛋糕說「超級好吃！」實際上入口是血腥味PTSD閃回） | PTSD 對日常生活的侵蝕；晴香拍完照後躲進廁所乾嘔五分鐘 |
| 4 | **深夜 Emo 與真實恐懼** | 矯情動態 vs PTSD 發作（朱音凌晨3點「好累」= 毒癮發作後的求救；操的全黑照片 = 剛從屍骸化噩夢驚醒） | 她們最接近真實的時刻，卻被誤讀為「矯情」 |
| 5 | **已讀不回的真相** | 社交冷淡 vs 生死戰場（朱音不回訊息 = 被屍骸圍攻手機被踩碎；晴香「等下回你」 = 被召喚去處理屍骸） | 「正常人」無法想像的日常；朱音在戰場看到「生日快樂」，想回覆時手機被劃成兩半 |
| 6 | **化妝教學的異化** | 變美需求 vs 人類偽裝（朱音用粉底遮青灰色屍骸化斑塊，美夜子不化妝 = 放棄「看起來像人」） | 她們正在失去「人」的資格；朱音化妝畫面可剪成「清新少女日常」，下一鏡頭是粉底下擴散的屍骸紋路 |

晴香可攜帶最多 4 種戰術物品進入戰鬥，每種限定數量。設計核心：**不是強化戰力，而是「彌補情報缺失」或「創造安全空間」**。

| 物品 | 效果 | 主題意義 | 獲得方式 |
|-----|-----|---------|---------|
| **金魚雷達** | 臨時恢復 15 秒情緒條顯示 | 依賴外物補足失去的「共感」 | 朔的工坊製作 |
| **金夫人花露水** | 降低目標屍骸仇恨值 30% | 用「香氣」安撫怪物（象徵溫柔） | 美夜子咖啡店兌換 |
| **替死鬼假人** | 吸引全體敵人 8 秒 | 「替身」與「犧牲」的隱喻 | 操的符咒商店 |
| **血糖手錶** | 晴香瀕死時自動觸發無敵 3 秒 | 對「崩潰」的物理干預 | 秋穗贈送（信任度 Lv.3） |

### <a id="section-lowtech-tactical-matrix"></a>低科技裝置戰術矩陣（與 CAN-07 對齊）

| 物件 | 最佳使用時機 | 禁忌用法 | 失敗後果 |
|---|---|---|---|
| [金魚雷達](07_entities_and_devices.md#entity-goldfish-radar) | 進入未知街區前 10-20 秒 | 把單次警報當作唯一真相 | 全隊誤判路線，被迫提早消耗資源 |
| [金夫人花露水](07_entities_and_devices.md#entity-florida-water) | 救援撤離的近身脫離窗口 | 對高執念目標連續硬壓 | 反撲仇恨疊高，追擊期延長 |
| [替死鬼假人](07_entities_and_devices.md#entity-scapegoat-mannequin) | 複合威脅同時逼近時 | 在狹窄死角過早部署 | 失效即仇恨回灌，主角瞬時暴露 |

- 低科技裝置只提供「窗口」，不提供「治癒」。

- 進入高風險區前，必須與 [威脅分級](#section-tactical-threat-tiering) 一起配置，否則收益會被噪訊抵消。

## <a id="section-level-design"></a>Level & Performance Integration（關卡與演出結合）

**核心原則**：每個關卡不僅是「戰鬥場地」，更是「角色內心世界的物理投影」。

### 關卡設計三層次

1. **L1 物理層**：可互動環境（倒塌柱子/爆炸油桶/上鎖的門）
2. **L2 敘事層**：場景暗示角色過去（美夜子關卡的焚毀醫院、操關卡的無人豪宅）
3. **L3 象徵層**：空間本身就是隱喻（彩的萬花筒迷宮 = 破碎人格、黑奏的齒輪地獄 = 機械秩序）

### 與導演手法的配合

- **[Alpha/Beta Line](01_world_rules_and_costs.md#rule-alpha-beta) 場景**：關卡中特定區域會「疊加過去與現在」，玩家需在雙重現實中找到唯一正確路徑
- **[鏡像法則](01_world_rules_and_costs.md#rule-mirror-law)**：Boss 戰場地為完美對稱空間（中軸線兩側是「理想與現實」的對比）
- **四幕氛圍轉變**：同一場景在不同幕重訪時，光線/配樂/NPC 對話完全不同

## <a id="section-mission-architecture"></a>任務架構（Beat / Scene / Mission 對齊）

> 把母文檔中的任務化拆分收斂成 Canon 可維護格式。

### 三層對齊規則
1. **Beat 層**：只描述敘事功能（鋪陳、對抗、崩解、收束）。
2. **Scene 層**：只描述互動意圖（探索、對話、戰鬥、救援、撤離）。
3. **Mission 層**：只描述可驗收目標（成功條件、失敗代價、資源回饋）。

### 驗收欄位（每個 Mission 必備）
- `NarrativePurpose`：這關推進哪條主題線。
- `PlayerPressure`：主要壓力類型（時間、資源、倫理、信任）。
- `FailureDebt`：失敗會把哪種債務推高（社會、情緒、因果）。
- `CarryOver`：如何影響下一關（敵性、物價、隊內連結、抽離難度）。
- `WinCondition`：過關成立的最低條件（可包含「不擊殺也可過」）。
- `LoseCondition`：失敗判定（全滅、超時、關鍵目標死亡、崩潰值爆表）。
- `RetryMode`：重試方式（即時重試 / 段落重置 / 當日重來）。
- `BranchPersistence`：哪些分支結果不可回滾（同伴可用性、風評、關係狀態）。

### <a id="section-retry-policy"></a>可重試性與不可回滾代價

本作允許「操作重試」，但不允許「敘事代價全洗白」：

1. **戰鬥重試**：同一節點可即時重試，保留關卡學習節奏。  
2. **段落重置**：迷失/潛行失手可回到段落起點，但不移除已觸發的風評噪音。  
3. **當日重來**：重大崩潰（如引爆點誤觸）可重來當日流程，但會提高後續壓力係數。  
4. **不可回滾項**：同伴重傷退場、關鍵人質死亡、重大關係破裂、情緒負債暴增等，必須跨關保留。

## <a id="section-failure-feedback"></a>失敗回饋與債務累積（母文檔回填）

失敗不只扣血或重試，而要把世界觀代價回寫到系統層，令玩家感受到「代價會留痕」：

1. **戰術失敗**：提高該區域敵人執念飽和度，下次進場更接近失控
2. **社交失敗**：風評提前惡化，NPC 支援與資源折扣下降
3. **倫理失敗**：錯誤抽離或粗暴共感可換短期收益，但會增加[因果債務](02_glossary.md#term-causal-debt)
4. **隊伍失敗**：隊內連結值下降，後續[情緒連結](02_glossary.md#term-emotion-link)成功率受罰

這一層回饋把[情緒守恆定律](01_world_rules_and_costs.md#rule-emotion-conservation)轉為可操作的玩法壓力，而非僅劇情設定。

## <a id="section-boss-ethics"></a>Boss 設計倫理（補齊）

- Boss 不是「血量變厚」，而是「價值衝突變硬」。
- 每場 Boss 戰至少有一個可被共感讀取的「人性殘片」。
- 最終勝利條件可不是擊殺，而是中止循環、解除控制或完成抽離。

### 無限再生類 Boss 規則
- 再生必須有敘事來源（守恆債務、裝置回灌或群體惡意供能）。
- 玩家若只追求輸出，會進入資源虧損死循環。
- 破局路徑以規則 owner 為準：切供能、拆認知濾鏡、完成靈魂層干預（見 [World Rules](01_world_rules_and_costs.md)）。

## <a id="section-player-atmosphere"></a>玩家氛圍體驗（Atmosphere Targets）

> 目標不是「一直爽」，而是讓玩家可感知地經歷：掌控 → 失衡 → 承擔。

| 幕 | 玩家主觀感受目標 | 主要系統手段 |
|---|---|---|
| 第一幕 | 「我幫到人」的高效與溫暖 | 高可讀 UI、明確獎勵、低噪訊 |
| 第二幕 | 「點解開始失靈」的不安 | 介面錯位、風評裂痕、代價留痕 |
| 第三幕 | 「我無法全救」的窒息 | 複合威脅、視窗稀缺、不可回滾失敗 |
| 第四幕 | 「我仍可選擇態度」的沉重清醒 | 低特權介面、高主體性決策、結局承擔 |
